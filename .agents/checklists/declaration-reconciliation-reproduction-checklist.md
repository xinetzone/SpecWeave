# 声明对账模式复现检查清单（A-004）

> 配套模式：[声明对账](../../playground/pipeline-parable/retrospective/pattern-declaration-reconciliation.md)（L1，单案例待验证）。
> 用途：在第 2 个独立任务中逐项复现模式 5 个核心步骤，全部留证且验收通过后，模式升 L2 并申请入 `docs/retrospective/patterns/`。
> 与 A-001 清单的区别：A-001 [declaration-reconciliation-checklist](declaration-reconciliation-checklist.md) 是**写产出物时**的 V 审查核验清单；本清单是**验证模式本身**的复现清单。
> 核心原则：产出物中的自我声明（"合计/不超过/均为/全覆盖"）不是写作的收尾语，而是需要自证的契约——写声明时作者并不掌握全文实际状态。

## 🚨 启用条件

以下全部成立才启用本清单（缺一即为不适用，不得强行套用）：

- [ ] 任务产出物含自我声明型内容（统计数字、覆盖范围、合规承诺任一）
- [ ] 声明处于"作者写作时未掌握全文实际状态"的场景（多文件、多轮改写、分批生成）
- [ ] 任务有质量审查环节（V 审查或人工审校）可承接步骤 5
- [ ] 与案例 1（《管道的故事》任务链）不同源、不同任务类型（独立性要求，防同源假复现；跨场景迁移案例优先，如测试报告、方案对比、数据交付）

## 🛡️ 复现步骤（5 步，对应模式核心步骤，逐步留证）

### 步骤 1：声明扫描
- [ ] 通读产出物，摘出全部自我声明句（特征词：合计、共计、不超过、均为、全部、覆盖、无断链）
- [ ] 每条声明编号登记（D-001 起），注明所在文件与位置
- [ ] 留证：声明登记表

### 步骤 2：实证对账
- [ ] 字数类声明：逐条实际统计（用搜索/脚本数，不用印象估）
- [ ] 条数类声明：逐项实际枚举并计数
- [ ] 覆盖类声明：范围清单逐项映射到实际内容
- [ ] 否定类声明（"无断链/不含 X"）：全量扫描验证，非抽查
- [ ] 留证：每条声明的验证方法与结果记录

### 步骤 3：缺口定性
- [ ] 声明宽于事实（声明过头）→ 标记必修
- [ ] 事实宽于声明（声明过保守）→ 记录可选修
- [ ] 留证：缺口定性记录（无缺口也需记录"零缺口"结论）

### 步骤 4：双向修正
- [ ] 优先修正内容使现状符合更严标准
- [ ] 无法修正内容时，下调声明至与事实一致
- [ ] **禁止上调声明迁就现状**（把契约改成愿望）
- [ ] 留证：每处修正的前后对照

### 步骤 5：声明回写
- [ ] 修正后的声明与验证方法一并写入产出物
- [ ] 后续审查者可按声明逐项抽验
- [ ] 留证：产出物中回写后的声明文本

## ✅ 复现后验收（模式检验标准逐条打勾）

- [ ] 每条声明都能回答"这个数字/结论是怎么数出来的"
- [ ] 审查者无需重新全文判断，只需按声明逐项抽验即可通过
- [ ] 声明句中无量词模糊化需求（不需要把"均为"改成"大部分"来通过验证）

## 🔴 反模式自查（逐项确认未触犯）

| 反模式 | 自查问题 | 案例 1 教训 |
|------|------|---------|
| 先写声明后产出 | 索引骨架阶段是否先把声明写进版权说明而正文未写完？ | F-011 直接成因：声明"不超过 50 字"沦为愿望 |
| 凭印象填统计数 | 数字是否来自写作记忆而非实际统计？ | F-012/F-013：改写后记忆与文本脱节，冗余未被发现 |
| 审查只查格式与链接 | V 审查清单是否缺少声明实证对账固定项？ | 最高发缺陷类别漏检，由 A-001 清单补位 |
| 反向修正 | 发现不符时是否放宽/删除声明而非收敛事实？ | 正确方向：削减引用以符合更严标准 + 声明下调至事实 |

## 🏁 升 L2 判定与归档

**判定线：5 步骤全部留证复现 + 3 项验收全过 + 4 项反模式自查通过，缺一不可。**

任一项未过：模式维持 L1，缺陷记入本次任务复盘，并反哺模式反模式清单。

全过后执行：
- [ ] 模式文件 `maturity` 由 L1 改为 L2，成熟度说明补记第 2 案例来源
- [ ] 案例 2 证据包归档：声明登记表、对账记录、缺口定性与修正前后对照
- [ ] 向用户申请将模式入 `docs/retrospective/patterns/`（需用户审批）
- [ ] 更新索引：`playground/pipeline-parable/retrospective/README.md` 成熟度列 + `docs/` 模式库索引
