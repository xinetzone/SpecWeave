# 扫描版版权材料摘要替代转录复现检查清单（A-005）

> 配套模式：[摘要替代转录](../../playground/pipeline-parable/retrospective/pattern-summary-over-transcription.md)（L1，单案例待验证）。
> 用途：在第 2 个独立扫描版版权材料任务中逐项复现模式 6 个核心步骤，全部留证且验收通过后，模式升 L2 并申请入 `docs/retrospective/patterns/`。
> 核心原则：完整性是负债，可溯源的转述才是资产——逐字转录物本身即高侵权风险衍生物。

## 🚨 启用条件

以下全部成立才启用本清单（缺一即为不适用，不得强行套用）：

- [ ] 源材料为扫描版（纯图像、无文本层）的商业出版物、内部培训材料或付费报告
- [ ] 任务目标为知识提炼类产出（教程、知识包、结构化摘要），非全文存档
- [ ] 产出物有合规要求（入公开文档中心、对外分享或须经合规审查）
- [ ] 与案例 1（《管道的故事》任务链）不同源、不同主题（独立性要求，防同源假复现）

## 🛡️ 复现步骤（6 步，对应模式核心步骤，逐步留证）

### 步骤 1：路线决策前置
- [ ] R 阶段第一步显式二选一：逐字转录 / 深度摘要（默认摘要路线）
- [ ] 任务 frontmatter 写入路线决策字段（如 `route: chaptered-summary`；若选转录，记录决策理由）
- [ ] 留证：frontmatter 中的 route 字段（禁止事后补记）

### 步骤 2：逐章多模态通读
- [ ] 按章（或自然章节组）通读扫描页，捕捉论证链、关键概念、数据
- [ ] 建立并记录页码映射规则（如"文件编号 − N = 印刷页码"）
- [ ] 留证：摘要 frontmatter 中的页码映射规则

### 步骤 3：深度摘要（非书摘）
- [ ] 每章摘要重构"论点 → 论据 → 结论"论证结构，非金句摘抄
- [ ] 摘要为独立成文分析物，frontmatter 含 `source` 溯源字段
- [ ] 留证：摘要文件本身 + 溯源 frontmatter

### 步骤 4：原创改写重构
- [ ] 最终产出对情节、数据、论证转述重组
- [ ] 通过"换个说法"测试：无连续 ≥30 字原文复现
- [ ] 引用仅限短语级（≤30 字）并逐条标注书页页码

### 步骤 5：合规声明契约化
- [ ] 产出物 index 显式声明引用红线，含三段式：标准（短语级 ≤30 字）+ 页码标注 + 转述说明
- [ ] 留证：index 中可核验的声明文本

### 步骤 6：V 审查实证对账
- [ ] 引用字数逐条实际统计（非印象估计）
- [ ] 页码标注逐个检查
- [ ] 验证 index 声明与实际统计一致
- [ ] 留证：对账记录（统计过程与结果）
- [ ] 可配合 [声明对账清单](declaration-reconciliation-checklist.md) 执行本步骤

## ✅ 复现后验收（模式检验标准逐条打勾）

- [ ] frontmatter 可找到显式 route 决策字段（非事后补记）
- [ ] 产出物无连续 ≥30 字原文复现
- [ ] 随机抽 3 段摘要与原文比对，无连续 30 字以上重合（防书摘集退化）
- [ ] 每条直接引用标注页码，index 声明与实际统计一致

## 🔴 反模式自查（逐项确认未触犯）

| 反模式 | 自查问题 | 案例 1 教训 |
|------|------|---------|
| 默认先 OCR 逐字转录 | 是否把"OCR 是第一步"当作未经验证的默认？ | F-001/F-004 默认假设被显式否决 |
| 摘要写成书摘集 | 摘要是否退化为金句摘抄汇编？ | 原创性不成立则合规红线失守 |
| 跳过路线决策隐式执行 | frontmatter 是否缺少 route 记录？ | 决策不可审计，下次任务滑回 OCR 路线 |
| 摘要与转录混合 | 是否存在部分章节转录？ | 红线声明无法覆盖转录部分，契约名存实亡 |

## 🏁 升 L2 判定与归档

**判定线：6 步骤全部留证复现 + 4 项验收全过 + 4 项反模式自查通过，缺一不可。**

任一项未过：模式维持 L1，缺陷记入本次任务复盘，并反哺模式反模式清单。

全过后执行：
- [ ] 模式文件 `maturity` 由 L1 改为 L2，成熟度说明补记第 2 案例来源
- [ ] 案例 2 证据包归档：任务 frontmatter（route 字段）、index 声明文本、V 对账记录
- [ ] 向用户申请将模式入 `docs/retrospective/patterns/`（需用户审批，参照 A-004 流程）
- [ ] 更新两处索引：`playground/pipeline-parable/retrospective/README.md` 成熟度列 + `docs/` 模式库索引
