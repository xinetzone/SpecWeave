# 合规契约化复现检查清单（A-006）

> 配套模式：[合规契约化](../../playground/pipeline-parable/retrospective/pattern-compliance-contracting.md)（L1，单案例待验证）。
> 用途：在第 2 个独立案例中逐项复现模式 4 个核心步骤，全部留证且验收通过后，模式升 L2 并申请入 `docs/retrospective/patterns/`。
> 核心原则：合规契约化把"要合规"的态度翻译成可度量标准 + 显式声明，审查者照契约逐项打勾即可判定，无需理解合规背景。
> 跨场景迁移类案例优先（模式成熟度说明指定）：数据脱敏契约、API 兼容承诺、性能指标报告等。

## 🚨 启用条件

以下全部成立才启用本清单（缺一即为不适用，不得强行套用）：

- [ ] 产出物有明确合规红线：版权引用、数据脱敏、许可证、隐私信息等
- [ ] 产出物须经他人或下一阶段审查（V 审查、合规审校、客户验收）
- [ ] 红线已可定数（能翻译为数字/正则/清单；红线尚在谈判中的阶段不适用，契约条款不得伪造确定性）
- [ ] 与案例 1（《管道的故事》版权引用红线）不同源、不同场景（独立性要求，防同源假复现；跨场景迁移案例尤佳）

## 🛡️ 复现步骤（4 步，对应模式核心步骤，逐步留证）

### 步骤 1：红线翻译
- [ ] 列出全部态度式约束原文（如"注意脱敏""尽量少引用""保持兼容"）
- [ ] 逐条翻译为可度量标准：数字（单条 ≤N 字、条数上限）、正则（`\d{11}`）、清单枚举，三者至少其一
- [ ] 对翻译不了的表述（"适量""合理"）继续下钻直至可判定，禁止留用不可判定词
- [ ] 留证：翻译对照表（态度式原文 → 可度量标准）

### 步骤 2：契约显式化
- [ ] 以"标准（可度量）+ 溯源（可核验）+ 边界（使用说明）"三段式写入产出物索引页
- [ ] 声明写入时机正确：正文实质完成后再固化契约，非索引骨架阶段先行（防"先写声明后产出"）
- [ ] 留证：index 中可核验的契约声明文本

### 步骤 3：契约同步
- [ ] 产出物每次改写/增补，新增内容先过契约标准再入稿
- [ ] 契约条款随实际状态同步更新，无"契约滞留原状与实际脱节"
- [ ] 契约修改留痕，能回答"为什么现在的标准和以前不同"
- [ ] 留证：契约变更记录（时间、变更内容、理由）

### 步骤 4：契约打勾
- [ ] 审查者按契约逐项打勾，不按笼统感觉审
- [ ] 每项标准实际执行了核验动作（正则实跑、逐条计数、清单比对），非印象估计
- [ ] 留证：打勾记录（逐项核验过程与结果）
- [ ] 核验动作对接 [声明对账清单](declaration-reconciliation-checklist.md)（实证对账是契约的执法机制）

## ✅ 复现后验收（模式检验标准逐条打勾）

- [ ] 每条红线能回答"怎么判定越线"（数字、正则或清单，三者至少其一）
- [ ] 审查者无需理解合规背景，照契约逐项打勾即可通过或指出具体违约项
- [ ] 契约修改可追溯（标准变更留了痕）
- [ ] 抽查契约声明与实际产出一致（声明对账无缺口）

## 🔴 反模式自查（逐项确认未触犯）

| 反模式 | 自查问题 | 案例 1 教训 |
|------|------|---------|
| 态度式合规 | 是否残留"尽量少引用"式模糊自我约束未翻译？ | F-014/F-015 两极摆动：过度谨慎或失守红线 |
| 先写声明后产出 | 契约是否在正文未写完时提前固化，沦为愿望？ | 与声明对账反模式 1 同源于 F-011 |
| 契约不随产出演进 | 改写引入新引用/新数据后，契约条款是否滞留原状？ | F-012/F-013 改写引入冗余的契约面 |
| 标准不可测 | 契约条款是否含"合理使用""适量"等不可判定词？ | 审查者无法打勾，契约名存实亡 |

## 🏁 升 L2 判定与归档

**判定线：4 步骤全部留证复现 + 4 项验收全过 + 4 项反模式自查通过，缺一不可。**

任一项未过：模式维持 L1，缺陷记入本次任务复盘，并反哺模式反模式清单。

全过后执行：
- [ ] 模式文件 `maturity` 由 L1 改为 L2，成熟度说明补记第 2 案例来源
- [ ] 案例 2 证据包归档：翻译对照表、契约声明文本、契约变更记录、打勾记录
- [ ] 向用户申请将模式入 `docs/retrospective/patterns/`（需用户审批，参照 A-004 流程）
- [ ] 更新两处索引：`playground/pipeline-parable/retrospective/README.md` 成熟度列 + `docs/` 模式库索引
