# 视觉评审 Prompt 模板（image_understanding）

> 通用结构：交代页面身份与用途 → 固定评审维度 → 明确评分标尺与输出语言。按页面类型替换方括号内容；每次评审一页一图。

## 模板一：首次全量评审（列表 / 首页类）

```text
这是[应用名称]的「[页面名]」页面截图。请从 UI/UX 评审角度详细描述：
1) 整体配色（底色、主色、文字色、卡片处理）；
2) 信息层级与排版密度（紧凑/松弛）；
3) 图标风格（线性/填充）与一致性；
4) 徽章、标签、按钮的视觉处理与权重区分；
5) 是否有明显的布局破损、错位、文字溢出或对比度问题；
6) 总体观感评分（1-5 分，1=粗糙后台模板感，5=精致工具感）与理由。
请用中文回答，具体客观。
```

## 模板二：复杂页面评审（详情 / 仪表盘类）

```text
这是[应用名称]的「[页面名]」截图（[布局说明，如：左侧按天分组的条目 + 右侧预算与清单侧栏]）。请评审：
1) 配色与层次（底色/主色/卡片/侧栏）；
2) [核心区块]的信息组织是否清晰（排布顺序、优先级）；
3) [次要区块]的呈现质量；
4) 布局密度与留白是否平衡；
5) 有无错位、溢出、对比度问题；
6) 总体观感评分 1-5（1=粗糙后台模板感，5=精致本地工具质感）与理由。
请用中文，具体客观。
```

## 模板三：表格密集页评审

```text
这是[应用名称]「[页面名]」截图（[结构说明，如：顶部说明条 + 可编辑表格 + 底部操作按钮]）。请评审：
1) 表格可读性与输入控件排布；
2) 与整体风格（[风格关键词，如白底淡蓝]）的一致性；
3) 有无错位/溢出/拥挤问题；
4) 评分 1-5（1=粗糙，5=精致）与理由。
请用中文，简洁客观。
```

## 模板四：打磨后复评（对比验证）

```text
这是[应用名称]「[页面名]」（打磨后）截图。重点对比通用模板感是否改善：
1) [本次打磨点清单，如：品牌色块、标题强调线、卡片渐变条与悬停层次]是否带来精致度；
2) [次要打磨点]的视觉处理；
3) 整体观感评分 1-5（1=粗糙后台模板，5=精致本地工具质感，[风格关键词]统领、留白与密度平衡）与理由。
请用中文，简洁客观。
```

## 使用要点

- 每次评审一页一图，prompt 中明确页面身份，避免视觉模型混淆
- 评分标尺必须在 prompt 中给出，否则不同轮次分数不可比
- 复评 prompt 要列出本次打磨点，让模型针对性对比而非泛泛重评
- 评审结论按维度记录，作为验收证据与下一轮打磨依据
