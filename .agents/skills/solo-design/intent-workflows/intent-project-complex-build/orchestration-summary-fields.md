# Complex Build Summary Fields

Write `project.resolvedLane`, `project.contextReadScope`, `project.dispatchPreflightManifest[]`, `project.generationTree`, `project.cssPreflightEvidence`, `project.mobileNavigation`, `pages[]`, and page-level quality/readiness evidence.

For layout-static graphic work, also write `project.graphicStrategyGate`, `project.layoutStaticRequired`, `project.textCriticality`, `project.copyDensity`, and `project.deliverableCompletenessChecklist`.

`project.deliverableCompletenessChecklist` must include required pages/assets, copy blocks, information types, expected/actual page count, source material coverage, `missingRequiredItems[]`, and `blocking`. Missing required items remain blocking until repaired or explicitly reduced in scope.
