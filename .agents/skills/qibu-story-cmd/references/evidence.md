## 2. 可以说 / 不能说

| 结论 | 证据强度 | 表述要求 |
|---|---|---|
| 七步序列是目标→阻碍→努力→结果→意外→转弯→结局 | **六源互证，可直接引用** | 写明「公开流传的靶心人公式」 |
| 公式由许荣哲提出 | S1 指名 + S5 书中自称改名 | **只说到人名**；具体书名有冲突（《小说课（贰）》vs《故事课1》），不裁定 |
| 作者自评「这个套路是三流的」 | S5 书中摘抄 #963 + S6 转述 | 可以引用，但注明「作者自评」，不是外部评价 |
| 七步适合 8,000–12,000 字短篇 | ❌ 无来源 | 只能说「本库按字数口径做的推断」 |
| 每一步该占多少字 | ❌ 六份来源全没给 | 一律标「本库推断」 |
| 七步能提高过稿率 | ❌ 无任何样本 | **禁止**做此承诺 |
| 课程「七步成文」= 公开靶心人公式 | ❌ 未验证 | 只能说「名称同族」 |
| 五句话 ↔ 七步的对齐 | ❌ 无来源 | 标「一种填法，非原文」 |

## 4. 明确不覆盖

- 视频号直播的正文、讲师、时长、回放
- 七步各自的字数占比、平台适配、过稿证据
- 三幕式与七步的逐步对应（S1 只有图题）
- 第 6 步的统一操作定义
- 任何稿费、收入、签约、流量数据
- 句子层面的语言功力（六份来源全部停在结构层）

## 5. 引用规范

- 引用数字时写明口径与年份；本技能**不含收益类数字**。
- 引用公式时写「公开流传的许荣哲靶心人公式」，不写「课程说」「老师讲」。
- 引用「三流」时写「作者自评」，不写「业界公认」。
- 任何推断句必须带「本库推断 / 一种填法 / 非原文」之一。
