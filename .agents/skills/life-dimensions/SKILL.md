# 生命多维坐标法（Life Multi-Dimensional Coordinates）

> **渐进式披露**：L0 [ONBOARDING](../../ONBOARDING.md) → L1 本文件（触发词 + 场景决策树 + 五步法 + 定义库 + 边界案例 + 反模式 + 质量门）→ L2 完整知识底座 [docs/knowledge/what-is-life](../../../docs/knowledge/what-is-life/index.md)（39 条事实 F-001~F-039 / 3 条洞察 / 1 模式 / 42 信源 / V 审查记录）。

## 1. Skill ID

`life-dimensions`（内部 ID，对外名称：生命多维坐标法）

## 2. 功能描述

本技能把「生命是什么」这类两千年未决的问题接到**可定位的坐标框架**上。**本技能解决三类失败**：

| 失败模式 | 表现 | 拦截机制 |
|---|---|---|
| **单视角主义** | 只用生物学八特征回答哲学问题，或只用物理"负熵"回答医学问题 | §5 六视角并列 + 三坐标锚定 |
| **定义独裁** | 要求"唯一正确的生命定义"，把工作定义当真理 | §6 八类定义库 + 目的轴选择 |
| **无视边界** | 讨论病毒/合成生命/地外生命不检验定义失效域 | §7 边界压力测试（强制） |

**核心能力**：三坐标定位（组织层次 × 学科视角 × 定义目的）→ 边界压力测试 → 限定性收敛。

> **为什么必须用本技能而非自由发挥？** "生命"是跨学科被使用最频繁、却从未有唯一定义的概念之一（知识底座 F-001/F-002/F-028）。自由作答的典型失败是：用印象中的"生物特征清单"回答一切生命问题，遇到病毒、合成细胞、AI 意识时自相矛盾。本技能强制先锚定坐标、再做边界测试，结论永远带"在……下"限定语——可复核、可迁移、不越界。

## 3. 何时使用本技能

当用户提到以下任何内容时触发：

- "什么是生命"、"生命是什么"、"生命维度"、"生命定义"、"生命到底算什么"、"生命 410"
- "生命的意义"、"生命的本质"、"生命从哪来"（涉及定义/维度时，不涉及历史/宗教叙事时）
- 边界判定："病毒算不算生命"、"XX 是不是生命"、"合成生命"、"人工生命算不算生命"、"克隆生命"、"AI 有意识算不算生命"、"地外生命"、"火星有没有生命"
- 多维度分析："从几个维度讲讲生命"、"多角度分析"、"生命的层次"、"生命的组织层级"
- 跨概念迁移："什么是智能"、"什么是健康"、"什么是美"（同类抽象概念分析，用户要求类比或系统化时）
- 任何同时涉及生命与"维度/层次/定义/边界"关键词的请求

**不适用**（须转其他路径）：

| 场景 | 处理 |
|---|---|
| 需要医疗/法律/伦理的权威判决 | 拒绝越界作答，提示引用领域权威定义（本技能不替代） |
| 纯宗教/文学抒情（无概念分析需求） | 直接答，不走本工作流 |
| 生物学具体知识问答（如"光合作用步骤"） | 不需要本技能，走一般知识回答 |

> **关于触发**：即使没有明说"用 skill"，只要核心对象落在"生命是什么/是不是生命/生命的维度"上，就应使用本技能——三坐标框架与边界测试是自由作答不具备的。

## 4. 场景决策树

```
用户请求属于哪种？
├─ 只要快速概念定位？ → 场景A 概念问答（§5 三坐标定位 + 一句话结论，quick）
├─ 要全面分析/写内容/深度讲解？ → 场景B 深度分析（§5 五步法 + 引用事实编号，standard）
├─ 要判定"XX 算不算生命"？ → 场景C 边界判定（§5 五步法 + §7 边界测试，standard）
└─ 要沉淀知识包/模式/Skill/迁移到其他概念？ → 场景D 知识沉淀（按 seven-concepts-cmd R→I→E→V→C，deep）
```

**深度裁剪**：A 默认 quick；B/C 默认 standard；D 必须走完 V 对抗审查（不可裁剪）。

> **为什么 D 必须 V？** 知识沉淀入库是对外可复用资产，未对抗审查的模式会带着"框架万能"之类错误印象入库——见知识底座 V 记录（V-08/V-09 修正结论）。

## 4.1 快速开始（Quick Start）

三行上手：**读 §5 五步法 → 按 §4 决策树定场景 → 输出前过 §9 清单**。五步法即执行流程；术语/定义/边界冲突时回查 §6/§7 速查表，事实溯源走 §15 知识包。

## 5. 核心方法：生命多维坐标法五步（场景 A/B/C 使用）

任何"生命"分析输出必须走完以下五步（来源：知识底座 I-2 洞察与 E 阶段模式）：

```
① 锚定层次：分析对象处于哪个组织层次？
   分子/细胞/组织/器官/个体/种群/群落/生态系统/生物圈（F-006/F-008）
   —— 记住：细胞是生命的最小单位（F-007）
② 选择视角：用哪个学科的透镜？
   物理（负熵/自由能 F-011/F-012）/ 化学（自组织 F-018）/
   信息（非周期晶体 F-013/F-014）/ 系统（自创生 F-020）/
   生物（八特征 F-003）/ 哲学（灵魂/涌现 F-015/F-017）
③ 列出候选定义：从 §6 定义库选择与本视角相容者（8 选 1-N）
④ 边界压力测试：用三类边界案例检验该定义（§7，强制）
   —— 通不过 → 标注该定义的失效边界
⑤ 限定性收敛：输出"在 X 层次、Y 视角、Z 目的下，生命被定义为……"
   —— 禁止输出无坐标的"生命就是 X"
```

**输出模板（场景 A 概念问答）**：

> 一句话结论：在 **[层次]** 层次、**[视角]** 视角、**[目的]** 目的下，**[对象]** 是/不是生命——因为 **[边界测试结果]**。若换到 **[另一视角]** 视角，结论会变为 **[对照结论]**。

**最小示例（Hello World）**：问"细菌是生命吗？"
→ 层次=细胞（F-007，细菌是单细胞生物）；视角=生物学八特征（F-003，细菌全部具备）；目的=教学；边界测试=通过（独立代谢、独立复制）→ 结论："在细胞层次、生物学视角、教学目的下，细菌是生命。"

## 6. 定义库速查（场景 B 用，来源 F-001~F-021）

| # | 定义流派 | 一句话版本 | 主要适用域 | 事实编号 |
|---|---|---|---|---|
| 1 | 特征清单论 | "有序、响应、繁殖、生长、稳态、能量处理、适应、演化" | 基础教学 | F-003 |
| 2 | 可操作工作定义 | "自维持的化学系统，能进行达尔文式演化" | 天体生物学/探测 | F-001/F-002 |
| 3 | 热力学/物理学 | "以负熵为生"（隐喻；严格表述为自由能） | 理论物理 | F-011/F-012 |
| 4 | 信息定义 | 基因是"非周期晶体"，生命是信息载体 | 分子生物学/遗传学 | F-013/F-014 |
| 5 | 系统论/自创生 | "制造并维持自身运转" | 系统论/认知科学 | F-020 |
| 6 | 化学自组织 | "内禀调控的蛋白质核酸等自组织有机整体" | 分子生物学 | F-018 |
| 7 | 生理/医学功能 | "能消化、代谢、呼吸、生长、发育、反应的系统" | 临床/医学 | F-019 |
| 8 | 哲学本质论 | 灵魂是生命体的"形式与实现" | 哲学/形上学 | F-015 |

> **为什么定义库要按适用域标注？** 知识底座 I-1：生命定义是"工具"而非"真理"，探测场景用 NASA 工作定义、教学用八特征、临床用生理功能——选错定义就是"用尺子量重量"。定义选择必须与目的轴（探测/教学/临床/哲学追问）对齐。

## 7. 边界案例速查（场景 C 用，强制压力测试）

任何"XX 算不算生命"的判定，必须显式引用至少一个边界案例（来源 F-022~F-035）：

| 边界案例 | 核心事实 | 对定义的压力 |
|---|---|---|
| **病毒** | 无细胞结构、无独立代谢（F-031）；须借宿主复制（F-029）；有学者主张"衣壳编码生物"亦是生命（F-030） | 击穿"独立代谢"必要条件 |
| **合成细胞** | JCVI-syn3.0：531 kbp/473 基因，最小自主复制基因组（F-027） | 击穿"自然发生"隐含前提——人工基因组亦可活 |
| **地外生命** | NASA 生命探测阶梯 + 生物特征（biosignature）（F-032/F-034） | 击穿"碳基/DNA 中心"——未知生化形态如何判定 |

**判定纪律**：
1. 引用定义交锋双方（如病毒：Microbiology Society 不算 vs Claverie 算，F-029/F-030）
2. 结论必须标注该定义在哪个边界案例下失效
3. 探测类问题优先用"证据阶梯"思维（收集多级证据）而非"符合清单才判活"（F-032）

## 8. 反模式清单（输出前对照）

| 反模式 | 表现 | 正确做法 |
|---|---|---|
| 单视角主义 | 只从生物学角度回答哲学问题 | 先声明视角，多视角并列（§5 步②） |
| 个体中心主义 | 谈"生命"只想到个体（人/动物） | 承认分子/种群/生态层次也是生命（§5 步①） |
| 定义独裁 | 要求"唯一正确的生命定义" | 按目的选定义，标注适用域（§6） |
| 无视边界 | 讨论病毒/合成生命不引用定义交锋 | 用边界案例做压力测试（§7，强制） |
| 媒体冒充权威 | 引用科普文章当权威定义 | 信源分级：权威/学者/媒体/转述（知识底座信源台账） |
| 无坐标断言 | 输出"生命就是 X" | 限定性收敛"在 X 层次、Y 视角、Z 目的下……"（§5 步⑤） |

## 9. 质量门与安全检查清单

产出前逐项确认：

- [ ] **三坐标完整**：结论包含层次坐标 + 视角坐标 + 目的坐标（缺一不可）
- [ ] **限定语到位**：无"生命就是 X"式无限定断言
- [ ] **边界测试执行**：涉及"是不是生命"判定时，已引用 ≥1 个边界案例（§7）
- [ ] **定义选择对齐**：定义与目的轴匹配（探测→NASA、教学→八特征、临床→生理功能）
- [ ] **事实溯源**：关键事实带编号（F-xxx），来源见[信源台账](../../../docs/knowledge/what-is-life/references/source-inventory.md)
- [ ] **口径分级**：媒体口径（如涌现科普文章 F-017）标注"一方称"，不作权威依据
- [ ] **不越界声明**：不提供医疗/法律/伦理权威判决；需要时提示引用领域权威标准
- [ ] **交付形态**：B/D 场景产物为 OKF 风格（frontmatter + 一句话摘要 + 事实编号）；D 场景走完整质量门（G1 无因果词/G2 四元组/G3 模式/V 审查）

> **为什么"不越界"是硬约束？** 生命议题常与医疗（生命体征）、法律（生命权）、伦理（人工生命/AI 意识）交界，AI 越界给出权威判决会产生真实后果（知识底座 V-06/V-07 修正结论）。凡涉及权威判决需求，本技能只提供框架与边界提示，不代行判决。

## 10. Gotchas（陷阱与反直觉行为）

- **"负熵"不是可直接测量的物理量**：薛定谔的"以负熵为生"是隐喻，严格表述是自由能（F-012）——引用时勿当物理常数。
- **NASA 定义不是"官方定义"**：NASA 明确它是"非约束性工作定义"，不用于设计任务（F-002）——勿写"NASA 官方定义生命为……"。
- **LUCA 不是第一个生命**：LUCA 是祖先种群而非"第一个细胞"，距今 40 亿（研究口径 42 亿）年（F-023/F-024）。
- **"最小生命"已被实验测量**：讨论"生命最少需要多少基因"时引用 JCVI-syn3.0（473 基因，F-027），不靠哲学思辨。
- **媒体科普不等于科学结论**：涌现视角（F-017）是媒体口径，可作为理解示例，不可作为权威定义依据。
- **"生命维度"有科学与人文两套用法**：科学指组织层次（F-006），人文指长度/宽度/高度或自然/社会/精神（F-036~F-039）——先问清用户指哪套，勿混用。

## 11. I/O Parameters（输入/输出参数）

**输入（Input）**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 场景 | string | 否 | 概念问答/深度分析/边界判定/知识沉淀；不填时按请求特征自动识别 |

**输出（Output）**：
- 场景 A：一句话限定结论 + 三坐标定位（≤200 字）

- 场景 C：判定结论 + 定义交锋双方 + 失效边界标注
- 场景 D：OKF 知识包/Skill/模式（按 seven-concepts-cmd 全链路）

## 14. 错误处理（Error Handling）

| 异常场景 | 应对 |
|---|---|
| 用户要求"唯一正确"定义 | 说明科学界无唯一定义（F-002/F-028），按目的给出适用定义，不迎合 |
| 边界案例数据过时 | 以知识底座信源台账为准复核；数字跨口径时并列标注（如 LUCA 40 vs 42 亿年） |
| 主题超出知识底座覆盖（如 AI 意识深挖） | 明确标注"知识底座未采集，需补充调研"（参照 F-035 后待补充区），不编造事实 |
| 用户表达临床/法律/伦理判决需求 | 拒绝越界，提供框架与转介提示（§9 不越界声明） |
