# Elite Longterm Memory

This skill provides advanced memory management capabilities, including:

- Enhanced memory storage and retrieval
- Long-term memory consolidation
- Memory association and linking
- Memory categorization and organization
- Advanced memory search and filtering

## Features

- **Memory Storage**: Store important information for long-term retention
- **Memory Retrieval**: Retrieve stored memories based on context and keywords
- **Memory Association**: Link related memories together for better recall
- **Memory Categorization**: Organize memories into categories for easier management
- **Memory Search**: Search through stored memories with advanced filtering

## Usage

To use this skill, simply ask about memory-related tasks such as:
- "存储这个信息到长期记忆"
- "检索关于某个主题的记忆"
- "组织我的记忆"
- "搜索特定的记忆"

The skill will help you manage your long-term memory effectively.
