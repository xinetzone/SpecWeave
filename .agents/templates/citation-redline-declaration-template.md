# 引用红线声明模板

> 适用于：基于版权书籍/课程/商业培训材料衍生的知识包、教程、Wiki 类产出的索引页（index.md）。
> 用法：复制本模板三段式到产出物的"版权与使用说明"章节，替换 `{占位符}`。声明一旦写入即成为审查契约，须按 [declaration-reconciliation-checklist](../checklists/declaration-reconciliation-checklist.md) 实证核验后方可定稿。

## 三段式声明

### 第 1 段：引用标准（可度量）

```markdown
本教程对原书的直接引用均为 {N} 字以内的短语级引用（实测最长 {N} 字），
直接引用总条数 {N} 条、合计约 {N} 字；
正文情节、数据与论证均经转述重组，不含成段原文复制。
```

### 第 2 段：溯源方式（可核验）

```markdown
全部直接引用均标注来源位置（书页页码 / 章节号 / URL），
可直接对照原书核验；素材 intermediate 产物（摘要）位于 {摘要路径}，
含 source 溯源 frontmatter 与页码映射规则。
```

### 第 3 段：使用说明（边界）

```markdown
本教程为学习性衍生内容，不可替代原书；如需深入阅读请购买/借阅正版：
《{书名}》，{作者}著，{译者}译，{出版社} {出版年} 年版，ISBN {ISBN}。
```

## 填写检查清单

- [ ] 三个数字（单条上限/条数/合计字数）均来自**实际统计**而非写作印象
- [ ] 第 1 段"实测最长"与全文最长引用一致
- [ ] 第 2 段的引用位置标注在正文中已逐条落实（非仅声明）
- [ ] 第 3 段书目信息与版权页一致（ISBN 逐位核对）
- [ ] 声明定稿后运行一次声明对账（核验步骤见清单）

## 反模式

| 反模式 | 说明 |
|------|------|
| 先写声明后产出 | 骨架阶段填入的数字是愿望，正文写完后必须重新统计修正 |
| 模糊量词 | 用"少量引用""适度引用"替代可度量标准，审查者无法核验 |
| 只声明不落实 | 声明"均标注页码"但正文存在未标注引文 |
| 反向修正 | 发现超红线后放宽声明而非削减引用 |
