# 合规契约化模式复现报告模板

> 适用于：第 2 个独立案例（有合规红线的产出物任务，跨场景迁移类优先）完成后，记录"合规契约化"模式复现过程与证据，供升 L2 判定。
> 用法：复制本模板到该任务复盘目录（建议命名 `reproduction-report-compliance-contracting.md`），替换 `{占位符}`，逐项对照 [compliance-contracting-reproduction-checklist](../checklists/compliance-contracting-reproduction-checklist.md) 打勾。全部通过后，模式升 L2 并申请入 `docs/retrospective/patterns/`。
> ⚠️ 基线对照报告（用案例 1 素材回填验证模板）不构成 L2 证据，仅验证模板可用性；升 L2 必须有第 2 个独立案例的随任务同步记录。

## 第 3 节：验收结果（4 项逐条打勾）

- [ ] 每条红线能回答"怎么判定越线"（数字、正则或清单，三者至少其一）
- [ ] 审查者无需理解合规背景，照契约逐项打勾即可通过或指出具体违约项
- [ ] 契约修改可追溯（标准变更留了痕）
- [ ] 抽查契约声明与实际产出一致（声明对账无缺口）

## 反模式

| 反模式 | 说明 |
|------|------|
| 事后补写报告 | 任务完成后凭记忆填写，翻译对照表与契约变更时间戳矛盾；报告必须随任务执行同步记录 |
| 证据链断裂 | 报告引用证据位置但实际文件不存在或已改写，审查者无法复核 |
| 全过流于形式 | 验收与自查不打勾先写"通过"；判定线三项缺一即维持 L1，不得凑数 |
| 案例 1 充数 | 用已完成的案例 1 素材改写充当第 2 案例，违反独立性要求 |
| 契约伪造确定性 | 红线尚在谈判中仍硬写可度量标准，把"待定"包装成"已达标" |
