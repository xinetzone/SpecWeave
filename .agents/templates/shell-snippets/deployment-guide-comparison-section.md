# 部署指南"方案对比"小节规范

> 来源：wsl2-docker-selection-decision 模式萃取（L2-validated）
> 适用场景：所有涉及技术选型的部署/安装文档

## 规范要求

所有部署类文档在描述多种可选方案时，**必须**包含以下三个小节：
1. 量化性能对比表
2. 场景化推荐矩阵
3. 已知陷阱与规避方法

## 质量检查清单

- [ ] 性能对比表包含**实测数据**，而非定性描述（"快"vs"慢"）
- [ ] 标注了**测试环境**（硬件配置），便于读者对照参考
- [ ] 推荐矩阵覆盖**至少5种常见场景**
- [ ] 明确列出**已知陷阱**，而非假设用户会自己发现
- [ ] 不偏向某一方案，客观说明优劣
- [ ] 标注了**最后验证日期**（见[文档版本标注规范](docs-version-annotation.md)）
