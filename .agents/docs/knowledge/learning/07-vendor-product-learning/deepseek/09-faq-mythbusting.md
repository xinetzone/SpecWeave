# 09 FAQ常见问题与误区澄清

## 9.1 关于"收费"与"免费"

### Q1: DeepSeek-V4正式版收费了吗？

**答：分情况。**

- **网页端和App（chat.deepseek.com）**：**完全免费**，没有收费计划，没有会员。
- **API服务（platform.deepseek.com）**：新用户赠送500万tokens（约30天有效），用完后按量付费。8月17日调整了API定价（峰谷定价），这是**开发者API的调价**，不是面向普通用户的收费。
- **开源模型（V4-Flash）**：模型权重免费，自托管需要自备GPU硬件。

> ❗ 很多自媒体混淆了"API涨价"和"网页版收费"这两个完全不同的概念。

### Q2: "DeepSeek推出79.9元/180元/299元会员"是真的吗？

**答：假消息。**

这是2026年7月底广泛传播的一条谣言，源头是某新浪新闻账号发布的不实信息。权威媒体（潮新闻、中新经纬、新浪财经等）均已辟谣，DeepSeek官方也明确表示：

- C端聊天产品**没有付费会员计划**
- **不设Plus/Pro/VIP等订阅档位**
- 网页/App使用V4-Pro**永久免费**
- "79.9元""180元""299元"等数字**纯属捏造**

### Q3: "DeepSeek对普通用户每天只能免费聊50次"是真的吗？

**答：假的。**

- 网页/App**没有每日对话次数限制**
- 网上流传的"50次"说法是误读（可能来自API早期测试阶段的每日免费次数描述，或第三方平台限制）
- 官方明确表示无硬性对话次数上限
- 仅在高峰期对"重新生成""修改消息重发"等操作有fair-use软限流

### Q4: 8月17日涨价后，网页/App还能免费使用吗？

**答：完全不受影响。**

API峰谷定价只影响通过API接口（platform.deepseek.com）调用模型的开发者。通过chat.deepseek.com网页端或App使用的普通用户，**完全不受此次调价影响**，继续免费使用V4-Pro满血版。

### Q5: DeepSeek会一直免费吗？会不会哪天突然收费？

**答：根据官方表态，C端聊天产品保持免费。**

- 官方多次声明不计划对C端聊天收费
- 商业模式是"API付费+企业服务"，C端免费用于吸引用户和生态建设
- 但未来政策可能调整，这是任何商业公司都无法100%保证的
- 建议重要对话及时备份导出，避免服务变更导致数据丢失

## 9.2 关于使用限制

### Q6: 为什么有时"重新生成"按钮点不了几次就提示上限？

**答：这是fair-use公平使用策略，不是bug也不是逼你付费。**

每次"重新生成"都会让模型从头完整推理一次，算力消耗是正常对话的数倍。限流阈值大致为：

| 操作 | 非高峰 | 高峰期 | 恢复时间 |
|------|-------|-------|---------|
| 重新生成（↻） | 约6-10次 | 约3-6次 | 15-30分钟 |
| 修改消息重发 | 约10+次 | 约6次 | 15-30分钟 |
| Think Max模式 | 约5次 | 约3次 | 30分钟+ |
| 正常发新消息 | 基本不限 | 基本不限 | - |

优化建议：与其反复点重新生成，不如修改提示词让回答更准确。

### Q7: 高峰期响应慢/Server Busy怎么办？

**答：这是正常的流量高峰现象。**

- 工作日9:00-12:00、14:00-18:00是使用高峰
- 建议：避开高峰使用、晚上/周末响应更快
- 如果遇到Server Busy，等几秒刷新即可
- 这**不是收费前兆**，免费用户和付费用户（如有）在网页端享有相同服务质量

### Q8: API的500万免费额度用完后会自动扣费吗？

**答：不会。**

- 赠送余额用完后，如果没有充值余额，API调用会返回错误（余额不足）
- **不会**自动从信用卡扣费
- **不会**产生意外账单
- 需要主动充值才会继续扣费
- 建议：不准备长期付费就不要绑定信用卡

### Q9: 注册API平台需要信用卡吗？

**答：不需要。**

- 注册platform.deepseek.com只需要邮箱+手机号验证
- 不需要绑定信用卡即可获得500万免费tokens
- 只有主动充值时才需要支付方式

## 9.3 关于模型能力

### Q10: 网页端用的是V4-Pro满血版还是阉割版？

**答：满血版。**

- 网页端默认使用DeepSeek-V4-Pro-0813（正式版）
- 与API调用的deepseek-v4-pro是同一个模型
- 没有"网页端用Flash、API用Pro"的区别
- 三档推理模式（Non-Think/Think High/Think Max）全部可用

### Q11: V4-Pro和V4-Flash有什么区别？我该用哪个？

**答：日常用Pro（免费），开发者按需选择。**

- 网页/App用户：直接用默认的V4-Pro，不需要关心Flash
- API开发者：
  - 复杂代码/推理/Agent任务 → V4-Pro
  - 高并发/简单任务/成本敏感 → V4-Flash
- 自托管用户：只能用V4-Flash（Pro未开源）

详见 [04 V4-Pro能力](04-v4-pro-capabilities.md) 和 [05 V4-Flash能力](05-v4-flash-capabilities.md)。

### Q12: 100万上下文是什么概念？能传多长的文档？

**答：约75万汉字，相当于一整本长篇小说。**

- 1M tokens ≈ 75万中文字 ≈ 100万英文字母
- 可以一次性输入：一整本《三体》、整个中型代码仓库、数百页PDF
- 但注意：长输入会消耗更多tokens，API用户需注意成本
- 网页端虽然支持1M上下文，但上传超大文件可能处理较慢

### Q13: V4-Flash自托管需要什么显卡？

**答：最小2张H20/H100（FP8），消费级最小4张RTX 4090（Int4量化）。**

详见 [06 自托管方案](06-self-hosting.md) 的硬件需求表。V4-Pro因1.6T参数过大，无法在消费级硬件上自托管。

## 9.4 关于数据与隐私

### Q14: DeepSeek会用我的对话数据训练模型吗？

**答：需查阅最新隐私政策。**

- API用户的数据使用政策请参考platform.deepseek.com的隐私协议
- 网页端用户的对话数据政策请参考chat.deepseek.com的隐私协议
- 如需严格的数据隐私保障，建议使用V4-Flash自托管方案（数据完全不出本地）

### Q15: 我的对话记录安全吗？会被别人看到吗？

**答：正常情况下只有你自己能看到。**

- 对话记录关联你的账号，他人无法访问
- 但不要在对话中输入密码、密钥、身份证号等极度敏感信息
- 公共电脑使用后记得退出账号
- 重要对话可通过分享功能导出备份

## 9.5 关于价格与成本

### Q16: API调用到底贵不贵？和ChatGPT比呢？

**答：非常便宜，是GPT-5.5的约1/8。**

- V4-Pro高峰输出27元/百万tokens，空闲13.5元
- GPT-5.5约216元/百万tokens
- V4-Flash空闲输出仅4.5元/百万tokens
- 500万免费tokens足够独立开发者用2-4周

详见 [03 API定价](03-api-pricing-comparison.md)。

### Q17: 什么是"峰谷定价"？我需要在意吗？

**答：普通用户完全不需要在意。**

- 峰谷定价仅针对API调用
- 高峰时段（9:00-12:00, 14:00-18:00）价格是空闲时段的2倍
- 网页/App用户完全不受影响
- API开发者可以将非实时任务调度到空闲时段省钱

### Q18: 缓存命中为什么这么便宜？怎么利用？

**答：缓存命中比未命中便宜97-98%，是API省钱最重要的手段。**

- 当多个请求有相同前缀（如相同的system prompt）时自动命中
- 实际应用：保持system prompt稳定、RAG场景将固定上下文放前面
- 详见 [03 API定价](03-api-pricing-comparison.md) 的缓存机制说明

### Q19: 为什么英文API文档价格和中文文档不一致？

**答：截至2026年8月19日，英文文档尚未更新峰谷定价。**

- 中文文档（api-docs.deepseek.com/zh-cn/）已更新为最新峰谷RMB定价
- 英文文档（api-docs.deepseek.com）仍显示旧的美元定价
- 请以中文文档或实际计费账单为准
- 价格单位：中文站是人民币（元），英文站是美元（$）

### Q20: DeepSeek支持哪些第三方客户端/插件？

**答：所有兼容OpenAI API格式的工具都可以接入。**

- ChatBox、LobeChat、Cherry Studio等聊天客户端
- Continue、Cline等IDE编程插件
- 各类RAG框架（LangChain、LlamaIndex等）
- 只需将base_url设为`https://api.deepseek.com`，填入API Key即可
- 注意：第三方客户端本身可能收费，但DeepSeek API费用是另一回事

### Q21: API并发不够用怎么办？

- 扩容不额外收费
- 自托管V4-Flash则完全自控并发
