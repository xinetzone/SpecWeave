# 08 免费vs付费对比与选型决策

## 8.1 "免费"与"付费"的正确理解

DeepSeek的商业模式不是"免费版vs付费版"的二元划分，而是：

1. **C端聊天产品**（网页/App）→ **完全免费**，没有付费会员，普通用户永远免费
2. **API服务**（开发者平台）→ 新用户赠送额度，之后**按用量付费**（峰谷定价）
3. **开源模型**（V4-Flash）→ **模型免费**，但自托管需要GPU硬件成本
4. **企业服务** → 定制化方案，单独报价

**关键认知**：API涨价≠网页版收费，这是两个完全不同的产品线。

## 8.3 不同用户画像的选型建议

### 8.3.1 普通用户（学生/上班族/内容创作者）

**你的需求**：日常问答、写文案、翻译、查资料、学习辅助

**推荐方案**：🟢 **网页/App直接用**

- 费用：0元
- 模型：V4-Pro满血版
- 功能：全部免费可用（联网、文件上传、深度思考）
- 不需要任何付费操作
- 注意：高峰期可能有软限流，但正常使用基本不受影响

### 8.3.2 开发者（个人项目/学习/原型验证）

**你的需求**：学习API调用、做项目原型、构建小型AI应用

**推荐方案**：🟢 **API注册拿500万免费额度**

- 费用：0元（额度内）
- 模型：V4-Pro + V4-Flash
- 额度：500万tokens，够2-4周原型开发
- 用完后可按需充值（V4-Flash空闲时段成本极低）
- 建议：原型阶段用V4-Flash节省额度，复杂任务才用V4-Pro

### 8.3.3 小团队/创业公司（有上线产品）

**你的需求**：AI产品上线，有稳定调用量，成本可控

**推荐方案**：🟡 **API按量付费 + 智能调度**

- 模型：V4-Flash为主，V4-Pro处理复杂任务
- 策略：
  - 简单任务用V4-Flash非思考模式（成本最低）
  - 非实时任务调度到空闲时段（18:00-次日9:00，成本减半）
  - 利用缓存机制降低输入成本
  - V4-Pro仅用于必须深度推理的场景
- 月度成本参考：日调用100万tokens，月成本约90-180元

### 8.3.4 中大型企业（有合规/大规模需求）

**你的需求**：数据安全、合规要求、大规模部署、定制化

**推荐方案**：🟠 **V4-Flash自托管 + API混合**

- 敏感数据场景：V4-Flash私有化部署（MIT协议自由使用）
- 非敏感高复杂度场景：V4-Pro API调用
- 考虑点：
  - 日调用量>5000万tokens时自托管开始省钱
  - 需要GPU运维团队
  - 可联系DeepSeek商务洽谈企业合作

### 8.3.5 研究者/AI爱好者

**你的需求**：实验、微调、研究模型行为

**推荐方案**：🟢 **V4-Flash开源 + API免费额度**

- 模型研究：HuggingFace下载V4-Flash权重本地实验
- 对比实验：用API免费额度测试V4-Pro
- 学术研究：MIT协议允许学术使用无限制

## 8.6 选型决策树

```
开始选型
│
├─ Q1: 你是否只是日常聊天/写东西/查资料？
│   └─ 是 → ✅ 网页/App免费使用，0成本，结束
│
├─ Q2: 你需要API接口调用吗（开发应用/脚本/自动化）？
│   └─ 否 → ✅ 网页/App免费使用，结束
│
├─ Q3: 是刚开始学习/做原型吗？
│   └─ 是 → ✅ 注册API拿500万免费额度，0成本开始
│
├─ Q4: 产品上线了吗？日调用量多大？
│   ├─ <100万tokens/天 → 🟢 API按量付费（V4-Flash为主），月成本几十到百元
│   ├─ 100万-5000万/天 → 🟡 API+错峰+缓存优化，月成本数百到数千元
│   └─ >5000万/天 → 🟠 考虑自托管V4-Flash+API混合
│
├─ Q5: 有数据合规/隐私/内网要求吗？
│   └─ 是 → 🔒 必须V4-Flash自托管
│
└─ Q6: 需要最强的代码/推理/Agent能力吗？
    └─ 是 → V4-Pro API（无论免费额度还是付费）
```

## 8.7 省钱最佳实践总结

1. **普通用户完全不花钱**：网页/App直接用，所有功能免费
2. **开发者先用完免费额度**：500万tokens足够充分测试
3. **简单任务用V4-Flash**：成本仅Pro的1/3，80%场景够用
4. **批量任务错峰**：18:00后和周末价格减半
5. **优化缓存命中**：相同前缀命中缓存省97%输入成本
6. **控制输出长度**：设置合理max_tokens
7. **大规模考虑自托管**：日调用超过5000万tokens时ROI转正
8. **警惕不实信息**：不存在"79.9元会员"，网页版永远免费
