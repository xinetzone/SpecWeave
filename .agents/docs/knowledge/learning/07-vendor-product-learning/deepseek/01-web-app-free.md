## 1.2 注册与登录

支持三种登录方式（三选一）：

1. **手机号**（推荐）：选择+86区号 → 输入手机号 → 获取验证码 → 填写验证码 → 勾选协议 → 登录（未注册自动完成注册）
2. **微信扫码**：点击"微信登录" → 用微信扫描二维码 → 授权绑定
3. **邮箱**：输入邮箱 → 收取验证邮件 → 点击链接 → 设置密码 → 登录

**不需要信用卡，不需要付费，注册即使用。**

## 1.3 默认模型与推理模式

网页端默认使用 **DeepSeek-V4-Pro** 正式版（DeepSeek-V4-Pro-0813），支持三档推理模式切换：

| 模式 | 说明 | 适用场景 | 响应速度 |
|------|------|---------|---------|
| **Non-Think（非思考）** | 快速响应，不显示思维链 | 日常对话、简单问答、翻译 | 最快 |
| **Think High（深度思考）** | 显示思维链，复杂推理 | 数学题、代码、逻辑分析 | 中等 |
| **Think Max（最深推理）** | 最深度推理，思维链最长 | 极其复杂的问题、深度分析 | 最慢 |

切换方式：输入框顶部有模式切换按钮。

## 1.5 使用限制与Fair-Use策略

### 1.5.1 官方政策

DeepSeek官方明确表示：
- ✅ **无硬性对话次数限制**
- ✅ **无Token消耗上限**
- ✅ **无会员订阅计划**（没有Plus/Pro等付费档）
- ✅ **不计划对C端聊天收费**

### 1.5.2 Fair-Use软限流

在高峰期（通常是工作日白天），为保证主干道服务稳定性，可能触发以下软限流：

| 操作 | 限流表现 | 触发条件 | 恢复方式 |
|------|---------|---------|---------|
| 正常提问 | 基本不限 | - | - |
| "重新生成"（↻按钮） | 约3-6次后提示"已达上限" | 高频重复点击 | 等待15-30分钟自动恢复 |
| "修改消息"重发 | 约6次左右提示"已达上限" | 高频修改重发 | 等待15-30分钟自动恢复 |
| Think Max模式 | 限流阈值更低（约3次） | 深度推理消耗算力大 | 切换到Think High或等待 |

> **理解限流逻辑**：每次"重新生成"都会让模型从头到尾完整推理一遍，算力消耗是正常对话的数倍。限流的本质是"保障主干道畅通"，类似于高峰期限行——不是不让你用，是防止个别人滥用拖慢所有人的速度。

### 1.5.3 高峰期可能的现象

- 响应速度变慢（排队）
- Server Busy提示
- 重新生成/修改消息受限

这些都是**临时措施**，非永久性功能阉割，也**不是收费的前兆**。

## 1.7 使用建议

1. **正常提问不受影响**：90%的用户日常使用不会触发限流
2. **优化Prompt比反复重生成更有效**：与其点10次"重新生成"，不如修改提示词让回答更精准
3. **避开高峰时段**：晚上和周末响应更快，限流更宽松
4. **重要对话及时备份**：利用分享功能保存重要对话
5. **区分官方与第三方**：只有chat.deepseek.com和官方App是官方免费渠道，第三方工具/小程序可能收费
