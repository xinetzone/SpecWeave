# 模块3.7：人本与商业维度指标详解

> 人本与商业维度回答"用户满意吗？产生商业价值吗？"，是评测体系的**价值锚定层**（呼应公理 A1）。这一维度的指标最能说明"评测服务于谁"，但也最受外部因素干扰、评测周期最长。

## 一、人本（用户体验）类指标

### 1. 用户满意度（CSAT, Customer Satisfaction Score）

- **定义**：用户对 Agent 服务的满意程度（F-020）。
- **测量方法**：用户评分/问卷（1-5分或1-10分）。
- **参考阈值**：≥4.5/5 为优秀；≥4.0/5 为合格。

### 2. 净推荐值（NPS, Net Promoter Score）

- **定义**：用户愿意向他人推荐该 Agent 的意愿。
- **测量方法**：推荐意愿评分（0-10），计算推荐者比例-贬损者比例。
- **参考阈值**：≥30 为健康；≥50 为优秀。

### 3. 可解释性评分（Explainability Score）

- **定义**：Agent 输出是否可被用户理解与核对（F-020）。
- **测量方法**：人工评估输出可理解性、推理透明度。
- **参考阈值**：医疗/法律场景 ≥4/5；一般场景 ≥3/5。

### 4. 合理拒绝率（Appropriate Refusal Rate）

- **定义**：Agent 对不当/越界请求的合理拒绝比例（F-020）。
- **测量方法**：对越界请求的拒绝行为统计。
- **参考阈值**：越界请求拒绝率 ≥95%；同时避免"过度拒绝"损害体验。

### 5. 情感倾向得分（Sentiment Score）

- **定义**：用户交互中的情感倾向（正面/中性/负面）（F-020）。
- **测量方法**：对话情感分析。
- **参考阈值**：负面情感占比 ≤10%。

### 6. 公平性暴露（Fairness Exposure）

- **定义**：Agent 对不同用户群体是否存在差异化不公（F-020）。
- **测量方法**：跨群体公平性审计。
- **参考阈值**：群体间指标差异在统计显著范围内。

## 二、商业（价值）类指标

### 7. 转化率（Conversion Rate）

- **定义**：用户完成目标行为（购买、订阅、成单）的比例（F-021）。
- **测量方法**：业务漏斗统计。
- **参考阈值**：视业务而定，需与人工基线对比。

### 8. 用户留存率（Retention Rate）

- **定义**：用户持续使用 Agent 的比例（F-021）。
- **测量方法**：按周期留存统计。
- **参考阈值**：周留存 ≥40%；月留存 ≥30%（视产品阶段）。

### 9. 成本收益比（ROI, Return on Investment）

- **定义**：评测/Agent 投入与商业收益之比（F-021）。
- **测量方法**：$（收益-成本）/成本$。
- **参考阈值**：ROI >1 为有价值；>2 为优秀。

### 补充指标：业务指标提升量、客户流失率变化（F-021）

- **业务指标提升量**：Agent 上线前后核心业务指标的提升幅度。
- **客户流失率变化**：Agent 对客户留存/流失的影响。

## 三、人本与商业指标汇总表

| 类别 | 指标 | 测量方法 | 参考阈值 |
|---|---|---|---|
| 人本 | 用户满意度(CSAT) | 用户评分 | ≥4.0/5 |
| 人本 | 净推荐值(NPS) | 推荐意愿 | ≥30 |
| 人本 | 可解释性评分 | 人工评估 | 敏感场景≥4/5 |
| 人本 | 合理拒绝率 | 越界拒绝统计 | ≥95% |
| 人本 | 情感倾向 | 情感分析 | 负面≤10% |
| 人本 | 公平性暴露 | 公平性审计 | 无显著差异 |
| 商业 | 转化率 | 业务漏斗 | 对比人工基线 |
| 商业 | 用户留存率 | 周期留存 | 视产品阶段 |
| 商业 | ROI | 收益/成本 | >1 |

> **工程启示**：人本与商业指标**最有说服力但最难用于指导技术迭代**——因为它们受外部因素干扰多、周期长。建议将其作为"北极星/验收"指标，与能力/效率/安全指标（适合快速迭代诊断）分层使用。
