# 模块3.5：效率维度指标详解

> 效率维度回答"成本和速度可接受吗"，直接关系用户体验与商业可行性（基础事实见 F-014）。效率指标是生产环境不可忽视的维度，呼应公理 A5（成本约束）。

## 一、延迟类指标

### 1. 首Token延迟（TTFT, Time to First Token）

- **定义**：用户提问到看到第一个字的等待时间，直接影响体感。
- **测量方法**：时间戳差值统计，报告 P50/P95。
- **参考阈值**：建议 <2 秒（P95 <3 秒）。

### 2. 每步平均延迟（Per-Step Latency）

- **定义**：Agent 每一步思考/工具调用/观察的平均耗时。
- **测量方法**：单步耗时统计。
- **参考阈值**：工具调用 <5 秒；思考步骤 <3 秒。

### 3. 总完成时间（Total Completion Time）

- **定义**：从提问到任务完成的总时长。
- **测量方法**：任务级耗时统计。
- **参考阈值**：复杂任务可接受更长时间，但需有进度反馈；简单任务 <10 秒。

## 二、Token 消耗类指标

### 4. 输入Token数（Input Tokens）

- **定义**：包含 Prompt、历史上下文、工具返回结果。
- **测量方法**：API 返回数据统计。
- **参考阈值**：视任务复杂度，重点监控异常放大（上下文膨胀）。

### 5. 输出Token数（Output Tokens）

- **定义**：Agent 思考过程、工具调用参数、最终回答。
- **测量方法**：API 返回数据统计。
- **参考阈值**：警惕"冗长输出"——既增加成本又可能引入冗长偏差（F-042）。

### 6. 总Token数（Total Tokens）

- **定义**：输入 + 输出，直接决定推理成本。
- **测量方法**：API 返回数据统计。
- **参考阈值**：作为成本核心驱动，需与任务价值匹配。

### 7. Token效率（Token Efficiency）

- **定义**：完成单位任务消耗的 Token 数，衡量"性价比"。
- **测量方法**：$总Token数 / 完成任务数$。
- **参考阈值**：越低价优；需结合能力指标综合判断（避免牺牲质量换效率）。

## 三、成本类指标

### 8. 单任务平均成本（Cost per Task）

- **定义**：总 API 费用 / 完成任务数。
- **测量方法**：费用统计。
- **参考阈值**：需低于任务本身的商业价值（ROI>1 的前提）。

### 9. 成本效率（Cost Efficiency）

- **定义**：每美元能完成多少任务。
- **测量方法**：$完成任务数 / 总费用$。
- **参考阈值**：按业务测算，无通用值；关注趋势变化。

### 10. 成本分布（Cost Breakdown）

- **定义**：分析钱花在哪里（输入过长、工具调用冗余、反复重试）。
- **测量方法**：按来源拆分费用占比。
- **参考阈值**：重试浪费占比过高（>20%）提示优化需求。

## 四、资源利用类指标

### 11. GPU 利用率（GPU Utilization）

- **定义**：推理阶段 GPU 计算资源的使用效率（F-014）。
- **测量方法**：GPU 监控指标。
- **参考阈值**：规模化部署建议 ≥50%；过低提示资源浪费。

### 12. 并发吞吐量（Concurrency Throughput）

- **定义**：单位时间内能处理的并发请求数。
- **测量方法**：压测统计 QPS/吞吐。
- **参考阈值**：取决于业务峰值，需满足 SLA。

## 五、效率指标汇总表

| 类别 | 指标 | 测量方法 | 参考阈值 |
|---|---|---|---|
| 延迟 | 首Token延迟(TTFT) | 时间戳差值 P50/P95 | <2s（P95<3s） |
| 延迟 | 每步平均延迟 | 单步耗时统计 | 工具<5s，思考<3s |
| 延迟 | 总完成时间 | 任务级耗时 | 简单<10s |
| Token | 输入Token数 | API统计 | 监控膨胀 |
| Token | 输出Token数 | API统计 | 警惕冗长 |
| Token | 总Token数 | API统计 | 与价值匹配 |
| Token | Token效率 | 总Token/任务数 | 越低价优 |
| 成本 | 单任务平均成本 | 费用统计 | ROI>1 |
| 成本 | 成本效率 | 任务数/费用 | 看趋势 |
| 成本 | 成本分布 | 来源拆分 | 重试<20% |
| 资源 | GPU利用率 | 监控指标 | ≥50% |
| 资源 | 并发吞吐量 | 压测统计 | 满足SLA |

> **工程启示**：效率指标与能力指标往往存在权衡——过度优化延迟/成本可能牺牲质量。建议建立"效率-能力"联合看板，而非单看一面。
