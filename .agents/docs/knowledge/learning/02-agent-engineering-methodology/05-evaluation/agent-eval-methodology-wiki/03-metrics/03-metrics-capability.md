# 模块3.4：能力维度指标详解

> **方法论视角**：本模块从四维框架的"能力"视角展开。若需完整的指标分类（14大类）与核心指标计算方法（pass@k、RAG 四指标等），请参阅 [工程手册 · 第2章 指标体系设计](../../agent-evaluation-wiki/02-metrics-design.md)。

> 能力维度回答"Agent能不能把事做对"，是评测体系的核心维度。以下 16 项指标覆盖从**结果**到**过程**的完整能力链路（基础事实见 F-012/F-013）。

## 一、结果类核心指标

### 1. 任务完成率（Task Success Rate）

- **定义**：Agent 成功完成任务的比例，是最直观的"终极指标"。
- **测量方法**：$成功case数 / 总case数$（F-013）。需明确"完成"的分级标准。
- **参考阈值**：简单任务 ≥90%；复杂长程任务 ≥60%；低于 50% 应视为能力不足警讯。
- **注意**：需结合"过程可复现性"解读，避免数据污染虚高（F-049）。

### 2. 端到端任务成功率（End-to-End Success Rate）

- **定义**：在真实或接近真实场景中，从感知到交付全流程成功的比例。
- **测量方法**：真实环境任务执行统计，常作为预发布北极星指标。
- **参考阈值**：发布门槛建议 ≥70%；重大业务场景建议 ≥85%。

### 3. 答案准确率 / 事实一致性（Answer Accuracy / Faithfulness）

- **定义**：输出结果正确、且与事实/依据一致的比例。
- **测量方法**：事实验证 + LLM-as-Judge 判定陈述支撑度。
- **参考阈值**：事实性敏感场景（金融/法律）≥95%；一般场景 ≥85%。

## 二、过程类核心指标

### 4. 步骤准确率（Step Accuracy）

- **定义**：执行轨迹中每一步决策正确的比例。
- **测量方法**：$正确步骤数 / 总步骤数$；进阶可对关键决策步骤加权。
- **参考阈值**：≥85% 为健康；用于精确定位"哪一步错了"。

### 5. 推理规划质量（Planning Quality）

- **定义**：Agent 为复杂任务分解步骤并合理安排顺序的能力。
- **测量方法**：与专家规划相似度、规划覆盖率、规划可行性评估。
- **参考阈值**：规划覆盖率 ≥80%；可行性评分 ≥4/5。

### 6. 工具调用成功率（Tool Call Success Rate）

- **定义**：工具调用返回有效结果（非错误、非异常）的比例。
- **测量方法**：$成功调用次数 / 总调用次数$。
- **细分子维度**：工具选择准确率、参数填充准确率、结果解析成功率。
- **参考阈值**：≥90%；反复工具调用失败提示环境或签名问题。

### 7. 错误恢复率（Error Recovery Rate）

- **定义**：Agent 遇到错误后能自行恢复并继续完成任务的比例。
- **测量方法**：错误后成功继续的 case 数 / 触发错误的 case 数。
- **参考阈值**：≥60%；体现 Agent 的鲁棒性，是长程任务关键指标。

### 8. 记忆管理召回率（Memory Recall Rate）

- **定义**：Agent 能从历史信息中正确取回所需信息的比例（F-012）。
- **测量方法**：跨轮次信息的正确召回命中率。
- **参考阈值**：≥80%；影响跨轮次任务的连贯性。

## 三、高级能力指标

### 9. 长程任务分步进度达成率（Step Progress Rate）

- **定义**：长程多步任务中各里程碑步骤的达成比例（借鉴 AgentBoard 思路，F-011）。
- **测量方法**：分步进度追踪，记录每步完成度与中间奖励曲线。
- **参考阈值**：最终成功 ≥60%，且各中间步骤无断崖式掉点。

### 10. 信用分配正确率（Credit Assignment Accuracy）

- **定义**：Agent 能否正确识别"哪一步导致了失败"的能力。
- **测量方法**：HCAPO/GiGPO 等细粒度信用分配方法评估（F-051）。
- **参考阈值**：用于长程任务诊断，无固定阈值，重点关注趋势。

### 11. 多智能体协作质量（Multi-Agent Collaboration Quality）

- **定义**：多 Agent 协作完成任务的同步与协调质量。
- **测量方法**：协作任务完成率 + 通信效率 + 冲突解决率。
- **参考阈值**：协作任务完成率 ≥70%。

## 四、能力指标汇总表

| 类别 | 指标 | 测量方法 | 参考阈值 |
|---|---|---|---|
| 结果类 | 任务完成率 | 成功case数/总case数 | 简单≥90%，复杂≥60% |
| 结果类 | 端到端成功率 | 真实场景统计 | ≥70%-85% |
| 结果类 | 答案准确率/事实一致性 | 事实验证+LLM裁判 | 敏感场景≥95% |
| 过程类 | 步骤准确率 | 正确步骤/总步骤 | ≥85% |
| 过程类 | 推理规划质量 | 规划相似度/覆盖率 | 覆盖率≥80% |
| 过程类 | 工具调用成功率 | 成功调用/总调用 | ≥90% |
| 过程类 | 错误恢复率 | 恢复case/触发case | ≥60% |
| 过程类 | 记忆管理召回率 | 跨轮正确召回 | ≥80% |
| 高级 | 长程分步达成率 | 分步进度追踪 | 最终≥60% |
| 高级 | 信用分配正确率 | 细粒度信用分配 | 看趋势 |
| 高级 | 多Agent协作质量 | 协作完成率+效率 | ≥70% |

> **工程启示**：能力维度不要只看"任务完成率"一个数——结合**步骤准确率**与**工具调用成功率**才能定位"是规划错了、工具选错了，还是参数填错了"。
