# AI/ML推理与模型部署

## 🎯 主题概述

> **AI/ML推理与模型部署是将训练好的模型落地到生产环境的关键环节**。本模块系统梳理机器学习模型的开放标准格式、推理引擎、量化优化、跨框架互操作等技术方向，为模型部署提供完整的技术栈参考。

### 技术全景图

| 层次 | 核心概念 | 解决的问题 | 代表技术 |
|------|---------|-----------|---------|
| 📦 **模型格式层** | ONNX/ONNX ML/标准算子集 | 跨框架模型互操作 | ONNX开放标准 |
| ⚡ **推理引擎层** | ONNX Runtime/TensorRT/OpenVINO | 高性能推理执行 | 多平台Runtime |
| 📉 **量化优化层** | INT8/FP16/QDQ/校准 | 模型压缩与加速 | Neural Compressor、原生量化 |
| 🔧 **工具链层** | 可视化/转换/验证/调试 | 模型工程化工具 | Netron、onnx2py等 |
