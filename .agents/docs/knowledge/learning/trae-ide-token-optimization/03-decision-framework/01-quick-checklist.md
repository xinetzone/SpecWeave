# 快速检查清单（上手即用）

按ROI优先级排序，做完前3项就能省50%以上：

## 🚀 5分钟配置（一次性完成）
- [ ] **1. 添加全局精简回答规则**（设置→规则→全局规则）
- [ ] **2. 精简AGENTS.md**：控制在200行以内，删除琐碎规范
- [ ] **3. 关闭不用的MCP和Skills**：只留当前需要的
- [ ] **4. 规则拆分**：大规则拆成小文件，设为智能生效/手动触发
- [ ] **5. 关闭不需要的自动导入**（CLAUDE.md等）

## 📝 日常使用习惯（每次）
- [ ] **6. 解决一个子问题后，新开对话处理下一个**
- [ ] **7. 简单任务切换到轻量模型**（GLM-5/DeepSeek-Flash）
- [ ] **8. 提问简洁直接，去掉客套话**
- [ ] **9. 大段日志/代码先存文件，用#引用**
- [ ] **10. 精准#引用需要的文件/函数，不要说"看整个项目"**

## ⚠️ 安全护栏（配置一次）
- [ ] **11. 自定义模型设置工具调用轮次上限（10-20轮）**
- [ ] **12. 设置合理的max_tokens（2000-4000）**
- [ ] **13. Agent模式发现连续3次试错无进展，手动停止**
- [ ] **14. 定期查看用量，大请求占比超过20%及时排查**

## ✅ 完成后验证
- 平均每次请求成本 < $0.08（参考基准$0.1337）
- 大请求（≥$0.20）占比 < 10%
- AI响应速度明显变快，遵守规则准确率提升
