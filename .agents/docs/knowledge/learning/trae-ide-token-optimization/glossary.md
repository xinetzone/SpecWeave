# 术语表

| 术语 | 解释 |
|-----|------|
| **静态输入** | 每次请求都会发送的固定内容，包括系统提示词、AGENTS.md、规则文件、MCP工具定义、Skills定义等，属于固定底座成本 |
| **动态上下文** | 随对话累积的内容，包括历史对话、工具调用记录、报错日志、读取的文件内容等，越长越贵 |
| **Agent循环** | Agent模式下AI自主"思考→调用工具→读取结果→再思考"的循环过程，陷入死循环时空消耗巨大 |
| **MCP** | Model Context Protocol，模型上下文协议，允许AI调用外部工具/服务，每个启用的MCP都会发送工具定义占用Token |
| **AGENTS.md** | 项目根目录的智能体配置文件，定义AI在该项目的行为规范，会被加载到每次请求的上下文中 |
| **全局规则** | Trae IDE设置中配置的用户级规则，所有项目生效，属于静态输入的一部分 |
| **项目规则** | `.trae/rules/`目录下的项目级规则，可配置触发方式，按需加载 |
| **Token计费** | Trae IDE 2026年起采用的计费方式，按实际输入输出Token消耗计费，比固定次数更灵活 |
| **SOLO模式** | Trae的一种工作模式，相同Token下请求量是普通模式3倍，性价比更高 |
| **模型分级** | 根据任务复杂度选择不同能力/价格的模型，简单任务用轻量模型，复杂任务才用重量级模型 |
| **熔断机制** | 发现AI陷入无效循环时人工停止，或配置工具调用轮次上限自动停止，防止极端超支 |
