# Trae IDE Token 节省：3分钟快速参考卡

## 核心一句话
> **省Token不是让AI少写代码，而是让它少读无用信息。输出只占小头，静态规则+历史上下文才是大头。**

## 最有效的3件事（省50%+）

| 做法 | 怎么做 | 省多少 |
|-----|-------|-------|
| **1. 勤开新对话** | 解决完一个问题就新开，不要一个对话聊到底 | 30-50% |
| **2. 精简规则** | AGENTS.md < 200行，关掉不用的MCP/Skills | 20-40% |
| **3. 简单任务用小模型** | 改bug/写注释用GLM-5/DeepSeek-Flash | 60-80%（简单任务） |

## 模型选择速查表

| 任务 | 选什么模型 |
|-----|----------|
| 改typo、补全代码、解释报错 | GLM-5、DeepSeek-V4-Flash、Doubao-Seed-Code |
| 写函数、重构、解释代码 | GLM-5.1、Qwen3.5-Plus |
| 架构设计、疑难bug、复杂算法 | DeepSeek-V4-Pro、Kimi-K2.6、Qwen3.6-Plus |

## 提问技巧

❌ 不要说：
> "你好，麻烦帮我仔细看看这个代码有什么问题，谢谢你了"

✅ 应该说：
> "#file:auth.py 检查性能问题，直接给修改建议"

## 红线警告
- 一个对话超过20轮 → **立刻新开**
- AGENTS.md超过300行 → **立刻精简**
- AI连续3次试错没进展 → **立刻停止**
- 开启5个以上MCP → **关掉不用的**

## 快速配置（5分钟搞定）

去「设置」→「规则」→「全局规则」，添加：
```markdown
# Token节省规范
- 默认极简回答：先给结论，必要时再解释
- 除非我说"详细解释"，否则不做背景铺垫
- 列表优先，不写冗余修饰
- 代码修改直接给diff，不重复完整文件
```

## 反模式黑名单
- ❌ 规则越多越好 → 规则越多AI越笨，还越贵
- ❌ 一个对话用到底 → 历史越久，无效信息越多
- ❌ 永远用最贵模型 → 80%任务小模型足够
- ❌ 大段日志直接粘贴 → 先存文件用#引用
- ❌ Agent跑起来不管 → 死循环一次烧$1+
