# 常见问题FAQ

本章汇总参与Agent Plan共创计划的10个常见问题。如果你有其他问题，欢迎在官方社群提问。

---

## 一、参与门槛相关

### Q1：我必须是付费订阅用户才能参与共创吗？

**A**：不是必须，但**强烈推荐订阅**。

- 如果你只是分享观察、测评观点、使用心得，不实际调用API，非订阅用户也可以参与
- 但如果要做实际项目、写代码、搭Agent，必须订阅才能获得API Key和调用额度
- 订阅本身门槛不高，而且优质分享可以赢回套餐奖励，相当于"免费"使用

### Q2：我是新手，刚开始接触大模型，能参与吗？

**A**：完全可以，而且特别欢迎！

- 新手的踩坑记录对其他新手最有价值
- "我是怎么从零开始跑通第一个Demo的"这类内容非常受欢迎
- 不需要你是专家，真实的学习过程本身就是好内容
- 哪怕只是"我遇到了XX报错，折腾了2小时终于解决了"，也是有效贡献

### Q3：我不是开发者，不会写代码，能参与吗？

**A**：当然可以！

共创计划五大方向中很多都不要求写代码：
- 🔬 评测类：你可以做模型效果对比（用UI界面就行）
- 🎨 应用类：你可以做产品原型、设计自动化工作流
- 💬 心得类：分享使用感受、效率提升经验
- 🌱 实验类：各种脑洞尝试，不需要代码基础

非开发者的视角往往能发现开发者忽略的问题，社区非常需要多元的声音。

## 二、内容形式相关

### Q4：内容必须是长篇大论吗？一句话/一张截图也行？

**A**：完全可以！官方明确说过：

> 无需排版精美，无需结构完整。一段代码、一张截图、一段心得、一个问题都是有效贡献。

参考标准：
- ✅ "刚用Agent Plan的生图模型跑了个图，效果惊艳！[截图]" + 标签 → 有效
- ✅ "有人遇到过这个报错吗？[错误截图]在线等，挺急的" + 标签 → 有效
- ✅ 三句话说清一个小技巧 → 有效
- ❌ 只发"Agent Plan真好"没有任何具体内容 → 无效

### Q5：我可以发视频吗？可以发外部链接吗？

**A**：可以！

- 视频Demo、操作录屏非常受欢迎，直观展示效果
- GitHub/GitCode仓库链接、个人博客文章、公众号文章都可以发
- B站/抖音等视频平台链接也欢迎
- **重要提醒**：在外部平台发布的同时，一定要在群内也发一份并带标签，否则无法参与评审
- 建议在群内发一段简介+链接，方便大家快速了解内容

### Q6：我做失败了，效果不好，还好意思发吗？

**A**：必须发！失败的经验同样宝贵！

官方明确说：**"不成功的实验同样欢迎"**。原因：
1. 你踩过的坑可以帮其他人避开
2. 失败的尝试本身就是有价值的信息（"这个方向目前走不通"）
3. 真实的失败比虚假的成功更有社区价值
4. 很多重要的发现都是从"为什么不行"开始的

参考标题：
- 《一个失败的实验：我尝试XX，结果……》
- 《踩坑记录：XX方法不要试，我帮你们试过了》
- 《为什么我做的跨模态视频效果不好？求大佬指点》

## 三、评审与奖励相关

### Q7：评审标准是什么？我怎么知道自己能不能获奖？

**A**：评审标准非常朴素，核心是四个词：**真实、有用、有料、有心**。

1. **真实**：是不是你真的实践了？还是空谈/搬运？
2. **有用**：其他开发者看了能不能学到东西或少走弯路？
3. **有料**：有没有具体细节（代码、截图、参数、步骤）？
4. **有心**：有没有花一点心思整理，让别人容易看懂？

不需要追求完美，也不需要和别人比，每周都会选，这周没中下周继续。

### Q8：Small套餐和Medium套餐怎么区分？我怎么才能拿Medium？

**A**：简单来说：

| 维度 | Small（优质） | Medium（超优质） |
|------|--------------|-----------------|
| **内容完整性** | 有核心内容就行 | 结构完整，背景/步骤/结果/总结齐全 |
| **可复用性** | 有一定参考价值 | 代码/方法可以直接复用 |
| **深度** | 讲清"怎么做" | 讲清"怎么做"+"为什么这么做"+"踩了什么坑" |
| **影响力** | 对部分人有帮助 | 对广大开发者有普遍参考价值 |
| **Cookbook** | 不一定收录 | 通常会收录进Cookbook |

**冲击Medium的建议**：
- 内容尽量完整，不是零散的片段
- 如果有代码，考虑开源到GitHub
- 跨多个方向（既有测评又有代码又有Demo）更容易脱颖而出
- 跨模态全链路实践是第二期重点关注方向
- 沉淀成方法论、决策树、最佳实践这类可复用内容权重高

### Q9：一个人可以多次获奖吗？

**A**：可以多次获奖，但同一内容不重复获奖。

- 你可以每周都发内容，每周都有机会获奖
- 但同一个项目/同一篇文章不会重复发奖
- 持续贡献高质量内容的开发者会被社区记住
- Cookbook收录没有次数限制，多篇好文可以多篇收录

### Q10：奖励怎么发放？什么时候发？

**A**：按周发放，流程如下：

1. 每周初在社群公示上周获奖名单
2. 运营会通过社群私信联系获奖者
3. 发放套餐兑换码或直接为账号充值
4. Cookbook内容会联系作者确认后编辑发布

**注意事项**：
- 确保你在群内可以接收私信
- 如果公示后3天没收到联系，可以主动@群管理
- 套餐奖励是月卡，发放后即时生效
- 税费问题：虚拟产品奖励，不涉及个人所得税
