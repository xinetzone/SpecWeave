## 🔑 核心观点

1. **自托管保障安全**：代码、数据、API密钥全部运行在用户自己机器上，解决传统量化SaaS平台的数据安全与密钥信任问题
2. **MCP原生集成**：通过Agent Gateway让Cursor/Claude Code等AI助手直接操作平台能力，而非传统API包装
3. **双轨策略开发**：IndicatorStrategy（向量化快速研究）与ScriptStrategy（事件驱动实盘控制）并行，共享同一引擎
4. **全流程闭环**：从研究、回测、模拟盘到实盘的完整链路，支持多市场与Docker Compose一键部署
