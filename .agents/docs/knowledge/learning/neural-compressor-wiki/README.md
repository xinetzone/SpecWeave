# Intel Neural Compressor 模型压缩

> 本目录 README 由 `generate-readme.py` 自动生成，可根据需要补充概述和导航说明。

**Intel® Neural Compressor** 是 Intel 开源的 Python 模型压缩库，为 PyTorch、TensorFlow 和 JAX 三大主流深度学习框架提供统一的量化 API 接口。它支持静态量化、动态量化、仅权重量化（RTN/GPTQ/AWQ/AutoRound 等）、FP8 量化、SmoothQuant 等多种主流量化算法，并针对 Intel Xeon 处理器、Intel Gaudi AI 加速器、Intel GPU 等硬件平台进行了深度优化，能够在保持模型精度的同时显著降低模型大小、提升推理速度、减少内存占用。

本 Wiki 教程面向 AI 应用开发者、机器学习工程师、大模型研究者和性能优化工程师，系统性地覆盖了 Intel Neural Compressor 的核心概念、安装配置、快速上手、量化技术原理、API 使用、最佳实践与常见问题解答，帮助读者从零开始掌握模型压缩技术并在生产环境中高效部署量化模型。
