## 📝 前置知识

学习本教程前，建议具备以下基础知识：

- **Three.js** 基础：了解场景（Scene）、相机（Camera）、渲染器（Renderer）、网格（Mesh）等核心概念
- **JavaScript ES6+** 基础：掌握箭头函数、解构赋值、模块化、Promise/async-await 等语法
