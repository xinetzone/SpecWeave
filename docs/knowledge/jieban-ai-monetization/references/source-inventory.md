## 三、采集缺口（未取证项，限制结论强度）

| 缺口 | 影响 | 计划取证方式 |
|---|---|---|
| 四群真实人数、活跃度、消息量、退群率 | 无法验证「客厅」机制的实际运转密度 | A4 类手工记录；不公开、不进仓 |
| 成员画像与 AI 技能基线分布 | P1-P5 的人群占比未知，Hello World 适用性未测 | 首月记录提交情况侧面观察，不做问卷采集（守 F-022） |
| 任何成员的真实变现到账数据 | 「飞轮能带来变现」无实证 | monetize 工作台 local 到账记录（个人侧）；90 天只核对有无，不公开金额 |
| 网站访问量、来源、案例页转化 | 声誉域→信任域的吸引环节无数据 | A4 来源问询；站点侧暂不埋点（一期零收集纪律） |
| 公约第四条的历史执行案例数 | 机械清单相对人肉判读的改进幅度无法对比 | A6 上线后按新口径记录，与历史不做严格对照 |
| F-026/F-028 类表述的因果效力 | 「先过好生活→对的结果出现」是社群自述，非对照实验结论 | 永久按「社群观察表述」引用，不升级为因果断言 |
