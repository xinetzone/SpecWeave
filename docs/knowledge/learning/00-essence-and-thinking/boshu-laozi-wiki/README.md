# 帛书老子 Wiki 教程

> 帛书《老子》——1973 年长沙马王堆三号汉墓出土的《老子》甲、乙本，是目前传世本之外最重要的《老子》早期文本。本教程基于马王堆帛书研究的公共领域学术知识，系统讲解其出土背景、版本体系、核心概念、注读方法论与可复用模式。教程源于对《帛书老子注读》一书的学习目标，因原 epub 为掌阅 DRM 加密无法读取正文，改以公共领域知识生成。

## 教程定位

- **主题**：中国哲学经典（道家）· 版本学 · 出土文献
- **方法论**：seven-concepts 场景4（知识沉淀）R→I→E→V→C 链路
- **事实基础**：F-001~F-021（见 `.trae/specs/boshu-laozi-wiki/facts.md`）
- **质量门**：G1 事实 ≥15 条、G2 洞察 ≥3 条、G3 模式 ≥2 个、V 对抗审查、G4 原子提交

## 学习路径

适合初次接触帛书老子的读者，建议按 00→07 顺序阅读；熟悉版本学的读者可直接从 02 章开始；想掌握方法论的可重点阅读 04/06 章。
