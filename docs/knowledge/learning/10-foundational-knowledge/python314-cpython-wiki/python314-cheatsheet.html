🔓 自由线程（无 GIL）PEP 703/779
# 启用方式
# 1. 使用自由线程二进制
python3.14t script.py

# 2. 运行时环境变量
PYTHON_GIL=0 python3.14 script.py
PYTHON_GIL=1 python3.14t script.py  # 强制启用GIL

# 检测运行模式
import sys
if hasattr(sys, '_is_gil_enabled'):
    ft = not sys._is_gil_enabled()
  • 单线程开销：约 5-10%
  • 多线程扩展：接近线性（4核≈3.5x）
  • 五大组件：QSBR · BRC · 关键区段 · Parking Lot · mimalloc
C 扩展需标记 Py_MOD_GIL 或适配后标记 Py_MOD_FREE_THREADED
⚡ Copy-and-Patch JIT 实验性
# 启用 JIT
PYTHON_JIT=1 python3.14 script.py

# 构建时启用
./configure --enable-experimental-jit

📝 t-Strings 模板字符串 PEP 750
# t-strings 返回 Template 对象
name = "World"
t = t"Hello, {name}!"
str(t)  # "Hello, World!"

# 逐段访问（安全SQL/HTML）
from string.templatelib import Template, Interpolation
for part in t:
    if isinstance(part, str): ...  # 静态文本
    else: part.value, part.expr  # 插值
  • 对比 f-strings：延迟求值、可拦截、可转义
  • 安全场景：SQL 参数化 · HTML 转义 · i18n · DSL
🔄 延迟注解 PEP 649/749
# 无需 __future__ annotations！
# 前向引用自然工作
class Node:
    def __init__(self, next: Node|None=None):
        self.next = next

import annotationlib
from annotationlib import Format
ann = annotationlib.get_annotations(
    Node, format=Format.VALUE)
# VALUE=真实类型, STRING=字符串, FORWARDREF=对象
from __future__ import annotations 已软弃用，直接删除即可！

codecs.open()弃用open(encoding=...)
argparse.FileType弃用pathlib.Path + open()

asyncio.ChildWatcher移除不再需要
ast.Num/Str移除ast.Constant
