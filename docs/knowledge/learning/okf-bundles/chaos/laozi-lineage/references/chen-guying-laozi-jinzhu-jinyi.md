# 老子今注今译

《老子今注今译》由陈鼓应著，2003年由商务印书馆初版，2016年5月出版修订版（参照简帛本最新修订版），是当代流传最广的《老子》注译本之一[^self]。

## 学术价值

陈鼓应是当代道家研究的代表性学者，其《老子》注译工作始于1970年代。本书在台湾商务印书馆1970年版《老子今注今译》的基础上，经数十年多次修订而成。2016年修订版参照了马王堆帛书本、郭店楚简本等出土文献，对原文校勘、注释和引述作了大量修正。

全书结构清晰，每章包括"注释""今译""引述"三部分：注释部分博采众长，训诂字词、考证名物；今译部分以现代汉语准确传达原文意蕴；引述部分则从哲学史角度进行义理阐发。书后附录"历代老子注书评介"和"老子校定文"，系统梳理了主要传世版本和出土文献的文本差异。陈鼓应还与赵建伟合作撰写《周易今注今译》，并主编《道家文化研究》辑刊，在道家文献整理与研究领域影响深远。

## 适用范围

本书适用于《老子》文本阅读、哲学思想阐释、简帛本与传世本比较等研究领域，是研究者和普通读者都可信赖的注译本。在本 bundle 中，本书被 [manuscripts/](../manuscripts/index.md) 和 [variants/](../variants/index.md) 目录下的相关概念作为参考注译来源引用。
