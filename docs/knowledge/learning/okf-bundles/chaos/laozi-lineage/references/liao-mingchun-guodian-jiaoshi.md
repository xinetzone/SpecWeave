# 郭店楚简老子校释

《郭店楚简老子校释》由廖名春著，2003年6月由清华大学出版社出版，是郭店楚简《老子》甲、乙、丙三组文本的系统校释著作[^self]。

## 学术价值

廖名春长期从事出土文献与先秦思想史研究，本书是在其博士学位论文基础上修订而成。全书以《郭店楚墓竹简》（文物出版社1998年版）的释文和图版为底本，逐章逐简进行校释，每章包括"释文""校释"和"讨论"三个部分。释文部分尽量吸收最新考释成果；校释部分对每一字词的训释广引诸家之说，并加按语判断；讨论部分则从思想史角度分析简本与传世本的差异及其意义。

本书的主要贡献在于：第一，对简本《老子》的文字释读提出了多处新见，如"大器曼成"的"曼"当读为"慢"（而非"免"），"执之者失之"的"执"当读为"设"等；第二，系统比较了简本与帛书本、传世本的文本层次，提出简本《老子》是一个节抄本而非完整本的观点；第三，对《老子》成书年代和儒道关系等重大问题提出了新的论证。书后附有简本《老子》与各本对照表和参考文献索引，便于检索。

## 适用范围

本书适用于郭店楚简《老子》文字考释、《老子》成书过程研究、先秦儒道关系研究等领域。在本 bundle 中，本书被 [manuscripts/](../manuscripts/index.md) 目录下的郭店楚简本概念和 [variants/](../variants/index.md) 目录下的异文概念引用，是对彭浩《郭店楚简老子校读》的重要补充。
