# 北京大学藏西汉竹书（贰）

《北京大学藏西汉竹书（贰）》收录北京大学于2009年初接受捐赠从海外抢救回归的西汉竹书中的《老子》卷，由北京大学出土文献研究所编纂、韩巍独立整理，2012年12月由上海古籍出版社出版[^self]。

## 学术价值

北大汉简《老子》是继马王堆帛书甲本、乙本和郭店楚简本之后出土的第四个简帛《老子》古本，也是目前保存最完整的简帛《老子》古本。现存竹简221枚，5300余字，残缺仅60余字。其抄写年代约在西汉中期（武帝前后），文本形态介于帛书本与传世本之间。

本书的重要发现包括：两枚竹简背面分别写有"老子上经"和"老子下经"篇题，这是《老子》书名在出土简帛中的首次发现；全书分77章，与传世81章本不同，为探讨古本《老子》分章问题提供了宝贵资料；书后附有《老子》主要版本全文对照表，极大便利了比较研究。韩巍在附录中系统论述了西汉竹书《老子》的文本特征和学术价值。

## 适用范围

本书适用于西汉简帛《老子》文本研究、《老子》分章与篇序演变研究、汉代隶书与书法研究等领域。在本 bundle 中，本书被 [manuscripts/](../manuscripts/index.md) 目录下的北大汉简本概念和 [variants/](../variants/index.md) 目录下的分章异文概念引用。
