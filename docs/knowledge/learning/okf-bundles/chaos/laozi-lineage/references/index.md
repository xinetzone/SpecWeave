# 信源登记簿（References）

本目录收录《老子》传本源流谱系知识包所依据的学术信源，共 14 条。

## 信源列表

* [高明《帛书老子校注》](gao-ming-boshu-jiaozhu.md) - 帛书甲乙本最权威的校注本，中华书局 1996
* [荆门市博物馆《郭店楚墓竹简》](guodian-chumu-zhujian.md) - 郭店楚简正式发掘报告，文物出版社 1998
* [国家文物局古文献研究室《马王堆汉墓帛书（壹）》](mawangdui-hanmu-boshu-yi.md) - 帛书老子甲乙本最早整理本，文物出版社 1980
* [湖南省博物馆等《长沙马王堆汉墓简帛集成》](changsha-mawangdui-jianbo-jicheng.md) - 马王堆简帛最新集成整理，中华书局 2014
* [北京大学出土文献研究所《北京大学藏西汉竹书（贰）》](beida-han-jian-er.md) - 北大汉简老子正式报告，上海古籍出版社 2012
* [楼宇烈《王弼集校释》](lou-yanglie-wangbi-jiaoshi.md) - 王弼注本权威校释，中华书局 1980
* [饶宗颐《老子想尔注校证》](rao-zongyi-xianger-jiaozheng.md) - 想尔注唯一校证本，上海古籍出版社 1991
* [王卡《老子道德经河上公章句》](wang-ka-heshanggong-zhangju.md) - 河上公注现代点校本，中华书局 1993
* [陈鼓应《老子今注今译》](chen-guying-laozi-jinzhu-jinyi.md) - 参照简帛本的权威今注今译，商务印书馆 2016
* [彭浩《郭店楚简老子校读》](peng-hao-guodian-jiaodu.md) - 郭店楚简老子专门校读，湖北人民出版社 2000
* [Robert G. Henricks, Lao-Tzu: Te-Tao Ching](henricks-lao-tzu-te-tao-ching.md) - 帛书老子英文权威译注，Ballantine 1989
* [廖名春《郭店楚简老子校释》](liao-mingchun-guodian-jiaoshi.md) - 郭店楚简老子系统校释，清华大学出版社 2003
* [王利器《文子疏义》](wang-liqi-wenzi-shuyi.md) - 今本《文子》权威整理本，中华书局 2000（方法论迁移验证用）
* [河北省文物研究所定州汉简整理小组《定州西汉中山怀王墓竹简〈文子〉释文》](dingzhou-zhujian-wenzi.md) - 八角廊汉简《文子》首次系统公布，《文物》1995年第12期（方法论迁移验证用）
