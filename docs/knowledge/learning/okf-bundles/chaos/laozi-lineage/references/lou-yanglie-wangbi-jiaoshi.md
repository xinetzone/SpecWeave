# 王弼集校释

《王弼集校释》由楼宇烈校释，1980年由中华书局出版，是魏代玄学家王弼（226—249）著作的权威整理本[^self]。全书汇辑校释了王弼的《老子道德经注》《老子指略》《周易注》《周易略例》《论语释疑》等著作，并附有《何劭王弼传》等相关资料。

## 学术价值

王弼《老子道德经注》是传世本《老子》最重要的注本之一，也是魏晋玄学的奠基之作。王弼本以"以无为本""举本统末"为哲学纲领，对《老子》的义理阐释影响深远，后世通行本多以王弼本为底本。楼宇烈的校释以明华亭张之象本（清浙江书局重刻本）为底本，参校多种版本，对文字讹误详加勘正，并汇集了清代以来的校勘成果。

本书初稿完成于1964年，楼宇烈在十余年间不断增补材料和研究体会，最终形成这一享有盛誉的王弼集整理本。中华书局后来又从中析出《老子道德经注校释》和《周易注（附周易略例）》分别出版，累计销量超过60万册，是研究王弼、魏晋玄学和传世本《老子》的必读基本参考书。

## 适用范围

本书适用于王弼哲学研究、魏晋玄学研究、传世本《老子》文本校勘等领域。在本 bundle 中，本书被 [manuscripts/](../manuscripts/index.md) 目录下的王弼注本概念引用，作为传世本系统的基准文本。
