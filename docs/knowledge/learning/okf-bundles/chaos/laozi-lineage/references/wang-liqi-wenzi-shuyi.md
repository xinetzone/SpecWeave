# 文子疏义

王利器撰《文子疏义》是今本《文子》（道教尊号《通玄真经》）的权威现代整理本，收入中华书局"新编诸子集成"丛书，2000年9月初版[^self]。

## 学术价值

本书以明《正统道藏》所收十二卷本为底本，参校唐写本、宋元刻本及类书引文，疏通文字、考辨史实，吸收俞樾、王叔岷等学者校勘成果。书后附有关《文子》著录与序跋资料，是研究今本《文子》文本面貌及其与定州汉简本、敦煌本关系的基础参照。

定州八角廊西汉中山怀王墓竹简《文子》于1995年公布后，学界以简本与今本比勘，发现两者在《道德》篇等部分有对应文字，但异文、佚文与章句差异甚多，今本经历代增益窜乱。《文子疏义》为这一比较提供了可靠的今本读本。

## 适用范围

本书适用于《文子》文本校勘、黄老道家思想研究、出土简本与传世本对勘等领域。在本 bundle 中，本书作为方法论迁移验证（传本源流重建法施于《文子》）的今本依据。
