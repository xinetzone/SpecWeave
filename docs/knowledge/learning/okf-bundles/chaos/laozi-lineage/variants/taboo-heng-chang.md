# 恒/常避讳异文

## 异文对照

"恒"字在《老子》中既是常用副词，又是核心哲学概念（"恒道""恒名"）。今本第一章"道可道，非常道"、第四十六章"故知足之为足，此恒足矣"等处，各传本用字如下：

| 传本 | 文字 | 避讳情况 | 说明 |
|---|---|---|---|
| 郭店楚简本 | 恒 | 不避汉讳 | 相当于今本第四十六章"知足之为足，此恒足矣"作"恒"；简本无第一章"道可道"内容[^liao-mingchun-guodian-jiaoshi][^peng-hao-guodian-jiaodu] |
| 帛书甲本 | 恒 | 不避文帝讳 | 第一章"道可道也，非恒道也"、"名可名也，非恒名也"均作"恒"[^gao-ming-boshu-jiaozhu] |
| 帛书乙本 | 恒 | 不避文帝讳 | 同甲本作"非恒道也""非恒名也"，未改作"常"[^gao-ming-boshu-jiaozhu] |
| 北大汉简本 | 恒 | 不避文帝讳 | 简本"恒"字仍见使用，未见对"恒"字的系统改易[^beida-han-jian-er] |
| 河上公本 | 常 | 已讳 | 第一章作"道可道，非常道；名可名，非常名"[^gao-ming-boshu-jiaozhu] |
| 王弼本 | 常 | 已讳 | 同河上公本作"非常道""非常名"，为通行本标准面貌[^gao-ming-boshu-jiaozhu] |
| 想尔注本 | 常（待核） | 待核 | 残卷起第三章，第一章已佚；所存道经部分"常"字用法与五千文系统一致，具体避讳情形待逐字核校[^gao-ming-boshu-jiaozhu] |
| 傅奕本 | 常（待核） | 待核 | 唐代传世本，第一章作"常"；其余章节是否保留个别"恒"字，尚待逐章核校[^gao-ming-boshu-jiaozhu] |

## 断代/谱系意义

- **现象**：郭店楚简本、马王堆帛书甲本与乙本、北大汉简本均用"恒"字；河上公本、王弼本等传世本作"常"[^gao-ming-boshu-jiaozhu][^beida-han-jian-er]。
- **根因**：汉文帝刘恒讳，制度性改"恒"为"常"[^mawangdui-hanmu-boshu-yi]。
- **影响**：甲、乙本均用"恒"字，证明两本抄写均早于文帝即位（前180）或不受其避讳约束，这是帛书本早出的关键证据之一，也是甲、乙本抄写年代下限判断的重要依据[^mawangdui-hanmu-boshu-yi]。"恒/常"在《老子》中兼具副词与哲学概念双重身份，"恒道""恒名"避讳改作"常道""常名"，对后世哲学解读产生深远影响："恒"强调永恒、不变之本体义，"常"则引申出常理、常则、寻常等含义，概念重心有所偏移[^gao-ming-boshu-jiaozhu]。
- **建议**：避讳断代须结合"邦/国"讳字作双重验证。甲本不避"邦"亦不避"恒"，乙本避"邦"而不避"恒"，两本讳字组合不同，恰可对应高祖至惠帝与惠帝至吕后两个抄写时段，此即多重讳字交叉断代的典型案例[^mawangdui-hanmu-boshu-yi]。哲学解读层面，引用"常道""常名"时应注意其本字作"恒"，不宜以后世"常"字含义覆盖"恒"的本体义。

## 争议与不确定性

- **观点一：甲乙本均用"恒"，证明抄写于文帝即位之前**。学界主流据甲乙本不避"恒"讳，结合乙本已避"邦"讳，推定乙本抄写于高祖称帝之后、文帝即位之前（约前194—前180），甲本更早[^mawangdui-hanmu-boshu-yi]。
- **观点二：文帝讳施行时间与地区执行程度存在差异，不可一概而论**。避讳诏令的颁布与实际执行之间或有时滞，长沙国地处南方边远地区，避讳执行未必严格同步于中央；北大汉简本推定抄写于武帝时期却仍用"恒"字，即为避讳执行弹性的一例[^beida-han-jian-er]。"恒"字在非讳语境（如人名、地名、专名）中的存废亦需逐字考察，不能将所有"恒"字均视为避讳判断依据。
- **哲学概念层面的争议**。部分学者强调"恒道"改"常道"不只是文字替换，更牵动《老子》本体论诠释；另有学者认为"恒""常"在汉语中词义本有重叠，传世本"常道"在汉语思想史上已形成独立解读传统，不宜简单判为"误改"[^gao-ming-boshu-jiaozhu]。
