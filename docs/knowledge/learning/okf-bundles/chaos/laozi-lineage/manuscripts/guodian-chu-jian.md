# 郭店楚简本《老子》

## 基本信息

- **出土时间**：1993年10月，出土于湖北省荆门市沙洋县郭店一号楚墓[^guodian-tomb]
- **抄写年代**：约公元前300年（战国中期偏晚），系据墓葬形制与器物组合的考古类型学断代，并非直接纪年证据[^guodian-chumu-zhujian]
- **材质与书体**：竹简，以楚系文字书写[^guodian-chumu-zhujian]
- **篇幅**：甲、乙、丙三组节选本，共71枚简，现存约1750字（含补字约2000字），约当今本《老子》篇幅的五分之二，并非全本[^guodian-chumu-zhujian]
- **公布时间**：1998年文物出版社出版《郭店楚墓竹简》正式公布[^guodian-chumu-zhujian]

## 避讳特征

郭店楚简下葬于战国中期偏晚的楚墓，早于汉代，简文不避汉高祖刘邦、汉文帝刘恒等汉代帝讳[^liao-mingchun-guodian-jiaoshi]。简中"邦"等字多见，未经汉代避讳改字，保留了先秦文本的用字面貌[^peng-hao-guodian-jiaodu]。

## 文本特征

- **不分道经、德经**：简本无"道经""德经"之分，甲、乙、丙三组各自独立，三组之间并无统一的篇序[^peng-hao-guodian-jiaodu]
- **节选性质**：三组均为节选，内容互不重复，部分学者认为系三次独立摘抄，亦有学者认为三组可能出自同一全本的选录，学界尚无定论[^liao-mingchun-guodian-jiaoshi]
- **文字差异**：简本文字与传世本差异较大。例如相当于今本第十九章"绝圣弃智""绝仁弃义"处，简甲本作"绝智弃辩""绝伪弃诈"，文句与思想倾向均与传世本有别[^liao-mingchun-guodian-jiaoshi]
- **楚系用字**：简文保留大量楚系文字特有的字形与通假写法，具有鲜明的地域文字特征[^guodian-chumu-zhujian]

## 整理与出版

- 1993年出土后，由荆门市博物馆等单位组织整理拼复[^guodian-chumu-zhujian]
- 1998年5月，文物出版社出版《郭店楚墓竹简》，刊布全部图版、释文与注释[^guodian-chumu-zhujian]
- 此后彭浩《郭店楚简老子校读》（湖北人民出版社2000年版）、廖名春《郭店楚简老子校释》（清华大学出版社2003年版）等专著相继问世，对简本作了系统校读与训释[^peng-hao-guodian-jiaodu][^liao-mingchun-guodian-jiaoshi]

## 谱系位置

郭店楚简本《老子》是现存最早的《老子》文本实物，抄写年代较马王堆帛书《老子》早约一个半世纪[^guodian-chumu-zhujian]。该本处于《老子》文本形态尚未定型的阶段：节选流传、无篇名划分、文字近古，为探讨《老子》文本的早期面貌及定型过程提供了关键实物材料[^liao-mingchun-guodian-jiaoshi]。

相关考古语境见[郭店一号楚墓](../archaeology/guodian-tomb.md)。其后的完整传本可参见[马王堆帛书甲本](./mawangdui-jia.md)、[马王堆帛书乙本](./mawangdui-yi.md)与[北大汉简本《老子》](./beida-han-jian.md)。
