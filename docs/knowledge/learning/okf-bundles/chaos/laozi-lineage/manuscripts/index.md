# 传本概念（Manuscripts）

本目录收录 8 个《老子》主要传本概念。

## 概念清单

* [郭店楚简本《老子》](guodian-chu-jian.md) - 战国中期偏晚郭店一号楚墓出土节选本，现存最早《老子》文本实物
* [马王堆帛书《老子》甲本](mawangdui-jia.md) - 马王堆三号汉墓出土帛书甲本，古隶，不避汉高祖讳
* [马王堆帛书《老子》乙本](mawangdui-yi.md) - 马王堆三号汉墓出土帛书乙本，成熟汉隶，避汉高祖讳
* [北大汉简本《老子》](beida-han-jian.md) - 北京大学藏西汉竹书本，现存最完整简帛古本，77章
* [河上公《老子道德经章句》](heshanggong-zhu.md) - 旧题汉河上公撰，八十一章，古本系统，道教重要传本
* [《老子想尔注》](xiang-er-zhu.md) - 敦煌六朝写本，早期天师道《老子》注残本
* [王弼《老子道德经注》](wangbi-zhu.md) - 魏王弼撰，魏晋玄学化文本，后世通行本之祖
* [傅奕校定本《道德经古本篇》](fuyi-jiao.md) - 唐傅奕校定，文字古奥，古本系统传世本
