# OpenMAIC 核心功能详解

OpenMAIC 提供三大核心功能，分别对应教育场景中最耗时的三个环节：备课、自学规划、论文解读。

## 功能一：课本 → 互动课程

这是 OpenMAIC 最具标志性的功能。用户上传任意 PDF 教材后，Agent 自动完成以下全流程：

### 自动化流程

1. **材料读取**：调用工具读取上传的 PDF 内容
2. **课程规划**：根据教材结构规划每节课的讲解内容
3. **课件生成**：生成带交互元素的 PPT 课件
4. **测验编写**：为每节课编写课后测验
5. **角色配音**：创建模拟教室环境（如 1 位老师 + 2 位同学），并为角色配音

### 课件特性

- 每节课为独立 PPT，配有老师语音讲解
- 重点内容有聚光效果
- 难点内容有动图演示
- 支持通过自然语言指令修改课件细节（如调整数轴刻度、间距、字号等）

### 输出格式

- 导出 PPT
- 导出教学资源包
- 导出带 AI 配音和字幕的视频（可用于离线学习或分享给他人）

### 实测案例

文章记录了一个七年级数学上册的实测案例：用户上传数学 PDF，要求规划一周课程（每节含测验和互动），Agent 在数分钟内完成七节课的完整课件生成，包括 PPT、讲解音频、测验题，并可导出视频。

> **事实溯源**：F-009 ~ F-016

## 功能二：技术学习路线规划

针对开发者和技术学习者，OpenMAIC 支持定制从入门到精通的学习路径。

### 工作流程

1. 用户上传开源书籍（如《深入理解 AI Agent》）
2. Agent 询问学习目标、编程基础、每周可投入时间
3. 生成定制化学习路线：基础入门 → 上下文工程 → 记忆与 RAG → 多 Agent 协作 → 构建 Agent 应用
4. 每节课包含：核心总结、代码演示、AI 语音讲解

### 适用场景

- 编程语言学习
- 框架/库的系统性掌握
- 技术领域转型的自学规划

> **事实溯源**：F-017 ~ F-018

## 功能三：论文通俗解读

OpenMAIC 可调用工具获取论文全文，并用通俗语言解释核心内容。

### 工作流程

1. 用户提供论文 URL 或上传论文 PDF
2. Agent 调用工具获取论文内容
3. 用比喻和通俗语言解释专业概念（如将大模型比作发动机、Agent 比作司机）
4. 可选：使用"费曼学习法 Skill"生成讲解课件，供向他人复述使用

### 特色能力

- 全程使用日常语言，不堆砌术语
- 专业术语首次出现时用比喻解释
- 生成的课件可用于"讲给别人听"的练习，以验证理解深度

> **事实溯源**：F-018

## 功能对比总结

| 功能 | 输入 | 输出 | 核心差异 |
|------|------|------|---------|
| 课本转课程 | PDF 教材 | PPT + 音频 + 测验 + 视频 | 从静态材料到多模态课程 |
| 学习路线规划 | 书籍/主题 | 结构化学习路径 + 课件 | 从分散自学到系统路径 |
| 论文解读 | 论文 URL/PDF | 通俗讲解 + 可选课件 | 从专业阅读到通俗理解 |
