# 09 · 边界与效力

> 回到 [知识包首页](../index.md)
>
> **本页性质**：边界与效力登记，**不承载任何正向方法**。正向规则见 [01](01-judgment-inputs.md) 至 [05](05-exit-judgment.md)，误判清单见 [06](06-misjudgment-redlines.md)。

## 1. 非决定论：测评不得进判据栏

性格 / 天赋类测评（含 MBTI、RIASEC、CliftonStrengths、VIA、grit 等）具科学效度争议，属**非决定论**工具，**不得作为变现方向判定依据**，仅可作自我反思的启发式参照（源包 F-041，本包转述为 F-033）。

- 两方口径须**并列**呈现，禁单取一方作结论（MBTI 信效度争议正反两方均已登记，F-037）；
- RIASEC 六类型适用于**兴趣**而非**能力**匹配——「享受某事 ≠ 擅长某事」（F-039）；
- 相关性描述（如 congruence 预测力 modest）不得读作因果预测（F-039）。

## 2. 非承诺：不提供任何收益或成功率

- 本模型与源知识包中一切收益 / 规模类表述均为**原作者在其限定语境下的主张或样本观察**，非对任何人的收益承诺（F-034）；
- 判断者**不得**据本模型产出「能赚多少」「成功率多高」「多久见效」类表述；
- 凡出现「必然 / 保证 / 一定 / 只需……」的收益表述，须回查是否为原文前提被剥离（F-036 证伪纪律）；
- 源包登记的收益类数字（1000 True Fans 算式、$100 Startup 样本等）存在单源、作者口径或选择偏差未披露等问题，**不得作为预期收益依据**，索引见源包 [核验报告](../../../../projects/awesome-okf-xs/doc/bundles/sheke/industry/monetization-direction/references/verification.md) 第 5 节。

## 3. 相关性 ≠ 因果

- 禁止把「某人用某路径成功」转述为「该路径带来成功」——个案不具备因果证据地位（F-041）；
- 刻意练习对**职业域**绩效变异的解释比例为 <1%（Macnamara 2014 元分析），禁把该数字读作「练习无效」（F-040）；
- 本模型自身的洞察（I-1~I-4）中，凡根因不在源知识包内可得者，均已如实标注「本包未给出，属待研究方法问题」——**不得**把本包的结构性描述读作实证因果。

## 4. 判断者的角色边界

判断者在五门链中**只承担两类工作**：

| 可以做 | 不可以做 |
|---|---|
| 逐项核验判据形态（是否为数值、等级或已发生行为） | 替被帮者填判据 |
| 对信号做三级分级（强 / 弱 / 无效） | 替方向背书（「这个能做」） |
| 按各门规则给出档位结论（不可判 / 三档准入 / 三档判定） | 给出方向结论本身（方向只由被帮者的行为证据承担，F-044） |
| 指出缺项并约定复判时点 | 用「不可判」推诿——缺项须给出具体补采动作 |
| 提示误判红线并纠正表述 | 给对方贴类型标签或作人格评判 |

> **一句话**：判断者交付的是**判据审核 + 档位判定**，不是方向授权。「不可判」是合法结论档，但必须附带可执行的补采动作，不得作为敷衍。

## 5. 模型的效力边界

- **未经实证**：本模型为方法设计，未做任何真实陪跑的效果验证；五门链是否真的优于「凭经验判断」，本包**未验证**。
- **阈值均为参数**：五门链中的所有数值（如 R3 的 ≥3 分、观察期 30 天、判据条数门槛）均为**方法参数**〔参数〕（F-045~F-052），非实证结论；调整参数须留痕。
- **单一信源**：本包唯一事实源为同簇 OKF 知识包（82 条 F 事实），未引入外部新信源，也未重新联网核验；源包的核验限制（部分著作未获官方免费原文页、采用二手替代并标降级）同样构成本包的效力上限。
- **继承源包的口径限制**：源包已登记的 10 组口径对照（如职业锚 5 类 / 8 类、MVP 定义、JTBD 发表渠道）在本包同样适用，不得混用（F-038）。

## 6. 不适用范围

本模型**不适用于**以下场景，用于这些场景即超出其设计边界：

- 对他人作**人格或能力评判**、贴类型标签；
- 预测收益、成功率、见效时间；
- 投资、财税、法律建议；
- 心理诊断或心理健康干预；
- 强迫他人接受判定（判定或退出结论均须由本人决定，判断者只提供判据与档位）；
- 不属「基于本人情况的方向性判定」的一般性决策（迁移见 [00 总览](00-overview.md) §3，迁移时须重设各门判据清单）。
