# 05 · 门 4 退出/迭代判断

> 回到 [知识包首页](../index.md)
>
> **本门只回答一个问题**：**go 之后，什么时候该继续、什么时候该改假设、什么时候该停？**
>
> **本门的最强纪律**：观察期与退出条件必须在**启动之前**写定登记；事后合理化（「再多等等」「再试一次」）不构成继续的理由。

## 1. 本门在五门链中的位置

门 3 判定为 `go`（或补验后 go）才进入本门。本门的输出不改变方向本身，只决定该方向的**投入节奏与终止点**；本门完成后交付判定卡与首个 30 天行动清单。

## 2. 输入项

| 判据 | 用途 |
|---|---|
| 门 3 的方向判定卡与依据信号行 | 判定基线（必须逐行对齐，不得另起口径） |
| 观察期登记值（天数 + 登记日期） | 退出判定 |
| 强信号出现情况（有无、何时、来源） | 继续 / 退出 |
| 弱信号趋势（是否增长） | 退出判定 |
| 未验证假设清单（来自门 3 的「未验证假设」） | 迭代判定 |
| 资源约束四栏（P1~P4，含硬约束） | 行动拆解与损害上限核对 |

## 3. 观察期与退出条件的登记

| 项 | 要求 | 说明 |
|---|---|---|
| **观察期** | 启动前写定天数与起算日期；本方法建议 30 天〔参数〕 | 源包 [08 §6](../../../../projects/awesome-okf-xs/doc/bundles/sheke/industry/monetization-direction/concepts/08-decision-and-launch-method.md) 建议为 30 天，属设计参数，非实证结论 |
| **退出条件** | 启动前写定：观察期内强信号未出现且弱信号无增长趋势 | 条件须可机械核对（有信号记录表即能核对） |
| **迭代条件** | 启动前写定：出现新的「最大不确定性」假设被证伪，但强信号仍存在 | 迭代不等于重启，只重写假设 |
| **回退路径** | 启动前写定：退出后回到候选池，启用**次优候选卡** | 不重新从零开始（避免整轮重做） |
| **损害上限** | 与 P2 可承受损失上限对齐 | 触达上限即暂停并回退，不因进度改上限 |

## 4. 三档判定

| 档位 | 触发条件 | 处置 | 须回到哪一门 |
|---|---|---|---|
| **继续** | 观察期内出现强信号，且无新的证伪假设 | 按首个 30 天行动推进到下一阶段；若延长观察期，须**重新登记**延长后的观察期（不得口头顺延） | — |
| **迭代** | 新的「最大不确定性」假设被证伪，但强信号仍存在 | 重写假设 + 补一小型实验（沿用原实验形态或换更贴合的形态） | [门 3](04-direction-judgment.md) |
| **退出** | 观察期内强信号未出现且弱信号无增长趋势 | 停止该方向；回候选池启用**次优候选卡**；退回 [门 2](03-path-judgment.md) 重过门槛 | [门 2](03-path-judgment.md) |

**判定规则**：
1. 判定须逐行对齐门 3 判定卡的信号行，**不得另起口径**；
2. 观察期未登记或事后改动的，本次退出判定无效，须先补登记再判；
3. 触达可承受损失上限时，无论信号如何，一律先暂停并回退。

## 5. 输出：退出/迭代判定卡

```text
退出/迭代判定卡
├─ 方向：＿＿＿（门 3 判定卡编号）
├─ 观察期：＿＿ 天 ｜ 起算日：＿＿ ｜ 登记日：＿＿
├─ 强信号：有 / 无（来源：＿＿）
├─ 弱信号趋势：增长 / 持平 / 下降
├─ 未验证假设：＿＿＿
├─ 判定档：继续 / 迭代 / 退出
├─ 依据信号行：逐行引用（与门 3 判定卡一致）
├─ 处置：＿＿＿＿＿
└─ 回退路径（退出时必填）：启用次优候选卡 ＿＿＿，回门 2 重过门槛
```

## 6. 完成本门的达标条件

- [ ] 观察期、退出条件、迭代条件、回退路径均在启动前登记，登记日期可查。
- [ ] 判定逐行对齐门 3 判定卡的信号行。
- [ ] 退出档已写明「启用次优候选卡」并注明回到门 2。
- [ ] 触达可承受损失上限的情形已单独处置。
- [ ] 输出中未出现任何收益或成功率的预期表述。

## 7. 边界与反模式

| 反模式 | 问题 | 纠正 |
|---|---|---|
| 事后合理化 | 「再多等两周看看」无登记依据 | 延长观察期须重新登记、写定新退出条件 |
| 把退出读作失败判决 | 退出被读作「此人不行」 | 退出是对**假设**的判定，不对人下结论；回候选池换候选 |
| 观察期未登记 | 没有终止点，方向长期悬置 | 启动前登记观察期（F-051〔参数〕） |
| 退出后从零重来 | 丢掉已有候选池，重新盘点 | 启用次优候选卡，只重过门槛（F-051〔参数〕） |
| 因沉没成本改上限 | 触达损失上限后上调上限 | 上限为硬约束，触达即暂停回退 |
| 借观察期出方向背书 | 在判定卡里写「该方向只是慢一点」 | 判定语汇限定为三档 + 依据信号行 |
