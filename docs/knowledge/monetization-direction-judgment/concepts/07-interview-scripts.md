# 07 · 判断者提问脚本

> 回到 [知识包首页](../index.md)
>
> **脚本的两条铁律**（源自源知识包 Mom Test 口径，F-010、F-029）：
> ① **只问过去行为，不问未来承诺**——「你上次遇到这个问题时是怎么处理的」远优于「你会不会买」；
> ② **不替对方答、不做评判式追问**——判断者的任务是采集判据，不是说服对方。
>
> 本页提供的是**判断者侧**的采集脚本骨架；被帮者自填的表格见 [08 自填工具](08-self-assessment-tools.md)；完整 Mom Test 十问脚本在源知识包 `examples/03-validation-experiment-template.md`，本包不复制。

## 1. 五层问句

### 层 0 · 判据采集（对应 [门 0](01-judgment-inputs.md)）

| 判据 | 问句 | 合格回答的形态 |
|---|---|---|
| P1 时间 | 「过去一个月，你每周实际能空出来做自己的事的时间大概几小时？这个数字在未来 3 个月会变吗？」 | 数字 + 是否可改变 |
| P2 资金 | 「如果这件事需要花钱，你最多能接受损失多少？这个上限是怎么定出来的？」 | 数字 + 定法 |
| P3 技能样本 | 「过去 12 个月里，你实际做出来过什么东西是可以拿给别人看的？给我看看。」 | 可查样本或样本计划 |
| P4 关系 | 「如果要找 5 个人聊这件事，你会找谁？把名字列一下，并标一下哪些是熟人、哪些不太熟。」 | 名单 + 关系标签 |
| P5 亲历问题 | 「过去半年，你自己遇到过、到现在还没被很好解决的问题有哪些？每个问题当时你是怎么凑合过去的？凑合的办法哪里不好？」 | ≥3 条（场景 / 替代方案 / 不足） |
| P6 过去行为 | 「针对这件事，你自己或别人**已经**做过什么？什么时候做的？当时用的是什么办法？」 | 已发生行为 + 时间 + 当时替代方案 |
| P7 候选与实验 | 「你现在最不确定的是什么？如果做一个小实验，你打算怎么判断它算成功？这个判断标准是什么时候写下来的？」 | 不确定性字段 + 阈值 + 登记时点 |
| P8 起点 | 「你现在是全职在职、已经离职 / 马上面临离职、还是已经有作品在手，或者是因为外部原因被动离场的？」 | 四类之一 |

### 层 1 · 准入澄清（对应 [门 1](02-readiness-judgment.md)）

| 问句 | 用途 |
|---|---|
| 「刚才这四个数里，哪个是你未来 3 个月内改不了的？」 | 标出硬约束 |
| 「如果现在卡住了，你大概多久能把它解决？」 | 判断「先补条件」还是「暂不入场」 |
| 「每周那几小时是稳定的吗？会不会被工作临时吃掉？」 | 核对时间硬约束余量 |
| 「你为什么想做这件事？如果不做，你会失去什么？」 | 采集动机（进**线索栏**，不作否决理由） |

### 层 2 · 路径澄清（对应 [门 2](03-path-judgment.md)）

| 问句 | 用途 |
|---|---|
| 「你现在最缺的是时间、钱、技能，还是能聊的人？」 | 资源约束修正 |
| 「你手上有没有一个已经能拿出来给人看的东西？」 | P3 路径判定与技能样本补齐 |
| 「如果你只能先做一件事，你会先做什么？」 | 门槛取值（是否有 1 个可验证的候选） |
| 「假设半年后这条路走不通，你能接受的损失是多少？」 | 损失上限与退出条件 |

### 层 3 · 方向核查（对应 [门 3](04-direction-judgment.md)）

**问句（采信号）**：

| 问句 | 采集目标 |
|---|---|
| 「你上次遇到这个问题的时候，具体是怎么解决的？」 | 过去行为 + 当时替代方案 |
| 「那次是什么时候？花了多少时间 / 多少钱？」 | 时间与成本可核验 |
| 「后来你换过别的办法吗？为什么换？」 | 现有替代方案的不足 |
| 「有没有人已经为类似的东西付过钱？谁？付了多少？」 | 强信号 + 样本来源 |
| 「这些跟你聊过的人里，哪些是你平时不太熟的？」 | 样本来源分布 |

**审查动作（核对方已交付的材料）**：

| 动作 | 判定 |
|---|---|
| 读对方写的 JTBD 三问（功能 / 社会 / 情感） | 三问须是「进展」表述，**不得出现产品功能名词**（F-030） |
| 查实验卡四要素（假设 / 对象 / 动作 / 阈值） | 四要素齐备 |
| 查阈值登记时点 | 早于取信号时点（F-011、F-018） |
| 查候选卡的「当前最大不确定性」字段 | 字段存在且未被删除（F-028） |

### 层 4 · 退出与迭代澄清（对应 [门 4](05-exit-judgment.md)）

| 问句 | 用途 |
|---|---|
| 「这个观察期你打算定多久？从哪里开始算？」 | 观察期登记 |
| 「什么情况下你会停？停的时候你打算换哪个备选？」 | 退出条件与回退路径 |
| 「如果出现什么新情况，你会调整而不是停止？」 | 迭代条件 |
| 「你最多能接受损失多少？到那个数你会怎么做？」 | 损害上限与暂停动作 |

## 2. 无效回答识别与丢弃

访谈中出现的以下回答**不进判据栏**（依源知识包 F-017、F-029）：

| 类型 | 识别信号 | 处置 |
|---|---|---|
| 恭维 | 「这个想法挺好的」「你挺适合的」 | 丢弃；改为追问最近一次具体做了什么 |
| 空话 | 「有需求」「市场很大」「以后肯定会用」 | 丢弃；追问发生时间与当时替代方案 |
| 他人的点子 | 「我觉得你可以做 XX」「我朋友会感兴趣」 | 丢弃；记录为「他人点子」，不作证据 |
| 未来承诺 | 「我会买」「到时候找我」 | 丢弃；改问「你上次是怎么做的」 |
| 社交信号 | 点赞、好评、转发、群里附和 | 丢弃；归入无效信号列（F-017） |
| 自家评语 | 「我这个方向我觉得很有前景」 | 记录但标为「被帮者自评」，不作判据 |

> **熟人样本的处理**：熟人倾向给出恭维（F-029）。若样本全为熟人，须在记录中显式标注，并据此落入 no-go 档（F-013）或安排补采半熟人 / 陌生人样本。

## 3. 访谈记录模板

```text
访谈记录（判断者侧）
├─ 受访者编号：＿＿ ｜ 与判断者关系：熟人 / 半熟人 / 陌生人 ｜ 日期：＿＿
├─ 层 0 判据采集
│   ├─ P1 时间：＿＿ 小时/周（硬 / 软）
│   ├─ P2 资金上限：＿＿ 元（硬 / 软）
│   ├─ P3 技能样本：＿＿（有样本 / 仅计划）
│   ├─ P4 可访谈名单：＿＿（熟人 ＿ / 半熟人 ＿ / 陌生人 ＿）
│   ├─ P5 亲历问题：＿＿ 条（逐条场景 / 替代方案 / 不足）
│   ├─ P6 过去行为：＿＿ 条（行为 / 时间 / 替代方案 / 来源）
│   ├─ P7 候选与实验：不确定性 ＿＿ ｜ 阈值 ＿＿ ｜ 登记时点 ＿＿
│   └─ P8 起点：＿＿（四类之一）
├─ 无效回答清单（恭维 / 空话 / 他人点子 / 未来承诺 / 社交信号）
├─ 线索栏（不作判定）：动机自述 ＿＿ ｜ 测评自述 ＿＿
└─ 缺项与补采约定：＿＿（复判时点 ＿＿）
```

## 4. 判断者常见提问错误

| 错误 | 问题 | 改法 |
|---|---|---|
| 问「你会不会买」 | 得到未来承诺，不构成强信号 | 改问「你上次是怎么解决的」 |
| 诱导式提问 | 「你是不是也觉得这个挺有市场的？」 | 改成开放式：「当时你是怎么处理的？」 |
| 替对方总结 | 判断者把印象写成判据 | 记录须引用对方原话与具体事件 |
| 只采线索栏 | 聊得很深，但一份判据都没拿到 | 每次访谈结束时逐项核对 P1~P8 |
| 追问动机追问到底 | 把访谈变成心理辅导 | 动机只记不判；一旦缺判据即转回采集 |
