# 02 · 门 1 准入判断

> 回到 [知识包首页](../index.md)
>
> **本门只回答一个问题**：**此人现在（或何时）适合开始做变现方向选择吗？** 本门**不判方向好坏**，也**不判该走哪条路径**。
>
> **非决定论声明**：本门的一切判定只看判据栏；测评类型、优势清单、动机打分之外的自我描述**不得**用于本门判定。

## 1. 本门在五门链中的位置

门 0 已确认 8 项判据齐备（见 [01](01-judgment-inputs.md)）；本门在齐备前提下做准入判断。三档结论的走向：

- **可入场** → 进入 [门 2 路径判断](03-path-judgment.md)
- **先补条件** → 给出补条件动作与复判时点，回到 [门 0](01-judgment-inputs.md)
- **暂不入场** → 不做方向选择；给出前置条件与「何时再来」的时间锚点

## 2. 输入项

| 判据 | 用途 |
|---|---|
| P1 可支配时间（数值 + 硬/软） | R1 |
| P2 可承受损失资金上限（数值 + 硬/软） | R1 |
| P3 可产出样本的技能项 | R1 |
| P4 可访谈对象清单（含关系标签） | R1 |
| P5 亲历问题记录（≥3 条） | R2 |
| P8 起点状态 | R4 |
| 线索栏：动机三维打分 | 仅作 R3 的**观察项**，不作否决项 |

> **硬约束 / 软约束的定义**（沿用源包步骤 1 口径）：**硬约束** = 3 个月内不可改变；**软约束** = 可规划改变（源包 05 §2.3）。

## 3. 四条规则与判定

| 规则 | 判定内容 | 通过条件 | 未通过时的性质 |
|---|---|---|---|
| **R1 硬约束可支撑** | P1~P4 四栏均有可核验数值/清单，且**硬约束**项留有余量 | 硬约束项均在可支撑范围内（时间有可支配余量、损失上限已明确且不为零、至少一项可产出样本的技能、至少 1 名可访谈对象） | 未过项为硬约束 → **暂不入场**；未过项全为软约束 → 先补条件 |
| **R2 亲历问题可交付** | P5 亲历问题记录 | ≥3 条，每条含场景 / 当时替代方案 / 替代方案不足 | 不足 3 条 → 先补条件（补采后复判） |
| **R3 动机三维不全低谷** | 线索栏的动机三维打分（自主 / 胜任 / 关联，源包 05 §2.4） | 三项中至少一项 ≥3 分（1~5 分制〔参数〕） | 三项均 ≤2 分 → 记入「观察区」，作为**提示**而非否决；须与 R1/R2 结果一并陈述 |
| **R4 起点可判定** | P8 起点状态 | 可判入四类之一（在职 / 已离职或即将离职 / 已有可展示作品 / 被动离场） | 不可判定 → 不作为否决项，转入门 2 时先澄清；本门结论仍可给出 |

> **为什么 R3 不是否决项**：动机打分为线索栏材料（自评），依本包分栏规则（F-046〔参数〕）不得承担判定权。它只提示「此人可能还没想清楚为什么做」，处置方式是**如实标注并告知**，不是替他否决。

## 4. 三档结论与处置动作

| 结论档 | 触发条件 | 处置动作 | 谁做 |
|---|---|---|---|
| **可入场** | R1、R2 均通过；R3 无全低谷（或虽有全低谷但已如实标注）；起点可判定或可转澄清 | 进入 [门 2 路径判断](03-path-judgment.md) | 判断者继续 |
| **先补条件** | R1 有未过项但**全部为软约束**；或 R2 未过（问题记录不足） | ① 列出补条件清单（哪一栏、要什么形态）；② 约定**复判时点**（时间锚点，须写定日期）；③ 回到门 0 重新采集 | 被帮者补采，判断者复判 |
| **暂不入场** | R1 有未过项且**至少一项为硬约束**（如时间无可支配余量且 3 个月内不可改变；可承受损失上限无法确定；无任何可产出样本的技能项） | ① 如实说明卡在哪一条硬约束；② 给出「前置条件达成后再来」的时间锚点；③ **不做任何方向建议** | 判断者说明，被帮者决定 |

> **「暂不入场」不是失败判决**，它是一个合法结论档。它保护的是被帮者：在硬约束未解决时生成候选与启动行动，会产出不合实际的候选（源包登记反模式 F-031：忽略硬约束生成不切实际的候选与行动）。

## 5. 输出：准入判定卡

```
准入判定卡
├─ 判据齐备性：门 0 结论 = 齐备 / 不可判（若不可判则本门不执行）
├─ R1：通过 / 未过（未过项：＿＿＿，硬/软：＿＿＿）
├─ R2：通过 / 未过（当前 ＿＿ 条，需 ≥3 条）
├─ R3：无全低谷 / 三项均 ≤2 分（观察区，如实标注）
├─ R4：可判定（＿＿类起点）/ 待澄清
├─ 结论档：可入场 / 先补条件 / 暂不入场
├─ 处置动作：＿＿＿＿＿
├─ 复判时点：＿＿＿＿（先补条件时必填）
└─ 本发明依据的判据行：逐条引用 P1~P8 编号与内容
```

**出卡硬要求**：结论必须逐条引用所依据的判据行；判据行引用不出的结论视为无效。

## 6. 完成本门的达标条件

- [ ] R1~R4 逐条给出结论与依据的判据行。
- [ ] 「先补条件」档已写明补条件清单与复判时点（日期）。
- [ ] 「暂不入场」档已写明卡在哪一条硬约束，且**未给出任何方向建议**。
- [ ] 线索栏材料未出现在任何否决理由中（R3 只作提示）。

## 7. 边界与反模式

| 反模式 | 问题 | 纠正 |
|---|---|---|
| 把意愿当准入 | 「他很想变现」被读作可入场 | 准入只看硬约束与判据，不看意愿强度 |
| 用测评否决准入 | 「他测评显示不适合」被当作暂不入场理由 | 测评为非决定论（F-033），不得承担判定权 |
| 硬约束被软化 | 把「每周可投入 2 小时」当作可支撑 | 硬约束未过 → 暂不入场，不得默认忽略（F-031） |
| 无复判时点 | 「先补条件」后无期限，长期悬置 | 补条件档必须写定复判日期 |
| 越门判方向 | 本门顺手给出方向建议 | 方向结论只由 [门 3](04-direction-judgment.md) 给出（F-044） |
