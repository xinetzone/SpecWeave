# 01 · 门 0 判据采集门

> 回到 [知识包首页](../index.md)
>
> **本门的作用**：在判断之前先确认**判断的依据是否已经到手**。本门不过，模型不输出任何倾向性建议——合法输出只有「不可判」。
>
> **非决定论声明**：本门涉及的职业锚排序、优势/心流清单、各类测评结果与动机打分，均为**线索类输入**，只作自我反思参照，**不得参与任何判定**（对齐源包 F-041 非决定论声明）。

## 1. 判据分两栏（这是本门最重要的一条规则）

判断者拿到的材料必须**先分栏**再使用。分栏依据是「这份材料是不是被帮者已交付的事实」：

| 栏位 | 定义 | 包含 | 能否参与判定 |
|---|---|---|---|
| **判据栏** | 可核验的数值、等级或**已发生行为** | 资源约束四栏数值或等级；硬/软约束标签；亲历问题记录；过去行为证据（含时间与当时替代方案）；登记过的信号阈值与登记时点；可展示的作品样本；起点状态 | ✅ 可判定 |
| **线索栏** | 启发式参照与主观自评 | 职业锚排序（源包 05 §2.1）；优势线索清单与心流场景清单（源包 05 §2.2）；内在动机三维打分（源包 05 §2.4）；MBTI / RIASEC / CliftonStrengths / VIA 等测评结果（源包 02） | ❌ 不判定，仅用于生成候选与自我反思 |

> **分栏依据**：源知识包登记「把测评类型直接当作方向判决」为反模式（F-026），并将性格/天赋测评定性为非决定论工具（F-033）；RIASEC 的六类型适用于**兴趣**而非**能力**匹配（F-039）。本包据此把判据归属显式化为两栏（F-046〔参数〕）。

**分栏时的两个硬动作**：

1. 线索栏材料可以进候选生成，但**不得**写进任何判定理由栏；
2. 判据栏材料若来自口头描述而无事件与数值，退回补采——「他说他很能吃苦」不是判据，「他过去 12 个月每周投入 X 小时在 Y 上」才是。

## 2. 8 项必备判据（P1 ~ P8）

本门设 8 项必备判据（F-047〔参数〕）。每项都要求**可核验形态**：

| # | 判据 | 可核验形态（合格） | 不合格形态（须退回补采） |
|---|---|---|---|
| P1 | 可支配时间 | 每周可投入小时数（数值）+ 硬/软约束标签 | 「我时间还行」「看情况」 |
| P2 | 可承受损失资金上限 | 可承受损失的金额上限（数值）+ 硬/软约束标签 | 「我不想投钱」但无上限数值 |
| P3 | 可产出样本的技能项 | 至少一项「能产出可交付样本」的技能（附已有样本或样本计划） | 只有技能名称清单，无任何样本或样本计划 |
| P4 | 可动用关系网络 | 可访谈对象清单，逐个标注关系（熟人/半熟人/陌生人） | 「我认识不少人」 |
| P5 | 亲历问题记录 | ≥3 条，每条含：发生场景 / 当时所用替代方案 / 替代方案的不足 | <3 条，或只有问题名称无场景 |
| P6 | 过去行为证据 | 针对候选方向的**已发生行为**，含发生时间与当时替代方案 | 「他们说会买」「我觉得有需求」 |
| P7 | 候选卡与实验卡 | 候选卡含「当前最大不确定性」字段；实验卡含假设 / 对象 / 动作 / 信号阈值 四要素，且**阈值登记时点**可查 | 候选卡删掉了不确定性字段；阈值事后补填 |
| P8 | 起点状态 | 能判入四类之一：在职 / 已离职或即将离职 / 已有可展示作品 / 被动离场 | 「我也不知道自己算哪种」且不肯澄清 |

**采集口径**：

- P1~P4 取自源知识包步骤 1 的资源约束四栏表（F-006、F-007、F-023），须带硬/软约束标签；
- P5 取自源知识包步骤 2 的输入项「至少 3 个本人亲身遇到且未被很好解决」的问题记录（F-008 输入项）；
- P6、P7 取自源知识包步骤 3 的输入项与实验卡四要素（F-010、F-011）；
- P8 取自源知识包路径层的四类起点（F-021）。

## 3. 缺项处理：什么时候必须输出「不可判」

本门不过时的输出只有一档：**不可判**（F-047〔参数〕）。判定见下表：

| 缺项 | 受影响的门 | 本门结论 | 补采动作 |
|---|---|---|---|
| 缺 P1 / P2 / P3 / P4 任一 | 门 1 准入判断 | **不可判** | 让对方填完资源约束四栏（数值或明确等级 + 硬软标签） |
| 缺 P5（亲历问题 <3 条） | 门 1、门 2 | **不可判** | 追加记录亲历问题；不足 3 条时如实记为「待补」，不凑数 |
| 缺 P8（起点无法判定） | 门 2 路径判断 | **不可判**（可先完成门 1） | 澄清当前在职/离场/作品状态 |
| 缺 P6 或 P7 | 门 3 方向成立性 | **不可判**（可先完成门 1、门 2） | 补采过去行为证据；补建候选卡与实验卡并在实验前登记阈值 |
| 缺全部线索栏材料 | 不影响判定 | 判据齐备即可判 | 提示补采（只影响候选生成质量与自我反思深度） |

> **硬纪律**：判据栏缺项时，**禁止用线索栏材料替代**。例如：不得以「他 RIASEC 是 A 型」替代缺失的 P3 技能样本，不得以「他很有热情」替代缺失的 P1 时间数值。

## 5. 完成本门的达标条件

- [ ] 8 项判据逐项有可核验形态，无「口头描述代替事实」项。
- [ ] 判据栏与线索栏已分表登记，线索栏材料未出现在任何判定理由中。
- [ ] P5 的亲历问题记录 ≥3 条且都不是凑数项。
- [ ] P7 的阈值登记时点可查（不能只有阈值数值）。
- [ ] 若存在缺项，本门结论已如实写为「不可判」并给出补采动作。

## 6. 边界与反模式

| 反模式 | 问题 | 纠正 |
|---|---|---|
| 拿线索当判据 | 测评类型/自评清单直接进判定理由 | 分栏登记，判定只看判据栏（F-046〔参数〕） |
| 用态度代替事件 | 「他很有决心」被当作准入依据 | 判据须是数值、等级或已发生行为 |
| 凑数补齐 3 条问题 | 为过门而临时编问题 | 不足 3 条如实记「待补」，标注复判时点 |
| 阈值事后补填 | 实验卡只有阈值没有登记时点 | 阈值须在取信号前登记（F-011） |
| 判断者代填 | 判断者凭对被帮者的印象代笔判据 | 判据须由被帮者交付；判断者只做形态核验 |
