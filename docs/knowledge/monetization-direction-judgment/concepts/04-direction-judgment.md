# 04 · 门 3 方向成立性判断

> 回到 [知识包首页](../index.md)
>
> **本门只回答一个问题**：**这个候选方向是否已经取得足以继续投入的信号？**
>
> **接口纪律**：源知识包的 go / no-go / 待补验三档阈值照原样沿用（F-012~F-014）；本包在其上另加四条**加重规则**（F-050〔参数〕），用于核查信号本身的质量。**判断者在本门只输出信号分级与档位，不输出「该方向可行」类表述**（I-2）。

## 1. 本门在五门链中的位置

门 1（准入）、门 2（路径）已过之后才进入本门。本门输出三档结论；`go` 交 [门 4](05-exit-judgment.md)，`no-go` 回候选池，`待补验` 补一轮实验后回到本门。

## 2. 输入项

| 判据 | 用途 |
|---|---|
| P7 候选卡（含「当前最大不确定性」字段） | 判定该方向被验证的假设覆盖范围 |
| P7 实验卡（假设 / 对象 / 动作 / 信号阈值 / **登记时点**） | 加重规则 G-1 |
| P6 过去行为证据（行为 / 时间 / 当时替代方案 / **样本来源**） | 信号分级与加重规则 G-2 |
| 信号记录表（强 / 弱 / 无效三类分行） | 分级与加重规则 G-3 |
| 可访谈对象清单（P4） | 样本来源核对 |

## 3. 信号三级分级

分级标准照源知识包 [08 §3](../../../../projects/awesome-okf-xs/doc/bundles/sheke/industry/monetization-direction/concepts/08-decision-and-launch-method.md)（F-015~F-017）：

| 级别 | 定义 | 判定形态 | 典型样本 |
|---|---|---|---|
| **强信号** | 已发生的行为 | 真实付费 / 真实使用 / 重复使用 | 有人付了钱、有人真的用完并回来再用 |
| **弱信号** | 未发生付费的行为 | 留资、预约、口头意向 | 填了表单、约了时间、说「我会买」 |
| **无效信号** | 不构成市场证据的表态 | 恭维 / 空话 / 他人点子 / 点赞 | 「这挺好的」「有需求」「我朋友会感兴趣」、点赞与好评 |

**分级纪律**：
- 每条记录必须落到三级之一，**不得有未分级记录**；
- 无效信号列**不得留空**（F-020）——留空即视为未做反模式过滤，本门判定无效；
- 分级只看**行为是否已发生**，不看说话者的热情、身份与关系亲疏。

## 4. 四条加重规则（判断者侧核查）

四条规则为本包新增（F-050〔参数〕），逐条核查后才可使用源包阈值出档：

| # | 规则 | 核查动作 | 不合格时的处置 |
|---|---|---|---|
| **G-1** | **阈值登记时点可查** | 比对实验卡上的阈值与登记时点；登记时点须早于取信号时点 | 事后补填或调整 → **本门判定无效**，回实验设计（F-011、F-018） |
| **G-2** | **样本来源逐行标注** | 每条强信号注明来源：熟人 / 半熟人 / 陌生人 | 有强信号未标来源 → 该行不计入 go 判定 |
| **G-3** | **无效信号列非空** | 检查信号记录表的无效信号列 | 留空 → 本门判定无效（F-020），须补做反模式过滤 |
| **G-4** | **判定依据逐行引用** | 判定卡须注明所依据的具体信号行 | 引用不出依据行 → 结论视为无效（F-019） |

## 5. 三档判定

阈值照源知识包 [08 §4](../../../../projects/awesome-okf-xs/doc/bundles/sheke/industry/monetization-direction/concepts/08-decision-and-launch-method.md)（F-012~F-014）：

| 档位 | 触发条件 | 处置 |
|---|---|---|
| **go** | 存在**至少一项强信号**，且该强信号来自**陌生或半熟人**样本，且已验证假设**覆盖候选卡的「最大不确定性」** | 进入 [门 4 退出/迭代判断](05-exit-judgment.md)，拆解首个 30 天行动 |
| **no-go** | 仅有弱信号；或强信号**全部来自熟人**样本；或「最大不确定性」尚未被任何实验触及 | 回候选池（不是失败判决），按 [门 2](03-path-judgment.md) 重过门槛 |
| **待补验** | 强信号存在但**来源单一**；或存在**未验证的高风险假设** | **待补验 ≠ go**；先补一轮实验，再回到本门重判 |

**判定规则**（F-018、F-019、F-014）：
1. 阈值在汇总前写定，**禁止据结果反向调整**；
2. 判定结果须**注明依据的具体信号行**；
3. 「待补验」不得直接升级为 go。

## 6. 外推边界

- 单次实验取得的信号只来自**特定样本与特定时点**；把单次信号读作「整体市场需求已验证」属超出实验设定的推断（F-043）。
- 超出实验设定的部分一律以**「待补验」**处理，不得先行 go。
- 禁止把「某人用某路径成功」转述为「该路径带来成功」——个案不具备因果证据地位（F-041）；本门的分级对象是**行为证据**，不是成功案例。
- 测评结果、congruence 类相关性描述**不得**用于本门判定（F-033、F-039）。

## 7. 输出：方向判定卡

```text
方向判定卡
├─ 候选方向：＿＿＿（候选卡编号）
├─ 该方向的「当前最大不确定性」：＿＿＿
├─ 已验证假设：＿＿＿（是否覆盖上述不确定性：是 / 否）
├─ 信号汇总
│   ├─ 强信号：＿＿条 ｜ 来源标注：熟 ＿ / 半熟 ＿ / 陌生 ＿
│   ├─ 弱信号：＿＿条
│   └─ 无效信号：＿＿条（列不得为空）
├─ 加重规则核查：G-1 ＿＿ ｜ G-2 ＿＿ ｜ G-3 ＿＿ ｜ G-4 ＿＿
├─ 判定档：go / no-go / 待补验
└─ 判定依据的信号行：逐行引用（第 ＿ 条：＿＿＿）
```

## 8. 完成本门的达标条件

- [ ] 全部信号已落入强 / 弱 / 无效三级，无未分级记录。
- [ ] 无效信号列非空；每条强信号标了样本来源。
- [ ] 阈值登记时点早于取信号时点（或已如实判定为无效）。
- [ ] 三档判定注明依据的具体信号行。
- [ ] 输出中未出现「该方向可行 / 能赚钱 / 值得做」类方向背书表述。

## 9. 边界与反模式

| 反模式 | 问题 | 纠正 |
|---|---|---|
| 把点赞 / 好评当付费意愿 | 社交信号被读作付费行为 | 归入无效信号（F-017、F-029） |
| 样本全是熟人却判 go | 强信号全来自熟人 | 落 no-go 档（F-013） |
| 事后调整阈值 | 阈值失去判据作用 | 判定无效，回实验设计（F-011、F-018） |
| 只验证最容易的假设 | 未测最高风险要素 | 优先测风险最高要素（F-030） |
| 单次信号当作市场已验证 | 超出实验设定外推 | 一律按「待补验」处理（F-043） |
| 判断者替方向背书 | 出现「能做」「有前景」表述 | 判断者只出分级与档位（I-2、F-034） |
| 用功能性名词替代 job | 混淆 job 与解决方案 | JTBD 三问须用「进展」表述（F-030） |
