# 03 · 门 2 路径判断

> 回到 [知识包首页](../index.md)
>
> **本门只回答一个问题**：**此人该走哪条主路径、这条路径的门槛取值是什么、适合用哪种实验形态？**
>
> **本门的最强纪律**：本门输出**不得包含方向结论**（F-049〔参数〕）。路径判定只用于**缩小搜索范围**，它不含任何方向成立性信息（源包 09 §7，F-042）。

## 1. 本门在五门链中的位置

门 1 判定为「可入场」后才进入本门。本门输出三栏（主路径 / 门槛取值 / 建议实验形态），交给 [门 3 方向成立性判断](04-direction-judgment.md) 使用。

## 2. 输入项

| 判据 | 用途 |
|---|---|
| P8 起点状态 | 起点判定 |
| P1 可支配时间（数值 + 硬/软） | 资源约束修正 |
| P2 可承受损失资金（数值 + 硬/软） | 资源约束修正 |
| P3 可产出样本的技能项（含样本） | 起点判定（P3 路径）与资源约束修正 |
| P4 可访谈对象清单（含关系标签） | 门槛取值（是否已有可访谈对象） |

## 3. 起点判定表

| 起点（P8） | 判定特征 | 落到路径 |
|---|---|---|
| 仍在全职岗位 | 有在职状态；每周可支配可变现时间有限；可承受损失上限较低 | **P1 在职副业型** |
| 已离职或即将离职 | 时间储备较充裕；现金流需在有限周期内重建 | **P2 全职转型型** |
| 已有可展示作品或样本 | 存在可交付技能或作品；生成器以内容或可复制产出物为主 | **P3 技能型创作者型** |
| 因外部变化被动离场 | 岗位裁撤、合约终止等外部原因；时间可支配但决策窗口紧 | **P4 被动转型型** |

> 起点判定依据源知识包路径层的四类起点划分（F-021）。若 P8 不可判定，**不得**由判断者代为归类；须先澄清再判（源包 [09 §7](../../../../projects/awesome-okf-xs/doc/bundles/sheke/industry/monetization-direction/concepts/09-path-matrix.md)：路径划分为启发式分类，不是实证分类）。

## 4. 四条主路径：门槛取值与实验形态

| 路径 | 准入门槛（逐条核对） | 建议实验形态 | 退出 / 切换条件 |
|---|---|---|---|
| **P1 在职副业型** | ① 时间硬约束可被明确标出 ② 存在 1 个可在业余时间验证的候选方向 ③ 关系网络中有可访谈对象 | **落地页型 / 预售型**（低成本） | 观察期内强信号未出现 → 回候选池换候选；岗位时间约束收紧至不可支撑 → 转 P4 或暂停 |
| **P2 全职转型型** | ① 明确的可承受损失上限与观察期 ② 至少 1 个候选方向已通过初步访谈 | **MVP 型**，可并行验证 2~3 个候选 | 可承受损失上限触达 → 暂停并回退；两个观察期内均无强信号 → 转 P1（先恢复稳定现金流再并行验证） |
| **P3 技能型创作者型** | ① 存在可展示的作品或样本 ② 目标对象可被具体描述 | **预售型**（检验付费意愿） | 作品更新停滞且信号无增长 → 回候选池；付费意愿始终停留在弱信号 → 转 P2 重新验证方向 |
| **P4 被动转型型** | ① 先完成现金流与可承受损失上限的盘点 ② 关系网络中有可立即访谈的对象 | **成本最低的实验形态**（跳过长周期验证） | 现金流触底 → 恢复稳定收入后转 P1；方向验证连续两轮失败 → 回候选池重选候选 |

> 上表逐格对应源知识包 [09 方向选择矩阵](../../../../projects/awesome-okf-xs/doc/bundles/sheke/industry/monetization-direction/concepts/09-path-matrix.md) §4 的「起点条件 / 准入门槛 / 分阶段行动 / 退出切换条件」（F-022）。**路径只决定门槛与实验形态，不决定方向。**

## 5. 资源约束修正

按源包 [09 §6](../../../../projects/awesome-okf-xs/doc/bundles/sheke/industry/monetization-direction/concepts/09-path-matrix.md) 的资源约束适配表（F-025），对本门输出的「实验形态」一栏做修正：

| 硬约束 | 适配动作 |
|---|---|
| 时间不足 | 优先选落地页 / 预售类低成本实验形态；推迟需长交付周期的候选 |
| 资金不足 | 避免需先投入成本结构的候选；以可复制产出物替代资本投入 |
| 技能不足 | 先按源包步骤 1 §2.2 的优势 / 心流清单定位可产出样本的技能项，再以「时间不足」行的低成本实验形态取得首个样本；本方法**假设**样本缺失可通过短期练习逐步补齐（方法前提假设，非实证结论） |
| 关系不足 | 访谈样本以半熟人 / 陌生人为先，减少对熟人样本的依赖（依源包 F-077） |

> **技能不足的处置纪律**：不得以「没有可交付样本」直接判定方向不成立。源包 [09 §6](../../../../projects/awesome-okf-xs/doc/bundles/sheke/industry/monetization-direction/concepts/09-path-matrix.md) 登记的洞察指出，准入失败常表现为可交付样本的缺失，而该缺失为方法假设可短期补齐的项——过早放弃可深化的候选属反向误判（见 [06 误判红线](06-misjudgment-redlines.md) 第 12 条）。

## 6. 路径切换条件矩阵

| 从 \ 到 | P1 在职副业 | P2 全职转型 | P3 技能型创作者 | P4 被动转型 |
|---|---|---|---|---|
| **P1** | — | 时间约束解除且已备损失上限 | 已有可展示作品 | 岗位意外终止 |
| **P2** | 损失上限触达 | — | 作品驱动且技能可交付 | 现金流告急 |
| **P3** | 需稳定现金流 | 需加速验证 | — | 收入中断 |
| **P4** | 恢复收入后 | 备足损失上限 | 已有作品 | — |

**切换纪律**（F-024）：切换发生在「起点条件不再成立」或「退出条件触达」时；切换后须**回到对应路径的门槛检查**，不得直接沿用上一路径的实验结论——同一候选在不同路径下取得的信号不具可比性。

## 7. 输出：路径判定卡（三栏制）

```text
路径判定卡
├─ 起点：＿＿＿（四类之一，依据 P8）
├─ 主路径：P1 / P2 / P3 / P4
├─ 门槛取值：逐条列出该路径的准入门槛及其当前满足情况
├─ 建议实验形态：落地页型 / MVP 型 / 预售型 / 成本最低形态
│   └─ 资源约束修正：＿＿＿（时间/资金/技能/关系约束下的调整）
├─ 当前不满足的门槛项及处置：＿＿＿
└─ 【留空】方向结论栏——本门不输出方向结论
```

> **留空栏是刻意设计**：把「方向结论」栏显式留空，用来阻断「判定路径后顺势给出方向」的滑移（I-3）。

## 8. 完成本门的达标条件

- [ ] 起点判定逐条对应 P8 的判据内容，未由判断者代为归类。
- [ ] 门槛取值逐条给出「满足 / 不满足」及依据。
- [ ] 实验形态已按资源约束修正。
- [ ] 输出卡中**方向结论栏为空**。
- [ ] 若发生路径切换，已注明按切换纪律重过门槛检查。

## 9. 边界与反模式

| 反模式 | 问题 | 纠正 |
|---|---|---|
| 把路径当方向结论 | 「他是 P1 型，所以做 X」 | 路径只缩小范围；方向结论回 [门 3](04-direction-judgment.md)（F-044、F-049） |
| 判断者代为归类起点 | 对方说不清起点，判断者替他选定 | 先澄清再判；路径划分为启发式分类（F-042） |
| 沿用旧路径结论 | 切换路径后直接沿用上一路径的信号 | 切换后须重过门槛检查（F-024） |
| 按路径「应该」选形态 | 不看资源约束，按路径默认形态执行 | 实验形态须按资源约束修正（F-025） |
| 技能缺口即淘汰候选 | 「没样本 → 方向不成立」 | 先补样本再判；样本缺失为可短期补齐的方法假设项 |
