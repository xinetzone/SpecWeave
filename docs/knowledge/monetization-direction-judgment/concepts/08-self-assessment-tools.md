# 08 · 被帮者自填工具

> 回到 [知识包首页](../index.md)
>
> **交付说明**：本页是可**直接复制给被帮者**的最小自填集。请**按门交付**，不要一次全给：门 0 阶段只交【表 A + 表 B】，候选生成阶段交【表 C】，验证阶段交【表 D】，启动阶段交【表 E】。
>
> **填写三条须知**：① 表 A 只填数值、等级与已发生的事件，**不填评价词**；② 表 B 只作自我反思，**不参与任何判定**，可以留白；③ 宁可留白写「暂时填不出」，也不要编内容——判据的形态不合格会被退回，编内容会让整轮判断作废。

## 表 C · 候选方向卡（每张一页，建议 3~5 张）

| 字段 | 填写栏 |
|---|---|
| 候选方向名 | |
| 目标对象（具体到某类人，不填抽象词） | |
| 他雇这个方案要完成的进展（JTBD 功能 / 社会 / 情感三句，不写产品功能名词） | 功能：／社会：／情感： |
| 我的特定知识（「几乎不费力却在做、别人难以速成」的项） | |
| 担责形式（署名 / 履约承诺 / 以个人声誉背书） | |
| 杠杆形式（可复制产出物 / 需投入时间人力 / 需投入资本） | |
| 可替代性（别人能否被训练替代） | |
| **当前最大不确定性**（必填，不得为让卡片好看而删除） | |
| 起点假设 | |

**取舍规则**：优先保留「可替代性低 + 有担责 + 本人亲历问题」三者兼备的卡；两张卡若目标对象与待办任务重合则合并。

## 表 F · 交付前自检勾选

- [ ] 表 A 全部填完，且 P1、P2 是数字不是形容词。
- [ ] P5 有 ≥3 条，且每条都有场景与替代方案。
- [ ] P6 填的是**已经发生过**的事，不是打算做的事。
- [ ] 表 B 与表 A 分表填写，表 B 内容没有被搬进表 A 的判定依据。
- [ ] 表 C 每张卡都保留了「当前最大不确定性」字段。
- [ ] 表 D 的阈值登记日期早于实验开始日期。
- [ ] 表 E 在启动**之前**填写完成。
