## 四、跨编号体系引用纪律

1. 本包 F 编号（F-001~F-052）与源包 F 编号（F-001~F-082）为**两套独立体系**；引用源事实时写「源包 F-xxx」并给出源篇目，禁止在系统间互推或重编号（沿用 M1 的同类纪律）。
2. A~D 组为**转述**：只转述源包的既定表述与结构，不新增年份、数字、提出者或结论。
3. 源包的勘误（E-01~E-05）在本包只作索引引用，不重述细节（见 [09 §8](../concepts/09-boundaries-and-limits.md)）。
4. 涉及测评、收益、成功率的表述一律沿用源包的非决定论（源包 F-041 → 本包 F-033）与非承诺（源包 F-056/F-057 等 → 本包 F-034）口径，不得改写为断言。
5. 本包引用的源包路径一律使用**相对路径**，未使用 `file:///`；源包位于 `projects/awesome-okf-xs/`（git 子模块），本包**未改动其任何文件**。

## 五、采集缺口（限制结论强度）

| 缺口 | 影响 | 可能的取证方式 |
|---|---|---|
| 无任何真实陪跑样本 | 五门链是否优于「凭经验判断」，本包**无证据** | 在真实陪跑中记录：出现「不可判」档的次数、被迫在判据缺失下出结论的次数 |
| 无 go/no-go 判定与结果的对照样本 | 三档阈值的判别力未测（源包亦未测） | 观察期结束后回填判定与结果对照，样本累积 ≥3 例后再议升级 |
| 参数取值（R3 分数门槛、观察期 30 天、判据条数）无校准数据 | 参数为设计值，非校准值 | 参数调整须留痕，累积调整记录后再校准 |
| 判断者行为规律（为何倾向出结论而非拒绝判断） | I-1 的根因如实标注为「本包未给出」 | 无计划；保持标注，不升级为因果断言 |
| 源包自身核验限制（部分著作未获官方原文页、采用二手替代并标降级） | 本包继承同一效力上限 | 源包 `stale_after` 到期复核时联动更新 |
