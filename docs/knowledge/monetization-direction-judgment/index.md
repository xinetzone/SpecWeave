# 变现方向判断模型：五门判据外置链

> 一句话摘要：**先拒绝判断，再判断。** 帮别人判断变现方向时，判断链是「判据采集门 → 准入 → 路径 → 方向成立性 → 退出/迭代」五道门；每一道门的判据都必须**外置**为被帮者已交付的事实（资源数值、已发生行为、登记过的阈值），判断者本人的经验、直觉与被帮者的测评类型**一律不进判据栏**。判据不齐时，模型的合法输出是**「不可判」**，而不是一个倾向性建议。

- **编排 session**：`sc-20261017-monetization-judgment`
- **场景与链路**：场景 4 知识沉淀 + 场景 5 创新突破混合（standard）：`R→I→E→V→C`
- **信源性质**：唯一事实源为同簇 OKF 知识包 [个人变现方向发现](../../../projects/awesome-okf-xs/doc/bundles/sheke/industry/monetization-direction/index.md)（82 条 F 事实，源包核验时点 2026-10-17，`status: stable`）；本包不引入任何外部新信源
- **事实编号**：F-001~F-052（A~D 组为**转述**源知识包的结构事实，逐条标注来源篇目与源 F 编号；E 组为**本包方法设计参数**，标〔参数〕）
- **判断者视角 vs 被帮者视角**：本包同时提供两侧资产——判断者侧见 [07 提问脚本](concepts/07-interview-scripts.md) 与 [06 误判红线](concepts/06-misjudgment-redlines.md)；被帮者侧见 [08 自填工具](concepts/08-self-assessment-tools.md)

## 2. I 阶段：核心洞察（四元组）

> G2 已通过：4 条洞察各含**现象 / 根因 / 影响 / 建议**四要素；四个维度（判断时机、判据归属、判断分层、工具定位）互不重叠。凡根因不在源知识包内可得的，一律如实写「本包未给出，属待研究方法问题」，不编造根因。

### I-1　判断模型的第一动作是拒绝判断

- **现象**：判断者（帮助者）常在被帮者尚未交出资源约束数值、亲历问题记录与过去行为证据时，就凭印象给出方向建议。
- **根因**：本包未给出实证成因，属待研究方法问题；结构层面可确认的是——本模型的全部判据都**外置于**被帮者的已交付事实（F-007、F-015、F-018），判断者自身的经验不构成判据（F-045〔参数〕、F-046〔参数〕）。
- **影响**：判据缺失时给出的建议没有可核验的依据，而建议本身会被被帮者当作结论采纳，使后续步骤 3 的验证失去意义（对照 F-028：不确定性字段被删→步骤 3 失去验证对象）。
- **建议**：把「不可判」设为模型的合法输出档（F-047〔参数〕）；判据采集门未过时不得进入准入判断（F-045〔参数〕），操作见 [01](concepts/01-judgment-inputs.md) §3。

### I-2　判断者能给的最大帮助是信号分级，不是方向背书

- **现象**：判断者最自然的动作是替人挑方向（「你就做 XX 吧」）。
- **根因**：本包未给出实证成因，属待研究方法问题；可确认的结构事实是——方向成立性的判据是「已发生行为 + 样本来源 + 阈值登记时点」（F-012~F-014、F-015~F-017），这些只能由被帮者自己的验证产生（F-044）。
- **影响**：一旦判断者以个人信誉替方向背书，判定依据就从「被帮者的信号」换成「判断者的判断」，与源知识包的非承诺红线（F-034）正面冲突，且把判断者的信誉变成一次性消耗品。
- **建议**：判断者输出中不出现「该方向能赚钱」类表述；只输出信号分级（强/弱/无效）与三档判定（go / no-go / 待补验），操作见 [04](concepts/04-direction-judgment.md) §4、§5。

### I-3　路径判断与方向判断必须分离，否则路径会成为方向的伪证据

- **现象**：一旦判定了路径（如「你是在职副业型」），容易顺势得出「这条路径上的某个方向就是你的方向」。
- **根因**：本包未给出实证成因，属待研究方法问题；可确认的结构事实是——四条路径共用同一套方法层步骤，差异只在门槛取值与实验形态（F-021~F-025），且路径划分是启发式分类而非实证分类（F-042）。
- **影响**：路径判定本身不含方向成立性信息；把路径当结论，等于用分类工具充当判定依据，其后果是方向未经验证即被启动，且退出时无判据可依。
- **建议**：路径判断的输出限定为「主路径 + 门槛取值 + 建议实验形态」三栏、显式排除方向结论（F-049〔参数〕），方向结论一律回到 [04 方向成立性判断](concepts/04-direction-judgment.md)。

### I-4　测评与自评只能进「输入」栏，不得进「判据」栏

- **现象**：判断者与被帮者都倾向用测评类型或自评清单（MBTI / RIASEC / 优势清单 / 心流清单）直接推出方向。
- **根因**：本包未给出实证成因，属待研究方法问题；可确认的结构事实是——源知识包将这些工具定性为**非决定论**的启发式参照（F-033），其与职业结果为相关性描述而非因果预测（F-039：congruence 预测力 modest）。
- **影响**：测评一旦进入判据栏，判定即获得一种「伪精确」，被帮者会把类型标签当方向判决，落入源知识包登记的「爱好即能力」误区（F-003、F-026）。
- **建议**：判据表显式分为判据类与线索类两栏（F-046〔参数〕），判定只看判据类；线索类输入仅用于生成候选与自我反思，操作见 [01](concepts/01-judgment-inputs.md) §1。

## 3. E 阶段：可迁移模式摘要

### 模式：判据外置五门链（Externalized-Evidence Five-Gate Chain，L1）

**一句话**：当一个人要帮另一个人判断「该不该做、走哪条、成不成立、何时退出」这类基于本人情况的方向性决策时，把判断拆成五道硬前置门（判据采集 → 准入 → 路径 → 成立性 → 退出），把全部判据外置为被判断者已交付的事实，判断者只做判据审核与信号分级，不做方向背书；判据不齐时合法输出为「不可判」。

| 要素 | 摘要 |
|---|---|
| **触发场景** | 判断者（教练/顾问/老师/朋友）需要就另一人的方向性决策给出判断；或判断者发现自己正在「凭印象给建议」；或被判断者要求判断者直接推荐一个方向 |
| **核心步骤（五门）** | ① **判据采集门**：8 项必备判据，缺判据类输入→输出「不可判」（[01](concepts/01-judgment-inputs.md)）→ ② **准入判断**：4 规则 → 可入场 / 先补条件 / 暂不入场（[02](concepts/02-readiness-judgment.md)）→ ③ **路径判断**：起点×资源约束 → 主路径 + 门槛 + 实验形态（[03](concepts/03-path-judgment.md)）→ ④ **成立性判断**：信号分级 → go / no-go / 待补验（[04](concepts/04-direction-judgment.md)）→ ⑤ **退出/迭代判断**：观察期 + 迭代条件 + 退出条件 + 回退路径（[05](concepts/05-exit-judgment.md)）。每门产出物递交给下一门，前门未过不进后门 |
| **反模式（六条）** | ① 判据不齐就出结论；② 用测评类型充当判据；③ 替被判断者背书方向（出现收益承诺类表述）；④ 把路径判定当方向结论；⑤ 用熟人样本或点赞当作验证信号；⑥ 事后调整阈值／观察期。逐条纠正见 [06](concepts/06-misjudgment-redlines.md) |
| **检验三问** | ① 本次判断所依据的每一行，能否指回一条**被帮者已交付的判据**？② 判断输出中是否出现了任何方向背书或收益表述？③ 阈值与观察期是否在取信号**之前**登记？ |
| **成熟度** | **L1**：单案例方法论推导，判据全部来自同簇知识包的 82 条既有事实（F-001~F-082）+ 本包 8 条方法参数，**无实证检验**。升级 L2 条件：在 ≥5 例真实陪跑中，五门链的「不可判」档被实际使用且无一例在判据缺失下出结论；≥3 例的 go/no-go 判定能在观察期后与结果对照复核 |
| **迁移边界** | 本模式的主干（判据外置 + 硬前置门 + 拒绝判断档）可迁移到同类「基于本人情况的方向性判定」场景（职业转型咨询、升学与专业选择、创业方向评估、课程/服务选型建议）；迁移时须重设各门的判据清单，不得直接套用变现场景的判据条目 |

全文（五门详解、逐门判据与规则、提问脚本、自填工具、边界）见 [00 总览](concepts/00-overview.md) 及其后的 01~09 各篇；本模式为文档结构层面的方法设计，**不得读作「照此五门判定即可成功」**。
