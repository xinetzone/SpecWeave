什么是生命？——生命维度框架
核心结论：生命 = 组织层次 × 学科视角 × 定义目的 三坐标交汇，辅以边界案例压力测试；没有"生命就是 X"的唯一答案，只有带坐标的限定结论。
① 组织层次（尺度轴）
对象处于哪个层次？细胞是生命最小单位
生物圈（最高级）
生态系统（群落+环境）
群落（所有种群总和）
种群（同种生物个体）
个体（单细胞生物：细胞=个体）
器官系统 / 器官 / 组织
细胞 ← 生命的最小单位
细胞器 / 分子（蛋白质、核酸）
原子（最低级，无生命）
② 学科视角（认识轴）
用哪个学科的透镜？六个视角各见一面
物理学
负熵（隐喻）/ 自由能；远离平衡态的有序结构
化学
蛋白质核酸等分子的自组织整体
信息学
非周期晶体；遗传密码；信息的存储与传递
系统论
自创生 autopoiesis：制造并维持自身
生物学
八特征清单：有序/响应/繁殖/稳态/能量/适应/演化
哲学
灵魂即形式（亚里士多德）；复杂系统的涌现
③ 定义目的（用途轴）
为什么定义？目的不同，定义不同
探测（天体生物学）
NASA 工作定义 + 生命探测阶梯："火星上有没有生命？"
教学（基础生物）
八特征清单："细菌算不算生命？"
临床 / 医学
生理功能系统定义："患者是否存活？"（须用领域权威标准）
本质追问（哲学）
哲学本质论 + 涌现视角："生命到底是什么？"
④ 边界压力测试（定义演化的引擎）
任何定义先用三个边界案例检验；通不过就标注失效边界
病毒：算不算生命？
无细胞结构、无独立代谢（Microbiology Society：不算；Claverie：算——把宿主细胞转化为新生物体）
合成细胞：最小生命
JCVI-syn3.0（2016）：531 kbp / 473 基因，最小自主复制基因组——"最小生命"可被实验测量
地外生命：未知生化
NASA 生命探测阶梯 + 生物特征（biosignature）：从"特征清单"退化为"证据阶梯"
五步收敛：生命多维坐标法
① 锚定层次 → ② 选择视角 → ③ 列出候选定义（8 种，见定义全景）→ ④ 边界压力测试 → ⑤ 限定性收敛："在 细胞层次、生物学视角、教学目的 下，病毒不是生命"——禁止无坐标的"生命就是 X"。
