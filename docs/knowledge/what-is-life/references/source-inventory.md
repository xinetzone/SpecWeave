4. **经典文献**（S09 薛定谔原文、S15/S16 亚里士多德）：为机制性引用，原文内容以出版物为准。
5. **深挖轮（F-040~F-060）口径新增**：①**预印本**（S48、S51、S61）：arXiv 平台发布，未经同行评议，结论为指标性评估（如"当前无 AI 有意识"）而非本体论判决；②**观点平台/非主流框架**（S55、S56、S59、S62、S63）：为个人/机构观点页，Biopoietic 与 Zenodo Kumar 框架未入主流学术共识；③**一方称**（S66）：中科院"科学智慧火花"为作者观点栏目，非同行评议；④**官方媒体口径**（S60、S64）：权威性与官方立场相关，不等同于科学共识（如人民日报"AI 短期不可能有自我意识"为政策/理论版表述）；⑤**哲学百科**（S50、S57、S58）：SEP/IEP 为同行评议型哲学百科，作为立场梳理依据可靠，但立场本身（如 Searle 生物自然主义）是哲学主张而非实证结论。
