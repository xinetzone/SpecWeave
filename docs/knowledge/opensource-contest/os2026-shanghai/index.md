# 2026 上海开源软件应用创新大赛 参赛知识包

## 速用路径

1. **我还没报名**：先看[参赛操作指南](concepts/03-participation-guide.md)第一节资格自检 → 官网报名；
2. **我已有项目，纠结报哪条赛道**：看[赛道与赛题](concepts/01-tracks-and-challenges.md)的"零件 vs 成品"判据与选题对照表；
