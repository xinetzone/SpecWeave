# 我用豆包搭了一个「理想气体定律实验室」，PV=nRT 从此看得见

> 带话题 #AI科学创新工坊

---

物理课上，PV=nRT 总是"背了又忘"——压强、体积、温度、物质的量四个量互相牵制，光靠公式实在想象不出它们怎么联动。这次参加知乎 AI 科学创新工坊第二弹的「模拟实验室」挑战题，我用豆包做了一个完全可交互的理想气体定律实验室，把公式"演"出来。

作品是一个单 HTML 文件的气体模拟器，零外部依赖、打开即用。三个滑块分别控制温度（100–600 K）、体积（1–10 L）、物质的量（0.5–5 mol）：温度越高，容器里的分子粒子跑得越快；体积越大，容器越大、分子越稀疏；物质的量越大，粒子数越多。右侧面板实时给出压强读数（kPa 与 atm 双单位）、分子均方根速率和分子数，并绘制 P–T 与 P–V 两条关系曲线——等容等量下 P–T 是一条直线，等温等量下 P–V 是一条反比双曲线，玻意耳定律直接"长"在了屏幕上。

[图1：豆包使用过程截图（方案编排 / 生成作品 / 过程留痕，共 6 张，见配图清单）]

整个创作过程我完全用豆包完成，四步走：

**第一步，方案编排**：用豆包内置的方法论梳理了参赛规则与 80 余条活动事实，锁定豆包赛道与「模拟实验室」选题——科研工具类目前还没有同题参赛作品，交互型模拟器也满足"有效作品"的门槛。

**第二步，交互设计**：和豆包讨论确定最小可行规格——3 个交互参数 + 粒子动画 + 实时计算 + 关系曲线，明确"用户操作才会发生"的交互原则。

**第三步，代码生成**：让豆包一次性生成完整可运行的 HTML（原生 JS + Canvas 粒子系统 + SVG 曲线），我复核了物理公式与单位换算：P = nRT/V，R = 8.314 J/(mol·K)，默认态 998 kPa ≈ 9.85 atm。

**第四步，质量自检**：用豆包接入的自动化截图工具跑桌面与手机两端渲染，确认无错误后交付；初版完成后又让豆包继续打磨，新增 P–V 反比曲线，并把粒子运动升级为 Maxwell 速度分布 + 弹性碰撞——现在粒子之间会互相弹开、快慢不一，更接近真实气体。

[图2：作品桌面渲染截图（已生成，见 `_shots/理想气体定律实验室_desktop.jpg`）]

[图3：作品 P–V / P–T 关系曲线特写，或移动端截图（可从渲染图中截取）]

作品的每个读数都可核验：默认状态 T=300 K、V=5.0 L、n=2.0 mol 时，P = 2×8.314×300/5 = 998 kPa，分子均方根速率 v_rms = √(3RT/M) ≈ 508 m/s，与公式手算完全一致。

如果你也在学热学，欢迎打开作品自己拖一拖滑块：把 T 从 300 K 拉到 600 K，压强近似翻倍；固定温度只拉体积，压强沿反比曲线下滑。看得见，或许就是理解公式最好的方式。
