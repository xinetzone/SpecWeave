# 知乎 AI 科学创新工坊第二弹 · 9 天冲刺参赛方案

> **时效声明**：本方案编制于 **2026-10-23 09:00**（活动窗口内）。活动截止 **2026-10-31**（F-008），剩余 **9 个日历日**。本方案为**设计产物**，非平台指引；所有规则引用挂 F 编号，收益零承诺。知识包 `status: flagged`，引用数字与产品名须连同证据层级转述。

## 一、决策前提（三条硬约束）

| 约束 | 依据 | 含义 |
|---|---|---|
| 工具绑定不可协商 | F-047、F-050 | 全程使用单一指定工具，违反即无资格 |
| 有效作品有形态门槛 | F-047 | 套壳/批量/搬运/无实质功能一律不计 |
| 获奖是审核后结果 | F-052、F-053、F-054 | 提交≠得奖，平台保留取消权 |

> 在这三条硬约束内，**唯一可自由决策的变量是：赛道、选题、作品规模、过程记录质量**。本方案全部围绕这四个变量展开。

## 二、赛道决策（今天就要做的第一个选择）

### 2.1 双路径决策卡

| 决策点 | 豆包专属赛道 | 看山工作台专属赛道 | 依据 |
|---|---|---|---|
| 工具状态 | 正式版，下载即可用 | **正在内测**，需问卷申请 | F-031 / F-021、F-033 |
| 启动等待 | **0 天** | **≥24 小时**，可能失败需重登 | F-031 / F-034 |
| 工具链路 | 官方下载页已核验（HTTP 200） | 安装包 href **不可复核**，官方手册全网未检索到 | C8 / F-075 |
| 额外权益 | 「有机会获得额外资源助推」（无形式） | 「免费获得海量 Token 额度」（**无量化**） | F-019 / F-022 |
| 现金奖 | 四档共 20,000 元 | 四档共 20,000 元 | F-014~F-017 / F-024~F-027 |

### 2.2 决策结论（洞察/推断）

**默认选豆包赛道。** 理由（第一性原理，见第五节公理 A3/A4）：9 天窗口内，看山赛道的「24h 等待 + 内测不确定性 + 安装包链路未验证」三项成本合计可能吃掉 1-3 天——占总预算的 11%-33%。而「海量 Token」权益**无量化口径**（缺口 G2），不能折算为收益对冲。

**例外**：若你**已经拥有**看山工作台内测权限（可正常登录使用），选看山赛道——此时时间成本前置已被历史支付，且该赛道参赛作品较少、Token 权益成为纯增量（F-022）。**不要为了 Token 现去申请内测**。

> ⚠️ 无论选哪条赛道，**只选一条**（F-050），全程只用该工具（F-047），投稿后公示期前不删帖（F-054）。

## 三、选题定位（差异化机会）

### 3.1 已参赛作品空白带（事实）

检出 6 篇独立参赛作品（F-066~F-071），形态分布：

| 形态 | 作品 | 对应题目 |
|---|---|---|
| 诺奖科普馆 / 数字组 | 辣笔小星、无奈 | 挑战题 1「通俗理解诺奖」（**已饱和**） |
| 图鉴 / 博物馆 | 中科院 Shinehope、一点鑫得 | 自主命题 / 挑战题 3 |
| 模拟器 / 组合式 | 杨杰、师匠 | 自主命题 / 模拟实验室 |

**空白带**：科研工具类 4 题中——「文献速读助手」（F-062）、「同行评审模拟器」（F-063）、「学科脉络地图」（F-064）**零参赛**；「模拟实验室」（F-065）仅 1 个近似形态。

### 3.2 选题三准则（洞察/推断）

1. **有「用户不做就不发生」的交互动作** —— 对应 F-047 有效作品判据；
2. **规模可控** —— 9 天内完成「开发 + 部署 + 文章」，单 HTML 文件 / 前端应用为上限；
3. **过程可留痕** —— 开发过程能截图举证（F-042 配图要求 + F-051 第三维度）。

### 3.3 推荐选题（按优先级）

| 优先级 | 选题 | 理由 | 规模红线 |
|---|---|---|---|
| ⭐ 首选 | **模拟实验室 · 单参数调优版**（F-065） | 空白带 + 天然可交互 + 与科学主题强绑定 | 单 HTML 文件，≤3 个交互参数，1 个可视化图表 |
| 次选 | **复原一项中国古代科技**（F-059，如简仪/水运仪象台简化版） | 空白带 + 文化差异化 + 参数可调模拟器形态成熟 | 同上 |
| 三选 | **把科学做成游戏**（F-060，如中微子通量主题轻量小游戏） | 呼应本期主题（IceCube 诺奖）且避开已饱和的"科普馆"形态 | 单关卡，≤2 个机制 |

> **避开**：诺奖科普馆/知识库形态（已 2 篇参赛，F-066/F-069）；纯文本问答式（撞 F-047「无实质功能」排除项）；多页复杂应用（9 天做不完）。

## 四、9 天执行时序（2026-10-23 ~ 10-31）

```
D0 10-23(五) 今天 ▸ 决策赛道（默认豆包）→ 下载安装豆包 → 选题三选一 → 用豆包生成作品骨架
D1 10-24(六)    ▸ 完成核心交互功能（调试到可正常运行，F-036）→ 全程截图

D4 10-27(二)    ▸ 上传源码至 AI Works「科学季」类型（F-037/F-038）→ 部署成功验证
D5 10-28(三)    ▸ 写介绍文章：≥500字 + ≥3张图（工具截图+作品展示）+ 嵌入作品链接
D6 10-29(四)    ▸ 文章定稿：赛道标注逐字（F-044）+ #AI科学创新工坊 话题发布（F-040/F-049）

D8 10-31(六)    ▸ 截止日：确认投稿完成 → 之后不再删帖（F-054）
```

**关键里程碑**：D4 部署成功（作品可在 AI Works 访问）｜D6 文章发布（投稿完成）。

## 五、第一性原理推导（本方案的生成逻辑）

### 5.1 公理（不可再分基础事实）

- **A1** 获奖资格 = 通过有效作品门槛 × 单赛道合规（F-047/F-050）
- **A2** 评审 = 四维无权重均衡，互动表现为弱参考（F-051）
- **A3** 时间 = 9 日历日，不可扩展（F-008）
- **A4** 工具绑定不可协商（F-047）
- **A5** 获奖是审核后结果，平台保留解释权（F-052/F-056）
- **A6** 退路 = 作品自留可复用，成本零

### 5.2 被证伪的假设（剥离清单）

| 假设 | 证伪依据 |
|---|---|
| 「海量 Token」是可折算收益 | G2 无量化口径，不得折算 |
| 获奖概率可估 | G6 无参与人数、无权重、无评委信息 |
| 挑战题重要（决定成败） | 8 题全部只有标题、无规格（F-057~F-065），只是主题边界 |
| AI 生成质量决定作品 | F-047 判据是**功能形态**，不是代码来源 |
| 互动表现重要 | F-051 措辞为「参考」；刷赞属取消资格（F-054） |
| 好礼有真实价值 | F-073 产品名/价格语义失实；F-082 不计入奖池 |

### 5.3 推导链

```
A3+A4 → 选即时可启动的工具（豆包）
A1    → 作品必须是可交互功能体（非套壳、非纯文本）
A3    → 规模红线：单 HTML 文件，3 天功能+1 天部署+1 天文章
A2    → 四维均衡覆盖（功能+科学+过程+创新），不押单点
A5+A6 → 只把现金当收益；作品自留可复用
```

## 七、合规清单（负向清单全规避）

| # | 禁止事项 | 依据 | 自检 |
|---|---|---|---|
| 1 | 一稿多投 / 轻改重投 / 跨赛道投稿 | F-053 | 一件作品只投一个赛道 |

## 八、收益口径（零承诺）

| 项 | 数值 | 性质 |
|---|---|---|
| 豆包赛道现金奖 | 金奖 5000 / 优秀 2000 / 创新 1500 / 潜力 300，合计 20,000 元 | F-014~F-017、F-083（**名义上限**，非个人可得） |
| 获奖概率 | — | **待验证**（G6） |
| 好礼 / Token / 助推 | — | 不计入奖池（F-082），无量化（G2/G5） |

> **预期管理**：奖池总额 ≠ 个人收益。52 个名额（F-083）对应未知参与人数，个人期望收益不可计算。本方案的收益底线是 **A6——作品自留可复用**（模拟器/游戏本身就是可用的工具），参赛是增量。

## 九、退出条件（止损线）

出现任一情形即停止参赛投入、保留作品自用：

1. 豆包无法在本机正常运行（下载页已核验 HTTP 200，C8；本机环境另测）；
2. 作品形态无法跨过 F-047 门槛（自检「用户不做就不发生」为否）；
3. D4 前作品仍无法部署至 AI Works（F-037/F-038）；
4. 时间不足以完成 4 条投稿要求（F-041~F-044）。
