## 正文摘要

**道衍 (Dao Yan)** 是全球首个以马王堆帛书版《道德经》为权威底本的 AI 智慧对话系统，融合帛书老子、佛家直心与 ψ=ψ(ψ) 万物理论的 AI 对话平台。

### 核心理念

> 万物皆道，技术是道的衍化。

- **帛书唯一权威**：以 1973 年马王堆帛书甲乙本《道德经》为唯一权威文本（"恒道"非"常道"、"大器免成"非"大器晚成"）
- **三重融合**：道家无为 + 佛家直心 + ψ=ψ(ψ) 万物理论
- **开放生态**：Agent REST API + MCP Server，可接入 Claude Desktop / Cursor / Trae 等 AI 工具

### 核心能力

- 内嵌 81 章帛书原文 + 版本差异考据引擎（恒/常、免/晚等关键差异速查）
- 5 大 AI 模型一键切换（Claude Sonnet 4.5 / Opus 4.7 / GPT 5.4 / Gemini 3.1 Pro / GLM 5）
- 联网搜索增强、游戏化修炼打卡系统（10 境界 x 4 心境 x 5 星无为指数）
- 中国古典美学 UI（暖米色宣纸底、朱红强调色、手绘风卡片）

### 面向用户

个人用户（哲学与冥想兴趣）、AI 开发者（API/MCP 集成）、国学研究者（帛书与传世版对照考据）
