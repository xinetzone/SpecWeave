## 各视角审查详述

### 视角一：魔鬼代言人（证伪攻击）

**V1（P0，采纳）——时代错位是本束最大事实风险。**
初稿全部事实来自 2017 年 4 月的单篇博文：Insider build 门槛、fstab 不生效、没有 metadata 选项、无 WSL 2 物理磁盘直挂。2026 年读者若只看命令与限制，会把三条历史约束当成现行行为。修正动作：

1. 补充独立信源 S-005a/b/c（现行官方文档，2026-10-13 抓取），登记现代事实 F-032～F-036；
2. 新增 [05 版本边界与现代 WSL 演进](../concepts/05-version-and-modern-wsl.md)，每篇概念文加「时代定位（先读）」或现代演进指引；
3. 历史与现代事实在事实台账中分节（A～G 节为 2017 史实，H 节为现代演进），编号不混排。

**V2（P1，采纳）——0777 结论的现代有效期攻击。**
博文「网络文件系统全部报告 0777」在 2017 年是完整事实，但现代 drvfs 支持 `metadata` 挂载选项与 uid/gid/umask 控制（F-033）。修正：[04](../concepts/04-filesystem-semantics.md) 的语义矩阵明确标注为「博文原文（2017）」，[05](../concepts/05-version-and-modern-wsl.md) 用选项表给出补救路径，并保留一条硬边界——选项改变呈现方式，不能让底层 FAT/网络共享凭空支持符号链接。

**V7（P2，不采纳为事实结论）——性能议题构陷攻击。**
评论区「慢 4～5 倍」类数字无统一测量方法、无环境基线，若进入正文成为「drvfs 性能差」的证据即构成错误因果。处置：F-029 以 C 级单源登记、只作现象；性能布局的**结论性建议**只引用现行权威信源 S-005a（F-034），并在 04/05 两处显式区分二者效力等级。初稿已按此处理，V7 不产生文档改动。

### 视角二：新人（零背景照做）

**V3（P1，采纳）——评论区是命令污染源。**
评论区包含 `sudo mount -t drvfs 'U:Windows' /mnt/u`（源路径与正文范式不一致，F-030）、fstab 写法与「新会话不自动挂载」的过期经验（F-028）。新人无法分辨正文与评论的权威度。修正：事实台账中 C 级条目标注「不进命令范式、只作排错现象」；[05](../concepts/05-version-and-modern-wsl.md) 第二节直接给出 fstab 的现代正式答案（`mountFsTab=true` 为默认行为，F-032）；F-030 在 02 排错场景中仅作症状引用。

**V4（P1，采纳）——无报错的失败最致命。**
博文只说凭据在 Windows 侧，未给失败形态与排查顺序；评论区真实症状是命令零报错、`ls` 报目录不存在（F-018）。修正：[02](../concepts/02-network-mount.md) 增补症状片段与三步排查（先在 Windows 侧验证可达与认证 → 回 WSL 挂载 → 以实际访问而非命令返回码判定成功）。

### 视角三：老板（成本/收益与可执行性）

**V5（P2，采纳为结构收敛）——单信源是否值得 6 篇文档。**
本束无多步实战案例（不同于部署类教程），强设 examples 目录会制造注水内容。修正：取消 examples 层，结构收敛为「6 篇概念文（含排错与现代演进）+ 3 篇 references + 首页」；首页以「三条必须先知道的结论」让读者 3 分钟获得可执行心智，细节按需下钻。命令均可直接复制执行，投入产出成立。
