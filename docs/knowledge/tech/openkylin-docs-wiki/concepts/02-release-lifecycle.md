# 02 版本发布与生命周期：LTS 与创新版双轨、代号与镜像

> 读完本文你会知道：openKylin 版本怎么编号、维护多久、各代号对应什么、下载页的镜像品类怎么选。本文事实以文档站《openKylin 操作系统版本规划》（2026-04-09 TC 表决通过）为主，与[同包项目调研](../references/project-overview.md)互证。

## 2.1 双轨版本制

| 轨道 | 发布节奏 | 维护周期 | 定位 |
|---|---|---|---|
| **LTS（长期支持版）** | 每 3 年一个主版本 | 2 年主动维护 + 3 年被动维护（共 5 年） | 稳定生产基线 |
| **创新版本** | 每 1 年一个 | 1 年被动维护 | 新技术试验田，快速迭代 |

三个维护阶段提供的服务不同：

- **开发阶段**：需求收集、组件选型升级、集成测试、RC 与正式版发布；
- **主动维护（仅 LTS，24 个月）**：定期（月度/季度）更新、严重缺陷修复、高危安全漏洞修补、评估后合入功能增强与硬件兼容更新；
- **被动维护（LTS 36 个月 / 创新版 12 个月）**：仅修严重稳定性问题与高危/严重安全漏洞，**不**提供新功能与非关键 Bug 修复。

> 选型含义：追求稳定、不愿每年跟版本升级，选 LTS；要第一时间用新内核与新 AI 能力、能接受一年维护窗口，选创新版。

## 2.2 代号谱系

| 版本 | 代号 | 发布时间 | 内核 | 维护窗口 |
|---|---|---|---|---|
| openKylin 1.0 | yangtze（软件源/源码包系列代号） | 2023-07 | 6.1 + 5.15 双内核 | 已不在当前规划页维护表 |
| openKylin 2.0 LTS | **Nile** | 2024-08-08 | Linux 6.6 LTS | 至约 2029-08 |
| openKylin 3.0 创新版 | **Huanghe** | 2026 年 | Linux 7.0 | 发布后 12 个月被动维护 |

代号不仅是名称，在工程平台上是实际参数：

- OKBS 上传源码包时，`changelog` 中的系列代号要设为对应代号（示例文档用 `yangtze`）；
- factory 版本构建平台的 bootstrap 软件源要按代号选（文档原文："1.0 软件源就是 yangtze；2.0 软件源就是 nile"）。

## 2.3 各版本关键特性（文档站口径）

**2.0 LTS（Nile）**——规划页列出的核心特性：

- 180+ 核心组件自主选型升级（系统基础库、工具链、多媒体框架等）；
- UKUI 4.10 桌面；
- AI 子系统，支持本地 AI 推理与智能助手；
- 开明软件包格式；不可变系统；wlcom Wayland 合成器；KARE 生态兼容方案。
- 其后续 SP1（2024-12）新增 ARM/LoongArch 通用镜像与统一 RISC-V 镜像；SP2（2025-08）搭载 UKUI 4.20、磐石架构（不可变系统 + KARE + 开明包）、多云模型接入。

**3.0 创新版（Huanghe）**——规划页与 2026-09 镜像：

| 组件 | 规划版本 |
|---|---|
| GCC | 15.2 |
| LLVM | 22 |
| glibc | 2.42 |
| Mesa | 26.0 |
| OpenSSL | 3.5 |

另列两大方向：强化 RISC-V RVA23 支持；AI 推理框架深度优化、提升端侧能力。3.0 实际发布形态（Linux 7.0、智能体开放底座、MCP、四架构同源等）以官网新闻为准，参见[同包项目调研 §2.2](../references/project-overview.md)。

## 2.4 下载页镜像品类（安装前先认清）

文档站与官网下载中心提供的镜像不是一个文件，而是按形态与架构分系列（2026-09 时点）：

| 镜像 | 用途 | 备注 |
|---|---|---|
| Desktop ISO（X86/ARM/LoongArch） | 物理机/虚拟机桌面安装 | 主镜像约 7.5G 量级 |
| Server ISO（X86/ARM/LoongArch） | 服务器场景 | 分架构日期不同 |
| WSL 基础镜像（约 336M） | Windows 子系统命令行环境 | `.wsl` 本质是 gzip tar，见 [03 安装路径](03-install-paths.md) |
| Desktop WSL 镜像 | WSL 内图形桌面 | xrdp 端口 3390 |
| RISC-V 镜像 | SpacemiT K3 Server/Embedded 等及统一镜像 | 配套烧录工具 |
| Phytium Pro | 飞腾平台专用 | — |
| Docker 应用镜像 | AI/云计算/大数据场景 | 3.0 提供 20 余款 |
| 衍生版（AgentOS / Claw Box OS / 行业定制） | 智能体与创新硬件形态 | 见[同包项目调研 F-048](../references/project-overview.md) |

> 文档站《版本发布动态》页目前为短索引页，历史发布仅存 SP1 一篇——**版本细节以官网新闻与下载页为准，文档站该板块不完整**。

## 2.5 升级路径提示

- FAQ 收录"如何升级 openKylin"条目；跨版本升级在官方体系中可通过 `kylin-revision-manager`（apt 安装）管理（见[同包项目调研 F-035](../references/project-overview.md)）。
- 磐石架构（不可变系统）下安装软件有专门条目："磐石架构如何手动安装软件包""当前模式禁止执行 unpack 操作"——不可变系统上的软件安装行为与传统 apt 路径不同，遇报错先查 [04 桌面使用 FAQ](04-desktop-usage.md)。
