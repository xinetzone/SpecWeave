# 04 桌面环境与基础使用：UKUI、装软件、驱动与 FAQ 导航

> 1_4 基础操作（68 篇）与 1_6 常见问题（5 篇）是整个文档库最厚的部分。本文把散页整理为"装完系统后"的能力地图，并给出官方文档中没有明说的阅读注意事项。

## 4.1 桌面环境：UKUI

openKylin 默认搭载 **UKUI**（Qt 技术栈桌面环境），文档站相关入口有三类：

- **使用侧**：《openKylin新手使用指南》《桌面展示》《openKylin用户手册》《查看用户手册》；
- **组件侧**：文件管理器（介绍/权限/默认分区/用户手册 4 篇）、归档管理器、系统监视器、终端三种启动方法、看图软件、护眼模式、个性化开关机动画、字体配置、国标字体迁移；
- **设计侧**（贡献者向）：4_9 桌面设计的 22 篇 UKUI 规范，含 UKUI3 框架介绍、UKUI4 设计理念与色彩/布局/图标/对话框/指针/触控手势/界面用语/空状态等设计指南，见 [06 开发者基础设施](06-developer-infrastructure.md)。

版本对应：UKUI 4.0 随 1.0（0.95 起）、4.10 随 2.0、4.20 随 SP2、4.24 随 3.0。**文档库中大量桌面截图与菜单描述来自 4.0 时代**，若你的系统是 3.0，菜单位置以实际界面为准。

常用设置条目：分辨率、屏保、纯色背景、时区与时间同步、休眠、默认应用、账户与免密/自动登录、全局搜索、默认快捷键、网络配置。

## 4.2 命令行基础（官方新手指南主线）

《openKylin新手使用指南》给出的最小命令集：

```bash
sudo apt update            # 系统/软件源更新
sudo apt install <包名>     # 安装
sudo apt remove <包名>      # 卸载
wget <url>                 # 下载
sudo dpkg -i <文件.deb>     # 安装本地 deb 包
```

其他常备文档：《Linux文件基本操作》《常用的组合命令》《查看linux系统相关信息命令汇总》《Linux中你一定要掌握的网络基本命令》《ssh基础用法》《ssh免密登录》《ssh-X11代理配置》。

进阶两篇《小白课程/Linux学习指南-基于openKylin》与《Linux新手大礼包》适合从零补课。

## 4.3 安装软件的三条路径

| 路径 | 适合 | 文档中的实例 |
|---|---|---|
| apt 源 | 已入仓库或可加源的软件 | 360 浏览器、Google Chrome |
| 本地 DEB | 官网提供 deb 的国产软件 | 微信、腾讯会议、腾讯文档、ToDesk、EasyConnect、Notepad-- |
| 编译/其他 | 无 deb 或需要定制 | PyCharm；另有 VS Code、OBS Studio 专篇 |

文档库还覆盖一批"在 openKylin 上玩起来"的场景：HMCL 玩 Minecraft、OpenRGB 灯效、tuned 电源管理、Epic 商城与虚幻引擎、RISC-V 上编译 Godot——属于社区投稿性质，随版本可能需要自行调整。

> 不可变系统（磐石架构）注意：FAQ 专门有"磐石架构如何手动安装软件包"与"当前模式禁止执行 unpack 操作"两个条目；3.0 还有独立的开明（Kaiming）包与软件商店渠道。传统 apt 路径报策略错误时先查这两条。

- **NVIDIA 独显**：《从NVIDIA官网安装闭源显卡驱动》（5721 字符）含支持列表与远程服务器命令行安装；装完问题查《GPU常见问题》。
- **无线网卡**：《无线网卡支持》（11252 字符，按制造商/芯片/版本组织，内容译自 Ubuntu WifiDocs）+《网卡常见问题》；USB/板载 Wi-Fi 选型前先查芯片型号是否在表。
- **整机信息自查**：FAQ 给出 CPU（含大小核）、内存、硬盘、电池、声卡、主板/BIOS、显示器、USB 3.0、虚拟化支持的查看命令——报 Issue 或求助前应先跑这些命令贴出环境。

## 4.6 FAQ 使用方法

总览 FAQ 约 20 个条目，组织方式是"现象→命令/步骤"，最高频的四类：

1. **包管理**：依赖损坏修复、文件冲突、unpack 被禁止、apk 包安装、版本升级；
2. **硬件自查**：CPU/内存/硬盘/电池/声卡/主板/USB/虚拟化信息；
3. **软件安装**：OBS Studio、磐石架构手动装包；
4. **环境设置**：root 密码、默认终端、补全大小写。

三个专题 FAQ（GPU / 文件操作 / 网卡）在 2026-09 仍有提交更新，是最新的一档文档。另有《FAQ文档贡献指南》——想给 FAQ 投稿先读它（注意其中分支与目录说明在 !518 中被修正过，以仓库最新版为准）。
