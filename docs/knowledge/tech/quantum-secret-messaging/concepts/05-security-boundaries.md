# 05 安全边界与争议

> 阅读目标：把「量子安全」从宣传语还原为工程边界——QKD 的安全证明覆盖到哪里、不覆盖哪里；国际主要安全机构为何对 QKD 持保留态度；普通用户应如何解读。

## 1. QKD 确实提供的东西

1. **密钥分发的物理可检测性**：对量子信道的窃听会扰动量子态、引入可测量的误码，双方可察觉；
2. **不依赖计算假设**：该环节安全性基于物理原理，未来量子计算机的算力不改变这一性质；
3. **高熵密钥源**：配合量子随机数发生器，提供高质量对称密钥材料。

注意覆盖范围：以上性质针对**量子信道与密钥建立环节**。

## 2. QKD 不覆盖的五个边界

| # | 边界 | 说明 |
|---|---|---|
| 1 | 不覆盖消息加密层 | 批量数据仍由 AES-256-GCM、SM4 等经典对称算法加密；经典层实现缺陷不被量子证明覆盖 |
| 2 | 自身不提供认证/签名 | 量子信道需预置密钥做经典认证或使用 PQC，否则存在中间人攻击面；QKD 不能替代数字签名 |
| 3 | 距离与可信节点 | 单段约百公里量级；长途经可信中继节点明文落地再加密，端到端安全归约为各节点物理/人员安全 |
| 4 | 实现与侧信道 | 真实器件偏离理想模型（弱脉冲多光子、探测器侧信道等），需诱骗态、MDI 等工程补丁，安全证明附带硬件假设 |
| 5 | 拒绝服务脆弱性 | 注入光信号可致盲/饱和单光子探测器，使密钥分发中断，必须有备用密钥机制 |

NSA 2021 年文件将上述意见概括为五项并列局限，并明确不支持将 QKD 用于国家安全系统通信；NCSC（英国）结论与其一致。

## 3. 国际机构立场全景

### 3.1 五机构联合立场文件

法国 ANSSI、德国 BSI、荷兰 NLNCSA、瑞典军方通信安全机构联合发布 QKD 立场文件，核心结论：

- 受当前及固有局限约束，QKD 实践中仅能用于**少数利基场景**；
- 绝大多数现有经典密钥协商场景无法实际改用 QKD；
- QKD 安全成熟度仍然不足；
- 优先事项应为**迁移到后量子密码和/或采用对称密钥**。

### 3.2 立场的准确解读

这些文件**不是宣布 QKD 物理原理无效**，而是从部署成本、认证依赖、可信节点、工程验证四个维度判断其不适用于一般场景；文件同时承认在特定高安全、资源充足场景可考虑 QKD。

### 3.3 与中国电信融合体系的对照

| 维度 | 欧美机构主张 | 量子密信融合体系 |
|---|---|---|
| 接入/认证层 | PQC 优先 | 接入段使用 PQC |
| 干线层 | QKD 仅利基场景 | 骨干跨域段使用 QKD（经可信中继） |
| 数据层 | 经典对称算法 | 国密对称算法 |
| QKD 中断韧性 | 需备用机制 | 不支持时回落 VoLTE；体系设计含分层降级 |

工程结构差距小于「路线之争」的舆论呈现；真正的分歧在干线层 QKD 的适用范围与成本判断。

## 4. 声明审计：三组高频表述的真实口径

| 宣传表述 | 学术/工程口径 |
|---|---|
| 「一次一密，无惧破译」 | 实际为会话级密钥更新（每会话新密钥、会后废弃）；香农 OTP 要求密钥与消息等长，当前网络不支持大规模等长供给（厂商论文自述） |
| 「无条件安全 / 绝对安全」 | 仅在理想协议假设下针对量子信道；真实器件安全是附带硬件假设的组合安全 |
| 「抗量子」 | QKD 提供密钥分发抗量子；终端接入靠 PQC（数学安全性需随密码分析进展复核） |

审计方法：要求供应商书面区分四个概念——OTP、会话密钥更新、信息论安全、计算安全，并说明安全证明的假设与边界。

## 5. 应用商店低评分应如何安放

- App Store 1.4 分、用户评论指向打卡/多端一致性等**办公体验问题**，属终端用户主观信号；
- 该信号不构成对密码安全能力的评价，也不能被安全能力认证抵消；
- 组织采购的正确做法：安全维度查认证（信通院 7 模块 109 项）与架构，体验维度安排真实办公场景试用。

## 6. 认证能说明什么、不能说明什么

2025 年 7 月量子密信通过中国信通院「铸基计划」软件平台网络安全防护能力完备性评测（7 大模块 109 项，泰尔终端实验室近 2 个月测试），为首个获认证的办公即时通讯软件。

- 能说明：在评测版本与条目范围内，客户端、通信、敏感信息防护等工程能力满足评测要求；
- 不能说明：不等同于对 QKD 物理设备的独立密码学鉴定，也不覆盖未纳入评测的定制部署版本。

## 7. 结论时效声明（V 审查补充）

本页结论受两类技术进展影响，需定期复核：

1. **量子中继器/量子存储器**若成熟，可削弱可信节点问题，改变 QKD 干线安全结构；
2. **PQC 密码分析**若出现新攻击，当前标准化算法的安全判断需更新；反之 PQC 软件迁移的紧迫性不因此消失。

## 8. 本篇结论

1. QKD 的价值真实但边界明确——**密钥分发环节的物理安全**，不是消息全链路安全；
2. 国际争议的实质是成本与适用范围，不是物理原理真伪；
3. 用户与采购方最可靠的工具是「逐段核验 + 声明审计 + 韧性预案」，立场站队没有工程意义。
