# 06 模式：双轨分层迁移法

> 定位：E 阶段萃取的可迁移模式。当组织面对「量子计算威胁」叙事与量子安全产品推销、需要决定密码升级路径时使用。成熟度 **L1-draft**：有三类相互独立的外部来源同向支撑，但尚未在本项目实战验证。

## 1. 触发场景

**适用于**

- 组织开始规划抗量子（quantum-safe）密码升级，面对 QKD 专线、量子安全产品、PQC 改造多种方案；
- 供应商以「量子加密」「一次一密」为卖点推销通讯/办公产品，需要工程化评估；
- 存量系统（OA、专线、VPN、IM）需要确定迁移优先级与预算分配。

**不适用于**

- 纯学术密码协议研究；
- 单个具体算法的代码实现（应直接遵循 FIPS/国密标准与实现指南）；
- 无长期保密要求、无 HNDL 暴露的纯短期数据系统（常规密码维护即可）。

## 2. 核心做法：六步流程

```mermaid
flowchart LR
    S1[①威胁分级] --> S2[②术语回验]
    S2 --> S3[③先PQC迁移]
    S3 --> S4[④分层映射QKD]
    S4 --> S5[⑤证明范围审计]
    S5 --> S6[⑥韧性降级预案]
```

### ① 威胁分级

按两个维度盘点数据资产：保密年限（公开/10 年/30 年以上）与 HNDL（先截获后解密）暴露面。长保密年限 + 可被批量采集的链路优先。

### ② 术语回验

在阅读任何方案前对齐四个词：OTP（密钥等长、信息论安全）、会话级密钥更新、QKD（密钥分发物理安全）、PQC（抗量子数学算法）。把供应商文案逐词映射到学术定义。

### ③ 先 PQC 迁移

优先以软件升级方式覆盖认证、密钥协商与签名：参照 NIST FIPS 203/204/205 与国内 PQC/国密进程，采用混合握手（传统 + PQC）降低迁移风险。这是跨阵营机构一致认为不可跳过的一层。

### ④ 分层映射 QKD

仅在跨域干线/专线、点对点高安全场景评估 QKD：核对城域网覆盖、可信中继节点安保、密钥率是否满足业务；接入层与批量数据层不依赖 QKD。

### ⑤ 安全证明范围审计

要求供应商逐段书面回答：密钥从哪里来、用什么算法、证明基于哪些硬件假设、覆盖哪些环节；明确「量子安全证明」不覆盖经典加密层与终端实现。

### ⑥ 韧性降级预案

为 QKD 中断设计降级路径（PQC、对称预共享密钥、通话回落）；定义切换触发条件与告警；把拒绝服务（探测器致盲）列入威胁建模。

## 3. 反模式（≥3，来自实际案例教训）

| # | 反模式 | 表现 | 替代做法 |
|---|---|---|---|
| 1 | 标签溢价 | 因「量子」二字接受更高报价，未按环节核验 | 逐段成本/能力对比，无 QKD 覆盖段按常规密码计价 |
| 2 | 语义混淆 | 把宣传语「一次一密/绝对安全」当学术 OTP/信息论安全 | 术语回验 + 书面证明边界 |
| 3 | 路线冒进 | 跳过 PQC 直接建设 QKD 专网 | PQC 先行，QKD 按干线场景增量评估 |
| 4 | 节点盲信 | 把可信中继当作「量子网络」默认安全 | 逐节点审计物理与人员安保，纳入端到端风险 |
| 5 | 评分替代审计 | 以应用商店评分或品牌判断安全能力 | 安全认证与体验试用分立评估 |

## 4. 检验标准

做完一轮迁移后，对每条关键链路都应能在一张表中回答四问：

1. 密钥从哪里来（QKD/PQC/预共享）？
2. 数据用什么算法加密（具体国密/国际算法与模式）？
3. 安全证明的边界与假设是什么？
4. 该段中断时降级到什么、多久切换？

四问中任一问答缺失，视为该段未完成迁移。

## 5. 跨领域迁移示例

**迁移到 AI 系统选型**：面对「大模型能力」推销时采用同构方法——①按任务失败成本分级（对应威胁分级）；②对齐术语（演示能力/生产 SLA/准确率口径，对应术语回验）；③先上成熟标准能力（对应先 PQC）；④把高阶方案用于高价值场景（对应干线 QKD）；⑤审计性能声明的测试边界（对应证明范围）；⑥准备模型不可用时的降级链路（对应韧性预案）。

结构同构：**先必备层、后增强层；声明逐字回验；失效必有降级**。

## 6. 升级条件

- 升 **L2-validated**：在本项目完成一次完整迁移实战，且六步产出物（分级表、术语表、PQC 迁移记录、QKD 评估、证明审计、降级预案）经独立复核；
- 升 **L3**：再获两个不同行业案例验证，并经一次真实中断（或演练）检验降级路径。

## 7. 与既有模式的边界

- 与「最小充分脚手架选型法」（agent 选库）同属选型族，但后者面向软件依赖、本模式面向密码体系，触发场景与产物不同；
- 不替代具体密码实施规范（FIPS/国密）与等保/商密合规流程，定位在它们之前的**路径决策层**。
