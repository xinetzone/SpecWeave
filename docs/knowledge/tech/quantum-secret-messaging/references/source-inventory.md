## A.7 复核方法

1. **App 版本**：重访对应应用商店页面，记录版本号与更新日期；安卓以包名 `com.ctq.qmchat` 检索；
2. **用户规模**：检索中国电信/中电信量子集团官方新闻稿，注意数字口径（注册/在网/服务用户）与时点，官方数字无第三方审计；
3. **基础设施**：核对中国电信官网与地方公司公告，城域网数量与互通状态按最新官方表述刷新；
4. **国际立场**：以各机构官网原始文件为准，注意文件发布/更新年份，立场可能随技术进展调整；
5. **标准版本**：NIST FIPS 203/204/205 以 csrc.nist.gov 公布文本为准；国内 PQC 进展以国家密码管理局公告为准。
