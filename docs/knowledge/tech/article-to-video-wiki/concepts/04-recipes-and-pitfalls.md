# 04 · 三种配方、成本账与避坑清单

[返回知识包首页](../index.md)

## 1. 配方一：漫剧（二次元/国漫风竖屏短剧）

**适用素材**：网文、公众号故事、民间传说、情感故事。**成片画像**：1–3 分钟/集、强钩子、连载。

| 段 | C 端方案（推荐新手） | API/Agent 方案（可批量） |
|---|---|---|
| 剧本 | LLM 拆镜（[03 模板](03-trae-workflow.md)） | 扣子 AI 漫剧 Agent（最多 80 集）/ 阅文 DramaBuddy（有网文 IP 时） |
| 资产 | 即梦主体库（外观+音色） | Seedream 5 三视图 ¥0.44/组 + 参考图绑定 |
| 视频 | 即梦 Agent `/创作分镜` | **Vidu q3-drama**（漫剧行业模型）/ PixVerse V6（便宜的二次元档，$1≈5 条）/ 可灵 3.0 Multi-Shot（质感档）/ Seedance 2.0（全能参考） |
| 动作大场面 | DomoAI 角色生视频 | Viggle $0.01/秒（打斗/舞蹈）；Wan Animate 自托管 |
| 画风统一 | 即梦风格大师 | GoEnhance 全片风格化/超分 $0.020/秒起 |
| 平台 | 剪映 → 红果漫剧/抖音/B 站 | 火山剧创（漫剧类型）/ LibTV |

扶持渠道（2026 口径，**以官方当期政策为准**）：快手星芒 × 可灵 8 亿分账 + 2 亿孵化 + 10 亿流量（F-032）；B 站觉醒计划媒体称最高 80% 分账（F-034，待核实）；快看/B 站/红果各有厂牌合作。

## 2. 配方二：AI 真人短剧（写实、出海为主）

**适用素材**：霸总/逆袭/悬疑类强情节文本。**成片画像**：1–2 分钟/集、DramaWave/ReelShort/NetShort 类平台。

| 段 | 平台闭环方案 | API 自建方案 |
|---|---|---|
| 剧本 | SkyProduction 导演 Agent / 火山剧创 | LLM + 角色圣经 |
| 资产 | 平台角色库 | Nano Banana Pro 关键帧（约 $0.06–0.12/张）/ 自训 LoRA |
| 视频 | 聚合 Seedance/可灵/SkyReels-V4 | 可灵 3.0 / Seedance 2.5（30 图参考）/ H3（12 文件绑定，¥0.5/秒）；关键镜头 Veo 3.1/Sora 2 提质感 |
| 配音 | 平台内置 | ElevenLabs v4（多说话人）/ 魔音工坊（中文情绪） |
| 口型 | 平台内置/重制工坊 | sync-3（$0.107–0.133/秒）/ HeyGen / 开源 LatentSync |
| 出海译配 | **火山重制工坊**（拉片翻拍）/ OiiOii 一键出海（人种替换 + 多语种）/ NetShort 17 语种工具 | HeyGen 视频翻译；飞兔兔类东盟语种服务商 |

**决策线**：有 IP 或想要发行流量 → 进 DramaBuddy/SkyProduction/红果体系（让渡工具自主权换渠道与分账）；纯制作工作室 → API 自建 + 向平台供片。市场信号：2026H1 海外微短剧 TOP20 中 16 款国产、AI 短剧 App 收入约 $12.7 亿（F-035，媒体转引），但同期国内半年 22 万部、破亿不足 0.5%（F-004）——**发行集中度极高，不要默认"做出来就有人看"**。

## 3. 配方三：文章解说 / 小说推文视频（门槛最低）

**适用素材**：干货文章、观点文、小说精彩片段。**成片画像**：单主播/单旁白 + 配图画面，30–90 秒，投流导向。

- **最快路径**：TRAE `explainer` Skill，mode=`story`（故事叙述型），文本直接进 `POST /storybook/episodes`，3–5 分钟成片（F-055）。
- **营销矩阵**：即创 AIC（制作即投放、一键过审）、闪剪/万兴播爆（数字人口播矩阵）。
- **小说推文**：云推巨量类工具（授权书库 + AI 混剪）；**必须**配句易网/句无忧违禁词检测再投流（F-051）。
- 不建议为此类需求调用 Seedance/Veo——解说类的画面是配音的陪衬，图生图 + Ken Burns 运镜（hyperframes GSAP 即可）性价比最高。

## 4. 单集成本测算（1–2 分钟/集，2026-10 量级口径）

> 仅用于建立预算感觉。模型按秒计费、平台按积分计费且月变；以下用"计价单位 × 用量"测算，不含投流费。

| 成本项 | 用量假设 | API 自建单价口径 | 单集量级 |
|---|---|---|---|
| 关键帧图 | 10–14 张 | Seedream ¥0.22/张、三视图 ¥0.44 | ¥3–10 |
| 视频生成 | 约 80–100 秒成片，按 2–3 倍废片率生成 200–300 秒 | Wan3.0 720P ¥0.6/秒、H3 768P ¥0.5、Seedance fast ¥0.34 起；可灵/PixVerse 积分档约 ¥0.2–0.7/秒 | ¥70–300（选档差异最大） |
| TTS | 约 300–500 字 | 剪映朗读≈0（含会员）；ElevenLabs 约 $0.08/千字符 | ¥0–10 |
| 口型 | 约 20–40 秒正面对白 | sync-3 ≈ ¥0.8–1/秒；LatentSync 自托管≈电费 | ¥0–40 |
| 风格化/超分 | 可选 | GoEnhance $0.020/秒 | ¥0–45 |
| **合计制作** | — | — | **约 ¥80–400/集**，与媒体口径"漫剧 ¥400–500/集（含修改筛选）、改编一本书 ¥3 万起"（F-005）同量级 |
| C 端订阅替代 | — | 即梦 ¥69/月 + 剪映 AI Ultra | 月费制，含积分，量小更划算 |

**ROI 提示**：制作成本已是零头（约实拍 1/10，F-006），单集成败主要由投流与完播率决定；先做 1 集小成本测钩子完播率，再决定是否连载，比一次性做 10 集更理性。

## 5. 反模式清单（8 条，见首页证据映射）

1. **跳过资产直接文生视频** → 跨镜换脸，整集返工。
2. **画面里生成汉字**（招牌/信件/手机屏幕）→ 几乎必崩；所有文字放字幕层。
3. **单镜头多主体群像** → 首要崩坏源；每镜一主体，对话用正反打或剪映多人对话功能。
4. **等"一次生成 10 分钟"的模型** → 错误路线；连载靠资产复用与镜头表，不靠单条时长。
5. **拿媒体价格做预算** → 按"计价单位 × 镜头数 × 废片率"自建模型；会员积分与按量付费分别测算。
6. **无授权三连**：未购改编权的小说、未授权的声音克隆、无授权 BGM → 一次下架吞没全部成本。
7. **只信接口 success** → 不核对物理量、不做逐镜目检；成功返回 ≠ 画面可用。
8. **推文裸投** → 不过违禁词、不查平台审核规则，封号概率显著上升。

## 6. 合规与版权清单（发行前逐项打勾）

- [ ] 文本：文章/小说改编授权链留存（自有、平台授权书、CC 协议截图）
- [ ] 声音：TTS 克隆声音的授权与使用范围；平台默认音色的商用档位（会员等级）
- [ ] 肖像：真人脸素材授权；注意 Seedance 人脸视频 30 天留存等平台条款
- [ ] 音乐：BGM/音效来源台账（剪映/平台曲库的商用范围、第三方授权）
- [ ] 标识：AI 生成内容按目标平台要求标注；C2PA/SynthID 等内容凭证不要抹除
- [ ] 广告：投流素材过违禁词（句易网/句无忧）+ 平台预审
- [ ] 出海：目的国对 AI 内容、深度合成、配音译制的监管要求（欧美/中东/东盟差异大）

## 8. 成熟度与回填要求

本配方为 **L1-draft**：价格与平台政策已核实到 2026-10-18，但尚缺端到端成片的实测返工率。执行第一批生产后请回填三个数：**各段废片率、单集实际成本、一次过审率**——这三个指标将驱动模式升级 L2 与镜头表 Prompt 的迭代。
