# 02 · 五层工具选型图谱（2026-10 时点）

[返回知识包首页](../index.md)

> **读法**：按管线五段（模型 / 一体化制片 / 漫剧短剧平台 / 图文成片 / 组件）分层。价格只用于建立"量级感"，**采购一律以官网实时价为准**。表中"计价单位"比数字更长寿——模型换代后按单位重新询价即可。

| 模型 | 动漫/写实倾向 | 时长/规格 | 计价单位与量级（2026-10） | API | 选型备注 |

**模型替换原则**（应对 3–6 个月生命周期）：镜头表用"能力槽位"而非模型名记录需求——槽位是「分辨率/时长/参考素材数/画幅/风格」；模型下线时按槽位参数在本表重选，剧本与资产零改动。
