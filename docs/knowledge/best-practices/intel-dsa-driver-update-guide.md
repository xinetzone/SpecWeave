# 英特尔 DSA 使用指南与老旧电脑驱动升级方案

> 一句话摘要：Intel DSA 是覆盖显卡、网卡、存储控制器的**自动更新通道之一**而非全部；驱动维护应先判定硬件生命周期，再按「自动—手动—OEM—系统内置—离线归档」分层取包。

---

## 1. 工具定位

英特尔® 驱动程序和支持助理（Intel® Driver & Support Assistant，简称 **Intel® DSA**）是英特尔官方提供的免费 Windows 应用程序，核心功能包括：

1. 识别系统中由英特尔及第三方安装的驱动程序；
2. 扫描英特尔驱动程序、软件更新以及系统与设备信息；
3. 在仪表板中提供下载、安装入口与支持信息链接。

典型的安装、加载与分析过程，在宽带连接（DSL/有线）下约需 **3–6 分钟**。工具仅收集系统与设备信息，不收取费用。

### 1.1 支持环境（官方文档口径）

| 项目 | 支持范围 |
|------|---------|
| 操作系统 | Windows 7 / 8 / 8.1 / 10 / 11（32 位与 64 位） |
| 浏览器 | Firefox、Chrome、Edge（或 Edge 旧版 44.17763/18.17763 及以上）；其他浏览器未经验证 |
| 语言 | 简体中文、繁体中文、英语、法语、德语、印尼语、日语、韩语、葡萄牙语（巴西）、西班牙语、泰语、越南语 |
| 网络端口 | 本地回环 `localhost` 端口 **28385–28389**；对外通过 **443（HTTPS）** 连接 `www.intel.com`、`dsadata.intel.com`、`downloadmirror.intel.com` |

> ⚠️ **重要时效提示（文档口径与实际运行时的差异）**：DSA 自 **25.2 版本**起进行 .NET 8 运行时现代化改造，而 **.NET 8 官方不支持 Windows 7 / 8.1**（这两个系统的最后受支持 .NET 版本为 .NET 6，已于 2024-11-12 终止支持）。因此尽管官方知识库的环境字段仍累计列出 Windows 7 / 8.1，运行 **25.2 及以上版本安装包在这些系统上可能无法启动**。受影响机器的可行路径为：使用 **25.1.x 或更早版本**的 DSA，或直接在英特尔下载中心手动取包。

> DSA 不支持「多会话操作系统」，即被配置为多用户同时远程登录会话的主机（如远程桌面会话主机、Citrix 类发布环境）。

## 2. 能力边界：DSA 能更新什么

DSA 提供的是英特尔下载中心可下载内容的一个**子集**，检测范围如下：

| 组件类别 | 检测与更新情况 |
|---------|---------------|
| 显卡 | 台式机与笔记本的英特尔集成/独立图形控制器 |
| 无线网络 | 当前活动的英特尔无线产品；停产产品可被检测但通常不提供更新 |
| 有线网络 | 部分零售版英特尔以太网适配器，以及英特尔台式机主板的集成网络连接 |
| 英特尔 NUC | 部分 NUC 产品的全套驱动 |
| 快速存储技术（RST） | 检测 RST 软件更新 |

### 2.1 DSA 明确不覆盖的内容

以下内容须通过下载中心或 OEM（整机制造商）渠道单独获取：

- 英特尔**服务器**驱动程序；
- **Linux** 驱动程序；
- **芯片组**驱动程序（芯片组 INF）；
- 图形媒体加速器 **GMA 500** 驱动；
- NUC 笔记本形态产品的驱动；
- **BIOS 文件**（仅英特尔 NUC 与电脑棒例外）；
- Visual Compute Accelerator 软件；
- 大多数**固件**（仅英特尔可信执行引擎与英特尔固态硬盘例外）；
- 已停用的传统无线适配器（如 Wireless-AC 7260/3160 系列等）。

### 2.2 DSA 找不到硬件的四种情形

当组件未被检测到时，官方列出的原因为：部件过于陈旧；组件已停产或不受支持；部件并非英特尔生产；组件不在英特尔数据库中。

> 上述四种情形均属**产品生命周期状态**，不是工具故障。反复重装 DSA 不会改变检测结果。

## 3. 安装、运行与卸载

### 3.1 安装步骤

1. 从英特尔 DSA 官方页面下载安装程序；
2. 双击 `Installer.exe`；
3. 阅读并同意许可条款；
4. 选择「安装」；
5. 安装完成后单击「启动」——托盘图标出现，并自动打开默认浏览器。

### 3.2 运行与更新

- 单击托盘图标并选择「检查新的驱动程序」，或从「开始」菜单搜索「英特尔® 驱动程序和支持助理」启动；
- 浏览器打开 DSA 仪表板，短暂扫描后展示结果。

仪表板包含五个区域：

1. **可用更新**：先「全部下载/单个下载」，再「全部安装/单个安装」；
2. **消息**：与本机或设备相关的重要通知；
3. **这台电脑**：操作系统与 BIOS 等概要信息；
4. **设备和驱动程序**：关键组件及其驱动状态；
5. **英特尔软件**：检测到的英特尔应用软件。

其他常用功能：

- **安装历史记录**：仅显示经 DSA 安装的更新（手动安装或 Windows Update 安装的不显示）；
- **隐藏更新**：展开更新详情后勾选「仅隐藏此更新」并选择隐藏时长；
- **设置项**：通知频率（每天/每周/立即/从不）、自动下载、WHQL 认证更新（默认开启，取消后可获取非 WHQL 显卡驱动）、语言、下载文件夹位置、ICIP 参与状态；
- **下载位置**：默认为 `C:\ProgramData\Intel\DSA\Downloads`；自定义文件夹不得包含硬链接、交接点或符号链接，且当前用户须具备读写权限。

### 3.3 卸载

- **方法一**：在 Windows「添加或删除程序」中搜索「英特尔® 驱动程序和支持助理」并卸载；
- **方法二**：当安装或卸载异常时，下载并运行英特尔官方 DSA 卸载程序，按向导完成清理。

### 3.4 驱动回滚（Windows 10/11）

1. 按 `Win + X`，选择「设备管理器」；
2. 展开「显示适配器」，双击英特尔显示设备；
3. 切换到「驱动程序」选项卡，单击「回滚驱动程序」。

「回滚驱动程序」呈灰色通常意味着：系统中不存在此前安装的驱动版本，或原始安装文件未被保留。此时需从下载中心或 OEM 官网下载旧版本手动安装。

> 🚫 **DCH 红线**：标记为 **Windows DCH** 的显卡驱动与「传统」驱动互不兼容。不要使用回滚/强刷方式在两者间切换，该操作会绕过英特尔安装程序，可能造成不同程度的系统不稳定。驱动类型切换应采用对应安装包的干净安装流程。

## 4. 故障排查速查

### 4.1 安装阶段

| 错误代码/类型 | 含义 | 处置方向 |
|---|---|---|
| `0x80070642` / `0x800704C7` | 安装被取消 | 重新运行安装 |
| `0x80072ee7` | 无法连接互联网 | 检查网络后重试 |
| `0x80070652` | 另一安装正在进行 | 等待或结束其他安装进程 |
| `HttpProxy` / `HttpServerAuthentication` | 代理认证失败 | 检查代理设置 |
| `0x80070570` / `0x80070666` | 文件丢失或损坏 | 修复 Visual C++ 可再发行程序、检查防火墙/杀软拦截，或重新下载安装包 |

### 4.2 扫描阶段

- 浏览器提示「扫描时出了些问题」：Chrome/Edge 等 Chromium 内核浏览器的**本地网络访问（LNA）**安全权限须允许 DSA 访问本地网络；
- `4003/4005/4008/4020/4027`：配置数据无效，刷新结果重试；
- `4021`：配置文件夹无效，在设置中指定可写文件夹；
- `4000–4002/4006/4007/4023/4025` 及 `4012/4013`：多为网络故障，检查连接后刷新；
- `4014–4019/4024/4026/4028`：数据过期，刷新获取最新结果。

### 4.3 下载与安装阶段

- 下载不可用：更新已撤销，刷新结果；
- 下载写入错误：检查下载文件夹的剩余空间与权限；
- 下载超时：检查网络后重试；
- 安装错误 `1633`：平台不受支持；`1632`：临时文件夹不可访问；`1623`：语言不受支持；`1618`：另一安装正在进行。

## 5. 可复用模式萃取

### 模式一：生命周期优先诊断

- **模式名称**：生命周期优先诊断（Lifecycle-First Diagnosis）
- **适用于**：任何「更新工具检测不到硬件 / 扫描无更新 / 取包页面找不到」的软件维护场景。
- **不适用于**：设备本身无法通电、识别异常的硬件故障排查。
- **核心步骤**：
  1. 识别硬件的确切型号（设备管理器、厂商标识工具）；
  2. 在官方规格库查询产品代际与支持状态（如英特尔 ARK、EOL 清单）；
  3. 按三态分流：支持期内 / 已停产但安装包仍在 / 已 EOL 且安装包下架；
  4. 按分流结果选取通道（自动更新 / 手动下载 / 替代来源）；
  5. 安装后逐件验证版本与功能。
- **检验标准**：每个组件都有明确的生命周期状态标签，且状态与所用获取通道一一对应。
- **反模式**：
  1. 把「无可用更新」当作工具故障，反复卸载重装；
  2. 不核实型号，直接使用来源不明的「万能驱动」包；
  3. 在 EOL 硬件上以「追到最新版本」为目标，忽略兼容性风险。
- **跨场景迁移**：同样适用于手机 App 对旧机型的兼容策略判断、服务端对已终止维护的开源依赖的升级决策。

### 模式二：分层驱动更新法

- **模式名称**：分层驱动更新法（Layered Driver Update）
- **适用于**：整机驱动维护、旧机重装系统后的驱动补齐。
- **不适用于**：单一已知故障设备的定点修复。
- **核心步骤**：
  1. **自动层**：DSA 处理显卡、有线/无线网卡、RST；
  2. **手动层**：芯片组 INF、存储相关工具从下载中心单独获取；
  3. **OEM 层**：BIOS、OEM 定制驱动、笔记本整机专属组件走整机厂商官网；
  4. **系统层**：以 Windows Update 提供的通用驱动作为兜底；
  5. **归档层**：下载成功的安装包按机型离线留存，供断网或官方下架时复用。
- **检验标准**：每个组件均可在对应层找到来源；更新完成后逐件验证，并保留回滚路径。
- **反模式**：
  1. 只依赖单一工具，遗漏芯片组与 BIOS；
  2. 全部组件一次性批量更新，出现问题时无法定位引入源；
  3. 未做备份即切换 DCH/传统驱动类型。
- **跨场景迁移**：与企业软件的多渠道分发模型（官方商店、官网直装、托管服务商、离线介质）同构。

## 6. 老旧电脑驱动升级专项方案

### 6.1 第一步：硬件识别与生命周期判定

先取得硬件清单，再决定是否值得更新：

- 用「设备管理器」查看显示适配器、网络适配器、存储控制器的具体型号；
- 用英特尔处理器标识工具确认处理器型号与代际，或在英特尔 ARK（`ark.intel.com`）检索规格；
- 对照已知 EOL 事实，例如：
  - Wireless 7265（Rev.C）、Dual Band Wireless-AC 3160、Wireless 7260 系列已 EOL，官方不再提供驱动；
  - 自无线软件 21.50.1 起，Windows 7 / 8.1 不再发布新无线驱动；
  - 自 2026 年 4 月起，英特尔从下载中心移除部分历史显卡驱动（Arc 早于 32.0.101.6987 的版本、第 7–10 代处理器显卡早于 31.0.101.2141 的版本）。

### 6.2 第二步：按生命周期状态分流取包

| 硬件状态 | 推荐通道 | 说明 |
|---------|---------|------|
| A. 在支持期内（近数代平台） | DSA 自动更新 | WHQL 默认，安装后核对版本 |
| B. 已停产但安装包仍在下载中心 | 手动下载 | 按操作系统筛选版本号，安装包本地留存 |
| C. 已 EOL 且官方包下架 | 见下方四条退路 | 停止对「官方最新版」的寻找 |

**状态 C 的四条退路（按优先级）**：

1. **OEM 官网**：联想、戴尔、惠普等整机厂商通常长期保留出厂驱动页，笔记本尤其优先走此渠道；
2. **Windows Update 内置驱动**：Windows 10/11 对多数老旧英特尔硬件提供通用驱动，可在「可选更新 → 驱动程序更新」中查看；
3. **离线归档复用**：复用该机此前已下载的安装包。对仍在服役的关键老机器，应提前建立按机型分类的驱动库；
4. **硬件替换**：网络类故障件可用新款适配器替换（如新型 M.2/PCIe 无线卡、USB 外置网卡），新硬件可获得完整驱动支持。

### 6.3 第三步：升级操作纪律

1. **先备份**：创建系统还原点，重要数据先行备份；
2. **确认驱动类型**：核实显卡驱动为 DCH 还是传统型，二者不可混刷；
3. **更新顺序**：建议「芯片组 INF → 显卡 → 网卡/其他 → BIOS（谨慎，仅在有明确必要性时）」，逐层验证；
4. **认证优先**：优先 WHQL 认证版本；非 WHQL 仅在需要特定修复时使用；
5. **逐件验证**：每次只更新一类组件，重启确认稳定后再继续，避免无法定位问题源；
6. **失败回退**：优先使用设备管理器回滚；DCH 切换失败时按官方干净安装流程处理，不采用覆盖安装。

### 6.4 第四步：判断「修还是换」

出现以下任一情况时，驱动升级的收益已接近上限，应评估更换硬件或系统：

- 目标软件的硬性要求无法满足（如要求特定指令集、TPM 2.0 等平台特性）；
- 驱动更新后，性能、兼容性或稳定性问题无改善；
- 故障部件的替换成本接近整机残值，且平台整体处于 EOL 状态；
- 机器仍运行 Windows 7 / 8.1：这两个系统已无安全更新，应规划系统升级，或将其隔离为不触网的专用设备。

### 6.5 特殊环境提示

- **Windows 7 / 8.1 机器**：不要安装 25.2 及以上版本 DSA（.NET 8 不支持），改用 25.1.x 旧版或直接手动取包；
- **国内网络环境**：直连 `downloadmirror.intel.com` 可能速度较慢，可优先走 OEM 官网渠道，或在网络条件好时提前离线下载归档；
- **Chromium 内核浏览器**：首次扫描须允许 DSA 的本地网络访问（LNA）权限，否则扫描无法完成；
- **企业批量场景**：DSA 自 23.3 版本起支持静默安装，IT 管理人员可结合脚本进行批量部署，并统一设置下载目录与通知策略。
