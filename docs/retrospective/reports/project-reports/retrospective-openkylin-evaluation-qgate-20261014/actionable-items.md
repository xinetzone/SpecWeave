# 原子行动项：openKylin 评估里程碑复盘

> 本文件承载本轮复盘的 G4 产出：5 条原子行动项，每条单一职责、可独立验证，含优先级、Owner、触发条件/时间节点、验收标准与来源。洞察见 [insight-extraction.md](insight-extraction.md)，主报告见 [README.md](README.md)。

## 行动项清单

### ACT-01 90 天窗口复核：LTS 三文本口径与升级通道时效

- **描述**：到期重取三类时间敏感证据并更新台账：①升级通道配置 upgrade-config/kylin-revision-manager-sources.json 与 display.json，记录 HTTP 状态、sources 数组条数与 Last-Modified（基线：1 条通道、2024-08-26/2024-06-06 冻结）；②NC-01 所列 LTS 三文本（2024-08 论坛公告 1+1、2026-04-09 TC 文档 2+3 与"约 2029-08"、TC 路线图甘特图 2.0 条带止于 2026）口径是否统一；③Q-4 关注意外出现的独立用户量审计源。
- **优先级**：高
- **Owner**：本仓复盘维护者
- **触发条件/时间节点**：2027-01-12 前后（自 2026-10-14 起 90 天窗口）
- **验收标准**：①三项各有一次带访问日期与 URL 的重取记录；②通道配置若变化（新增 SPx/3.0 通道或时间戳更新），Q-2 由"闭环"重开并按双轮核验法补证；③NC-01 状态更新为"口径统一/仍冲突"之一；④无独立审计源时按负证据留痕格式记录检索路径与结果数
- **来源**：I-3 建议②、V-3；F-015；原报告 Q-1/Q-2/Q-4、NC-01

### ACT-02 VF-61 三项端到端验证（用户接管 GUI onboard）

- **描述**：在已就绪的 openKylin 3.0 WSL 切片（xrdp 3390 远程桌面）完成 Gen2 三项 L3 级验证：①用户执行 GUI onboard 填入模型 Key，跑一次真实模型推理并留存输入/输出/版本；②配置外部 MCP server，完成一次 tools/call 真实往返；③语音链路端到端一次（输入音频→识别/合成输出）。
- **优先级**：高
- **Owner**：用户（需要人工 onboard 与 Key），本仓维护者配合记录
- **触发条件/时间节点**：用户具备 onboard 条件时一次性完成；不晚于下次引用 7.6 维结论之前
- **验收标准**：①三项各有输入、输出、软件版本与时间记录；②结果回填附录 C 的 VF-61，证据等级由 L2 改判为 L3 或维持并说明失败原因；③7.6 维评分据结果独立裁决，变动须留算式（当前 4 分、总分 73）
- **来源**：I-2 建议②、模式三道收口第 2 条；F-023；原报告 Q-8

### ACT-03 两个 L1-draft 模式的第二案例验证与升级

- **描述**：在第二个非同谱系案例（候选：SaaS/企业软件采购尽调、二手设备评估、供应商审计等模式文件已列迁移场景）中应用缺口双轮核验法与社区指标三查法，回填案例证据并将成熟度由 L1-draft 升级为 L1.5（validation_count=2）。
- **优先级**：中
- **Owner**：方法论维护者
- **触发条件/时间节点**：下一次评估/尽调类任务立项时主动套用，不晚于 2027-Q1
- **验收标准**：①新模式文件新增第二案例证据节且 validation_count 更新为 2；②第二案例与 openKylin 非同谱系（非操作系统/开源社区领域）；③两模式在新案例中的失效步骤或术语混淆（参见 V-6）如实登记，据需修订；④同步更新模式索引的成熟度列
- **来源**：I-1/I-2/I-3 综合、模式成熟度节；F-007

### ACT-04 Gitee API 恢复后补齐全量 Star 枚举

- **描述**：Q-5 首轮因 Gitee API 返回 500 仅取得枚举子集 6,952★；待 API 恢复或取得带凭证访问后，补跑 openKylin 组织全量仓库 Star/Watcher 枚举，替换子集口径。
- **优先级**：低
- **Owner**：本仓复盘维护者
- **触发条件/时间节点**：Gitee API 对匿名请求稳定返回 200，或取得有效凭证时（可与 ACT-01 同日顺带探测）
- **验收标准**：①记录 API 状态码与访问日期；②成功时产出组织级 Star 总量与仓库级明细，登记新 VF/S 编号事实并核销"API 500 阻塞"注记；③仍失败则维持子集口径并刷新访问时间戳
- **来源**：I-3（窗口化负债）；原报告 Q-5（VF-31~VF-37）

### ACT-05 季度抽查安全可靠测评新公告

- **描述**：Q-6 已证伪（2023—2026 共 9 份安可公告零"openKylin/开放麒麟"在列），按既定窗口每季度抽查新发布公告，监测社区版是否进入名录；等保对象制度上为信息系统而非发行版产品的定性不变。
- **优先级**：低
- **Owner**：本仓复盘维护者
- **触发条件/时间节点**：每季度末（首次：2026-12-31 前后）
- **验收标准**：每次抽查按负证据留痕格式记录检索路径、关键词、时间窗、结果数；若 openKylin 社区版在列，重开 Q-6 并按影响重评 7.5 维；连续四次零命中后可降为半年频次并在报告中注明
- **来源**：I-3 建议②③；原报告 Q-6（VF-38~VF-40）
