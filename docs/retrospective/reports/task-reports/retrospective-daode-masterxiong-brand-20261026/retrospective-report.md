# 道德大师兄品牌定位诊断复盘报告

## 执行摘要

本复盘记录2026-10-26对微信小程序"道德大师兄"的品牌定位诊断全过程。诊断从用户提供的微信公众平台后台链接开始，经过三轮方向修正（先误判为改名问题→再误判层级关系→最终确认三环闭环架构），最终萃取为可复用Skill `persona-brand-positioning`。

**关键发现：**

1. **层级误判是最大风险**：三轮对话中分析者两次误判品牌层级——先把"结伴"当产品本体建议改名，再把"结伴"当品类后缀加在品牌名后。根因是没有先画层级图就跳到诊断。
2. **人格化IP名不需要品类后缀**："道德大师兄"有哲学厚度（道德即得到）和人格温度（大师兄亲切认真），名称本身不动，靠简介和页面内容补搜索桥。
3. **自闭环不是三个独立产品，而是一个用户旅程的三段**：结伴（人）→学习（学）→变现（钱），顺序不能反。第一个付费产品选学习体检深度报告（最轻，内容已有）。

**萃取产出：** Skill `persona-brand-positioning`（.agents/skills/persona-brand-positioning/SKILL.md）

## I · 洞察（G2通过）

### 洞察一：层级误判是品牌诊断的最大风险

**四元组：**

| 维度 | 内容 |
|---|---|
| **陈述** | 人格化品牌名是一个容器，诊断前必须先画层级树。在错误的层级上做再深的分析，方向全错。 |
| **证据** | F-022（第一次建议改名被纠正）、F-023（第二次建议加后缀被纠正）——两次错误都源于没有先问清楚"这个名字下面有什么" |
| **反常识** | 通常品牌诊断会直接分析名字本身好不好，但人格化品牌名的问题往往不在名字本身，而在诊断者把哪个层级当成品类招牌。再深的分析如果层级错了，等于在错误的地图上导航。 |
| **行动** | 品牌定位分析第一步必须画层级图：品牌→子模块→子频道。问用户"这个名字下面有哪些产品线？当前主推哪个？未来还会加什么？"确认后再诊断。 |

### 洞察二：人格化IP名不需要品类后缀，靠简介补桥

**四元组：**

| 维度 | 内容 |
|---|---|
| **陈述** | 有人格温度和哲学厚度的品牌名，名称本身不动。搜索权重不靠名字里塞品类词，靠简介三层结构和各子模块页面内容索引。 |
| **证据** | F-022（用户解释"道德即得到"的哲学层和"大师兄亲切认真"的人格层）、F-024（结伴只是子模块不是品类） |
| **反常识** | 通常品牌建议是"名字要带品类词便于搜索"。但人格化IP名加品类后缀会限制未来扩展——今天加"·结伴"，明天加学习实验室时后缀就不对了。搜索应该靠简介和页面内容，不是靠名字本身。 |
| **行动** | 名称保留原文不动。简介用三层结构：现在开放什么（主推子模块详情）/生态是什么（品牌定位）/怎么进来（行动召唤）。类目选和主推子模块匹配的主类目。 |

### 洞察三：自闭环是一个用户旅程的三段，不是三个平行产品

**四元组：**

| 维度 | 内容 |
|---|---|
| **陈述** | 结伴闭环（人）、学习闭环（学）、变现闭环（钱）不是三个独立产品，而是同一个用户从"认识→成长→付费"的连续旅程。顺序不能反：先有人，再留人，后养人。 |
| **证据** | F-025（用户提出三环愿景）、F-011（学习实验室已有工具但无路径）、F-014（支付链路有基础设施但无C端产品） |
| **反常识** | "自闭环"容易被理解为三个产品各自闭环再拼起来。但实际咬合点在交叉处——知足频道的感恩记录同时是学习闭环的练习，愈多频道的AI分享同时是费曼学习法的输出。三个环是转在同一个轴上的，不是三个独立齿轮。 |
| **行动** | 按结伴→学习→变现顺序建，不要三个一起上。第一个付费产品选最轻的（学习体检深度报告），不卖课、不卖会员、只卖工具。 |

## E · 萃取（G3通过）

### 萃取产出：persona-brand-positioning Skill

**位置：** `.agents/skills/persona-brand-positioning/SKILL.md`

**模式名称：** 人格化品牌定位四步法

**触发场景：**
- 适用于：有人格温度/哲学深度的品牌名需要做小程序/搜索生态定位诊断
- 不适用于：纯工具类产品命名、用户明确要改名、已有成熟品牌只需微调简介

**核心步骤：**
1. 画层级图（品牌→子模块→子频道）
2. 理解命名哲学（哲学层/美学层/人格层）
3. 补桥不改名（名称保留，简介三层结构）
4. 三环闭环设计（人→学→钱顺序建）

**6个反模式：**
1. 层级误判——把子模块当品类后缀
2. 替用户改名——把人格化名改成关键词堆砌
3. 三个环一起建——顺序反了就是割韭菜
4. 卖课变现——和反割韭菜立场矛盾
5. 名称加品类后缀——限制未来扩展
6. 视觉不接人格——"大师兄"画成白胡子老道

**检验标准：** 6项检查清单（见SKILL.md）

**跨领域迁移：** 同样的方法适用于抖音IP号定位、小红书品牌号定位——只要品牌名有人格温度，就先画层级、理解哲学、补桥不改名、三环按序建。
