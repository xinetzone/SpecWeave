# 风险、时效与边界：单源清单、规则变动、口径冲突与 AI 协作合规

> 本页是[主路径](ai-creator-main-path.md)的风险台账。规则登记时点 **2026-09-23**；核验状态 `flagged`；强制复核线 **2026-12-31**。超过复核线未重采的数字，不作为决策依据。

## 一、单源声明清单（引用纪律）

核验报告判定：16 条 P0 声明中 **10 条为平台活动页单源**（其中 3 条因 JS 动态渲染未能在静态抓取中复现，原始提取由截图转录支撑）。引用以下事实时，必须连同来源层级转述：

| F 编号 | 内容 | 标注要点 |
|---|---|---|
| F-029 | 400 万盐粒横幅 / 28 天翻倍 | 横幅文案静态抓取不复现（JS 渲染） |
| F-031 | 周满 1 天瓜分 + 逐日 100w 档位 | 文案经直连复现，但无知乎域名官方规则页 |
| F-032 | 1 创作 + 3 互动 | 明细静态抓取不复现 |
| F-036 | 回答任务 300 万盐粒 | 页面图片化渲染，文字规则不可见 |
| F-039 | 想法任务 100 万盐粒 | 同上 |
| F-041/F-042 | 彩蛋「无上限」/「读一读攒盐粒」 | 「无上限」为平台宣告口径，非个人可得承诺；入口曾拥塞 |
| F-046 | 提问瓜分 50,000 盐粒 | 计划名与数额无独立佐证 |

**层级受限**：盐粒兑换比 100:1（F-059）为「合作方官方公告 + 多三级源」，未见知乎域名官方规则页——折算口径仅作参考，不应作为收益预期基础。

## 二、规则按期变动风险

- 打卡挑战按期数滚动（当前登记为第五十三期，F-028；多期并存的 UGC 旁证 F-064）；
- 回答字数门槛存在历史演变（UGC 旁证 F-067：初期 100 字 → 300 → 500）；想法旧口径为「30 字 + 3 图」，与现行 20 字 + 1 图为**版本差异非错误**；
- **含义**：本页规则登记仅对采集期（2026-09-23，第五十三期）有效；引用前回活动页复核当期规则。主路径 O-5（每期规则快照）即为此设计。

## 三、时间窗错失风险

- 科学知识开源计划报名窗 9.3–9.30（F-055）先于活动窗 09.30–10.30（F-044）关闭；
- 错过报名窗则当届不可参与（推断，依据 F-055 报名期表述）；活动窗内其他板块（提问 F-046、入圈 F-048）不依赖该报名窗；
- 处置：[主路径 §六](ai-creator-main-path.md)三分支（附条件补位 / 非报名入口替代 / 五渠道跟踪）。

## 四、口径冲突风险（F-065）

次级来源与活动页两处冲突：① 自媒体载发奖节点为第 2/4/7 天，与活动页逐日 100w 档位（F-031）冲突；② 自媒体载「4 个简单任务任选一个」，与 F-032「1 创作 + 3 互动」冲突。**纪律：一律以平台活动页为准**，转述自媒体内容须注明为次级来源分歧。

## 五、收益不确定性（防画饼专章）

- 瓜分池总额与个人实得之间存在**参与人数摊薄变量，无任何信源披露**——池规模不可用作个人收益预期；
- 「无上限」（F-041/F-042）为平台宣告口径，实际可达规模无信源；
- 现金奖励为排名竞争型：总榜前三（F-056）、周榜前 30（F-058）均有名额口径；平台原文措辞「即有机会获得万元奖励」（F-047/F-055）本身不含概率承诺；
- 热度数值口径未标注（F-026）：项目广场「数值」不可解读为收益或流量预期；
- 历史口径陷阱：2019 年直播打赏采购侧 1 元 = 10 盐粒（F-060），与现行 100:1 场景不同，禁止混用；
- 自媒体「短期打卡获数百元」类成效宣称：无平台口径支撑、无参与人数与摊薄数据、未标个人基线，属选择性呈现——本系列文档不转述任何此类个案收益。

## 六、AI 协作排除条款的合规边界

- **平台口径（事实）**：「涉及 AI 协作」在回答任务与想法任务排除条款中均存在（F-037/F-040）；开源计划积分条件为「非纯 AIGC 生成」（F-057）；
- **边界解读（设计判断，非平台口径）**：平台信号指向「人类原创」甄别；AI 辅助的保守合规线在于「人类判断显性化」——观点、案例、结构由人主导，AI 限于资料检索、编辑辅助、代码调试；
- **认定标准无官方细则**，最终裁定权在平台；[主路径 §五](ai-creator-main-path.md)「发布前三问自检」即为此设计的可操作落地；
- **处置**：被判定排除的后果口径为「不参与此次瓜分」（F-037/F-040），其他后果无信源、不作推断。

## 七、防混用对照（三组）

| 对照项 | 规则 |
|---|---|
| 100,000 盐粒的两个活动 | F-058 开源计划周榜前 30 名瓜分 ≠ F-048 人人都是科学家入圈瓜分，分属不同玩法，禁止互证 |
| 两张限定凭证 | F-056「2026 知乎科学季限定纪念卡」与 F-048「科学季限定徽章」形态不同，禁止互证 |
| 盐粒兑换比 | F-059 现行 100:1（活动收益/提现）≠ F-060 2019 直播打赏采购 10:1，场景分离 |

## 八、复核清单（到期或规则变动时执行）

1. 打卡挑战赛当期期数与规则条款（对比 F-028~F-043）；
2. 科学季活动页与报名窗状态（对比 F-044/F-055）；
3. 盐粒兑换口径是否出现知乎域名官方规则页（升级 F-059 层级）；
4. 热度/榜单口径是否获官方说明（升级 F-026 层级）。
