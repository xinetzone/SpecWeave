# 洞察库演化规律：三阶段/完备线/锚点识别

## 模式概述

洞察库（或任何设计决策记录系统）遵循通用的三阶段演化规律，存在明确的"概念完备线"，并且每个成熟的洞察库都有5个左右的核心锚点洞察。理解这些规律可以帮助预判洞察库的发展阶段，避免无效写作。

## 演化三阶段

| 阶段 | 特征 | 洞察类型分布 | 信息密度 | 应该做什么 |
|------|------|------------|---------|----------|
| 描述期 | 回答"是什么" | 定位型+命名型为主 | 极高 | 快速写，不要怕重复 |
| 概念展开期 | 每个概念独立展开 | 方法应用型+架构设计型为主 | U形下降 | 坚持写，密度下降是正常的 |
| 系统期+元期 | 整合+自我反思 | 系统化手册+元洞察为主 | 回升 | 开始萃取方法论，停止引入新概念 |

## 概念完备线

洞察库会在某一条达到"概念完备"——之后不再引入全新概念，只组织和反思已有概念。

**竹简悟道完备线**：第46条（概念自繁殖定律）

**完备线信号**（满足任意2条即说明已到达）：
1. 发现自己在重复解释类似的概念
2. 开始写"关于洞察的洞察"（元洞察）
3. 新洞察主要是已有概念的组合或应用，而非全新概念

到达完备线后，应该：
- ✅ 停止引入全新概念
- ✅ 开始组织、整合、系统化已有洞察
- ✅ 开始萃取可迁移方法论
- ❌ 不要为了"凑数"继续写新洞察

## 核心锚点识别

每个洞察库都有5个左右"移除后会导致结构性受损"的锚点洞察。快速理解一个陌生项目的方法是先找到这些锚点。

**锚点特征**：
- 被其他洞察引用次数最多
- 定义了产品/项目的核心定位或原则
- 是其他概念推导的起点
- 移除后整个体系的逻辑链断裂

**竹简悟道5锚点示例**：
1. 洞察1（概念解缚）—— 产品定位根基
2. 洞察8/35（玄同）—— 核心承诺
3. 洞察15（体道链）—— 深度标尺
4. 洞察26（四法×八景）—— 推荐逻辑矩阵
5. 洞察46（概念自繁殖）—— 设计哲学

## 快速理解陌生洞察库的方法

1. 先找锚点洞察（通常是前10条中的3-5条）
2. 再找元洞察（关于"如何写洞察"的洞察）
3. 最后按需查阅具体应用类洞察

## 适用场景

- 洞察库建设（高适用性）
- 架构决策记录（ADR）系统
- 设计原则库
- 理解陌生项目的文档体系

## 失败案例

**临时目录无完备线熵增事故（本仓真实）**：`.temp/active/` 约定 ≤5 个活跃文件，但突破约定后无人叫停，目录持续膨胀失控，最终被迫重建分类归档体系（`.temp/archive/` 按类别组织历史版本 + README 说明启动命令）才能恢复可用性。教训映射：任何"库"若无显式的完备线/容量线信号与归档出口，描述期的高密度写作会自然滑向无序堆积——不是作者不自律，是缺少演化阶段的显式判定机制。

**双文档中心重复登记事故**：`.agents/docs/` 与根 `docs/` 并存期，同一知识资产在两处索引重复登记、引用各自为政，收敛（ACT-5 台账）耗资巨大。映射：到达"概念完备线"后（跨区引用已自然消解）台账即结项封存为治理记录、**不再继续增长**——验证了完备线后"停止引入、只做组织与整合"的纪律；反面教训是并存期内未及时判定"已到完备线"，让重复登记持续了数周。

## 反目标用户/场景

以下场景**不适用**本模式的三阶段预判：

1. **全新探索期项目**：连描述期都未进入，谈完备线预判是伪精确；
2. **不适用**于外部强制的固定清单（如合规检查表）——其条目数由外部决定，无自发演化规律；
3. **不适合**以"凑完备线"为目的写作：完备线是观测结果不是 KPI，为凑数写的新洞察恰恰违反"不要为了凑数继续写"纪律；
4. **高频删除重构的实验性库**：锚点尚不稳定，识别结果次日即失效。

## 早期预警信号

出现以下任一早期预警信号时，应立即处置：

| 预警信号 | 处置 |
|---------|------|
| 新写的洞察主要是已有条目的改写/组合 | 已近完备线，转向组织与萃取 |
| 库中开始出现"关于库自身怎么写"的元条目 | 正常进入元期，停止引入新概念 |
| 活跃区文件数突破约定容量且无归档动作 | 立即建归档出口，防止熵增失控 |
| 同一知识在两处索引重复登记 | 裁决单一事实源，废弃重复处 |
| 读者只能靠全文搜索找到内容（锚点失效） | 重新识别并显式标注锚点洞察 |

## 适用边界

- **适用前提**：库有自发演化空间（非外部固定清单）且预期持续积累；
- **边界条件**：三阶段是竹简悟道单案例 + 本仓 `.temp/` 与台账实践的归纳，迁移到其他领域（如 ADR 系统）需重新标定完备线信号与锚点数量（"5 个左右"是观测值非常数）。
