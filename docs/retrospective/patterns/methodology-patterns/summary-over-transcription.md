# 摘要替代转录（Summary over Transcription）

> 对扫描版版权书籍，放弃整本 OCR 逐字转录，改用"多模态通读→逐章深度摘要→原创改写"路线：完整性是负债，可溯源的转述才是资产。

## 一句话定义

当源材料是扫描版（无文本层，或文本层不可信）且受版权保护时，第一道工序不是"把字抠出来"，而是先做路线决策——逐字转录物本身即高侵权风险衍生物，无法入公开文档中心；逐章深度摘要 + 原创改写反而在合规性与信息保真度上同时占优。

## 触发场景

**适用于**：
- 扫描版 PDF（纯图像无文本层，或"扫描图 + 内嵌噪声 OCR 层"的混合型）的商业出版物、内部培训材料、付费报告
- 任务目标是知识提炼、教程、知识包，而非全文存档或全文检索
- 产出物需要进入公开文档中心或对外分享，有合规审查环节

**不适用于**：
- 公版书、开源文档、官方公开资料：转录无侵权风险，且全文检索价值高于摘要
- 需要原文级精确引用的场景（法律举证、学术引注逐字核对）
- 源文件自带可信文本层：直接解析文本层即可，"扫描版"前提不成立
- 个人学习用途的全文存档（无公开产出、无合规审查环节）

## 核心步骤（6 步）

1. **路线决策前置**：R 阶段第一步显式二选一（逐字转录 / 深度摘要），默认摘要路线，并将决策写入任务 frontmatter（如 `route: chaptered-summary` 与决策时间戳），使后续环节与审查者可审计当时的判断依据。
2. **文本层可信度判定（混合型 PDF 必做）**：若 PDF 内嵌 OCR 文本层，先抽查错字率判定可信度；不可信时降格为"章节定位工具"（配合内嵌目录锚点），内容一律以渲染页图像为准，并将该策略写入 frontmatter（如 `ocr_layer_policy: image-first-ocr-locate-only`）。
3. **逐章多模态通读**：按章（或自然章节组/练习单元）多模态通读扫描页，不追求逐字，追求论证链、关键概念、数据的完整捕捉；同步建立页码映射规则（PDF 物理页与纸质书印刷页偏移须显式记录），为后续引用标注打底。
4. **深度摘要而非书摘**：每个阅读单位的摘要必须重构作者的论证结构（论点→论据→结论）或操作规程（步骤→口令→边界），而非摘录金句；摘要本身是独立成文的分析物，不是原文的压缩副本。
5. **原创改写重构 + 合规声明契约化**：教程/知识包正文对情节、数据、论证做转述重组，保留思想与事实，不保留原文表达；引用仅限短语级并逐条标注页码，在产出物 index 中以可度量契约显式声明（对接模式 [合规契约化](compliance-contracting.md)）。
6. **V 审查实证对账**：对声明做实际统计验证（引用字数逐条数、页码标注逐个查、中间摘要中的数字标注同样回图核验），而非检查格式与链接了事（对接模式 [声明对账](../documentation-patterns/declaration-reconciliation.md)）。

配套资产：复现检查清单 `.agents/checklists/summary-over-transcription-reproduction-checklist.md`、复现报告模板 `.agents/templates/summary-over-transcription-reproduction-report-template.md`、执行 Skill [scanned-book-to-okf-wiki](../../../../.agents/skills/scanned-book-to-okf-wiki/SKILL.md)。

## 检验标准（怎么知道做对了）

- 任务 frontmatter 中可找到显式的路线决策字段（`route`），而非事后补记；混合型 PDF 另需文本层策略字段
- 产出物通过"换个说法"测试：不存在连续 ≥30 字的原文复现，全部内容经转述重组
- 每条直接引用均标注 PDF 物理页页码，index 声明与实际统计结果一致
- 摘要独立成文检验：随机抽 3 段摘要与渲染页比对，无连续 30 字以上重合（防止摘要退化为书摘集）
- 产出物能顺利通过合规审查入公开文档中心（公开场景）或被引用方接受

## 反模式（均来自实际教训）

1. **默认先 OCR 逐字转录**：把"转录越完整越好、OCR 是第一步"当作无条件默认——逐字转录物本身即高侵权风险衍生物，完整性反而是负债。混合型 PDF 还多一层陷阱：噪声 OCR 层的存在会诱导直接信文本，跳过可信度判定即被错字污染。
2. **摘要写成书摘集**：深度摘要退化为原文金句摘抄的汇编，原创性不成立，仍是衍生复制，合规红线依旧失守。
3. **跳过路线决策隐式执行**：不在 frontmatter 记录"转录/摘要"选择，任务看似完成但决策不可审计，下个同类任务会重新滑回默认 OCR 路线。
4. **摘要与转录混合**：部分章节转录、部分章节摘要，index 的引用红线声明无法覆盖转录部分，契约名存实亡。
5. **信任中间产物的内嵌数字**：摘要写作时随手标注的引语字数误差率可达 9/19；不回渲染图核验就把中间数字搬进最终声明，声明必然失真（案例 2 实测教训）。

## 跨场景迁移示例

- **内部培训视频/课程**：沉淀知识包时做"结构化纪要 + 要点重构"，而非逐字稿——逐字稿含讲师口语表达，同样是高侵权风险衍生物。
- **付费行业报告 PDF**：向团队输出"结论摘要 + 数据转述"，替代全文复制分发，既保真关键数据又避开整本复制风险。
- **会议录像**：产出"决议与行动项清单"替代完整转录，信息保真聚焦决策，表达层全部重写。
- **练习册/手册类出版物**：多个同构练习单元可用统一摘要模板批量生产，教程按"训练功能/进阶周期"重组而非逐日罗列；操作口令密集时须预先定义引用计数口径（见 [合规契约化](compliance-contracting.md)）。

## 验证记录

### 案例 1（2026-09-11，萃取源案例）

- 对象：扫描版财商寓言《管道的故事》（130 页，纯图像无文本层）转 OKF wiki 教程，5 份摘要 + 7 教程文件
- 结果：route 决策前置、30 字引用红线契约、声明对账均在该任务链首验；详见 [pipeline-parable v1 复盘](../../../../playground/pipeline-parable/retrospective/retrospective-2026-09-11-pipeline-parable-v1.md)

### 案例 2（2026-09-11，独立复现——不同源、不同主题、不同 PDF 形态）

- 对象：《魔力》（28 天感恩练习手册，170 页，**扫描图 + 内嵌噪声 OCR 层混合型**），session `sc-20260911-the-magic`
- 结果：六步骤完整复现——route=chaptered-summary 在 S0 frontmatter 留证；新增文本层可信度判定步骤（OCR 错字如"被"→"㻛"，降格为定位工具）；产出 30 份逐日摘要 + 7 文件教程；19 条直接引用全部 ≤30 字带 PDF 页码（合计 219 字、最长 26 字），回看 12 张渲染图勘正 9 处中间摘要字数误标
- 证据：[复现报告](../../../../playground/the-magic/retrospective/reproduction-report-summary-over-transcription.md)、[S5 对账台账](../../../../playground/the-magic/retrospective/s5-reconciliation-ledger.md)
- 结论：跨体裁（寓言→练习手册）、跨 PDF 形态（纯图像→混合 OCR）独立复现成功，步骤 2"文本层可信度判定"为案例 2 新增步骤，升 L2

L2（双案例验证）：萃取自财商寓言转教程任务链，并在异质的 28 天练习册（混合型 PDF）任务中独立复现成功；两次案例不同源、不同主题，六步骤（含案例 2 新增的文本层可信度判定）均有留证。
