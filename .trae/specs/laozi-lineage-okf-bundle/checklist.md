# 《老子》传本源流谱系 OKF 知识包 - 验证清单

> 本清单由独立验证子代理在实现完成后逐项黑盒检查。每项必须给出"通过/失败"结论与证据（文件路径、命令输出或抽查引文）。任一项失败即视为整体未通过，需返工后重新验证。

## 一、OKF v0.2 格式合规性

- [ ] **C1.1**：`bundles/laozi-lineage/` 根目录存在 `index.md` 与 `log.md`，且含 `manuscripts/`、`archaeology/`、`variants/`、`methodology/`、`references/` 五个子目录。
- [ ] **C1.2**：根 `index.md` frontmatter 含 `okf_version: "0.2"`。
- [ ] **C1.3**：每个子目录含 `index.md`（子目录 index 无 frontmatter，或仅有合规 frontmatter）。
- [ ] **C1.4**：所有非保留 `.md` 文件（即非 index.md/log.md）均含以 `---` 分隔的 YAML frontmatter 块，且 YAML 可被解析无语法错误。
- [ ] **C1.5**：每个非保留 `.md` 文件 frontmatter 含非空 `type` 字段；`type` 值为 PascalCase 描述性命名。
- [ ] **C1.6**：`log.md` 按 `YYYY-MM-DD` 日期倒序排列，含 Creation 条目。
- [ ] **C1.7**：无文件使用 `index.md`/`log.md` 之外的保留文件名；无概念文件命名为保留名。

## 二、概念覆盖度

- [ ] **C2.1**：`manuscripts/` 下存在至少 8 个传本概念文件：郭店楚简本、帛书甲本、帛书乙本、北大汉简本、河上公注本、想尔注本、王弼注本、傅奕校定本。
- [ ] **C2.2**：`archaeology/` 下存在马王堆三号汉墓、郭店一号楚墓 2 个考古语境概念。
- [ ] **C2.3**：`variants/` 下存在至少 4 个异文概念：邦/国、恒/常、德道篇序、大器免成/晚成。
- [ ] **C2.4**：`methodology/` 下存在避讳断代法、传本源流重建法 2 个方法论模式概念。
- [ ] **C2.5**：`references/` 下存在至少 10 个信源概念（不含 index.md），覆盖 spec.md FR-6 所列核心文献。
- [ ] **C2.6**：概念文件总数（不含 index/log）≥ 26。

## 三、溯源与信源质量

- [ ] **C3.1**：抽查 ≥10 条事实性论断（跨至少 5 个概念文件），每条均带 `[^source-id]` 脚注，且该 id 在同文件 frontmatter `sources` 列表中存在对应条目。
- [ ] **C3.2**：每个被正文引用的 `sources[].resource` 为具体可核查文献（ISBN、DOI、博物馆/高校/出版社官方 URL），非"某书""网络资料"等泛称。
- [ ] **C3.3**：抽查 ≥3 条信源的 ISBN/URL，实际可核查且与标注的作者/出版社/年份一致；无编造 ISBN。
- [ ] **C3.4**：`references/` 中信源 ≥80% 为正式出版学术专著、发掘报告、整理本或机构官方页；无匿名博客、百度知道、未注明出处帖作为唯一来源。
- [ ] **C3.5**：所有标注"待核"的字段均显式写明"待核"字样，未伪造数据；无"待核"残留于关键字段（如 `type`、`resource`）。

## 四、七概念质量门

- [ ] **C4.1 (G1)**：R 阶段产出的考古语境与传本概念正文中无因果推断词（"因为/导致/所以/因而/从而/由于"）作为事实陈述连接；推断性语句显式标注"学界推测""一般认为"。
- [ ] **C4.2 (G2)**：每个 `variants/` 异文概念含完整洞察四元组——现象描述、根因分析、影响评估、改进/研究建议四要素齐全且可识别。
- [ ] **C4.3 (G3)**：每个 `methodology/` 模式概念含触发场景、核心步骤、反模式、迁移验证四要素；迁移验证引用《老子》之外的至少 1 个可迁移目标文献。
- [ ] **C4.4 (V)**：河上公成书年代、想尔注作者、北大简出土地点缺失、大器免成释读 4 个争议点均在对应概念正文中设"争议与不确定性"小节，并列 ≥2 种学术观点及代表学者，不做单一确定性断言。
- [ ] **C4.5**：无过度断言（如"《老子》成书于某年""某本必定最早"）；所有年代范围标注为推定区间或学界共识而非精确年份（除非有硬证据如墓葬纪年）。

## 五、交叉链接与可遍历性

- [ ] **C5.1**：每个传本概念至少链接到其考古语境（如适用）或相关异文，bundle 内相对路径使用 `/` 开头的 bundle-relative 路径或合规相对路径。
- [ ] **C5.2**：关键交叉链接（传本↔考古、传本↔异文、异文↔方法论、信源↔引用者）目标文件实际存在，无断链（允许 OKF 容忍的非关键断链，但关键路径必须连通）。
- [ ] **C5.3**：≥80% 的概念文件有至少 1 个出链或入链，不形成孤立文件。
- [ ] **C5.4**：链接路径格式正确（POSIX 风格、`.md` 后缀、无 Windows 反斜杠）。

## 六、信任与生命周期元数据

- [ ] **C6.1**：每个概念 frontmatter 含 `generated: { by: ..., at: ... }`，`by` 符合 actor 约定（`reference_agent/<version>` 或 `human:<id>` 或 `process:<id>`），`at` 为 ISO 8601 datetime。
- [ ] **C6.2**：每个概念含 `verified` 字段（至少一条，可为 process 或 human）；无 `verified` 的概念必须 `status: draft`。
- [ ] **C6.3**：`status` 值为 `draft`/`stable`/`deprecated` 之一；有争议概念标注得当（`draft` 或 `stable`+争议小节）。
- [ ] **C6.4**：`tags` 为 YAML 列表，标签语义合理（如 `[laozi, manuscript, mawangdui]`）。

## 七、Vendor 边界与项目约定

- [ ] **C7.1**：`vendor/knowledge-catalog/` 目录下无任何新增或修改文件（通过 `git -C vendor/knowledge-catalog status` 确认干净）。
- [ ] **C7.2**：bundle 内无硬编码 `file:///` 绝对路径（OKF 链接均为 bundle-relative 或外部 http(s) URL）。
- [ ] **C7.3**：所有文件 UTF-8 编码、无 BOM、换行符一致。
- [ ] **C7.4**：正文以中文为主，专有名词附英文/拼音；无中英文混排导致的乱码。

## 八、最终交付物可读性

- [ ] **C8.1**：根 `index.md` 人类可读，含 bundle 简介、概念分组清单、OKF 版本声明。
- [ ] **C8.2**：每个概念正文使用结构化 Markdown（标题、表格、列表），无大段无结构散文。
- [ ] **C8.3**：异文概念的对照表可读（各本文字并列、差异醒目）。
- [ ] **C8.4**：抽查任意 1 个传本概念，从 frontmatter 到正文到脚注到 sources，全链路可独立阅读而不依赖对话上下文。
