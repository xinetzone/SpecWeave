```python
# 版本感知类型
Ps1Version = str  # Literal['5.1', '7.x', 'auto']，运行时为 str，类型检查可用 typing.Literal

_PS_VERSION_RE = re.compile(r'#Requires\s+-Version\s+(\d+)', re.IGNORECASE)
_PS_EDITION_RE = re.compile(r'#Requires\s+-PSEdition\s+(\w+)', re.IGNORECASE)
_PS7_VARS = re.compile(r'\$Is(Windows|Linux|MacOS)\b')
_PS7_OPS = re.compile(r'\?\?=?|\?\s+[^:]+\s*:')  # ?? ??= 三元运算符


def detect_ps_version_from_content(content: str) -> str:
    """从脚本内容启发式推断目标 PowerShell 版本。

    检测规则（按优先级）：
    1. #Requires -Version 7 → '7.x'
    2. #Requires -PSEdition Core → '7.x'
    3. #Requires -Version 5 → '5.1'
    4. #Requires -PSEdition Desktop → '5.1'
    5. 含 $IsWindows/$IsLinux/$IsMacOS 自动变量 → '7.x'
    6. 含 ?? 或 ??= 运算符 → '7.x'
    7. 其他 → '7.x'（默认跨平台模式）

    Returns:
        '5.1' 或 '7.x'
    """
    # #Requires -Version N
    m = _PS_VERSION_RE.search(content)
    if m:
        ver = m.group(1)
        if ver.startswith('7'):
            return '7.x'
        if ver.startswith('5'):
            return '5.1'
    # #Requires -PSEdition
    m = _PS_EDITION_RE.search(content)
    if m:
        edition = m.group(1).lower()
        if edition == 'core':
            return '7.x'
        if edition == 'desktop':
            return '5.1'
    # PS7+ 自动变量
    if _PS7_VARS.search(content):
        return '7.x'
    # PS7+ 运算符
    if _PS7_OPS.search(content):
        return '7.x'
    # 默认跨平台模式
    return '7.x'


def _resolve_target_version(content: str, target_version: str = 'auto') -> str:
    """解析 target_version 参数：'auto' 时自动检测，否则返回指定版本。

    Returns:
        '5.1' 或 '7.x'
    """
    if target_version == 'auto':
        return detect_ps_version_from_content(content)
    return target_version
```

在第 253 行（`function Test-Ps1AtLineStart` 之前）插入：

```powershell
# ── 版本检测 ──────────────────────────────────────────────────────────────

function Get-Ps1TargetVersion {
    <#
    .SYNOPSIS
        从脚本内容启发式推断目标 PowerShell 版本（与 Python 端 detect_ps_version_from_content 对齐）。
    .PARAMETER Content
        要分析的 PowerShell 脚本内容。
    .OUTPUTS
        '5.1' 或 '7.x'
    #>
    [CmdletBinding()]
    param(
        [Parameter(Mandatory=$true, Position=0)][AllowEmptyString()][string]$Content
    )

    if ([string]::IsNullOrEmpty($Content)) {
        return '7.x'
    }

    # #Requires -Version N
    if ($Content -match '(?im)#Requires\s+-Version\s+(\d+)') {
        $ver = $Matches[1]
        if ($ver.StartsWith('7')) { return '7.x' }
        if ($ver.StartsWith('5')) { return '5.1' }
    }

    # #Requires -PSEdition
    if ($Content -match '(?im)#Requires\s+-PSEdition\s+(\w+)') {
        $edition = $Matches[1].ToLower()
        if ($edition -eq 'core') { return '7.x' }
        if ($edition -eq 'desktop') { return '5.1' }
    }

    # PS7+ 自动变量 $IsWindows/$IsLinux/$IsMacOS
    if ($Content -match '\$Is(Windows|Linux|MacOS)\b') {
        return '7.x'
    }

    # PS7+ 运算符 ?? ??=
    if ($Content -match '\?\?=?') {
        return '7.x'
    }

    # 默认跨平台模式
    return '7.x'
}


function Resolve-Ps1TargetVersion {
    <#
    .SYNOPSIS
        解析 -TargetVersion 参数：'auto' 时自动检测，否则返回指定版本。
    #>
    [CmdletBinding()]
    param(
        [Parameter(Mandatory=$true)][string]$Content,
        [Parameter()][ValidateSet('5.1','7.x','auto')][string]$TargetVersion = 'auto'
    )

    if ($TargetVersion -eq 'auto') {
        return (Get-Ps1TargetVersion -Content $Content)
    }
    return $TargetVersion
}
```

## 风险和注意事项

1. **skip_line_comments 的 CR 逻辑最易出错**：CRLF (`\r\n`) 和 CR-only (`\r`) 的区分需要仔细处理位置递增。关键规则：遇到 `\r` 时先看下一个字符是否 `\n`，是则跳 2 个字符（CRLF），否则跳 1 个字符（CR-only）。
2. **_skip_ps1_here_string 返回值语义**：非 here-string 时返回原始 position 参数（不是跳过 BOM 后的 i），这是 v1.1.0 已确立的行为，必须保持。
3. **向后兼容性**：所有新增参数必须有默认值 `'auto'`，不传参时行为与 v1.1.0 完全一致（默认 7.x 跨平台模式）。
4. **PowerShell 正则语法**：`(?im)` 表示 IgnoreCase + Multiline，与 Python 的 `re.IGNORECASE` 对应。
5. **ValidateSet 属性**：PowerShell 的 `[ValidateSet('5.1','7.x','auto')]` 会在参数值不在集合中时自动抛错，无需手动校验。
