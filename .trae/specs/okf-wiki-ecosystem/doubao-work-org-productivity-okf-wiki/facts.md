## 企业没跟上：Context瓶颈（F-009~F-014）

| 编号 | 事实 | 核验 |
|------|------|------|
| F-009 | Deloitte 2026年调查：全球24国3235名企业高管；AI工具覆盖率从不到四成涨到六成；深度改造产品/流程/商业模式的企业仅34%；37%停留在表层应用 | ✅ 官方PDF确认（另有30%中间档） |
| F-010 | 📝 员工让Agent"复盘项目"或"看项目为什么延期"时，阻碍发生在AI工作之前——客户需求变更/会议结论/方案版本/负责人/审批状态等信息不在Agent对话框里 | 📝 |
| F-011 | 📝 员工得先翻群聊、找纪要、下载表格文档，整理信息后再向AI解释一遍——"Agent看似替人工作，人却要先替Agent准备工作" | 📝 金句 |
| F-012 | 📝 企业工作不是孤立任务：需求从群聊→会议→文档表格→项目任务→审批，在不同部门和负责人间流转，前因后果散落在知识/数据/流程/权限/组织关系/历史决策中 | 📝 |
| F-013 | 📝 "能力决定Agent会不会干活，上下文决定Agent能不能干好活"——前者已不是瓶颈，后者才是 | 📝 金句 |
| F-014 | 过去需要团队自建的Agent Harness如今越来越多被模型厂商和开源框架直接提供 | ✅ |

## 豆包工作+飞书：账号级集成（F-015~F-022）

| 编号 | 事实 | 核验 |
|------|------|------|
| F-015 | 豆包工作与飞书做账号级别集成：飞书账号登录后，Agent直接继承用户工作上下文（聊天记录/文档/会议纪要/日程），在权限范围内调用 | ✅ 飞书官方帮助中心确认 |
| F-016 | 飞书天然将聊天/文档/会议/知识库/多维表格/项目/审批放在同一套组织身份、权限和协作体系里 | ✅ |
| F-017 | 飞书过去几年为AI调用做基础设施准备：会议沉淀为可搜索可引用的妙记，文档/知识库/群消息/多维表格已针对AI调用做适配 | ✅ |
| F-018 | 📝 飞书是国内主流协同平台中组织信息统一程度最高、对Agent适配最完整的平台，更接近AI原生组织操作系统 | 📝 |
| F-019 | 📝 飞书被开发者圈定为"龙虾"浪潮下Agent的核心执行与协作入口 | 📝 |
| F-020 | 📝 使用场景：问豆包工作"x月x日还能不能上线"，Agent沿飞书轨迹自行寻找信息拉出进度与风险；可追溯GPU扩容/资源申请/版本上线等关键节点的申请人和审批影响 | 📝 使用场景 |
| F-021 | 📝 "员工不用再花半小时给AI补背景。Agent开始像从头参与过项目的同事——自己找信息、理清前因后果，再给出判断" | 📝 |
| F-022 | 📝 豆包工作可处理文档/表格/PPT、搭建网页应用、生成图片视频、操作浏览器和本地电脑；区别不在功能本身而在"产物去哪了" | 📝 |

## 闭环：理解→执行→协作→沉淀（F-023~F-026）

| 编号 | 事实 | 核验 |
|------|------|------|
| F-023 | 📝 AI生成报告若停留在个人对话框，同事看不到改不了，下次还得重新解释——效率提升在下一次工作时消失 | 📝 |
| F-024 | 连接飞书后，豆包工作生成内容可回到飞书被分享/评论/修改；成熟工作方法可沉淀为组织共享技能，下次直接调用 | ✅ 产品特性 |
| F-025 | 📝 完整闭环：理解组织→执行任务→进入协作→获得反馈→沉淀为新的组织经验；Agent做得越多，产出越多转化为企业资产，反过来成为后续上下文 | 📝 核心框架 |
| F-026 | 📝 "能干活的是工具，知道公司在发生什么、能自己把事推下去、把结果留给团队的，才算员工" | 📝 金句 |

## ROI：从个人到组织（F-027~F-031）

| 编号 | 事实 | 核验 |
|------|------|------|
| F-027 | BCG 2026年6月《AI at Work》调查：42%经常使用AI的一线员工每周至少省8小时（一个完整工作日）；但多数企业还没搞清如何将省下的时间转化为组织价值 | ✅ BCG官方报告确认 |
| F-028 | BCG调查规模为11,749名受访者、覆盖14个市场（第四年度调查） | 补充事实 |
| F-029 | 📝 "一个人快了不等于一个团队快了"——企业效率损耗不在任务内部，而在任务间/人间：找资料/问进度/同步信息/确认负责人/跨部门沟通/等待审批 | 📝 |
| F-030 | 📝 AI把PPT从两小时压到半小时，但评审/修改/跟进照旧则组织效率没变；Agent价值在接手材料后的衔接动作——查/问/同步/推进 | 📝 |
| F-031 | 📝 这要求Agent进入组织业务现场：客户资料/经营数据/会议内容/审批流程 | 📝 |
