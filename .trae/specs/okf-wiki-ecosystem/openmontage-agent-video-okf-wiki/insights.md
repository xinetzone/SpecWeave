## 洞察一：核心资产是生产契约，不是单个生成模型

- 现象：项目把阶段、工具、技能和质量标准写入仓库文件。
- 证据：F-006、F-007。
- 反常识：视频系统的可复用性来自流程约束，而非接入模型数量。
- 建议：评估同类 Agent 系统时先检查 manifest、stage skill、状态和验收标准。

## 洞察二：Agent 导演模式把控制面交给可读文件

- 现象：AI 编程助手读取规则、选择流水线、调用 Python 工具并在创意节点等待确认。
- 证据：F-007、F-013。
- 反常识：系统没有必须依赖的专有黑盒编排器，仓库本身承担“片场”角色。
- 建议：把每个阶段的输入、输出、暂停点和失败回退写成可审查资产。

## 洞察三：零密钥路径仍需把成本和合规显式建模

- 现象：本地 TTS、开放素材与本地渲染可以减少外部 API 依赖，但高级能力仍可能调用付费服务。
- 证据：F-014、F-015。
- 反常识：免费入口并不自动意味着零成本、零授权风险或零维护。
- 建议：交付前分别记录 API 成本、素材许可证、生成模型条款和 AGPL 义务。
