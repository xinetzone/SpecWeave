### 洞察四元组（G2 质量门）

- **现象**：Dolt 将 Git 的版本控制理念（分支/提交/合并/历史追溯）移植到数据库存储层，提供行级历史追踪
- **根因**：传统备份 + binlog 方案颗粒度大、协作成本高，无法满足数据审计（谁改了哪一行）与数据实验（分支隔离）需求
- **影响**：AI Agent 获得安全的数据操作沙箱（独立分支 + 合并确认），数据科学团队获得分支隔离的实验环境
- **建议**：读多写少、数据实验、AI Agent 数据操作、审计追溯场景优先考虑 Dolt；高并发 OLTP 与复杂分析查询密集型场景需谨慎评估（性能开销）
