## 一、5 项洞察（四元组：陈述 / 证据 / 反常识 / 行动）

### 洞察 1：真正的突破不是"更强的记忆"，而是"保留原始像素并允许按需重看"

- **陈述**：VISTA 的核心增量不在于把画面摘要得更准，而在于把原始帧原样留在上下文之外，并提供按需回看的工具，把"看过的"与"用过的"彻底解耦。
- **证据**：F-020、F-022、F-023、F-026、F-051、F-059、F-070。
- **反常识**：主流记忆方案（笔记、摘要、文本网格）都在**压缩**，而 VISTA 反而**增加存储**——它增加的是存储成本，换取"未来可能需要某个细节"的期权。模型第一次看图时不知道哪个细节会变重要（F-015），这个不确定性只能靠保留原始信息来对冲，靠摘要无法对冲。
- **行动**：设计 Agent 记忆时，先问"未来可能回看什么"，而不是先问"怎么总结得更准"；对无法预判重要性的信息（视觉、原始日志、多模态输入），保留原始形式 + 提供检索工具，比写摘要更稳。

### 洞察 2："显式注意力"是语境层机制，不是模型能力层机制

- **陈述**：VISTA 没有训练模型，它改变的是模型获取、保存和使用视觉信息的方式；得分从基线到满分的提升发生在**语境编排层**。
- **证据**：F-034、F-035、F-054、F-063、F-079。
- **反常识**：看到"满分 100"容易推断"模型变强了"。消融阶梯（13.33 → 47.32 → 51.66 → 65.82 → 70.05 → 94.10 → 99.00，F-079）显示提升来自逐步叠加的配置变更，且论文 §3.2 明确 Harness 是"纯机械的，不涉及任何被训练的模型"（F-054）。同一批模型，语境不同，分数差 7 倍。
- **边界**：该结论只对消融阶梯成立；头部"40.68 → 100.00"同时变了推理强度（high→xhigh）与评测协议（官方 5× 动作预算/12 小时 → 2,000 动作/48 小时），不能直接相减（F-077、F-079）。
- **行动**：把"能力提升"与"编排提升"分开记账。做 Agent 评测时，基线必须固定模型、只换 harness，否则无法归因；反过来，做产品时提升 harness 的投入产出比往往远高于等量模型升级。

### 洞察 3："满分 100"是一个被限定条件包裹的结论

- **陈述**：ARC-AGI-3 的 RHAE 满分只在"公开 25 局 + 未限定训练数据"的条件下成立，论文自身把它列为局限。
- **证据**：F-047、F-068、F-073、F-074、F-064。
- **反常识**：最容易传播的版本是"何恺明团队拿下 ARC-AGI-3 满分"，最容易被略去的恰恰是论文 §6：所用模型在公开基准之后发布，**无法排除这些游戏已被纳入训练数据**，作者明确指出只有私有集上的评估才是更强的泛化检验（F-068）。此外 RHAE 的计分本身有"单关上限 1.15 倍人类基线、权重平均、未通关关卡计 0"等具体口径（F-073），不做功课就无法判断 100 分意味着什么。
- **行动**：引用任何交互式基准的满分/接近满分结论时，必须同时给出三条限定：① 基线是什么（官方实现 40.68 / 13.33，F-064）；② 是否限定了数据污染；③ 私有集/未见题目上的表现。缺一条，结论就不能直接用于决策。

### 洞察 4：Agent 记忆需要双层结构——跨任务复用层 + 当前任务工作层

- **陈述**：VISTA 用两份文字笔记配合一份视觉档案，构成"长期复用 / 当前工作 / 原始证据"三层记忆结构，与 Anthropic 的 harness 笔记法同构但介质不同。
- **证据**：F-030、F-031、F-053、F-012、F-072。
- **反常识**：直觉上"视觉经验"应该主要存在视觉形态里，但 VISTA 真正承担"规则沉淀"的是**文字笔记**（GUIDE.md 存跨关卡可复用知识，WORKING.md 存当前关卡临时状态与计划，F-053）。视觉档案负责的是"证据可回溯"，文字笔记负责的是"结论可继承"。二者生命周期不同：WORKING.md 随关卡推进清空，GUIDE.md 跨会话保留。
- **行动**：给 Agent 设计记忆时显式区分三种生命周期——跨任务沉淀、当前任务状态、原始证据；并为每种指定清理策略。混在一起就会出现"上下文越滚越大但有效信息不增"的问题。

### 洞察 5：跨环境可迁移性来自"机制普适 + 适配极少"，且必须由多基准而非单基准证明

- **陈述**：VISTA 的可迁移性主张（少量适配即可用于不同游戏与谜题）成立，但它的证据强度取决于四个基准的差异度是否真的构成"不同环境"。
- **证据**：F-040、F-056、F-057、F-058、F-009。
- **反常识**：四个基准看起来跨度很大（浏览器游戏 / 开放游戏库 / 静态视觉谜题），但 BabyVision 只有静态图片（F-058），与"交互式"这一核心卖点并不同源；而 GameWorld 与 AI GameStore 都是浏览器游戏，共享大量引擎与渲染假设。因此"跨环境"证据的强度是**混合**的，不能整体采信。
- **行动**：读"一套框架通吃 N 个基准"的结论时，逐个核对基准在**交互性、媒介、视觉分布**三个轴上的差异；同质基准的重复验证只证明稳健性，不证明可迁移性。
