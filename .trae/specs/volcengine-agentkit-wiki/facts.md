**F004.** AgentKit 覆盖制作、配置、部署、调用/测试、观测与评测等关键环节。[来源：S2]

## 类别 B：8大功能模块事实（10条）

**F009.** Runtime（智能体运行时）提供托管执行环境与运行管理能力。[来源：S2]

**F010.** Identity（统一鉴权）提供受控访问与凭证/权限边界管理能力。[来源：S2]

**F011.** Gateway（工具介入）是智能体访问外部系统与服务的统一入口，负责连接、路由与调用治理。[来源：S2]

**F012.** Gateway 支持通过 MCP Server 接入，或将现有 REST/OpenAPI 服务快速转换接入。[来源：S2]

**F013.** A2A（Agent to Agent）基于 A2A 协议，可构建多 Agent 编排场景，实现跨 Agent 的任务分发、结果回传与状态同步。[来源：S2]

**F014.** Session/Memory（会话与记忆管理）提供短期记忆与长期记忆的分层管理能力。[来源：S2]

**F015.** Session 负责多轮会话中的上下文持久化，Memory 支持跨会话的信息沉淀与召回。[来源：S2]

**F016.** Knowledge（知识检索与调优）提供知识检索与调优相关能力，用于构建企业知识问答与检索增强类应用的标准组件。[来源：S2]

**F017.** Observability（全链路观测与排障）提供调用链路观测与问题定位能力，区分模型、Runtime、Gateway、Tool、Memory/Knowledge 等环节的异常来源。[来源：S2]

**F018.** Evaluation（评测与质量闭环）提供评测与质量闭环相关能力，支撑上线前验证、上线后持续优化与发布闸门建设。[来源：S2]

## 类别 C：VeADK 技术栈事实（12条）

**F019.** VeADK 全称为 Volcengine Agent Development Kit，是火山引擎推出的智能体开发套件。[来源：S4]

**F020.** VeADK 提供 Python、Go、Java 三种语言的 SDK 支持。[来源：S4]

**F021.** Python SDK 稳定版安装命令为 `pip install veadk-python`，主分支预览版安装命令为 `pip install git+https://github.com/volcengine/veadk-python.git@main`。[来源：S4]

**F022.** Go SDK 安装命令为 `go get github.com/volcengine/veadk-go`。[来源：S4]

**F023.** Java SDK 通过 pom.xml 引入依赖，groupId 为 com.volcengine.veadk，artifactId 为 veadk-java。[来源：S4]

**F024.** VeADK 与 Google ADK 实现完全兼容，支持现有项目无缝迁移。[来源：S4]

**F025.** VeADK 与 LiteLLM 模型推理服务兼容，支持各类主流模型接入。[来源：S4]

**F026.** VeADK Family 产品矩阵覆盖 9 大类组件：大模型、提示词工程、工具、短期记忆、长期记忆、知识库、可观测、评测、云部署。[来源：S4]

**F027.** VeADK Family 产品矩阵共列出 20+ 项火山引擎产品映射关系。[来源：S4]

**F028.** DeepResearch 包含 6 大特性：多生态与模型兼容、完善的记忆与知识库支持、内置丰富工具和生态集成、可观测性与评估能力、云原生架构与快速部署、企业级安全防护。[来源：S4]

**F029.** VeADK 的 GitHub 仓库共 3 个：veadk-python、veadk-go、veadk-java。[来源：S4]

**F030.** VeADK 的镜像地址共 3 类标签：latest（稳定版）、preview（预览版）、指定版本号（如 0.2.20），镜像仓库域名为 veadk-cn-beijing.cr.volces.com/veadk/veadk-python。[来源：S4]

## 类别 D：SDK & CLI 事实（8条）

**F031.** AgentKit Python SDK 提供基于装饰器的 API，使用 `@app.entrypoint` 定义入口函数。[来源：S5]

**F032.** AgentKit CLI 包含 init 命令，一键生成项目模板，内置 Basic App、Stream App 等多种应用类型。[来源：S5]

**F033.** AgentKit CLI 包含 config 命令，引导式配置部署参数、环境变量和镜像仓库。[来源：S5]

**F034.** AgentKit CLI 包含 build 命令，用于构建应用镜像。[来源：S5]

**F035.** AgentKit CLI 包含 deploy 命令，用于将应用部署到 Runtime。[来源：S5]

**F036.** AgentKit CLI 包含 launch 命令，组合 build 和 deploy，自动完成构建镜像和部署到 Runtime。[来源：S5]

**F037.** AgentKit 支持三种部署模式：Local、Hybrid、Cloud。[来源：S5]

**F038.** AgentKit Platform 服务集成包含 3 项核心服务：Memory、Knowledge、MCP Gateway。[来源：S5]
