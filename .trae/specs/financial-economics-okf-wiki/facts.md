| F-001 | 金融体系的核心功能可归纳为六项：支付清算、跨时间与跨空间配置资源、风险管理、信息生产与监督、激励约束、储蓄动员。该六功能框架由默顿与博迪（Merton & Bodie）在 1990 年代系统表述。【P0】 | S1 |
| F-002 | 金融活动的最终目的是服务实体经济：把家庭部门的储蓄转化为企业部门的投资，并提高资本配置效率；金融资产自身的涨跌不直接等于实体财富增加。 | S1 |

| F-004 | 资金流量核算（flow of funds）记录居民、企业、政府、金融、国外等部门之间的资金往来；中国人民银行编制中国金融账户与资金流量表。 | S2 |
| F-005 | 金融深化常用 M2/GDP、信贷/GDP、股票市值/GDP 等指标衡量；单一指标不能完整刻画金融发展水平，指标上升也不必然意味着配置效率提高。 | S3、S4 |
| F-006 | 金融抑制（financial repression）指利率上限、信贷配给、资本管制等压制金融中介功能的政策组合；麦金农（McKinnon）与肖（Shaw）1973 年分别系统论述。 | S4 |
| F-007 | 金融发展与经济增长：King 与 Levine（1993）的跨国回归发现金融深度与长期增长正相关；但因果方向、制度质量与遗漏变量问题仍有争议，不能简化为「金融越发达增长越快」。 | S5 |
| F-008 | 金融化（financialization）指金融部门利润与金融资产规模相对实体部门持续上升的现象；其与收入不平等、系统性风险的关系存在学界争议，本包按「现象描述 + 争议」处理。 | S4 |

| F-020 | 普通年金现值 PV = PMT × [1 − (1 + r)^(−n)] / r；永续年金现值 PV = PMT / r（r 为折现率）。 | S8 |

| F-023 | 修正久期 D* = D / (1 + y)；利率小幅变动时，债券价格变化率约等于 −D* × Δy；久期越长，利率敏感度越高。 | S8 |
| F-024 | 利率期限结构的三类解释：预期理论、流动性偏好理论、市场分割理论；三者对长端利率的风险补偿解释不同。 | S1 |
| F-025 | 央行政策利率通过利率走廊与银行间市场传导至短端利率，再影响贷款利率、债券收益率与资产价格；传导存在时滞与阻塞。 | S1 |
| F-026 | 当名义利率低于通胀率时，实际利率为负；储蓄者的购买力受损，借款人实际负担下降。 | S8 |

| F-042 | 中国多层次资本市场包括主板、科创板（2019-07-22 首批上市）、创业板、北京证券交易所（2021-11-15 开市）、新三板与区域性股权市场。【P0】 | S17 |

## 六、宏观经济学框架（F-043–F-052）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-043 | GDP 支出法恒等式：GDP = C + I + G + (X − M)，即消费、投资、政府购买与净出口之和。 | S18 |
| F-044 | 名义 GDP 按当期价格计算，实际 GDP 按基期价格计算；GDP 平减指数 = 名义 GDP / 实际 GDP × 100。 | S18 |
| F-045 | CPI 衡量居民消费价格，PPI 衡量工业生产者出厂价格；核心 CPI 通常剔除食品与能源等波动较大的项目。 | S18 |
| F-046 | 失业率 = 失业人口 / 劳动力人口；劳动参与率 = 劳动力人口 / 劳动年龄人口；定义依 ILO 标准。 | S19 |
| F-047 | 潜在产出是经济在不过度使用资源时可持续生产的水平；产出缺口 = 实际产出 − 潜在产出，正缺口常伴随通胀压力，负缺口伴随资源闲置。 | S20 |
| F-048 | 总需求—总供给模型：短期总供给曲线向上倾斜，长期总供给曲线垂直；长期货币中性，短期需求冲击可影响产出。 | S21 |
| F-049 | 财政乘数衡量政府支出或减税对 GDP 的放大效应；常见估计区间约为 0.5–1.5，衰退与零利率环境下可能更高，具体数值存在争议。 | S20 |
| F-050 | 自动稳定器指累进所得税、失业保险与转移支付等随经济周期自动逆周期调节的财政机制。 | S21 |
| F-051 | 索洛增长模型：资本积累受边际报酬递减约束，长期人均产出增长最终依赖技术进步。Solow 1956 年提出。【P0】 | S22 |
| F-052 | 菲利普斯曲线：短期通胀与失业存在负相关；长期曲线垂直，即不存在长期的通胀—失业权衡（Friedman、Phelps 1968）。【P0】 | S23 |

## 九、金融风险与危机（F-069–F-076）

| 编号 | 事实内容 | 信源 |

## 口径与核验说明

1. **定义与恒等式**（如 GDP 恒等式、费雪方程、货币乘数、久期公式）属教科书级共识，按 S1/S8/S18/S21 登记，不再逐条给网页链接。
2. **中国制度事实**（监管架构、法规生效日、统计口径）以官方文件为准；正文引用时标注「以官方最新发布为准」，不把时点性参数写成永久规则。
3. **经验估计**（财政乘数、损失厌恶系数、金融发展与增长的因果强度）标注区间与争议，不作为精确常数使用。
4. **不写死易变统计值**：本清单不登记 GDP 总量、CPI 同比、汇率点位、股市市值等实时数据；需要时由读者按官方统计口径自行查询。
5. **P0 定义**：日期、比率、制度安排、统计口径、历史事件节点。P0 项在 [02-verification.md](references/02-verification.md) 中逐项给出核验方式与结论。

## 放弃核验清单

- 不核验任何实时行情、实时利率、实时汇率、实时市值与排名（除「长期居全球第二/第一」这类稳定量级表述外）。
- 不核验具体金融产品的费率、收益率、风险等级与销售规则。
- 不核验地方政府债务余额、房地产价格指数、居民杠杆率等高频统计值。
- 不核验未生效或仅为草案的政策条文；正文只写已生效的里程碑。
- 不核验个体机构的财务数据与信用评级。
