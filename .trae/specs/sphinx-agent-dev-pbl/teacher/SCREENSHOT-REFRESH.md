# 截图替换指引（教师侧）

> 本文档收录"什么该由教师做"的截图相关事项。
> **来源**：原位于 [`../handbook/README.md`](../handbook/README.md) §「已填的图是示意图」的「**给教师**」块。
> R14 分离处置：学生手册只保留学生向内容，教师事项移入教师包。

## 为什么移到这里

`handbook/` 是**发给学生**的手册。它原本在同一节里既写"给学生"又写"给教师"，
导致学生读到自己不需要执行、也无法执行的内容（覆盖 PNG 是教师开课前的事）。

> 判据：**一份要发出去的文件，不应包含收件人无法执行的待办。**

## 一、用真实画面覆盖示意图

正式开课前建议用真实画面**同名覆盖** `handbook/shots/` 下的 PNG，
手册中的图片引用无需改动（文件名一致即可）。

```bash
# 在方案根目录执行：用实拍图覆盖同名示意图
cp your-real-shot.png handbook/shots/S3-2.png
```

## 二、优先替换这 4 张

这 4 张是「规格合成」图，**界面细节最可能与最新版平台有出入**：

| 位点 | 内容 | 为什么优先 |
|---|---|---|
| `S3-2` | CI 工作流页面 | 平台 UI 变更频繁 |
| `S3-4` | Actions 运行结果 | 同上 |
| `S3-5` | Pages 部署地址 | 同上 |
| `S4-3` | API 调用返回 | 涉及第三方控制台 |
