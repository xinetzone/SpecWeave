# Task6 档 A 素材包

> 用途：Task6「元文档闭环」的**档 A（教学化形态）**所需实物。
> 档 A 是**必做**形态（零 Token 成本），承载 AC-4 硬门槛——见 `decisions.md` DQ-3。

---

## 一、包含什么

| 文件 | 给谁 | 怎么用 |
|---|---|---|
| [`calculator-draft.md`](calculator-draft.md) | **发给学生** | 这就是"AI 生成的草稿"。学生以它为对象找差异 |
| [`ANSWER-KEY.md`](ANSWER-KEY.md) | **只给教师** | 核对答案 + 课堂讨论引导稿。**不得发给学生** |
| 本文件 | 教师 | 分发说明 |

---

## 二、课堂分发顺序（重要）

```
① 打印 calculator-draft.md（每组 1 份，或投影）
        ↓
② 学生独立找差异（10 分钟）
        ↓
③ 小组讨论「为什么 AI 会这么理解」（10 分钟）★ 关键环节
        ↓
④ 全班分享 + 教师用 ANSWER-KEY.md 收口（10 分钟）
```

> 🚨 **绝对不要**在②③之前把 `ANSWER-KEY.md` 的任何内容讲出去。
> 一旦提前给出答案，第②③环节归零，本任务的教学目标（TR-6.1）随之不可达。

---

## 三、为什么这份草稿是"预置"的而不是真调 API

原设计与本素材的关系：

| 形态 | 草稿从哪来 | Token 成本 | 属性 |
|---|---|---|---|
| **档 A（本素材）** | 教师预置（本目录） | **0** | **必做** |
| 档 B | 学生真实调用 LLM | 自付 | 选做、加分 |
| 档 C | 复用 Task2 的 `api-draft.md` | 0 | 降级通道 |

**关键设计**：本任务的核心认知目标是"**看到 AI 误解我的代码**"，
而**不要求代码真的被 AI 读过**——这就是三档并存可行的根本原因。

因此档 A 的教学效果与档 B **等价**（都能让学生发现"AI 看不到我的设计意图"），
只是**不产生真实 API 调用**。这也是为什么档 A 是"必做"而非"降级"。

---

## 四、诚实性红线（务必讲）

使用档 A 的学生，必须在 `diff-notes.md` **开头如实声明**：

> 本次草稿来自**教师预置样例**，非我本人调用生成。

- ❌ 谎报为"我调用 AI 生成的"→ **学术诚信问题，本项判 0**
- ✅ 如实声明走档 A → **AC-4 一样能拿满分**

**讲法**（教师可直接照说）：

> *"用老师给的样例拿满分，和调 API 拿满分，是一样多的分。
> 降级完全正当，只有伪装降级才不正当。"*

> 🔑 红线的真正作用：**让降级没有动机伪装成满配**。
> 若降级要扣分，学生就会谎报；只有降级不扣分，诚实才不需要勇气。

## 五、常见问题（教师）

**Q：学生说"我找不到差异，草稿写得挺好的"怎么办？**
A：这是最常见的反应。用 `ANSWER-KEY.md` 第二节的"差异 4/5"提示他——
草稿**自相矛盾**（正文说返回字符串，示例注释说返回数字；同一个函数给了两种传参方式）。
这类矛盾**不需要懂代码就能发现**，是有效的破冰点。

**Q：学生找出了 5 条以上，还要不要给满分？**
A：TR-6.1 的 rubric ≥4 分档看的是**深度**（是否说出根因），不是**条数**。
找到 8 条但只说"AI 不行" → 3 分（拼贴）；
找到 3 条但说清"AI 缺的是我脑子里的意图" → 5 分（闭环咬合）。

**Q：学生要求"再给一份不同函数的草稿"？**
A：建议劝退。本任务的认知目标是**一次深刻的发现**，不是**批量找茬**。
若确有需要（如补考），教师可照 `calculator-draft.md` 的写法，
为 `get_time` 仿制一份（同样植入 3 处误解），但**不要扩散到全班**，
否则会出现"答案在班级里流传"的问题。
