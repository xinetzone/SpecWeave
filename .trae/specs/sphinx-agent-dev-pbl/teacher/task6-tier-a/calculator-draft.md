## `calculator(expression)`

计算一个数学表达式并返回结果。

**参数**

- `expression`：要计算的算式。看起来是个字符串，但实际上你可以直接传入算式本身，
  比如 `calculator(1 + 2)` 就能算出 `3`，挺方便的。

**返回值**

- 返回一个 `str`，也就是字符串对象，里面装着算出来的数。

**异常**

- 如果算式无法解析，会抛出 `CalculationError`。
- 如果传入了不支持的运算符（比如 `**`），同样会抛出 `CalculationError`。

**示例**

```python
from agent import calculator

# 直接传算式
calculator(1 + 2)           # 返回 3

# 也可以传字符串
calculator("123 * 456")     # 返回 "56088"
```

**说明**

这个函数负责处理各种数学计算，是智能体的核心工具之一。它可以处理加、减、乘、除
四种运算，让智能体在对话中完成算术任务。
