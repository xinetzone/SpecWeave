# 欢迎！这是你的第一个文档站 👋

> 30 分钟，你就能看到自己写的文字变成网页。
> **不用装任何软件，不用写代码。**

---

## 你只需要做三件事

### ① 打开这个文件

```
docs/index.md
```

用任意文本编辑器打开它（VS Code、记事本都可以）。

---

### ② 把它改成你自己的介绍

把里面的内容**全部删掉**，换成你自己的版本。要有四样东西：

| 要什么 | 怎么写 |
|---|---|
| **标题** | 用 `#` 开头，如 `# 我是李四` |
| **正文** | 至少 100 字，写什么都行 |
| **列表** | 用 `-` 开头，如 `- 打篮球` |
| **行内代码** | 用反引号包起来，如 `` `Python` `` |

**照着这个改**（复制过去，把内容换成你的）：

```markdown
# 我是李四

我是一个喜欢折腾电脑的学生。这是我用 Sphinx 做的第一个文档站。
原来做网页不用会编程，写几行字就行了，挺神奇的。

## 我的三个爱好

- 打羽毛球
- 看动漫
- 研究手机

我最常用的软件是 `VS Code`。
```

写完记得**保存**（`Ctrl+S`）。

---

### ③ 运行构建

- **Windows**：双击文件夹里的 `build.bat`
- **macOS / Linux**：在终端执行 `bash build.sh`

或者手动执行：

```bash
python -m sphinx -b html docs docs/_build/html
```

然后打开 `docs/_build/html/index.html`。

🎉 **看到你自己的名字出现在网页上了吗？**

---

## 出问题了？

| 现象 | 怎么办 |
|---|---|
| 提示找不到 python | 举手找老师（这属于环境问题，不是你的错） |
| 构建报错了 | 把**完整的红色文字**拍照给老师 |
| 报 `Configuration error!` | 你没在 `warmup-docs\` 目录里、或命令路径写错了 → 改用双击 `build.bat` |
| 网页打开了但内容没变 | 按 `Ctrl+F5` 强制刷新 |
| 网页是空白的 | 确认打开的是 `docs/_build/html/index.html` |

---

## ⚠️ 两个"不要"

1. **不要改 `docs/conf.py`** —— 那是配置文件，已经帮你配好了
2. **不要装任何东西** —— 环境已经准备好了，`pip install` 之类完全不需要
