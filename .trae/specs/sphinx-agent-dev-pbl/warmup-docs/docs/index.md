这是第一段文字。

## 待办：把上面这段换成你自己的内容

请把整个文件替换成你的自我介绍。要求包含四样东西：

1. **标题**（像上面这行 `# 我的文档站` 一样，用 `#` 开头）
2. **一段正文**（至少 100 字，写什么都行）
3. **一个列表**（用 `-` 开头）
4. **一段行内代码**（用反引号包起来，比如 `Python`）

---

## 参考示例（可照着改）

下面是一个完整的例子，你可以直接照着改成自己的：

```markdown
# 我是张三

我是一名高中生，喜欢数学和编程。这是我用 Sphinx 做的第一个文档页。
我以前以为做网站很复杂，没想到写几行文字就能变成网页。

## 我的三个爱好

- 打篮球
- 看科幻小说
- 写代码

我最喜欢的编程语言是 `Python`。
```

---

## 写完之后

1. 保存这个文件（`Ctrl+S`）
2. 回到 `warmup-docs\` 文件夹，**双击 `build.bat`**（Mac 用 `bash build.sh`），
   或执行命令 `python -m sphinx -b html docs docs/_build/html`
3. 用浏览器打开 `docs/_build/html/index.html`

🎉 你会看到自己写的文字变成网页。

> 💡 这个文件就是 MyST Markdown 格式。
> 你现在写的这些语法（`#` 标题、`-` 列表、反引号代码），
> 后面的正式项目里全都会用到。
