#  为什么不能直接用 pip freeze 的输出？

#    所以这里用「直接依赖 + 下限」的方式手写。
#
#  下限按实测环境标注（Sphinx 9.1.0 / myst-parser 5.1.0 / openai 3.20.0
#  / 2026-09 验证）。不锁死上限，装到更新的小版本通常也没问题。
