## 双源逐字核读法

### 触发场景

适用于：
- 引用古籍/经典/历史文献原文入库（知识库、知识包、工具书）——原文一字之差可能改变义理
- 对接的是无版本控制的电子文本（网站、语料库、GitHub 转录本）而非权威影印本
- 同一文本存在多个"版本系统"的并行载体（底本不同、辑本不同、排印本不同）

不适用于：
- 有单一权威定本且无版本歧异的现代文本（当代出版物原文直接引用即可）
- 只需了解大意、不逐字引用的浏览性阅读

### 核心步骤

1. **选源**：主信源选权威底本的数字化本（先查明其底本系统，如 ctext.org 标注的四部丛刊本）；第二信源选**不同版本系统**的独立源（通行整理本/他辑本）——两源版本系统错开才有校勘价值
2. **逐字对读**：按最小文本单元（一篇/一条/一味药）逐字比对，不跳读；发现差异即登记（位置 + 两源原文）
3. **异文分类**：判定每处差异类型——版本系统差异 / 句读差异 / 古今字·异体字 / 脱文衍文 / 义理级差异（影响语义理解者）
4. **加第三参证**：义理级异文或有疑问处引入第三源参证；三源两同可增强倾向性判断，但义理级仍不作终裁
5. **信源失效即换源补位**：主信源被拦截/失效时立即切换备源补位，**保持双源数量不降级**为单源继续
6. **处理入库**：非义理级差异按"底本为尊 + 校记存异"处理（底本文字基本保持，异文出校记）；义理级差异并列登记两读并注明各自信源
7. **出库标注**：每段入库原文标注底本 + 校记来源 + 核对日期

### 反模式（≥3 个，来自本次调研的实际教训）

- ❌ **单源直录入库**——同一底本的两个电子转录之间都会有条目出入（教训来源：BC-019，同为孙星衍辑本的两个电子版在"石胆"一味上互有有无——任何单一电子文本都不可尽信）
- ❌ **把网络文本当"原文"，不辨版本系统**——网站用字是版本立场的投影（教训来源：NGJ-043 ctext"荥货"vs 通行本"荣华"；NGJ-033/NJ-081"五藏六府/荣卫"与"五脏六腑/营卫"全书通例——单取一源会把某一版本系统的用字固化成"通用文本"）
- ❌ **主信源失效后降级单源继续**——拦截不是降低核对标准的理由（教训来源：NGJ-035，ctext 反爬拦截后四气调神大论改用古诗文网 + 古文之家双源替代，双源标准未降级）
- ❌ **发现异文擅自"择善而从"径改**——编辑者立场会静默写入知识包（教训来源：NJ-073"故知肾有一也/二也"为义理级两读；NGJ-028 通行整理本对《太素》异文亦有"从改"与"保留加注"两种处理——两读类差异必须并列登记）

### 检验标准

- **抽样复现**：随机抽取 ≥10% 的入库段落，按登记的异文信息能重新核对复现（打开两源即见登记的差异）
- **异文登记覆盖率 100%**：抽查段落中两源差异全部有登记，不存在"静默择一"（取了某源文字但登记里查不到该处曾有分歧）
- **底本标注率 100%**：每段入库原文可追溯到底本名与信源 URL
- **义理级异文零裁决**：所有影响语义的异文均以"两读并列 + 信源"形式存在，无一被无声取舍

### 迁移示例

- **开源文档版本管理**：把外部 RFC / LICENSE / 官方规范文本引入项目文档库时，用"官方源 + 独立镜像"双源核对后入库，并记录"取自哪个源、两源差异何处"（对应 BC-019 教训：同一底本的不同转录会有出入，镜像站转录错误需要第二源拦截）
- **法律文本考据**：引用法条时核对"权威公报文本 + 专业数据库文本"两源；引用宪法条文区分修正案前后文本并标注现行有效版次（对应 NJ-081 教训：不同载体呈现同一文本时用字与条序可能不同）

## 托名辑复分层法

### 触发场景

适用于：
- 阅读/引用"作者"与"文本"关系复杂的古典文本：托名著作（署名者非实际作者）、层累汇编文本（历经多人整理校订）、辑复本（原书亡佚后从引文复原）
- 构建知识库/知识包时需要为古籍标注"这段文字到底是谁、哪个时代的"
- 核查一段广为流传的"古人曰"的真实出处

不适用于：
- 现代单一作者、版权归属清晰的当代文本（作者与文本关系透明）
- 已有权威校勘定本且无版本歧异、无托名问题的普及读物

### 核心步骤

1. **文本性质三分**：先判定三层——托名层（署名者与实际作者的关系：托名/伪托/存疑）、文本层（现存文字的实际生成链：汇编→整理→校订各环节）、辑复层（是否为后世复原本及其辑本系统）
2. **查正史书目著录链**：检索最早正史书目著录（《汉书·艺文志》《隋书·经籍志》《旧唐书·经籍志》等）及卷数记载——著录缺位、卷数变动、作者栏空缺都是流变信号
3. **梳理整理者链**：从托名作者到现行本之间列出所有整理者（谁编、谁注、谁校、谁刊），明确现行本文字最终定型于谁之手
4. **辑复本并置**：对辑复本，并置各辑本（辑者/年代/辑复方法/收文差异），明确引用对象是"某辑本"而非"原书"
5. **分层引用表述**：知识产出中区分两种表述——"托名作者说"（传统语境归属）与"某本作某"（文本事实归属），不一锅煮
6. **争议并列**：作者归属、成书年代的诸学说并列登记并附信源，不作裁决

### 反模式（≥3 个，来自本次调研的实际教训）

- ❌ **把托名当真名**——"神农曰""黄帝曰"直接当历史事实陈述（教训来源：BC-001"神农"为托名、NGJ-025"黄帝"为托名"以自尊其道"、NJ-008《史记·扁鹊仓公列传》不载秦越人著《难经》且 NJ-016 考证为后人伪托）
- ❌ **把整理者文字当原作者文字**——引文署名与文字实际定型者错位（教训来源：SH-008/SH-009 今本《伤寒论》经王叔和整理、宋臣校订；SH-019 条文编号为现代校注者所加；NGJ-011 林亿"正谬误者六千余字"——今本文字大量是历代整理定型的结果）
- ❌ **把某一辑本当原书**——辑本间三品归属、条目数、药序都可不同（教训来源：BC-034/BC-035 水银、雄黄三品归属在两本间不同；BC-018 辑本目录 353 条与序录 365 之数差 12；BC-033 两本药序不同）
- ❌ **忽视正史著录的"沉默"**——书目不载本身就是证据（教训来源：NJ-009《汉书·艺文志》未著录《难经》、SH-005 张仲景正史无传——"缺位"用于断代与辨伪，不能因名气大反推记载早）
- ❌ **成书年代取单一说**——诸说并存时只标一说（教训来源：NGJ-022《内经》成书诸说并存、BC-002《本经》或秦汉或战国、NJ-013~017《难经》成书五说并存——年代结论必须并列登记）

### 检验标准

- **五问能答**：对每部经典都能答出——①托名者是谁？②最早见于哪部正史书目？③主要整理者是谁？④现存最早版本是什么？⑤现行本是原本/整理本/辑复本？五问答不全即分层未完成
- **引用可溯源**：任一段引文能指明出自哪个具体版本/辑本（而非笼统书名）
- **争议登记率**：作者归属、成书年代的学术争议 100% 并列登记且各附信源，无"取一说而隐他说"

### 迁移示例

- **开源项目文档考据**：判断"官方文档"某段是初版设计还是社区后续修订——README 署名者未必是当前内容的作者，git 历史 / CHANGELOG / ADR 记录即该项目的"整理者链"（对应王叔和/林亿之于仲景原文：引用文档时区分"初版作者主张"与"现行维护者文字"）
- **法律文本考据**：引用宪法/法条时区分"制宪者·立法者原意"（权威来源叙事）与"修正案后现行文本"（实际生效文字），立法史与现行有效文本分开引用，不可把立法目的表述当作现行条文内容

## 谱系分级阅读法

### 触发场景

适用于：
- 面对一个庞大古典文献体系（一个学科的经典群）需要为不同层次读者设计阅读路径或知识包结构
- 需要回答"先读什么、后读什么、核心是哪几本"的体系性问题
- "核心书目"本身存在历史争议、需要透明化处理时

不适用于：
- 单一文本的深度研读（只需版本考据，无需体系分级）
- 已有权威机构给定路径且用户无定制需求的场景（直接采用即可）

### 核心步骤

1. **定核心层（经典层）**：确定学科奠基文本集合——先核查该集合是否为后世建构（组合的提出年代、历史流变、现存争议），各种组合并列登记不裁决
2. **建流派层（各家学说层）**：登记核心层之后的理论发展流派（流派→代表人物→代表作三元组，含师承与论争关系）
3. **建应用层（临床/专科层）**：登记面向专门应用的文本（专科专著、工具书性质文本）
4. **按读者层次映射形态**：同一文本按形态分层推荐（诵读本/通识导读/原文译注/白文本/影印善本），入门者从导读层进入，研究者进底本层
5. **挂接权威信源**：每层每个条目标注一句定位 + 权威信源（国家项目/专业出版社/数据库），使路径中任何一本书都可独立核实

### 反模式（≥3 个，来自本次调研的实际教训）

- ❌ **把"经典组合"当天然固定边界**——核心书单多有建构性（教训来源：OV-002~005，"四大经典"1955 年首提、首提名单与今不同、含《难经》说 1979 年才出现、多组合并存至今）
- ❌ **入门者直推最古最善底本**——底本与读者层次错配（教训来源：OV-040 中华书局同书分诵读本/通识/译注三形态供给、OV-041 人卫白文本"只收原文不作校记"面向已有基础者——分级供给是行业惯例，单一路径会劝退入门者）
- ❌ **无视现成权威分级体系从零自建**——重复劳动且权威性弱（教训来源：OV-029~037，《中华医藏》四编结构、国家中医药管理局研修项目分科书目、人卫必读丛书分级等现成权威资源可直接对齐复用）
- ❌ **分层只按"时代先后"不按"知识功能"**——时间轴不等于阅读路径（教训来源：OV-030《中华医藏》四编按医经/伤寒金匮/本草/养生/医史等知识功能分编而非按朝代——功能维度才贴合读者的实际进入方式）

### 检验标准

- **三层齐备**：核心层/流派层/应用层均有条目，每本书有层级定位 + 一句定位语 + 信源
- **组合透明**：核心层的入选依据、历史争议组合均已登记；不同目标读者（考试/临床/文献研究）能各自切换对应书单
- **形态映射**：至少两档读者层次（入门/进阶）各有对应的文本形态推荐
- **信源可核**：每层至少挂接一个可访问的权威信源

### 迁移示例

- **开源技术栈学习路径设计**：核心层（语言规范/官方标准库文档）→ 流派层（框架及流派比较）→ 应用层（领域专项实践）；同一规范按"快速上手/通识导读/规范全文"分层供不同读者——与 SpecWeave 渐进式披露 L0/L1/L2 三层架构同构（一个体系同时为入门者与专家供给不同深度的入口）
- **法学入门路径设计**：核心层（宪法/民法典等基本法）→ 流派层（法学流派与代表性论著）→ 应用层（部门法实务与案例汇编），同一法典按"普法读本/教科书/法条评注"分层推荐（对应 OV-040 中华书局分层出版实践的跨领域重现）
