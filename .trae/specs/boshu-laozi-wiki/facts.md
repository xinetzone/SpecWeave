## F-001 ~ F-021 事实清单

| 编号 | 事实陈述 | 备注/可追溯来源 |
|------|----------|----------------|
| F-001 | 1973 年长沙马王堆三号汉墓出土大量帛书，其中包括《老子》甲、乙两种抄本 | 马王堆汉墓考古发现（1973-1974 年发掘报告） |
| F-002 | 帛书《老子》甲本不避汉高祖刘邦名讳，用"邦"字 | 避讳学证据：甲本抄写于刘邦称帝（公元前 202 年）之前 |
| F-003 | 帛书《老子》乙本避"邦"字讳，改作"国"；同时避"恒"（汉文帝刘恒讳）作"常" | 乙本抄写于汉文帝在位（公元前 179-157 年）及其后 |
| F-004 | 甲乙本均以《德经》在前、《道经》在后的顺序编排 | 与传世王弼本"道经在前、德经在后"相反 |
| F-005 | 传世通行本《道德经》共 81 章，上篇《道经》37 章、下篇《德经》44 章 | 通行本分章结构（王弼本系统） |
| F-006 | 帛书《老子》分章与传世本不同：德经在前（约 44 段）、道经在后（约 37 段） | 帛书出土后的整理本（马王堆汉墓帛书整理小组） |
| F-007 | "大器免成"出现在帛书乙本，传世本作"大器晚成" | 文字差异经典案例（高明《帛书老子校注》） |
| F-008 | 帛书用"恒"处，传世本多作"常"（如"道可道，非常道"帛书作"非恒道也"） | 避汉文帝刘恒讳所致 |
| F-009 | 帛书用"邦"处，传世本多作"国" | 避汉高祖刘邦讳所致 |
| F-010 | 帛书多虚词："也""者""矣"等语气词较传世本丰富（如"道可道也，非恒道也"）；帛书亦多用否定词"弗"（传世本多作"不"） | 帛书保留更多战国/汉初书面语特征 |
| F-011 | 高明《帛书老子校注》（中华书局，1996 年）以帛书甲乙本为底本，以王弼本为主校本 | 学界公认的重要帛书校注著作 |
| F-012 | 秦复观《帛书老子注读》（东方出版社，2022-12）以帛书甲乙本为基础作注读 | 当代帛书注读著作，344 页/270 千字 |
| F-013 | 1993 年湖北荆门郭店楚墓出土楚简《老子》（郭店楚简） | 现存最早的《老子》抄本，早于马王堆帛书约百年 |
| F-014 | 郭店楚简《老子》为节选本（约 2000 字），分为甲、乙、丙三组 | 竹简本与帛书本、传世本章次文字均有差异 |
| F-015 | 王弼本《老子道德经注》为魏晋玄学代表性注本，是通行本《道德经》的主要来源 | 三国魏王弼（226-249）注 |
| F-016 | 河上公本《老子章句》为另一重要传世注本系统，与王弼本并存 | 道教系统注本，托名河上公 |
| F-017 | 帛书《老子》甲乙本皆无篇名、无章名，仅以分章符（黑点）标示段落 | 帛书原貌：分章以符号标记，无后世章名 |
| F-018 | 帛书《老子》德经部分内容与传世本《道德经》下篇（德经）大致对应 | 内容对应关系（德经→德经） |
| F-019 | 帛书《老子》道经部分内容与传世本《道德经》上篇（道经）大致对应 | 内容对应关系（道经→道经） |
| F-020 | 1972-1974 年马王堆汉墓考古发掘为长沙马王堆汉墓发掘的一部分，三号墓为利豨（汉初长沙国丞相利苍之子）之墓 | 马王堆三号墓墓主身份 |
| F-021 | 郭店楚简《老子》抄写年代学界主流判为战国中期偏晚，约公元前 300 年前后 | 版本学通识（早于马王堆帛书约百年） |
