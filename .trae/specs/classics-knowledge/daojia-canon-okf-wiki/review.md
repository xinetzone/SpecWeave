# Checklist — 道家著作全谱系调研与 OKF 知识包

> Phase 0（调研）为本次可执行交付，其检查点在本清单前列；Phase 1+（入库）检查点在用户确认后展开时激活。

## Phase 0：内容正确性与覆盖

- [ ] 四段谱系均有代表性著作覆盖：先秦诸子（庄/列/文子/鹖冠子/关尹子/管子）、黄老（阴符经/黄帝四经/淮南子/尹文子/慎到田骈）、玄学注疏（王弼/河上公/严遵/郭象/成玄英）、道教经典（参同契/抱朴子/太平经/黄庭经/清静经）
- [ ] 每部著作登记完整元数据：书名/别称、托名作者、推定年代、版本体系（出土/传世/道藏）、核心思想一句话、权威底本注本、信源 URL
- [ ] 托名/伪书/年代争议处（关尹子、列子、黄帝系、文子-淮南子等）显式区分「托名层/文本层」，列出 ≥2 种学术观点及依据，无单一确定性断言

## Phase 0：权威信源与溯源性

- [ ] 每部著作信源权威可核查（学术专著/整理本/机构藏本/ctext 等），无匿名博客/百科帖/无出处网络文本作为唯一来源
- [ ] facts.md 每部著作带信源 URL 与权威性评级
- [ ] 无虚构引证（抽查可逐条核对信源）

## Phase 0：方法论质量门

- [ ] G1：facts.md 编号事实纯客观描述，无「因为/导致/所以」等因果推断词
- [ ] G2：insights.md ≥5 条四元组洞察（现象+根因+影响+建议）
- [ ] G3：≥3 个可复用「经典判读/谱系重建」模式，各含触发场景/核心步骤/反模式/迁移示例

## Phase 0：决策输入与确认点

- [ ] 已提出 `think/daojia/` 统一分组的子 bundle 结构建议（含既有 `think/laozi` 与《阴符经》spec 的迁移/并入方案）
- [ ] 已提出入库优先级序与每部著作 bundle 粒度建议
- [ ] 已向用户呈现并获确认（入库范围/顺序/迁移决策）——未确认不得进入 Phase 1+

## Phase 1+：OKF 格式与结构（确认后激活）

- [ ] 全部新增文档 frontmatter 符合 OKF v0.2（type/source/generated/verified/status/stale_after）
- [ ] `think/daojia/index.md` 总纲及每册 bundle 根 index 均含 toctree，引用全部子文档，无孤立文档
- [ ] 文件名 kebab-case 纯英文；正文中文；交叉引用相对路径无断链、无 file:///
- [ ] `bundles/think/index.md` 与 `bundles/index.md` 统计数字、分组表行、toctree 已同步更新

## Phase 1+：交付验证

- [ ] `invoke gates.all`（在 projects/awesome-okf-xs）全部通过（toctrees + utf8）
- [ ] 每册 V 对抗审查完成（原文 10 处 + 事实 10 条双源抽查通过）
- [ ] 逐册 atomic-commit 原子提交，符合 Conventional Commits；主仓 gitlink 处理妥当
