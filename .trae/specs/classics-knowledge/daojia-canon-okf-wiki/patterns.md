## P-001 托名文本三层判读法

- **触发场景**：判断一部道家／子书典籍的真伪、成书年代与作者归属——尤其存在托名、伪书、辑佚争议时（如《列子》《关尹子》《尹文子》《阴符经》《文子》）。
- **核心步骤**：
  1. **著录层**：校核历代目录著录（《汉书·艺文志》《隋书·经籍志》《四库全书总目》等）的卷数、篇目、流传沿革。
  2. **文本层**：校核版本形态——有无出土本、传世本系统、道藏本，文辞风格、避讳、用词的时代特征。
  3. **思想层**：定位义理在思想史中的位置，判断其与可确定年代文献的先后承继关系。
  4. **交叉定谳**：三层证据齐备且指向一致，方可下「真／伪／托名」结论；单一层不下定论。
- **反模式**：
  - 单点定案：仅凭「思想浅近」「著录缺载」即下伪书结论。
  - 托名当史实：把署名作者（黄帝、老子、尹喜、河上公）当作确证作者。
  - 忽略下限约束：无视出土文献提供的成书下限，仍沿用旧断代。
- **迁移示例**：已被用于本谱系 22 部著作的「托名层/文本层」判定（引用 facts.md 各条）；可迁移至墨家《墨子》城守诸篇、儒家子书（如《孔子家语》）等托名/成书争议的判读。

## P-002 双源逐字核读法

- **触发场景**：入库原文需保证「最权威、最真实」时，对每条原文做至少两个独立权威信源的逐字核对。
- **核心步骤**：
  1. **选源**：确定两个相互独立的权威信源（学术整理本 / 出土整理本 / ctext.org 公开整理本），禁止匿名博客、百科帖作为任一源。
  2. **逐字核对**：同一文本段在双源间逐字比对，记录异文、脱文、衍文。
  3. **差异裁决**：异文处优先采 A 级（出土＋传世双重印证）整理本，并在 references 层登记异文依据。
  4. **评级落地**：为每部著作标注权威性评级（A/B/C）与底本形态，C 级（辑佚／残本）不引全本。
- **反模式**：
  - 单一信源依赖（尤以百科、网络转述为唯一来源）。
  - 以 C 级辑佚残本冒充全本（如《慎子》《田子》仅存辑本却引作完整原文）。
  - 双源实为同源（两个版本实出自同一整理本，未构成独立核对）。
- **迁移示例**：老子原文以王弼本（楼宇烈校释）与帛书本（高明《帛书老子校注》）双源核对；可迁移至任意古籍原文的权威性入库。

## P-003 传本谱系重建法

- **触发场景**：建立一部著作的版本体系与流传谱系，供读者理解文本形态差异（出土本／传世本／道藏本沿革）。
- **核心步骤**：
  1. **枚举版本形态**：列出土文献（简帛/敦煌写本）、传世整理本系统、道藏本系统。
  2. **标注来源性质**：区分「出土（孤本/残卷）」与「传世（经删定）」。
  3. **锚定权威整理本**：为每部著作选定一个权威整理本作为引用底本（含点校者、出版社、ISBN）。
  4. **评级**：按「出土＋传世双重印证且整理本权威＝A；传世本为主＝B；辑佚/残本/托名争议大＝C」评级。
- **反模式**：
  - 线性排列混淆并行：把道藏本当「原始本」、视传世本为唯一正统。
  - 出土至上：把出土文献当作「全书定型」的充分证据（实仅为下限硬约束）。
  - 评级与底本脱节：A/B/C 与所引整理本不对应。
- **迁移示例**：黄帝四经（无传世本，仅马王堆帛书出土本）与老子（郭店简/帛书/传世多系统）的谱系定位；可迁移至任意出土vs传世的版本谱系重建。

## P-004 段—家—著三级谱系分层法

- **触发场景**：为「道家」这类思想流派生态构建导航总纲，避免线性时间线误导并行演化。
- **核心步骤**：
  1. **分段**：按思想史坐标划分谱系段（先秦诸子／黄老之学／玄学注疏／道教经典）。
  2. **分家**：每段内识别学派或注家脉络（如稷下黄老、正始玄学、重玄学）。
  3. **分著**：落到具体著作／注本一束，形成 bundle 颗粒。
  4. **标注关系**：以谱系图（mermaid）呈现段—家—著三级，并标注并流与回环（如黄老与诸子并行、道教上承玄学兼方术）。
- **反模式**：
  - 线性堆叠：把并行谱系排成单一时序链。
  - 附庸化：把玄学注疏、道教经典并入先秦诸子的「附庸」，抹煞独立思想流派地位。
  - 颗粒失当：整段合一束（过粗，失导航）或每篇一束（过细，失主题边界）。
- **迁移示例**：本谱系 `think/daojia/` 总纲 index 即按此法生成；可迁移至儒家、墨家、法家等诸子谱系的导航组织。
