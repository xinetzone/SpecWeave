# 法家经典知识包——可复用阅读模式（E 阶段，G3）

> session: sc-20260830-legalism-wiki | 从本次四部文献（韩非子/商君书/管子/申慎辑佚）实践中萃取

## 模式 P-01：托名古籍三问法（成书性质分层）

- **触发场景**：阅读任何一部先秦子书（尤其《管子》《商君书》《列子》等托名结集体），或需要向读者保证"最真实原文"时。
- **核心步骤**：
  1. **第一问"谁写的"**：查传统归属与学界归属是否一致；不一致时列出主要学说（如《初见秦》"韩非作/非韩非作"两说）及文献学依据，并列呈现、不作裁决。
  2. **第二问"何时结集"**：确定成书链条（单篇流传→学派结集→刘向校定→刊本定型），将文本定位到链条的某一层（托名层/结集层/亲著层/辑佚层）。
  3. **第三问"哪些可信"**：按证据强度给篇章分级——亲著/无争篇可全文精读；争议篇引用时标注归属学说；辑佚篇逐条标注辑佚出处。
- **反模式**：① 以书名等同作者（"商君书=商鞅著"）；② 因托名而整体否定史料价值（学界共识：托名不影响其作为该学派思想史料的价值）；③ 将某一归属学说当作定论写入教程。
- **迁移示例**：可用于《列子》（托名列御寇，或为魏晋人结集）、《文子》（托名文子，竹简本与传世本关系有争）等任何真伪有争古籍的阅读教程设计；亦可用于评估二手学术引用的可靠性。

## 模式 P-02：辑佚文献出处链核验法

- **触发场景**：引用大部散佚、仅存辑本的文献（《申子》《慎子》《尸子》等），或数字库给出"某某曰"断片引文时。
- **核心步骤**：
  1. 建立三级出处链：**佚文 → 辑本 → 类书/古注原始出处**（如"申不害曰……——严可均《全上古三代文》辑，出《艺文类聚》"）。
  2. 区分辑本源流（守山阁丛书本/四部丛刊本/玉函山房辑佚书）与保存链（《群书治要》卷三十六存《申子·大体》全文）。
  3. 显式标注"辑佚残篇，非传世完本"警示，存目文献（如马国翰辑本）"存目、不引文字、不裁决"。
- **反模式**：① 把辑佚文本当作完整传世本引用；② 断片佚文不注类书出处，使读者无法回溯真伪；③ 将后世辑本文字与先秦原貌直接画等号。
- **迁移示例**：适用于《尸子》《惠子》等残籍，也适用于评估现代出版物中"某某子曰"引文的真实性（缺出处链的断片一律存疑）。

## 模式 P-03：双源异文登记法（数字古文核对）

- **触发场景**：为古籍制作数字教程并承诺"最真实原文"时；任何需要从网络信源复制古文的场合。
- **核心步骤**：
  1. 选定主源（如 ctext.org，记录其底本信息）+ 备源池（维基文库/古诗文网/中华典藏等 ≥2 个）。
  2. 逐字比对，异文处登记编号事实："某句，A 本作 X，B 本作 Y"，并列呈现不作裁决。
  3. 影响义理的重大异文（如《开塞》"刑者/利者"）单独分析，明示两种读法的义理后果。
  4. 信源降级（如维基文库超时）时在 facts 登记实际信源与失败记录，未核验内容标"转引"。
- **反模式**：① 单源复制即发布；② 发现异文后径直裁决择一（应交读者按校本自断）；③ 隐瞒信源失败记录造成"已双源核对"的假象。
- **迁移示例**：适用于一切多版本流传文本（帛书/通行本《老子》异文、红楼梦诸本异文），也可推广到 API 文档多版本核对等工程场景。
