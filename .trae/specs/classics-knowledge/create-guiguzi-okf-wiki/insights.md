# 架构洞察（Architecture Insights）

> 基于事实清单（facts.md）分析得出，每条洞察遵循四元组结构（现象/根因/影响/建议）。

---

## 洞察1：托名层/文本层之分

| 四元组 | 内容 |
|--------|------|
| **现象** | 《鬼谷子》托名鬼谷子，历代或疑其伪（柳宗元“后出”说）或信其真（俞棪考证存于西汉前）。 |
| **根因** | 《汉志》未著录而首见于《隋志》，且《史记》仅记“鬼谷先生”之名未记其书；但刘向《说苑》《淮南子》《史记索隐》等早于或近于班固的文献已引其文。 |
| **影响** | 不作分层易把托名当史实或全盘否定其先秦价值。 |
| **建议** | 采用“托名层/文本层”双层判读，不在作者真伪上武断裁决。 |

## 洞察2：纵横术双重评价

| 四元组 | 内容 |
|--------|------|
| **现象** | 柳宗元斥“险盭峭薄”而高似孙赞“智谋数术出于战国诸人之表”。 |
| **根因** | 纵横术讲求揣摩人心、因势捭阖，在重道义的儒家正统话语下被视为权谋诈术，在重智略的传统中又被视为韬略源泉。 |
| **影响** | 评价分裂使该书长期处于“禁书/奇书”两极叙事。 |
| **建议** | 并置褒贬两脉，以思想史定位而非道德评判组织章节。 |

## 洞察3：底本注者未决性

| 四元组 | 内容 |
|--------|------|
| **现象** | 道藏本注者不署名，传统认定陶弘景注，现代有学者考证为尹知章注。 |
| **根因** | 正史仅著录皇甫谧、乐壹、尹知章三家，而南宋书目又明确录“梁陶弘景注”，且《持枢》注有“元亮曰”呼应陶氏先辈。 |
| **影响** | 径标“陶弘景注”可能张冠李戴，过度否定则弱化道藏本价值。 |
| **建议** | 采用“道藏本（传陶弘景注，或尹知章注）”谨慎表述并在 commentaries.md 单列考辨。 |

## 洞察4：出土文献互证

| 四元组 | 内容 |
|--------|------|
| **现象** | 1973 马王堆《战国纵横家书》出土。 |
| **根因** | 传世《史记》对苏秦事迹有年代错乱，帛书提供更原始一手纵横家文献。 |
| **影响** | 为《鬼谷子》纵横术的时代背景提供旁证并修正苏秦张仪同时的传统印象。 |
| **建议** | 在 06-influence 与 cross-ref 引入该书作旁证信源。 |

## 可复用阅读模式

### 模式1：双源逐字核读法

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读有异文的古籍原文。 |
| **核心步骤** | 选定核心底本+至少一个独立参照源→逐字对照→登记异文“某本作某”→标注注家出处。 |
| **反模式** | 只依赖单一网络文本、拼合不同版本而不标注。 |
| **迁移示例** | 可迁移到《老子》《阴符经》等有异文的古籍。 |

### 模式2：托名文本三层判读框架

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读托名/伪托争议的古籍。 |
| **核心步骤** | 分层=托名层（作者归属）→文本层（思想内容与成书时代）→接受层（历代注疏与评价），各层独立取证。 |
| **反模式** | 把托名当史实、据伪托争议全盘否定文本价值。 |
| **迁移示例** | 可迁移到《阴符经》（托名黄帝）、《列子》（托名列御寇）等。 |
