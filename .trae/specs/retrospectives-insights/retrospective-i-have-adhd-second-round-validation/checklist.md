## 七概念质量门检查

- [ ] G1（R阶段·事实无因果词）
  - [ ] Grep检查事实描述章节无"因为/导致/所以/因此/由于/之所以"等因果推断词
  - [ ] 事实均为可验证的客观描述，无主观判断

- [ ] G2（I阶段·洞察四元组完整）
  - [ ] ≥3条核心洞察每条都包含：现象描述+根因分析+影响评估+改进建议
  - [ ] 根因分析追溯到流程/方法论层面，不是表面原因
  - [ ] 改进建议具体可执行

- [ ] G3（E阶段·模式可迁移）
  - [ ] 元复盘SOP包含：触发场景+核心步骤+反模式+迁移验证
  - [ ] SOP可应用于未来其他知识沉淀任务的二次验证
  - [ ] 迁移验证至少覆盖2个不同类型的知识沉淀场景

- [ ] G-V1（V阶段·第二轮对抗意见具体）
  - [ ] 第二轮审查意见均为具体问题，非客套话或泛泛而谈

- [ ] G-V2（V阶段·新视角覆盖）
  - [ ] 审查视角未在第一次V阶段使用
  - [ ] 覆盖至少4个不同视角（非技术用户/长对话/创意/高风险/失败案例）

- [ ] G-V3（V阶段·采纳修改对应具体问题）

  - [ ] 修改记录清晰，说明哪条意见对应哪处修改
