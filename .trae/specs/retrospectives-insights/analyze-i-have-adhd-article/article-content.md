经常用 Claude Code 的朋友应该都有这个感觉。 它什么都好，就是太爱说话了。 你让它改一个函数，它就会先说一句"问的好"，然后铺垫三段上下文。 最后要加一句希望可以对你有所帮助。 答案藏在第三段的中间，要自己去找。 更烦的是它还爱跑题。 你让它改一个bug，它修完之后。倒是很热心。 给你来一句你的xx依赖要升级了。 一两次还可以，但是天天这样下去，真的会让人头疼。 最近在 GitHub 上刷到一个项目，是用来解决这个问题的。 它的名字是i-have-adhd，在 GitHub 上已经有9400多个Star了。 其实就是在给 Agent 装上一套"说话规矩"，让它的回答直接进入主题，不啰嗦。

## 来看看实际用起来是啥样

很多人用 Claude Code 直接就开干了。 让它改一个函数大概率就会出现这样的结果。 很简单的问题，噼里啪啦说了很多，答案也给出来了，但是就太啰嗦了。 用上i-have-adhd skill。 在 Claude Code 里输入 `/i-have-adhd` ，激活。 然后再问它同样的问题。改一个认证函数。 **第一行直接告诉你该干啥。**
```
运行 npm install jsonwebtoken@latest，然后编辑 src/auth.ts:42。
```
不作任何铺垫，也不给我思考的时间，直接下达了你可以执行的命令。 **然后给你编号步骤。**
```
1. 打开 src/auth.ts
2. 将 verifyToken 替换为下面的代码片段
3. 运行 npm test -- auth.spec.ts
```
每一句只做一件事，不能在一句话里出现"然后……然后……"。 **最后给出一个具体的下一步。**
```
下一步：如果有测试失败，请粘贴第一行报错。
```
对比一下之前： `先是问得好！让我想一想` ，中间塞了依赖建议，结尾 `希望这能帮到你` 。 答案简洁，顺便还省了很多 token。

## 它到底是怎么做到的

**01 行动为先，答案总是在第一行。** 回复的第一行一定是你可以做的东西，命令、路径、代码片段先给出。解释放在后面。 以前读完三段废话才知道要干什么，现在第一行就是答案，照着做就可以了。 它会给出一个具体的时间估计，而不会说"一会儿"，比如说"大约15分钟"。

**02 步骤编号，按步骤执行。** 超过一步的任务，用1-2-3编号并列出，每一项只做一件事。不会把五个动作塞进一句话里让你自己拆。 并且会去掉多余的环节，把可以合并的合并在一起。

**03 每轮重述进度，不用你记上下文。** 它会告诉你每一回合你处在哪个阶段，刚刚做了些什么。收到消息之后上下文还在。 ADHD 大脑工作记忆小，不在屏幕上显示的信息就等于没有。这就解决了前面提到的问题。

**04 压制离题和客套，只拿答案走人。** 不再"顺便提一下"你的依赖也过时了，做完当前任务再说下一个。 不再"问得好！"开场、"希望这有帮助！"收尾。 而且会在发送前进行一次自检，去掉开头的预告句和结尾的客套句。 当项目数量大于5个的时候会自动分出"现在做"和"以后做"，不会给你塞进去10条没有顺序的建议。

## 想试的话，装起来很简单

Claude Code 用户只要用两条命令就可以安装。
```
claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd
```
安装好之后输入 `/i-have-adhd` 就会激活。 为了让每次对话都自动开启，可以执行一次 `touch ~/.claude/.i-have-adhd-always` 。 Codex 用户也差不多，把 claude 换成 codex 就行。 一个 SKILL.md 通吃所有，规则就是纯文本，谁都能读，不需要编译不需要联网。

## 不过有几点也得提一下

它并没有改变 AI 的推理能力，只是改变了输出格式。 AI不会因此而变得更聪明，但是它的回答会更加直接、可执行。 规则有 6 种例外情况可以打破。比如破坏性操作前必须确认，你要求详细解释时可以长篇。 不是死板的格式化，在需要的时候要灵活。

## 写在最后

有一本书叫《The Adult ADHD Tool Kit》，主要就是教给ADHD患者怎样来安排自己的生活。 我认为i-have-adhd最有趣的地方就是： 它把心理学教材里的建议，反过来用在了 AI 身上。 现在变成了教 AI 怎么说话才让人听得懂。从人到AI的逆向改编很少见，但是效果却很好。 嫌 AI 啰嗦就够理由装一个。 用一个SKILL.md来解决一个痛点，直接了当。 项目基于 MIT 协议开放，感兴趣的同学可以去看看源码和文档。 开源地址：https://github.com/ayghri/i-have-adhd
