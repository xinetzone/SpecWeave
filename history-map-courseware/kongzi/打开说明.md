# 孔子生平足迹 · 交互地图课件 — 使用说明

## 文件清单
| 文件 | 作用 |
|---|---|
| `index.html` | 课件主文件（双击即可在浏览器打开）|
| `app.js` | 交互逻辑（地图、时间线、巡览）|
| `kongzi_data.js` | 内嵌数据（坐标·讲稿·依据），供 index.html 直接读取 |
| `kongzi_data.json` | 同源数据 JSON 版（便于查看/二次编辑，非运行必需）|

## 打开方式
直接**双击 `index.html`**，用 Chrome / Edge / Firefox 打开即可（数据已内嵌为 JS，`file://` 双击可直接运行，无需本地服务器）。

## 功能
- **左栏**：bio 简介、quote 名言（《论语·学而》）、人物消歧、生平时间线（8 站）。
- **右侧地图**：真实 OpenStreetMap 底图，8 个带编号足迹点，红色虚线为生平叙事主线。
- **交互**：点击地图标记或时间线条目 → 弹出时间、古今地名、经纬度、事件、定位方法、置信度与史料依据。
- **底部按钮**：`上一站 / 自动巡览 / 下一站`，自动巡览按生平顺序逐站讲解。

## 足迹主线（8 站）
诞生尼山 → 成长讲学曲阜阙里 → 入周问礼洛邑 → 适齐闻韶临淄 → 出仕夹谷·堕三都 → 周游首站卫国帝丘 → 陈蔡绝粮 → 归鲁治学·葬孔林。

## 置信度与存疑说明
- 诞生地（尼山/曲阜）、阙里、孔林等**地望确凿**（高置信）。
- **问礼年份**（前518/前508）、**夹谷确址**（曲阜/莱芜/淄博）、**陈蔡绝粮具体地点**（淮阳/上蔡纪念性遗址）、周游路线细节均存考证差异，弹窗中已逐点标「存疑」。
- 点 1、2、5、8 集中在曲阜一带，低缩放会重叠，放大地图即可区分。
