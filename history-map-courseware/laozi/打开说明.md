# 老子生平足迹 · 交互地图课件 — 使用说明

## 文件清单
| 文件 | 作用 |
|---|---|
| `index.html` | 课件主文件（双击即可在浏览器打开）|
| `app.js` | 交互逻辑（地图、时间线、巡览）|
| `laozi_data.js` | 内嵌数据（坐标、讲稿、依据），供 index.html 直接读取 |
| `laozi_data.json` | 同源数据的 JSON 版（便于查看/二次编辑，非运行必需）|

## 打开方式
直接**双击 `index.html`**，用 Chrome / Edge / Firefox 打开即可。
> 数据已内嵌为 JS，无需本地服务器；`file://` 双击可正常运行。

## 功能
- **左栏**：人物 bio 简介、quote 名言、人物消歧说明、生平时间线。
- **右侧地图**：真实 OpenStreetMap 底图，7 个带编号的足迹点，红色虚线为课堂讲述主线。
- **交互**：点击地图标记或左侧时间线条目 → 弹出该站的时间、古今地名、经纬度、事件、定位方法、置信度与史料依据。
- **底部按钮**：`上一站 / 自动巡览 / 下一站`，自动巡览按课堂讲述顺序逐站讲解。

## 关于地图底图
- 联网时自动加载 OpenStreetMap 真实底图；主源不通会依次切换备用在线源。
- 若完全无网络，自动降级为浅色经纬网格兜底图并提示，联网刷新即恢复真实底图。

## 置信度与存疑说明
- 每个点标注定位方法（映射表 / 典籍考据 / 碑刻方志 / 推理兜底）与置信度（高/中/低）。
- 老子为半传说人物，**出生地（鹿邑 vs 涡阳）**、**问礼年份**、**著经之关（函谷关 vs 大散关）**、**最终去向** 均存学界争议，课件内均标注「存疑」，未作硬编定论。
