# 庄子生平足迹 · 交互地图课件 — 使用说明

## 文件清单
| 文件 | 作用 |
|---|---|
| `index.html` | 课件主文件（双击即可在浏览器打开）|
| `app.js` | 交互逻辑（地图、时间线、巡览）|
| `zhuangzi_data.js` | 内嵌数据（坐标·讲稿·依据），供 index.html 直接读取 |
| `zhuangzi_data.json` | 同源数据 JSON 版（便于查看/二次编辑，非运行必需）|

## 打开方式
直接**双击 `index.html`**，用 Chrome / Edge / Firefox 打开即可（数据已内嵌为 JS，`file://` 双击可直接运行，无需本地服务器）。

## 功能
- **左栏**：bio 简介、quote 名言（逍遥游·鲲鹏）、人物消歧、生平时间线。
- **右侧地图**：真实 OpenStreetMap 底图，7 个带编号的足迹点，红色虚线为课堂讲述主线。
- **交互**：点击地图标记或时间线条目 → 弹出时间、古今地名、经纬度、事件、定位方法、置信度与史料依据。
- **底部按钮**：`上一站 / 自动巡览 / 下一站`，自动巡览按课堂讲述顺序逐站讲解。

## 置信度与存疑说明
庄子生平史料匮乏，课件对争议点均标「存疑」，不硬编：
- **故里四说**：①商丘梁园区（蒙墙寺，主流学术倾向，取为主点）；②民权青莲寺（地方/文旅认定，列为异说点2）；③安徽蒙城（苏轼《庄子祠堂记》，学界多质疑）；④山东东明/曹县。
- **漆园确址**、**濮水/濠水具体水段**、**卒年与葬地** 均存争议，弹窗中已逐点标注。
- 点 1、2、3、7 集中在商丘一带，低缩放下会重叠，放大地图即可区分。
