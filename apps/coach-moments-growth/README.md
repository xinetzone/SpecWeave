# 商业教练朋友圈 AI 增长系统（coach-moments-growth）

> 一套面向高净值客群（企业创始人 / 个体创业者 / 高管）的商业教练私域内容运营方案：以 **AI 生成高转化朋友圈内容**为引擎，打通「定位 → 内容 → 转化 → 度量 → 合规」闭环，服务「万元私教稳定成交」的运营目标。
>
> 规格来源：`.trae/specs/coach-moments-growth/`（spec.md + tasks.md + review.md）。

---

## ⚠️ 防画饼声明（先读）

- 本系统提供的是**方法论、模板、提示词与追踪工具**，不是成交保证。文中一切成交数字（含「连续 3 个月每月 ≥2 单万元私教」）均为**运营目标/假设**，非承诺。
- 成交取决于教练自身专业度、客群质量、执行一致性与市场环境。系统只能提高"内容—信任—转化"的效率。
- AI 是**生产助手**，不是决策与发布主体：生成内容必须经人工**事实校验 + 合规自查**后方可发布。

## ⏱️ 每日用法（≤30 分钟）

1. **选题（3 分钟）**：一次决定当日 2-3 条的档位（看 [templates/content-calendar.md](templates/content-calendar.md)），或从 [docs/02-content-system.md](docs/02-content-system.md) 选题母题现取。
2. **批量生成（12 分钟）**：把当日各品类提示词（[prompts/01-five-categories.md](prompts/01-five-categories.md)）+ 素材填入 AI，一次产出 2-3 条草稿。
3. **批量校验（10 分钟）**：逐条核对事实（数据/案例/资质）→ 跑 [docs/05-compliance.md](docs/05-compliance.md) 发布前自查清单。
4. **发布（3 分钟）**：按黄金时段分时发布 2-3 条（见 [docs/03-conversion-funnel.md](docs/03-conversion-funnel.md)）。
5. **记录（2 分钟）**：在 [templates/tracking-sheet.md](templates/tracking-sheet.md) 登记当日 2-3 条的数据与互动。

## 🚫 合规红线（发布前必守）

1. 用户见证类内容**必须先取得书面授权**（模板见 [templates/testimonial-authorization.md](templates/testimonial-authorization.md)）；
2. 禁用广告法极限词与平台违规词（清单见 [docs/05-compliance.md](docs/05-compliance.md)）；
3. 不做诱导分享、不承诺收益、不虚构案例与数据；
4. 不采集/公开客户隐私信息。

## 🕐 时效声明

本文档中的平台规则、广告法与行业口径存在时效性。建议每季度复核一次合规清单（[docs/05-compliance.md](docs/05-compliance.md)）；若平台或法规发生重大变化，优先以最新官方口径为准。
