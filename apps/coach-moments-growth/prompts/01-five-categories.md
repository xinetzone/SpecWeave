# 五大品类分场景提示词（01-five-categories）

> 用法：先粘贴 [00-system.md](00-system.md) 作为系统提示，再按当日品类粘贴下方对应提示。
> `{{...}}` 为占位变量；「素材」处填入你自己的素材库条目（见 [../docs/02-content-system.md](../docs/02-content-system.md) §3）。

---

## 1. 案例拆解

```
品类：案例拆解
目标：用真实案例建立专业信任，引流到"想了解怎么做"。
素材：
- 案例背景：{{客户类型/规模/处境，脱敏}}
- 核心问题：{{他遇到的关键问题}}
- 关键动作：{{你介入后做的 1-3 个关键动作}}
- 结果：{{可公开的（脱敏）结果，需已授权}}
要求：
- 结构：钩子（一个反直觉的结果或场景）→ 问题 → 关键动作 → 结果 → 一句可迁移的洞察；
- 结果表述用"从…到…"的具体变化，禁止夸大；
- 若涉及客户隐私，自动脱敏并提示我确认授权。
```

## 2. 干货输出

```
品类：干货输出
目标：提供即时价值，展示专业深度，引流到"领取完整清单/模型"。
主题：{{如：创始人如何从救火中脱身}}
要求：
- 给出一个清晰的框架/清单（3-5 点），每点一句话讲清"怎么做"；
- 开头用一个高频痛点场景切入；
- 结尾钩子：引导评论/私信领取"完整版/模板"。
```

## 3. 用户见证

```
品类：用户见证
目标：用他人之口降低信任成本。
素材：
- 见证人：{{脱敏代号，如"某电商创始人 L"}}
- 原始评价/成果：{{对方的原话或成果，需已授权}}
要求：
- 以对方视角或引用对方原话为主，教练只做一句轻点评；
- 使用前必须确认已获授权；输出末尾提示授权状态待确认；
- 结尾钩子：引导"想了解他是怎么做到的"来私信。
```

## 4. 价值预告

```
品类：价值预告
目标：制造期待，预告一个成交场景，引流私信。
素材：{{即将推出的服务/活动/方法分享}}
要求：
- 抛出与目标客群强相关的"更大问题"，暗示你有解法；
- 不直接报价、不硬卖；
- 结尾钩子：引导私信了解详情或预约。
```

## 5. 成交场景

```
品类：成交场景
目标：明确给出成交入口（价值主张 + 服务 + 名额/时间 + 行动）。
素材：
- 服务名称/形式：{{万元私教：1 对 1 陪跑 X 周}}
- 适合谁：{{一句话筛选}}
- 交付内容：{{3-4 条交付点}}
- 门槛/名额：{{如：本期限 3 位}}
要求：
- 先讲"适合谁/不适合谁"，再讲交付，最后给明确行动（私信/预约）；
- 禁止收益承诺与极限词；用"我服务过 / 部分学员反馈"类克制表述；
- 结尾钩子清晰且唯一。
```

---

## 组合用法建议

- 每日 2-3 条典型组合：`干货/案例（早档）` + `见证/干货（午档）` + `价值预告/成交（晚档）`；
- 成交场景发布前，前 1-2 日最好有案例或见证铺垫（见 [../docs/03-conversion-funnel.md](../docs/03-conversion-funnel.md)）；
- 每条生成后走四步闭环（[../docs/02-content-system.md](../docs/02-content-system.md) §4）。
