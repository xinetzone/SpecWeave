# 五大品类文案模板（copy-templates）

> 用法：直接套用，把 `{{...}}` 替换为你的内容。每品类给了 ≥2 个模板，覆盖不同结构。
> 原则：所有模板均可被 [../prompts/01-five-categories.md](../prompts/01-five-categories.md) 的 AI 提示词生成，模板是"人工兜底"，提示词是"AI 加速"。
> 结构说明：模板遵循统一骨架 **钩子 → 冲突 → 证据 → 行动**；案例/见证类可细化为 **钩子 → 问题 → 关键动作 → 结果 → 洞察**（与 prompts/01 一致）。
> ⚠️ 强制门：用户见证 / 案例类模板中的授权声明含占位，**未取得授权并填入授权编号前，不得发布**。

---

## 1. 案例拆解

### 模板 A：结果前置型

```
{{一位脱敏客户，如"某 50 人制造企业的创始人"}}，3 个月前每天工作 14 小时，还在救火。
今天他每周只开 1 次经营会，团队自己跑了起来。

我们只做了一件事：{{关键动作，如"把'他一个人盯'变成'每人一张行动表'"}}。

结果是：{{从…到…的具体变化}}。

真正的增长，不是老板更忙，而是系统能自己转。
```

### 模板 B：转折点型

```
有个创始人问我："{{客户的原话问题}}"。

我没直接给答案，反而问了他一句：{{你的一句反问}}。

他愣住，然后说："我一直以为问题在团队。"

转折点就在那。后来 {{后续动作与结果}}。

很多卡点不在方法，在我们从没被问过那个关键问题。
```

## 2. 干货输出

### 模板 A：清单型

```
{{目标客群}}最常踩的一个坑：{{痛点场景}}。

分享我常用的 {{框架名，如"三问脱身法"}}：

1. {{要点1}}：{{一句话怎么做}}
2. {{要点2}}：{{一句话怎么做}}
3. {{要点3}}：{{一句话怎么做}}

你想先解决哪一个？评论区告诉我。
```

### 模板 B：反常识型

```
大多数 {{目标客群}}以为 {{常见做法}} 能解决问题。
其实恰恰相反——{{反常识结论}}。

原因很简单：{{一句核心逻辑}}。

{{给出一个具体可操作的建议}}。

下次你 {{场景}} 时，试试先 {{一个具体动作}}。
```

## 3. 用户见证

### 模板 A：引用型

```
{{见证人代号}} 上周发来一句话：{{原话，需授权}}。

半年前他还在 {{之前的处境}}。

说实话，我没做什么神奇的事——{{一句你做的关键动作}}。

他变了，是因为他开始 {{对方的关键转变}}。

（内容须已获本人授权，信息已脱敏；授权编号 {{授权编号}}，日期 {{授权日期}}）
```

### 模板 B：故事型

```
今天收到 {{见证人代号}} 的消息，我看了好久。

他说：{{成果/感受，需授权}}。

想起第一次见面时，他 {{最初的状态}}。
中间最难的一次，是 {{一个具体的坎}}。

陪一个创始人突破，比讲一百个道理都值。

想知道他是怎么走过来的？私信我「案例」。

（内容须已获本人授权，信息已脱敏；授权编号 {{授权编号}}，日期 {{授权日期}}）
```

## 4. 价值预告

### 模板 A：问题升级型

```
最近好几个 {{客群}} 问我同一个问题：{{更大更痛的问题}}。

我发现，大多数人卡在 {{表层问题}}，真正的原因是 {{深层问题}}。

这个问题我有一套解法，准备在本周 {{形式，如"直播/文章/私信"}} 里讲透。

想听的，私信我「{{关键词}}」。
```

### 模板 B：悬念型

```
有件事憋了好几天，今天忍不住想说。

做了 {{N}} 年 {{领域}}，我发现一个规律：{{一个有洞察的观察}}。

基于它，我整理了一份 {{交付物}}。

先不剧透，想要的私信我「{{关键词}}」。
```

## 5. 成交场景

### 模板 A：筛选型

```
我的 {{服务名，如"万元私教·90 天增长陪跑"}}，本期限 {{N}} 位。

它**适合**：
- {{适合人群1}}
- {{适合人群2}}

它**不适合**：
- {{不适合人群，如"想找速成秘诀的"}}

交付：
1. {{交付点1}}
2. {{交付点2}}
3. {{交付点3}}

我不承诺结果，但我会把我做 {{年限}} 年的方法，全部用在你身上。

想聊的，私信我「陪跑」。
```

### 模板 B：价值主张型

```
如果你正卡在 {{核心痛点}}——我想跟你聊 20 分钟。

我的学员里，有人用 {{方法}} 在 {{时限}} 内实现了 {{脱敏结果}}（已授权）。

我不卖课，我做的是 1 对 1 陪跑：{{一句你独特的方式}}。

本期留 {{N}} 个名额，私信我「{{关键词}}」预约。
```

---

## 套用注意

- 所有 `{{...}}` 必须替换，禁止留着占位符直接发；
- 涉及真实客户的信息，发布前必须确认**授权 + 脱敏**（见 [../docs/05-compliance.md](../docs/05-compliance.md)）；
- 结果类表述一律用"从…到…"的真实变化，禁止夸大与收益承诺。
