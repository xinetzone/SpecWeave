# 定位打造：IP 定位 · 客群画像 · 人设

> 本文件是内容与话术的"源头设定"。所有朋友圈内容、互动话术、成交话术都必须与本文件的定位自洽。
> 内容敏感度：面向内部运营使用；付费能力等数字均为**估计区间**，非承诺。

## 1. 个人 IP 定位

### 1.1 细分赛道（服务谁）

> 示例（可整体替换为你的真实赛道）：**创始人 / 中小企业主增长教练**——帮助 10-200 人规模企业的创始人，突破"个人能力天花板"，建立可复制的经营与增长系统。

选赛道三问（自我校准）：

1. 我服务哪一类人（行业 × 阶段 × 规模）？
2. 他们最贵、最痛的"一个"问题是什么？
3. 为什么是我（别人做不到/做不好的那一点）？

### 1.2 差异化价值主张（一句话）

结构：**帮（谁）在（时限）内获得（可感知结果），而不靠（客户不想要的代价）**。

示例：

> 帮创始人在 90 天内把"事事亲力亲为"变成"有一套能带人的经营系统"，不再靠加班和救火维持增长。
>
> ⚠️ 效果表述为目标/方向，非承诺（合规要求，见 [05-compliance.md](05-compliance.md)）。

自检：是否同时含 **对象 + 时限 + 结果** 三要素？是否避免了空泛形容词（"赋能""打造""提升"）？

### 1.3 人设关键词（3-5 个）

> 示例：**实战派 · 结构化 · 敢说真话 · 结果导向 · 长期主义**

人设设计原则：

- **专业可信导向**：以"证据 + 方法论"支撑，而非包装头衔；
- **可辨识**：观点 / 语言风格 / 表达格式（如固定"三问式""反常识开场"）形成记忆点；
- **可持续**：人设是你真人可长期维持的样子，不是表演。

### 1.4 专业可信证明体系（四要素）

| 要素 | 说明 | 在朋友圈的呈现方式 |
|---|---|---|
| 资质 | 认证/经验/服务年限 | 偶尔自然带出，不刷简历 |
| 案例 | 服务过的典型客户与结果（脱敏、经授权） | 案例拆解品类主供 |
| 方法论 | 你独有的分析框架/工具 | 干货输出品类主供 |
| 内容一致性 | 长期稳定输出同一价值观与判断 | 全品类统一语气与立场 |

## 2. 目标客群画像

> 三类高净值客群差异显著，须分层触达（分层策略见 [03-conversion-funnel.md](03-conversion-funnel.md)）。

### 2.1 企业创始人

| 维度 | 描述 |
|---|---|
| 典型处境 | 公司 10-200 人，增长遇到"人、钱、事"三重瓶颈，自己是最忙的人 |
| 核心痛点 | ① 团队带不动，事事亲力亲为；② 战略清晰但落不了地；③ 孤独，缺可对话的同频者 |
| 显性需求 | 增长方案、组织与人才、决策陪跑 |
| 隐性需求 | 被理解、被挑战、有一个安全的"真话空间" |
| 决策链 | 多为个人决策（自掏腰包或公司预算皆可能），决策快但要求高 |
| 付费能力（估计） | 高；客单价区间（估计示例）约 ¥10,000–¥30,000/期；对"能带来明确经营回报"的方案付费意愿强，价格敏感度低 |
| 触达要点 | 讲"系统/杠杆/脱离救火"，忌鸡汤；用同规模案例建立可信 |

### 2.2 个体创业者

| 维度 | 描述 |
|---|---|
| 典型处境 | 一人公司或小团队，靠个人能力变现，收入波动、时间被榨干 |
| 核心痛点 | ① 收入不稳定，不敢涨价；② 个人即产品，规模化难；③ 定位模糊、客户不精准 |
| 显性需求 | 定位、获客、定价、可复制的变现路径 |
| 隐性需求 | 确定性、安全感、被"看见"与鼓励 |
| 决策链 | 个人决策为主，价格相对敏感，重"投入产出" |
| 付费能力（估计） | 中高；客单价区间（估计示例）约 ¥5,000–¥15,000/期；愿为"能立刻用上"的方法付费，需要更强的价值证明 |
| 触达要点 | 讲"从 0 到 1 的具体动作/避坑"，用真实、可验证的小结果建立信任 |

### 2.3 企业高管

| 维度 | 描述 |
|---|---|
| 典型处境 | 大公司中高层，专业强但向上/跨部门推动难，职业天花板与转型焦虑 |
| 核心痛点 | ① 影响力受限，推不动事；② 职业路径不确定（升职 or 转型）；③ 时间碎片化 |
| 显性需求 | 领导力、跨部门影响、职业跃迁 |
| 隐性需求 | 职业安全感、被同行认可、"更进一步的路径" |
| 决策链 | 个人为主，但受公司文化/报销政策影响；决策审慎 |
| 付费能力（估计） | 中高；客单价区间（估计示例）约 ¥8,000–¥20,000/期；愿为"身份跃迁/能力认证"付费，看重专业背书 |
| 触达要点 | 讲"可迁移的方法论 + 高势能人脉"，用框架与洞察建立专业感 |

## 3. 人设一致性自检（每季度一次）

- [ ] 近 30 天内容是否稳定传递同一价值主张？
- [ ] 是否至少每 5 条内容出现一次"专业证据"（案例/数据/方法论）？
- [ ] 语气是否统一（语调、格式、立场）？
- [ ] 客群是否聚焦（是否误伤/混杂了不服务的人群）？
