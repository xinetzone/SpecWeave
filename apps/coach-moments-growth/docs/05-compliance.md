# 合规保障：自查清单 · 禁用词 · 授权流程

> 目的：在满足平台规范与《广告法》前提下做商业推广，避免封号、投诉与法律风险。
> 时效：以下清单基于现行常识性规范整理，**建议每季度复核**；以最新官方口径为准。
> ⚠️ 本文件为运营自查参考，不构成法律意见；重大推广前建议咨询专业法务。

## 1. 发布前固定自查清单（每条必过）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 真实性 | 所有案例、数据、资质真实可追溯，无虚构/夸大 |
| 2 | 极限词 | 无《广告法》禁用极限词（见 §2） |
| 3 | 收益承诺 | 无"保证成交/包赚/稳赚/必成"等承诺性表述；效果一律表述为目标或"部分学员反馈" |
| 4 | 诱导分享 | 无"集赞/转发领奖/不转不是…"等诱导分享话术 |
| 5 | 导流合规 | 加微/引流话术不违规（不诱导、不群发骚扰、不虚假福利） |
| 6 | 用户见证 | 见证内容均已有**书面授权**（见 §3），且已脱敏 |
| 7 | 隐私 | 无客户真实姓名/公司/联系方式/成交金额等 PII（除授权且必要外） |
| 8 | 对比贬低 | 不贬低同业、不做无依据的"最好/第一"比较 |
| 9 | 效果/能力保证 | 无对培训/服务效果的明示或暗示保证性承诺（《广告法》第 24 条，见 §6） |

> 未过第 6 项（见证授权）与第 3 项（收益承诺）的内容，一律不得发布。

## 2. 禁用词 / 敏感表述表（含替换建议）

> 中国《广告法》第九条禁止使用"国家级""最高级""最佳"等用语；广告不得含有虚假或引人误解的内容。以下为常见高风险词类，发布前对照替换。

| 类型 | 高风险词（示例） | 替换建议 |
|---|---|---|
| 极限用语 | 最好、第一、顶级、绝对、唯一、独家、史上最强 | "许多学员反馈""在我服务过的案例中""我常用的方法之一" |
| 收益承诺 | 保证、包赚、稳赚、必成、月入过万、躺赚 | "目标""有机会""部分学员已实现……（需授权+脱敏）" |
| 权威背书 | 国家级、权威认证、官方指定、专家推荐（无凭证） | 如实写"XX 认证""XX 年限经验" |
| 时效绝对 | 永久、100% 有效、无风险、零失败 | "在多数情况下""通常""需结合个人情况" |
| 医疗/功效 | 治愈、疗效、包治（若涉及身心健康话题） | 避免医疗化表述，改述为"成长/状态调整" |
| 诱导 | 转发抽奖、集赞、不转不是中国人 | 删除，改为内容价值驱动的自然互动 |
| 效果/能力保证 | 包学会、保证见效、X 天必成（培训/服务效果类） | "目标""部分学员反馈""通常需结合个人情况" |

> 平台（微信/朋友圈）另有各自的社区规范与营销限制，重点关注：诱导分享、频繁营销、虚假宣传、外链风险。

## 3. 用户见证授权流程

1. **取得联系**：在与见证人沟通时说明用途（用于朋友圈/宣传），征得口头同意后发授权模板；
2. **签署授权**：使用 [templates/testimonial-authorization.md](../templates/testimonial-authorization.md)，至少取得电子确认（聊天记录明确同意）或书面签署；
3. **脱敏处理**：默认隐去公司全称、联系方式、敏感数字；如需展示实名/公司，须在授权书中单独勾选同意；
4. **留存证据**：授权记录与发布内容一并留痕（见 §4）；
5. **尊重撤回**：见证人可随时撤回授权，撤回后须在合理期限内撤下相关内容。

## 4. 合规留痕要求

建立一份轻量台账（可并入 [templates/tracking-sheet.md](../templates/tracking-sheet.md) 备注列，或单独存放）：

| 字段 | 说明 |
|---|---|
| 见证人（代号） | 脱敏代号即可 |
| 授权状态 | 已授权 / 未授权 / 已撤回 |
| 授权日期 | 取得授权的时间 |
| 使用内容 | 对应朋友圈内容标识 |
| 撤回记录 | 若有，记录撤回时间与处置 |

> ⚠️ 隐私隔离：含 PII（姓名/联系方式等）的授权原件与台账**不得提交代码仓库**，请置于仓库外或加入 `.gitignore`。

## 5. 风险分级与处置

| 风险等级 | 示例 | 处置 |
|---|---|---|
| 高（禁止发布） | 收益承诺、无授权见证、虚假数据 | 立即整改，不得发布 |
| 中（需改写） | 极限词、无依据比较 | 按替换建议改写后再发布 |
| 低（可发布） | 语气过强、表述可更客观 | 尽量优化，不影响发布 |
