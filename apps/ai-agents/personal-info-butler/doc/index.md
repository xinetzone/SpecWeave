## 解决什么

| 痛点 | 做法 |
|---|---|
| 想法、资料、待办混在一起 | 录入即判定类型，并生成标题、摘要、标签 |
| 记完就忘、彼此孤立 | 自动计算与已有条目的关联度，写入关联关系并给出理由 |
| 想不起记在哪 | 关键词检索（中文二元组 + 英文词元混合打分）+ 智能问答（带引用） |
| 一堆记录看不过来 | 重点信息提取 + 待办整理（去重、分组、优先级） |
| 不知道这段时间干了啥 | 阶段总结：概览 → 主题分布 → 进展 → 风险 → 后续行动建议 |

## 它是怎么拼起来的

```{mermaid}
flowchart LR
    UI["Sphinx 静态站<br/>GitHub Pages"] -->|"HTTPS /api/*"| API["Python 3.14 FastAPI<br/>云端常驻"]
    API -->|"PostgREST"| DB[("Supabase<br/>PostgreSQL")]
    API -->|"OpenAI 兼容协议"| LLM[("大模型<br/>可 BYOK")]
```

- **前端**：Sphinx + MyST 构建的静态站（本页所在站点），零框架、零打包；
- **后端**：Python 3.14 + FastAPI，负责归类、关联、检索、问答、总结；
- **存储**：Supabase / PostgreSQL，未配置时自动退回内存存储；
- **大模型**：任何 OpenAI 兼容端点，支持页面 BYOK（凭据只留在本机浏览器）。
