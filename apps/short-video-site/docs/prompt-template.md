# AI 全栈短视频网站开发提示词模板

> 本模板从 ReelVibe 短视频网站开发实践中萃取，可直接复制使用，替换括号中的变量即可。

## 使用说明

1. 将 `[项目名称]` 替换为你的项目名称
2. 将 `[参考截图路径]` 替换为你上传的设计参考图
3. 根据需要增减素材主题和功能模块
4. 确保 AI 工具已安装生图、生视频、联网搜索等 Skill/插件

---

## 完整提示词

```
请帮我实现一个短视频网站项目，项目名称为 [项目名称]：

## 1. 功能调研
- 使用联网搜索 Skill 调研主流短视频平台（抖音、TikTok、快手、B站）的 Web 端设计
- 总结关键功能：导航结构、视频播放器、推荐算法UI、互动功能、分类体系
- 输出一份功能清单，标注必做功能和可选功能

## 2. 页面设计
- 网页风格：简洁时尚，深色主题
- 布局参考：[参考截图路径]（如未提供则参考抖音 Web 端三栏布局）
- 页面结构要求：
  - 左侧固定导航栏（Logo、首页、推荐、关注、我的、直播等）
  - 顶部搜索栏（居中搜索框 + 右侧用户操作）
  - 分类标签栏（全部、美食、旅行、美妆、知识等可横滑）
  - 主内容区：大视频播放器（16:9）+ 右侧推荐视频列表
  - 底部：视频卡片网格（缩略图 + 标题 + 作者 + 播放量）
- 视频播放器功能：播放/暂停、进度条、音量控制、全屏、字幕
- 互动按钮：点赞、评论、收藏、分享
- 响应式适配：桌面端三栏，平板两栏，移动端单栏

## 3. 素材生成
- 调用生图 Skill 绘制网站 Logo：
  - 风格：现代简约，渐变色（粉色到青色）
  - 元素：播放按钮 + 胶片/字母组合
  - 尺寸：正方形 1024x1024
  - 背景：深色
- 调用生视频 Skill 生成首页视频素材（每个 5 秒，9:16 竖屏）：
  - 视频1主题：[自然风光] - 描述：航拍金色山峦、云雾缭绕
  - 视频2主题：[美食推荐] - 描述：特写美食制作过程
  - 视频3主题：[美妆护肤] - 描述：护肤品展示与使用场景
  - （可按需增减视频主题）

## 4. 技术要求
- 纯 HTML + CSS + JavaScript，不依赖框架
- 使用 CSS 变量管理主题色
- 使用 Google Material Icons 图标
- 代码结构清晰，分文件组织（index.html / css/style.css / js/app.js）
- 视频数据用 JS 对象数组管理，方便后续扩展
- 支持键盘快捷键（空格播放、方向键切换、M静音、F全屏）
- 图片/视频加载失败时有渐变占位 fallback

## 5. 交付要求
- 在 apps/[项目文件夹名]/ 下创建完整项目
- 包含 README.md 说明文档
- 启动本地 HTTP 服务器预览
- 输出功能清单和使用说明
```

## 最佳实践

1. **先传截图再描述**：一张参考图胜过千言万语
2. **素材主题要具体**：不要只写"生成风景视频"，要写"航拍金色山峦、云雾缭绕、暖光"
3. **分步确认**：先确认功能清单，再确认设计，最后生成代码
4. **预留素材轮次**：视频生成通常每轮只能生成 1 条，多视频需要多轮对话
5. **零依赖优先**：Demo 阶段用纯 HTML/CSS/JS，不引入构建工具
6. **指定文件结构**：明确告诉 AI 文件组织方式，避免单文件巨石

## 反模式

- ❌ "做一个像抖音一样的网站"（太模糊，没有具体需求）
- ❌ 不提供参考截图，只靠文字描述布局
- ❌ 一次要求生成 10 条视频（会被 API 限制）
- ❌ 不指定技术栈，让 AI 自由选择（可能引入过重框架）
- ❌ 素材主题过于宽泛（"好看的视频"无法生成有效内容）
