# Skill 导航台

> 秒悟应用赏金广场赏金 **IDEA · 026**「帮新手快速找到最合适的 Skill，并直接体验结果」的交付物。

**线上地址**：<https://yzv5eq2kp2uc.meoo.run>（Meoo CDN 静态部署，项目「Skill 导航台」，URL ID `yzv5eq2kp2uc`，发布版本 v2 active，2026-10-18）

第一次用 Meoo 的人不用翻完整页技能市场：点一下自己现在的处境（或用自己的话说一句），
页面在 3 秒内给出 **1–2 个最对得上的技能**，讲清它到底能帮你做什么、什么时候不该用它，
并**先给你看一眼结果长什么样**，再决定要不要用。

## 它解决什么

平台技能市场是「平铺目录」：条目多、只有分类和一句话简介，新用户缺一个「从我的问题反推该用哪个」的入口。
本页补的就是这一段——把「目录」翻译成 **问题 → 技能 → 结果** 三跳路径。

## 页面结构

| 区域 | 内容 |
|---|---|
| 入口 | 14 张痛点卡（两组：我想做点什么 / 我卡在哪一步）+ 一句话自由输入 |
| 结果 | 1–2 张技能卡：技能名、作者、累计使用量、它能帮你解决什么、命中依据、主按钮「先看看结果」 |
| 演示 | 页内面板三段式：你大概会这样输入 / 它会怎么做 / 你会拿到什么（**示意演示，非真实运行结果**） |
| 兜底 | 「都不太对」→ 该处境下全部候选，按对得上的程度排序 + 技能市场直达 |
| 页脚 | 数据来源与快照日期、官方口径与本页整理的区分、本页不做的事 |

## 本地运行

```bash
mise trust --yes ./mise.toml
mise install
mise run dev            # → http://127.0.0.1:3015/
```

## 部署到 Meoo

```bash
cd apps/samples/skill-navigator
meoo projects create "Skill 导航台"
meoo deploy
```

静态模式：`[meoo.deploy] mode = "static"`、`output = "site"`，发布到 Meoo CDN。
协议校验：`node .agents/skills/meoo-cli/scripts/validate-mise-protocol.cjs ./mise.toml`。

- **官方口径**：技能名称、作者、累计使用量、「官方简介原文」逐字来自平台页面。
- **本页整理**：「它能帮你解决什么」「适合谁」「什么时候不该用它」「它会怎么做」「你会拿到什么」由本页从该条目的公开简介整理而来，**不是技能作者的承诺**。
- **演示为示意**：静态页无法真实运行 Skill，演示面板用示例数据展示结果形态，面板内与页脚均有显著标识。

## 设计取舍（为什么不接大模型）

赏金原文写的是「智能推荐」。本页实现为 **策展首选 + 标签加权命中 + 使用量决胜**，理由：

1. 受众痛点域是有限集合，策展映射的准确率不低于通用模型猜测，且**命中依据可回显、可审计**；
2. 静态部署不携带 `MEOO_PROJECT_API_KEY`，接大模型需走 Edge Function 并消耗额度；
3. 零网络请求 → 断网可用、无延迟、无埋点。

数据层独立成 `data.js`，若后续要接模型或换数据源，视图层无需重写。

## 本页不做的事

不评测、不背书任何技能或创作者；**页面先后顺序只表示「与你这句描述的匹配程度」**（按命中你所述要点的数量算，
同分时参考平台使用量），**不代表质量、口碑或收益的排名**；不承诺收益；不收集输入、不做埋点。

**关于网络请求**：本页**源码自身**不发起任何网络请求（无 fetch/XHR、无外链字体与图片，断网可用）。
部署到 Meoo 后，托管方会在返回的 HTML 中注入平台自带的安全脚本（`g.alicdn.com` 上的 baxia）与 Meoo logo 图片——
那是托管方行为，不在本页代码内（实测公网首页含这 2 个外部引用）。

## 已知边界

- **无逐条详情页链接**：技能市场列表页的卡片外层无 `<a>` 标签，原始 HTML 中也无 `/skills/<数字ID>`，因此无法生成到单个技能的直达链接；结果卡的出口是技能市场首页。
- **数据为快照**：条目与使用量取自 2026-10-18 的快照。使用量是**实时变动的计数**，独立复核（同日稍晚）已观察到 3 条比快照多 1–2 次（前端设计SKILL 3765→3766、玻璃拟态UI 2477→2479、高级UI/UX 37115→37116）；页面与页脚均声明以来源页实时显示为准。
- **同主题不同署名的条目各自登记**：市场页与共创计划页存在同主题但署名不同的条目，本页不判同一性、不合并。
