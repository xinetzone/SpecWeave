01 原始色阶 Primitives

与主题无关的静态色板。Light / Dark 两个 Mode 取值一致；语义色一律从这里取值，业务层禁止直接引用。

02 语义色 Semantic Colors

组件唯一允许引用的颜色层。同名变量在 Light / Dark 两个 Mode 下取不同值，切换节点或页面的 Mode 即可整体换肤。

LIGHT 模式 · 27 个语义变量

DARK 模式 · 27 个语义变量（与上方 Light 面板完全同名、同结构，仅 Mode 不同）

03 圆角 Radius

8 级圆角，双主题取值一致。inset 按 card 尺寸约束，卡片圆角不小于「内容圆角 + 内边距」的一半。

04 阴影 Elevation / Shadow

5 级高度。暗色下整体失焦变虚，所以 Dark 模式统一切换为纯黑并提高不透明度，避免阴影「消失」。

LIGHT · shadow-N-color = #0E1218 @ 5%–16%
DARK · shadow-N-color = #000000 @ 30%–60%

05 明暗主题切换验证 Component Preview

左右两块 UI 结构完全一致、变量名完全一致；右侧只是把 Semantic 集合切到 Dark Mode，全部颜色自动换肤，没有改过任何一个节点属性。
