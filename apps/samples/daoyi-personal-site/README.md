# 道一 daoyi · 个人站

> 三线并行的个人品牌站：**AI 工程**（SpecWeave 多智能体协作规范）、**知识工程**（OKF 可溯源知识包）、**内容创作**（公开内容 → 知识资产流水线）。
>
> 纯静态零构建站点：HTML + CSS + 原生 JS + 自绘 SVG 插图，无外部依赖、无 CDN、无字体外链，断网可完整运行。

## 一、定位

`apps/samples/` 下的示例/原型类应用。目录本身即部署单元：根目录 `index.html` 为入口，`assets/` 存放样式、脚本与插图，可直接作为静态站点发布。

## 二、目录结构

```
apps/samples/daoyi-personal-site/
├── index.html            -- 单页入口（语义化结构 + 内联无障碍标注）
├── assets/
│   ├── styles.css        -- 设计系统：色板 / 排版 / 栅格 / 动效 token
│   ├── app.js            -- 一次性滚动揭示 + 导航分隔线（无循环动效）
│   └── img/              -- 10 张自绘 SVG 插图（无第三方素材）
└── README.md
```

## 四、设计系统

| 维度 | 取值 |
|---|---|
| 底色 | 纸感暖白 `#e9e7e1` + 卡片 `#f7f6f2` |
| 文字 | 深墨 `#14161a` / 次级 `#2a2e35` / 弱化 `#6b7078` |
| 三线主色 | AI 工程 靛蓝 `#2b45d8` · 知识工程 墨绿 `#1f6f6b` · 内容创作 藏红 `#efb03f` |
| 深色区 | `#0b0c0b`，行分隔用 `rgba(240,238,229,.15)` |
| 字体 | 系统栈（Segoe UI / PingFang SC / Microsoft YaHei），中文不外链字库；数字与标签用等宽栈 |
| 圆角 | 卡片 14px / 控件 9px / 胶囊 999px |
| 纸面颗粒 | 内联 SVG feTurbulence 噪点，3.5% 不透明度，固定全屏 |

**动效约束**：仅保留「轻微悬停反馈」（位移 ≤3px、边框与阴影 170–230ms 过渡）与「一次性淡入上移」（IntersectionObserver 触发后即停止观察，640ms，带 60–210ms 阶梯延迟）。无循环动画、无视差、无自动播放、无跟随光标。`prefers-reduced-motion: reduce` 下全部动效降级为瞬时。

## 六、发布

```bash
# 本地预览（任意静态服务器均可）
python -m http.server 8731 --bind 127.0.0.1 --directory apps/samples/daoyi-personal-site
```

发布时以本目录为部署根（根目录含 `index.html`，资源均为相对路径），由 `website_deploy` 打包为公开静态站点。

## 七、维护说明

- 插图全部为手写 SVG，主题色跟随 `--indigo` / `--teal` / `--saffron`；修改配色时优先改 `assets/styles.css` 的 `:root` 变量。
- 新增项目：复制 `index.html` 中任一 `.work-row` 结构，替换 `work-info` 文案与 `.stage` 内的 `<img>`。
- 滚动揭示依赖 `data-reveal` 属性与 `assets/app.js` 中的 IntersectionObserver；新增区块加 `data-reveal` 即可获得一次性淡入。
- 无第三方依赖、无构建步骤、无密钥；发布前无需额外脱敏处理。
