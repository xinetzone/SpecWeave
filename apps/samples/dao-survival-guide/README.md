# 大道极简生存指南（七条判据）

将知识包「04 · 大道极简生存指南」实现为可交互的判牍式应用：七条判据逐条当场回答是 / 否 / 说不清，每条盖印裁定；全部判完后生成一份「判状」——按诊断层 / 能力层 / 行动版分层统计，未过的条目直接给出 5 分钟可完成的最小动作。

## 运行

零构建，直接打开 `index.html` 即可（或部署到任意静态托管）。

## 结构

- `index.html` — 唯一入口（序 / 判 / 状 / 表 四个视图，hash 路由）
- `styles.css` — 宣纸 · 墨 · 朱砂印视觉体系
- `app.js` — 判据数据（源自原文）与盖印交互、判状计算

## 内容保真

所有判据、反例、动作与分层结构均逐字取自源知识包原文，未增删；判定逻辑（诊断在前、能力在后、顺序不可颠倒）同样来自原文「内在结构」一节。

## 边界

本应用不含医疗 / 心理 / 法律 / 财税 / 投资建议；临床心理健康问题请转专业干预。
