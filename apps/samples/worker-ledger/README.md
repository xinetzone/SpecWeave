# 打工人小账本 · Worker Ledger

> 离线个人工作台（零构建单文件 Demo）：把每一笔花销换算成「你要为它工作多久」，用真实时薪、月度总结、自由基金与情景模拟，回答一个问题——**这笔钱值不值**。

## 一、定位

`apps/samples/` 下的示例/原型类应用。**单个 `index.html` 文件**，HTML/CSS/JS 全内联，不依赖 CDN、后端或任何在线图表库，双击即可运行。数据保存在浏览器 `localStorage`，支持 JSON 导入导出。

## 二、目录结构

```
apps/samples/worker-ledger/
├── index.html    -- 全部内容（内联 <style> + <script> + 内联 SVG 图标库/插画）
└── README.md     -- 本文件
```

## 三、功能模块

| 模块 | 说明 |
|---|---|
| **真实时薪计算器** | 分子 =（到手月薪 × 发薪月数 ÷ 12）− 工作成本（通勤/餐费/咖啡/通勤行头/其他）；分母 = 在场 + 加班 + 通勤 + 待命。页面内**逐行展开公式**，并给出名义时薪对照与缩水率 |
| **10 秒记账** | 首页快捷条（金额 + 分类 chip + 保存）与「记一笔」完整版（金额/分类/日期/固定弹性/备注）。输入金额即**实时**换算工时，保存后 toast 提示「≈ 你 42 分钟的工作」 |
| **首页最近 4 笔** | 倒序展示，每条附分类色点、金额与工时换算，可直接删除 |
| **月度总结** | 月份前后翻页；到手收入 / 固定支出 / 弹性支出 / 结余四卡 + 分类占比条 + 本月明细 |
| **自由基金** | 目标金额与进度、安全垫按「能撑几个月」表达（建议 ≥6 个月）、预计达成年月；小猪存钱罐随进度注水 |
| **存款曲线** | 原生 SVG 手绘：渐变面积 + Catmull-Rom 平滑曲线 + 目标虚线 + 网格刻度，支持鼠标悬停/触摸查看每月数值 |
| **情景模拟** | 通勤变化 / 每周加班 / 涨薪幅度三滑块，实时联动真实时薪、年占用小时、自由达成月数、月可支配 |
| **数据管理** | 导出 JSON、导入 JSON（结构校验 + 字段净化）、四档清理（仅示例 / 仅账目 / 仅存款点 / 恢复出厂）、存储状态与体积 |

## 四、真实时薪公式

```
月可支配 = 到手月薪 × 发薪月数 ÷ 12 − 工作成本合计
月占用   = 工作日 × 每天在场小时
         + 每周加班 × 4.345
         + 工作日 × 每日通勤分钟 ÷ 60
         + 每周待命 × 4.345
真实时薪 = 月可支配 ÷ 月占用
名义时薪 = 月到手收入 ÷（工作日 × 8）      ← 仅作对照，不参与换算
```

> 通勤与待命是否计入由使用者决定：把对应数值改成 `0` 即相当于不计。公式页会列出每一项的独立贡献，不做隐藏加权。

## 五、设计要点

- **奶油薄荷手账风**：奶油底 + 薄荷点阵纸纹、虚线分隔、胶带贴纸装饰、楷体标题；CSS 变量统一定义于 `:root`。
- **统一内联 SVG**：`<symbol>` 图标库（24 网格 / 1.8 描边，32 个 symbol）经 `<use>` 复用；两处小猪存钱罐插画（首页 / 自由基金）均为手写 SVG，含落币动画并遵循 `prefers-reduced-motion`。
- **响应式**：桌面 238px 侧栏；移动端（≤900px）切换为底部 6 格 Tab，含 `env(safe-area-inset-bottom)` 安全区。所有按钮 ≥44px、输入 `font-size:16px` 防 iOS 缩放。
- **安全**：所有用户可控文本经 `esc()` 转义后渲染；导入 JSON 逐字段净化并丢弃非法项；除法均有正值守卫。

## 六、演示数据

首次打开会生成一套**相对当前日期**的演示数据：最近 12 个月存款点 + 近 30 天内 21 笔账目，全部带 `demo: true` 标记，页面顶部显示醒目横幅。

- 「清除示例」只删除带标记的数据，不会碰到自己录入的记录；
- 「恢复出厂」重置设置并重新载入一套新示例。
