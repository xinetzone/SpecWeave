# 一页生活 · 集成式生活工作台（life-workbench）

面向泛生活人群的本地生活工作台：**一个 `index.html` 文件，双击即用**。全部 CSS、JavaScript、图标与演示数据内联，不依赖任何外部组件、字体、图标库或网络请求。

## 快速开始

1. 直接双击打开 `index.html`（或用任意静态服务器托管后访问）。
2. 首次打开会载入少量演示数据，可在「设置 → 清空演示数据」一键清掉。
3. 所有输入即时保存，关闭页面后重新打开数据仍在。

## 包含模块

| 模块 | 能力 |
|------|------|
| 今日 | 生活节奏综合指数（预算健康 / 习惯完成 / 日程完成 / 运动记录加权）、今日焦点清单、今日习惯与本月收支速览 |
| 记账理财 | 收支记录、月预算、月度对比、月份/类型/分类筛选、消费结构、Excel 导出（CSV） |
| 习惯健康 | 自定义习惯，勾选 / 计数 / 数值三种打卡方式、目标与单位、最近 30 天热力图 |
| 减脂健身 | 体重体脂日志、BMI、目标进度、热量缺口、7 日均线趋势图（内联 SVG）、周一至周日可编辑训练计划 |
| 日程统筹 | 新增/完成/删除，今天 / 未来 / 逾期 / 全部筛选，可按具体日期查看 |
| 待买清单 | 数量、预估单价、优先级、分类，未买/已买/全部筛选，未买数量与预估总额 |
| 书影音收藏 | 书/电影/剧集/音乐/播客，状态、星级、短评、本地色块封面墙（可直接删除）与列表切换、年度统计 |

## 数据与备份

- 数据存放在**当前浏览器**的 `localStorage`（主存储 `life-workbench:state:v1`，另维护最近一次可解析的安全快照）。
- 「导出备份」生成全量 JSON（含 schema 版本与导出时间）；「导入备份」支持**合并追加**与**整体替换**两种模式，**不设人工条数上限**（实际规模受设备内存与浏览器存储配额约束）。
  - 合并：保留当前设置，逐条追加记录；`id` 冲突时自动生成新 `id`（同名习惯会被保留为两条，需要手动删除其中一条）；合并不会重置「未备份新增」计数。
  - 替换：完全覆盖现有全部数据。
  - 导入时对每条记录做字段与类型校验（日期/枚举/数值/颜色白名单），非法字段会被收敛为安全默认值，不会因脏数据导致模块无法渲染。
- 今日生活指数权重：预算健康 30% · 习惯完成 30% · 日程完成 20% · 运动记录 20%；缺失维度不参与计算，按剩余项归一化。
- 每新增满 20 条记录会提醒导出备份；导出后计数清零。
- 存储写入失败（配额已满 / 隐私模式）时显示明确错误并提供**紧急导出**，不会伪装成保存成功。
- 主数据解析失败时弹出恢复对话框：可从安全快照恢复、下载损坏原始内容，或重置为演示数据。
- 清理浏览器数据、更换浏览器或设备都会导致数据丢失，请定期导出 JSON 备份。

## 关于 Excel 导出

「导出 Excel(CSV)」生成**带 BOM 的 UTF-8 CSV**（`\r\n` 换行、字段双引号转义），Excel 双击即可打开且中文不乱码；文件按当前月份与筛选条件命名，末尾附收入/支出/结余合计行。不引入任何第三方 Excel 库。

## 工程说明（零构建豁免）

本应用为**零构建单文件应用**：无 `package.json`、无 `src/`、无 `tests/`，依赖声明与测试目录要求不适用（与 `samples/maitian-bakehouse`、`samples/worker-ledger`、`samples/study-goal-hub` 一致）。

- 运行资源：`index.html`（自包含）。
- 运行时依赖：无。仅在浏览器中运行标准 API（DOM、`localStorage`、`Blob`、`FileReader`、SVG）。
- 交付验证：静态扫描无外链；无头浏览器冒烟覆盖七个模块主路径 + Excel 导出 + 不限量导入 + 脏数据导入 + 20 条备份提醒 + 存储失败 + 数据损坏恢复（44 条断言全绿）；360px 与 1440px 双视口七模块无横向溢出（30 条断言全绿）。
- 规格与验收：`.trae/specs/life-workbench/`（spec.md / tasks.md / review.md）。

## 已知边界

- 单用户、单浏览器，无账号、无云同步、无服务端。
- 生活指数、BMI、热量缺口均为个人记录参考，不构成医疗或财务建议。
- 数据规模受浏览器 `localStorage` 配额（通常约 5–10 MB）限制。
