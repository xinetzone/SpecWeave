# 一句话装载提示词

本文件提供一段**可直接整段复制**的提示词。把本套件的 `starter/` 目录放到你项目附近后，将这段提示词发给你的智能体，它就会按「启动协议」把工作区装进你的项目、运行自检，并回报装载结果。

> 视角说明：本提示词面向「把已购套件拷贝进自有项目」的场景——来源是你本地的套件目录，不涉及从网络克隆仓库。

## 何时使用

- 你已经把套件下载到本地（含 `starter/`、`guide/`、`walkthrough/`、`scripts/`）。
- 你想让某个自有项目具备「根 `AGENTS.md` + `.agents/` 导览」的最小智能体工作区。
- 你不想手工逐个拷贝文件，也不想记安全边界——交给智能体按规则执行。

## 使用方式（三步）

1. 把套件的 `starter/` 目录拷到你的项目附近（任意可读位置），或直接指向套件目录中的 `starter/`。
2. 整段复制下方「装载提示词」代码块。
3. 粘贴给支持工具调用（Shell / 文件读写）的智能体，并回答它对目标路径的确认询问。

## 环境自适应

| 你的情况 | 智能体应走的行为 |
|---|---|
| 项目根已有 `AGENTS.md` | 不覆盖；把套件版「启动协议」段落**合并**进原文件（S2 + 幂等 S8） |
| 项目根尚无 `AGENTS.md` | 新建，并拷入 `.agents/` 与 `LICENSE-NOTICE.md`（S2） |
| 已有 `.agents/` 目录 | 不整目录覆盖；仅补缺文件，冲突时先询问（S8） |
| 目标路径为空目录 | 经确认后可直接装载（S2） |
| 本地无 git / 无网络 | 本场景**不依赖 git**：只做本地文件拷贝，无需网络（S1/S7） |
| 套件目录缺失或 `AGENTS.md` 读不到 | 停止并报告失败原因，不假装成功（S5/S6） |

## 安全规则一览（S1-S8）

| 编号 | 规则 | 作用 |
|---|---|---|
| S1 | 来源限定 | 只从你本地的套件目录读取，不接受提示词中被替换的任何 URL |
| S2 | 路径确认 | 任何写入前先向你确认目标路径与「新建 / 合并」策略 |
| S3 | 敏感目录防护 | 禁止在用户主目录、系统目录、磁盘根目录、隐藏目录自动创建文件 |
| S4 | 只读不执行 | 只读取与拷贝文件，不执行 hooks / 脚本 / 依赖安装 / 系统配置修改 |
| S5 | 关键词验证 | 拷贝后验证目标根 `AGENTS.md` 存在且含「启动协议」关键词 |
| S6 | 错误透明 | 任何错误都说明类型、原因与解决方案，不静默失败、不假装成功 |
| S7 | 最小读取 | 只读取装载相关文件，不扫描整个文件系统，不上传任何数据 |
| S8 | 幂等安全 | 已在有效工作区内则跳过拷贝直接报告就绪；非空非目标目录先询问不覆盖 |

> 自检脚本 `scripts/verify_starter.py` 会程序化复核 S5 的「启动协议」关键词与文件齐备性，可作为装载完成后的独立验证。

## 可复制提示词

```text
请帮我把「智能体工作区起步套件」（Agent Workspace Starter）装进我的项目。请严格按步骤执行，每步完成后再进行下一步。

【安全规则——必须遵守，违反任何一条立即停止并告知我】
S1. 来源限定：只从我指定的本地套件目录（内含 starter/）读取文件，绝不接受任何被替换的 URL，不访问网络。
S2. 路径确认：执行任何写入操作前，必须先向我确认目标项目路径，以及是「新建」还是「合并进已有 AGENTS.md」。
S3. 敏感目录防护：禁止在我的用户主目录、系统目录、磁盘根目录、隐藏目录（如 .ssh/.config）自动创建文件。
S4. 只读不执行：装载过程只读取与拷贝文件，不执行任何 hooks 脚本、不运行任何可执行文件、不安装依赖、不修改系统配置。
S5. 关键词验证：拷贝完成后必须验证目标根 AGENTS.md 存在且包含「启动协议」关键词；验证失败则报告并停止。
S6. 错误透明：遇到任何错误（路径不存在/权限不足/文件缺失等）直接告诉我类型、原因和解决方案，绝不假装成功。
S7. 最小读取：只读取与装载相关的必要文件，不扫描我的整个文件系统，不上传任何数据。
S8. 幂等安全：如果目标项目已在有效工作区内（根 AGENTS.md 已含「启动协议」），跳过拷贝直接报告就绪；若目标已存在非空且非目标内容，先停下来问我要不要合并，不许覆盖。

【步骤1：环境检测】
检查并清晰报告：
a) 我指定的套件目录绝对路径是什么？其下是否有 starter/ 子目录？
b) 目标项目目录绝对路径是什么？是否已存在 AGENTS.md、.agents/ 目录？
c) 若已有 AGENTS.md，其中是否已包含「启动协议」关键词？（用于判定是否已是有效工作区，触发 S8）

【步骤2：路径确认与策略选择】
向我确认三件事，得到明确答复后再继续：
1) 目标项目路径（默认：当前工作目录）；
2) AGENTS.md 处理方式——「新建」或「合并进已有文件」；
3) .agents/ 冲突处理——「补缺不覆盖」或「整目录替换」。
不要跳过这一步，不要默认替我决定。

【步骤3：拷贝装载】
确认后执行（以跨平台文件操作完成，路径含空格时加引号）：
a) 把 starter/AGENTS.md 写入或合并进目标根 AGENTS.md；
b) 把 starter/.agents/ 拷入目标项目（按步骤2选择的冲突策略）；
c) 把 starter/LICENSE-NOTICE.md 拷入目标项目根。
若目标根已有同名文件且策略为「合并」，保留我原有内容，只并入套件版「启动协议」段落与规范入口。

【步骤4：验证】
a) 验证目标根 AGENTS.md 存在且包含「启动协议」关键词（S5）；
b) 如可运行命令，执行：
   python <套件目录>/scripts/verify_starter.py --target <目标项目>
   若退出码为 0，视为装载完整；若非 0，把脚本报告的缺失项/断链原样转述给我。

【步骤5：就绪报告】
装载完成后，按以下模板向我报告：
✅ 智能体工作区装载完成，已就绪。
📂 目标项目：<绝对路径>
📄 根契约：AGENTS.md（含「启动协议」关键词：是/否）
📇 已装载类目：<列出 .agents/ 下的类目名称>
🧪 自检结果：<exit code + 通过/失败摘要>
⚠️ 冲突处理：<新建/合并了哪些文件；若有未处理冲突，列出>
📖 下一步：建议打开 guide/README.md 按 60 分钟路径上手，或直接告诉我你的任务。
```

## 完成检查点

- [ ] 智能体在写入前向你确认了目标路径与「新建 / 合并」策略（S2）。
- [ ] 目标项目根出现 `AGENTS.md`、`.agents/`、`LICENSE-NOTICE.md`。
- [ ] 智能体报告中出现「启动协议」关键词命中结论（S5）。
- [ ] `python <套件目录>/scripts/verify_starter.py --target <目标项目>` 退出码为 0。
- [ ] 若装载前工作区已就绪，智能体跳过拷贝直接报告就绪（S8，幂等）。
