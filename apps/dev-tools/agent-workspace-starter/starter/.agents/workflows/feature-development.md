# 功能开发流程

本流程定义功能开发的标准阶段序列、角色参与、变更类型分类与执行要点。所有开发任务必须遵循本流程。

## 文档导航

| 文档 | 内容 |
|------|------|
| 01 变更类型判定与流程概览 | 变更类型判定（新功能/扩展/重构）+ 三种流程图 + 角色参与矩阵 |
| 02 新功能完整流程（8步） | 需求→设计→分配→实现→测试→审查→合并→确认 |
| 03 功能扩展轻量流程（6步） | 影响分析→增量方案→实现→回归→审查→合并 |
| 04 功能重构重量流程（7步） | 全量评估→方案重审→重规划→迁移实现→全量回归→双重审查→合并 |
| 05 治理规则引用 | 治理规则引用（阶段守卫 / PDR / 交接 / 硬编码治理） |
| 06 结构化日志与交接协议 | 结构化日志输出要求 + 交接协议 |

> 完整子文档见 SpecWeave 开源仓库。
