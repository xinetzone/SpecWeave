# 指令集目录

`.agents/commands/` 目录存放智能体执行的标准化指令集，定义各核心操作的执行步骤、输入输出规范与质量验收标准。

## 设计理念

指令集是智能体与任务之间的桥梁，将高层任务需求转化为可执行的标准化操作流程。每条指令集包含：触发条件、执行步骤、输入规范、输出规范与质量验收。

## 指令集清单

| 指令集 | 用途 |
|---|---|
| 复盘 | 项目复盘流程，生成复盘报告与改进建议 |
| 洞察 | 数据分析与问题诊断，识别优化机会与异常 |
| 导出报告 | 结构化报告导出，支持多格式与归档 |
| 原子化 | 文档与代码的原子化拆分，确保单一职责 |
| 原子提交 | Git 原子化提交规范，确保单次提交单一职责 |
| Mermaid 图表管理 | Mermaid 图表生成、解析、检查、修复与协作管理 |
| 第一性原理 | 应用第一性原理思维方法进行复杂问题分析与创新方案设计 |
| 对抗性审查 | 对抗性审查方法论执行 |
| 萃取 | 从复盘/洞察中提炼可复用模式，跨案例抽象、标准化入库 |
| 方法论编排 | 基于七概念方法论的元编排引擎 |

## 与其他目录的关系

- **roles/**：角色定义决定何时调用哪个指令集
- **rules/**：指令集必须遵循规则体系中的约束条件
- **templates/**：指令集产出物依模板规范组织

> 每个指令集的完整定义与逐活动 RACI 矩阵见 SpecWeave 开源仓库。
