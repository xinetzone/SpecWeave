# Code Review 检查清单

## 一、总览检查清单

| 序号 | 检查项 | 通过标准 |
|:---:|--------|---------|
| 1 | 代码规范 | 无 lint 错误，命名清晰，结构合理 |
| 2 | 功能正确性 | 功能测试通过，边界条件已处理 |
| 3 | 测试覆盖 | 覆盖率 ≥ 80%，覆盖正常/边界/异常场景 |
| 4 | **敏感信息安全** | **通过敏感信息检测（必检项，详见第二节）** |
| 5 | 输入输出安全 | 无注入风险，API 不返回敏感字段 |
| 6 | 依赖安全 | 无 CVE 高危漏洞，来源可信 |
| 7 | 性能 | 无明显性能问题，查询已优化 |
| 8 | 文档 | 接口文档/设计说明/CHANGELOG 已同步 |
| 9 | 治理闭环 | 二次同类问题附根因分析 + 预防措施 |

## 二、敏感信息硬编码检查（必检项）

reviewer 必须逐项确认以下类别不存在硬编码：

| 类别 | 检查要点 |
|------|---------|
| API 密钥/Token | 无硬编码的 API Key、Access Token、Secret Key |
| 数据库凭据 | 无数据库密码、含明文密码的连接串 |
| 账号密码 | 无用户名/密码组合（含默认密码） |
| 私钥/证书 | 无私钥内容（PEM 格式）、PEM 证书 |
| 手机号/个人信息 | 无真实手机号、身份证号、银行卡号 |
| 内部 URL/IP | 无生产环境内网地址、IP:Port 组合 |
| 云服务凭据 | 无云服务 AK/SK |
| 个人路径 | 无开发者本地绝对路径 |
| .env 文件 | 含真实密钥的文件未被提交 |
| 第三方服务密钥 | 无支付平台密钥、OAuth Client Secret |

**豁免规则**：代码行尾带 `# nosec` 注释标记的示例/测试数据；模板文件只含占位符。

## 三、审查结果处理

| 结果 | 处理方式 |
|------|---------|
| ✅ **通过** | reviewer 批准 PR，通知 orchestrator 执行合并 |
| ⚠️ **需修改** | reviewer 列出具体修改建议，退回 developer 修改后重新提交 |
| ❌ **拒绝** | reviewer 说明拒绝原因，关闭 PR 并通知 orchestrator |
