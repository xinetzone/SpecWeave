# 标准化检查清单索引

本目录收录标准化检查清单，用于在提交或审查前逐项核对质量要求。

## 内容

| 清单 | 用途 | 适用场景 |
|------|------|---------|
| [code-review-checklist.md](code-review-checklist.md) | 代码审查检查清单 | 代码审查标准流程 |
| 风险评分决策检查清单（见 SpecWeave 开源仓库） | 风险评分与安全闸门 | 工具权限设计、自动化流程安全闸门 |

## 使用方式

1. 选定与任务类型匹配的清单。
2. 提交前逐项勾选，未通过项须修复或说明豁免理由。

> 完整清单（Docker 构建、构建配置变更、安全修复、技术文档写作、声明核验等）见 SpecWeave 开源仓库。
