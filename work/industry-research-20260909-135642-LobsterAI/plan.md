# 研究计划

## 用户目标

全面调研 `https://lobsterai.youdao.com/#/index`，即网易有道出品的 LobsterAI（有道龙虾）开源桌面级 AI Agent，采用方法论编排（七概念 R-I-E 为主、辅以 F-V 创新审视）与行业全景研究框架，输出可独立阅读的管理摘要与图文报告。

## 范围

- 行业定义：桌面级 AI Agent / AI 办公助手产品市场，聚焦可连接本地文件、终端、浏览器与项目的桌面端智能体
- 包含：LobsterAI 产品功能、技术架构、开源模式、OpenClaw 生态、目标场景（应用开发、数据分析、定时任务、调研报告、网页操作、文档处理、长期记忆）、桌面级 Agent 竞争格局、AI Agent 产业链与政策环境
- 不包含：非桌面端的纯云 Agent、移动原生 Agent、垂直行业专用 Agent（医疗/法律等）、闭源且无桌面形态的通用大模型产品
- 地域：中国市场为主（有道为网易系国内产品），兼顾全球桌面 Agent 生态与开源 Agent 框架发展
- 资料截止日：2026-09-09
- 历史观察期：以资料截止日可确认的最新完整年度及最新部分年度为准
- 预测期：无
- 指定企业或焦点：网易有道 / LobsterAI；竞品样本由重点企业研究根据正式搜索证据确定，候选方向包括 Manus、GPT-4o 桌面端、豆包桌面端、扣子等同类产品

## 研究问题

### 宏观与政策
- 中国对 AI Agent、开源大模型、数据本地化的政策取向如何影响桌面级 Agent？
- 开源 Agent 生态（OpenClaw 等）的发展态势与政策环境

### 市场规模
- 桌面级 AI Agent / AI 办公助手市场规模与增长态势（以公开可查的口径为准）
- AI PC 与桌面 Agent 的渗透率与用户付费意愿

### 产业链
- AI Agent 产业链结构：底层模型、Agent 框架（OpenClaw）、工具与连接器、桌面应用层
- LobsterAI 在产业链中的位置与关键依赖

### 竞争格局
- 桌面级 Agent 主要玩家与分层（开源 vs 闭源、国内 vs 海外、全能型 vs 垂直型）
- LobsterAI 的差异化定位与竞争优劣势

### 重点企业
- 网易有道的业务背景、LobsterAI 的产品定位与商业化路径
- LobsterAI 开源仓库活跃度、版本演进、社区生态

### 趋势机会风险
- 桌面级 Agent 的技术趋势（多模态、本地推理、IM 远程指挥）
- LobsterAI 的机会窗口与潜在风险（安全、隐私、竞争、商业模式）
