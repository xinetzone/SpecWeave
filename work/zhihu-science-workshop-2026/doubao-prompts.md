# 豆包提示词序列

> 用法：在豆包桌面版新建**一个**对话，按顺序粘贴。每段提示词都要求豆包输出完整 `index.html`，收到后立刻另存为 `index-v1.html`、`index-v2.html`。
> 每段结束按「截图检查点」存图，投稿文章至少需要 3 张，建议存 8–10 张。
> 版本：v1.1 / 2026-10-23。本版改动：Prompt 1 补全为六段式；Prompt 4 的 10 题题库直接内嵌，不再需要手动从 spec.md 复制；七段提示词统一补上验收标准与输出纪律。

## 使用顺序

| 轮次 | 目标 | 存档名 | 必须截图 | 通过标准 |
|---|---|---|---|---|
| 1 | 项目骨架 | `index-v1.html` | 豆包对话里的需求描述 | 标题区、空实验台、页脚齐全 |
| 2 | 实验台 | `index-v2.html` | 初始状态 + 调大 S 后的状态 | 滑块能驱动曲线与统计卡 |
| 3 | 策略对比 | `index-v3.html` | 三条曲线 + 对比表 | 结论数字随参数变化 |
| 4 | 10 题自测 | `index-v4.html` | 答题中一题 + 结果页 | 三档建议都能触发 |
| 5 | 计划生成器 | `index-v5.html` | 生成的计划列表 | 过期节点标注正确 |
| 6 | 科学依据与打磨 | `index-v6.html` | 手机宽度首屏与实验台 | 375px 无溢出、断网可用 |
| 7 | 验收修复 | `index-final.html` | 测试结果表 | 12 条验收全部通过 |

## 通用约定（每轮都适用）

- 一次只改一个区块，不让豆包同时重构全文。
- 每次收到完整文件后，先在浏览器打开、点一遍，再进入下一轮。
- 豆包输出中断时，回复：`继续输出剩余部分，从 <!-- 断点 --> 之后开始，不要重复已输出内容。`
- 豆包改坏功能时，把上一版完整文件贴回去：`回到这个版本，只改我说的那一处，其余代码保持不变。`
- 每轮都要保留上一轮已有功能；任何「顺手优化」都先拒绝。

## Prompt 1 · 项目骨架

**粘贴：**

```
你是我这次的前端开发搭档。我们要做一个单文件网页应用「记忆实验室」，主题是用可交互的方式解释艾宾浩斯遗忘曲线与间隔重复。

本轮只做项目骨架，不实现任何图表、计算和题库。请严格按下面的范围执行。

【交付物】
- 只输出一个完整的 index.html。
- CSS 与 JS 全部内联在文件里。
- 禁止任何外部依赖：不引用 CDN、外部字体文件、外部图片、图标库，不发任何网络请求。
- 不要输出 Markdown 代码围栏之外的解释。文件必须能直接保存为 index.html，双击在浏览器打开即可运行。

【本轮范围】
1. 顶部标题区：主标题「记忆实验室」，副标题「把遗忘曲线变成可以拖动的实验台」，一个「开始调参」按钮；点击后平滑滚动到下方 id="lab" 的容器。
2. 中间：一个空的 <section id="lab">，里面只放一句占位提示「实验台将在下一步生成」。不要提前实现滑块、图表或统计卡。
3. 页脚：写明「这是一个简化的学习科学模型，不用于预测个人成绩」。

本轮明确不做：遗忘曲线绘制、策略对比、自测题库、复习计划生成器、深色模式、登录、后端、任何数据存储。

【视觉规范】
- 暖灰纸感：页面底色 #F3EFE7，卡片 #FBF8F1，正文 #37322C，次要文字 #7A7168，分隔线 #DED5C7，强调色 #8B6B43。
- 标题字体栈："Songti SC", "Noto Serif SC", Georgia, serif；正文用系统无衬线字体栈。
- 圆角 12px，阴影极轻：0 1px 2px rgba(55,50,44,.06)。
- 禁止深色模式、纯黑背景、霓虹色、大面积渐变、发光效果。
- 内容最大宽度 1080px，居中；桌面留白充足，手机单栏。

【技术要求】
- 语义化 HTML5：header / main / footer / section，标题层级正确。
- <html lang="zh-CN">，包含 viewport meta，标题为「记忆实验室」。
- 375px 宽度下无横向滚动；按钮和文字不被裁切。
- Chrome、Edge、Safari 近两年版本可正常显示。
- 控制台无报错，不起任何网络请求。
- 可访问性：按钮有可读文本；键盘焦点样式可见；尊重 prefers-reduced-motion（本轮只影响平滑滚动）。

【验收标准】
- 打开文件能看到标题区、空实验台容器、页脚三部分。
- 点「开始调参」能滚动到实验台。
- 断网打开仍正常显示。
- 源码中搜索不到 http:// 或 https:// 形式的外部资源引用（字体栈里的系统字体名不算）。

【输出要求】
- 输出完整文件，不要省略任何代码，不要用「此处省略」「其余同上」。
- 如果一次输出过长，先输出到文件末尾的前一半，并在断点处写 <!-- 断点 -->；我说「继续」后你再输出剩余部分，不要重复已输出内容。
- 如果需求有歧义，选一个合理方案直接做，并在文件顶部的 HTML 注释里用一行说明你的选择。
```

**验收：** 打开后能看到标题区、空容器、页脚；缩放窗口不横向滚动。

**截图检查点：** 豆包对话里你发出这条需求的界面（证明真实使用过程）。

## Prompt 2 · 实验台（滑块 + 曲线 + 统计卡）

**粘贴：**

```
在 id 为 lab 的容器里，做出「实验台」区块。仍然只输出完整 index.html，保留已有功能，不要改动标题区和页脚。

【模型（必须按这个实现）】
R(t) = R0 * Math.exp(-t / S)
R0 是初始保持率（0 到 1），S 是记忆稳定度（天）。
每次复习发生时：R = Math.min(1, R + (1 - R) * 0.6)；S = S * 1.6。

【控件】
1. 滑块「初始保持率 R0」：50% 到 100%，默认 90%，步长 1%。
2. 滑块「记忆稳定度 S」：0.5 到 10 天，默认 2 天，步长 0.1。
3. 滑块「复习次数」：0 到 5 次，默认 2 次，步长 1。
4. 下拉「复习间隔」：1 天 / 1+3 天 / 1+3+7 天 / 1+3+7+14 天，默认 1+3 天。
   实际复习次数取「滑块值」与「所选间隔的长度」两者较小值。
5. 「重置参数」按钮：恢复 R0=90%、S=2、复习次数=2、间隔=1+3 天。

【图表】
用 Canvas 2D 自己画，不要引第三方图表库。横轴 0 到 30 天，纵轴 0 到 100%。
两条线：当前策略（#8B6B43 实线）和无复习（#999 虚线）。
要有坐标轴、刻度、单位、图例；鼠标悬停时显示该天数值，触屏点击也能显示。
Canvas 要按 devicePixelRatio 缩放，保证高分屏不模糊。

【统计卡】
四张：第 7 天保持率、第 14 天保持率、第 30 天保持率、30 天平均保持率。
四个数字必须由上面的模型实时计算，不能写死。

【交互】
拖动任一滑块或切换下拉，曲线和统计卡立即更新；用 requestAnimationFrame 合并重绘，避免卡顿。

【验收标准】
- 拖动三个滑块，曲线形状和四个数字都会变。
- 把 S 从 2 改到 8，第 30 天保持率明显升高。
- 重置按钮能把所有参数恢复默认。
- 控制台无报错，仍然没有任何外部请求。

【输出要求】
输出完整文件，不要省略代码；保留 Prompt 1 已实现的标题区、页脚与锚点滚动。
```

**验收：** 拖动三个滑块，曲线形状和四个数字都会变；第 30 天保持率随 S 增大而升高。

**截图检查点：** 实验台初始状态一张；把 S 拉到 8 天后再截一张（两张对比能说明参数真的在起作用）。

## Prompt 4 · 10 题自测

**粘贴：**

```
在策略对比下面新增「自测」区块。仍然只输出完整 index.html，保留已有功能。

【答题规则】
1. 10 道四选一，一次只显示一题，顶部有进度条「第 X / 10 题」。
2. 选中选项后立即显示对错和一句解析，再出现「下一题」按钮。
3. 全部做完进入结果页：得分（例如 7/10）、错题知识点列表、按分数给出复习建议：
   - 0 到 5 分：建议第 1、3、7、14 天复习；
   - 6 到 8 分：建议第 1、3、7 天复习；
   - 9 到 10 分：建议第 1、7 天复习。
4. 「重新测试」按钮可以清零重来。

【题库（逐字使用，不要改写、不要增删）】
1. 遗忘曲线最早由谁通过实验系统研究？
   A 巴甫洛夫 / B 艾宾浩斯 / C 斯金纳 / D 皮亚杰
   答案：B。解析：艾宾浩斯 1885 年用无意义音节研究记忆保持。
2. 间隔效应最准确的描述是？
   A 一次学很久最好 / B 分散到多次、间隔进行更利于长期保持 / C 睡前学习一定更好 / D 复习次数越多越好
   答案：B。解析：同样总时长下，分散练习的长期保持通常优于集中练习。
3. 测试效应指的是？
   A 考试让人焦虑 / B 主动提取比重复阅读更利于长期保持 / C 选择题比填空题好 / D 测试只适合评估
   答案：B。解析：自测是提取练习，不只是评估手段。
4. 交错练习（interleaving）通常指？
   A 同一题型连续练 / B 把不同类型题目混合练习 / C 每次换学习环境 / D 只练最简单的题
   答案：B。解析：混合题型迫使大脑区分问题类型。
5. 下列哪种安排最符合间隔重复？
   A 考前一夜连学 6 小时 / B 每天同一时间读同一段 / C 第 1、3、7、14 天各复习一次 / D 只看一遍
   答案：C。解析：间隔逐次拉长，是间隔重复的典型形式。
6. 「合意困难」的含义是？
   A 越难越好 / B 适度增加提取难度可促进长期保持 / C 困难一定有害 / D 只做难题
   答案：B。解析：难度要「合意」，不是无条件加难。
7. 睡眠对记忆的主要作用是？
   A 没有作用 / B 巩固与整合记忆 / C 只影响情绪 / D 只在儿童期有效
   答案：B。解析：睡眠参与记忆巩固，尤其与慢波睡眠相关。
8. 工作记忆容量大致是？
   A 1 个组块 / B 4 个左右组块 / C 20 个组块 / D 无限
   答案：B。解析：Cowan（2001）估计约 4 个组块。
9. 重读笔记时的「熟悉感」为什么不可靠？
   A 因为笔记写错了 / B 流畅性错觉：熟悉不等于需要时能提取 / C 因为字体问题 / D 因为笔记太长
   答案：B。解析：再认的流畅感会被误当成掌握。
10. 考前突击的主要问题是？
    A 完全无效 / B 短期可能有效，但长期保持差、迁移弱 / C 会损伤记忆 / D 只对理科无效
    答案：B。解析：突击能应付短期考试，但不利于长期留存。

【验收标准】
- 10 题顺序与题库一致，选项不串位。
- 答完每题都能看到对错与解析，再进入下一题。
- 分别做错到 4 分、7 分、10 分，三档建议都能出现。
- 「重新测试」能回到第 1 题，进度条归零。
- 不改变前几轮已有功能。

【输出要求】
输出完整文件，不要省略代码；如果一次写不下，按断点协议分两次输出。
```

**验收：** 完整做一遍 10 题；分别故意做错到 4 分、7 分、10 分，确认三档建议都能出现。

**截图检查点：** 作答中的一题（带解析）一张；结果页一张。

## Prompt 7 · 逐条验收与修复

**粘贴：**

```
现在按下面的验收清单逐条测试你写的页面，先输出一张「测试结果表」（标准、结果、证据/问题），再修复所有不通过项，最后输出完整 index.html。

验收清单：
1. 首屏有标题、副标题、开始调参按钮。
2. 三个滑块拖动后曲线和四张统计卡同步变化。
```

## 常见故障处理

| 现象 | 处理 |
|---|---|
| 豆包输出到一半停了 | 回复「继续输出剩余部分，从 `<!-- 断点 -->` 之后开始，不要重复已输出内容」 |
| 豆包顺手改了别的区块 | 贴回上一版完整文件，说「回到这个版本，只改我说的那一处」 |
| 页面白屏或交互失效 | 把浏览器控制台的完整报错贴给豆包，要求只修这一处并重新输出完整文件 |
| 图表在高分屏发虚 | 让豆包检查 Canvas 的 devicePixelRatio 缩放 |
| 日期少一天 | 让豆包改用本地时区 00:00 计算，并检查 `new Date()` 的时区处理 |
| 想加新功能 | 先停下，问自己是否属于 spec.md 的范围；超出范围一律不加 |
