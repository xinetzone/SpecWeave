# 提交前逐条门禁

> 用法：从 10-27 开始每天过一遍；10-30 完整过最后一遍。每条都要有「证据」——截图、链接或字数统计，不接受「应该没问题」。

## A. 账号与资格（F-054）

- [ ] 知乎账号用正常手机号注册，**不是虚拟手机号**
- [ ] 活动期间账号没有违规处罚记录
- [ ] 账号能正常发布文章、能上传项目
- [ ] 已确认不打算在获奖公示期结束前删除任何活动内容

## B. 工具与赛道（F-047、F-050）

- [ ] 全程使用豆包完成作品，没有用其他工具代写核心代码
- [ ] 只报名豆包专属赛道，没有同时报看山赛道
- [ ] 作品只使用豆包一个工具完成
- [ ] 豆包对话记录、版本文件、截图都还在（证明过程真实）

## C. 作品有效性（F-047 五问）

- [ ] 有一个「用户不做就不发生」的动作：拖滑块、点运行、做自测、生成计划
- [ ] 去掉 AI 之后作品仍然是一个可运行的模拟器，不是聊天框换皮
- [ ] 不是同一模板批量换内容
- [ ] 素材和文案是原创，没有搬运
- [ ] 与科学/科研主题明确相关（学习科学，含文献来源）
- [ ] 作品可以正常运行，没有白屏、没有控制台报错
- [ ] 通过 spec.md 第 7 节 AC-01 至 AC-12

## D. 部署（F-037、F-038、F-048）

- [ ] `index.html` 在 ZIP 根目录，不是套了两层文件夹
- [ ] ZIP 小于 2MB，无外部依赖
- [ ] 在知乎项目广场选择「科学季」项目类型
- [ ] 用「上传源码」方式完成部署，不是其他方式
- [ ] 部署成功，拿到公开作品链接
- [ ] 未登录状态打开链接，作品能运行
- [ ] 手机打开链接，布局正常、交互可用
- [ ] 作品页显示「项目类型：科学季」相关信息（如有）

### 部署兜底（F-076）

项目广场的「科学季」筛选可能不在前端显示。按顺序尝试：

1. 在项目广场搜索「AI 科学创新工坊」，打开已有参赛作品，看它的项目类型怎么标注；
2. 刷新页面、换浏览器、退出重登；
3. 在活动文章评论区提问官方；
4. 以上都不行且已到 10-28，停止参赛，作品自留。
