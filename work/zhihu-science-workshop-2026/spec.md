## 0. 一句话定义

一个纯前端的交互式学习科学实验台：拖动参数看遗忘曲线怎么变，对比突击复习与间隔复习的 30 天保持率，做 10 题自测，并按考试日期生成复习计划。

它不是聊天套壳，也不是静态科普长图。核心功能是**模拟与计算**：用户不拖滑块、不点运行，就不会发生任何结果。

## 1. 科学内核

### 1.1 三条被反复验证的结论

| 结论 | 含义 | 主要来源 |
|---|---|---|
| 遗忘曲线 | 新学内容在无复习时呈指数式衰减，早期最快 | Ebbinghaus, 1885 |
| 间隔效应 | 把同样总时长的学习分散到多次、间隔进行，长期保持优于集中突击 | Cepeda et al., 2006（元分析） |
| 测试效应 | 主动提取（自测）比重复阅读更能促进长期保持 | Roediger & Karpicke, 2006 |

### 1.2 简化模型（作品内必须原样标注）

```
保持率 R(t) = R0 × e^(−t / S)
R0：学完当时的初始保持率（0–1）
S ：记忆稳定度（天），越大衰减越慢
复习发生时：R ← min(1, R + (1 − R) × 0.6)；S ← S × 1.6
```

**这是示意模型，不是个人预测模型。** 作品页脚与「科学依据」区块都要写明：真实记忆受材料难度、睡眠、情绪、既有知识影响，本模型只用于展示趋势差异。

### 1.3 可用于自测的知识点

- 艾宾浩斯 1885 年系统研究遗忘曲线
- 间隔效应：分散练习优于集中练习
- 测试效应：主动提取优于重复阅读
- 交错练习：混合不同类型题目
- 合意困难：适度增加提取难度有利于长期保持
- 睡眠对记忆巩固的作用
- 工作记忆容量约 4 个组块（Cowan, 2001）
- 流畅性错觉：熟悉感不等于可提取

## 2. 目标用户与场景

| 项 | 内容 |
|---|---|
| 主要用户 | 备考学生、需要长期记住知识的职场学习者、教师 |
| 典型场景 | 考前 1 个月规划复习；想知道「为什么背了就忘」；想比较两种复习策略 |
| 使用时长 | 单次 3–8 分钟 |
| 设备 | 桌面浏览器为主，手机可完整使用 |

## 3. 信息架构

单页五个区块，按顺序：

1. **首屏**：标题、副标题、一个「开始调参」按钮（锚点滚动到实验台）。
2. **实验台**：三个滑块 + 复习间隔选择 + 曲线图 + 四个统计卡 + 重置按钮。
3. **策略对比**：三张策略卡 + 「运行 30 天模拟」按钮 + 对比表 + 一句自动生成的结论。
4. **自测**：10 道四选一，逐题作答、即时解析、结果页给薄弱点与复习建议。
5. **计划生成器**：输入考试日期，生成 5 个复习节点，支持一键复制。
6. **科学依据与局限**：三条来源、模型公式、边界声明、页脚。

## 4. 交互规格

### 4.1 实验台

| 控件 | 范围 | 默认 | 行为 |
|---|---|---|---|
| 初始保持率 R0 | 50%–100% | 90% | 拖动时曲线与统计卡实时更新 |
| 记忆稳定度 S | 0.5–10 天 | 2 天 | 同上 |
| 复习次数 | 0–5 次 | 2 次 | 与间隔策略联动 |
| 间隔策略 | 1 天 / 1+3 天 / 1+3+7 天 / 1+3+7+14 天 | 1+3 天 | 复习次数取策略长度与滑块值的较小者 |

图表：横轴 0–30 天，纵轴 0–100%，两条线——当前策略（强调色实线）与无复习（灰色虚线）。悬停显示某天数值，触屏点击显示。

统计卡：第 7 天保持率、第 14 天保持率、第 30 天保持率、30 天平均保持率。全部由同一模型计算，不允许写死数字。

### 4.2 策略对比

| 策略 | 复习安排 |
|---|---|
| 无复习 | 不复习 |
| 突击复习 | 第 1 天集中复习 1 次 |
| 间隔复习 | 第 1、3、7、14 天各 1 次 |

点击「运行 30 天模拟」后：三条曲线依次绘制（尊重 `prefers-reduced-motion`，该设置下直接显示），对比表填充第 1/7/14/30 天保持率与 30 天平均值，底部生成一句结论。结论必须是计算结果，例如「在本模型下，间隔复习的第 30 天保持率比突击复习高 XX 个百分点」。

### 4.3 自测

- 10 题四选一，一次一题，选中后立即显示对错与一句解析。
- 顶部进度条显示 1/10。
- 结果页：得分、错题知识点列表、按分数给出的复习建议。
- 建议规则：0–5 分 → 1/3/7/14 天；6–8 分 → 1/3/7 天；9–10 分 → 1/7 天。

### 4.5 计划生成器

- 输入：考试日期（`<input type="date">`）。
- 输出：考试前第 30、14、7、3、1 天五个复习节点；早于今天的节点自动跳过并标注「已过期」。
- 每行显示日期、距考试天数、建议动作（首次学习 / 快速回顾 / 自测 / 错题重做 / 轻量过一遍）。
- 「复制计划」按钮把纯文本写入剪贴板，复制失败时显示可手动选中的文本框。

## 6. 技术规格

| 项 | 要求 |
|---|---|
| 文件形态 | **单个 `index.html`**，CSS 与 JS 全部内联 |
| 外部依赖 | 零。禁止 CDN、外部字体、外部图片、网络请求 |
| 图表 | Canvas 2D 或内联 SVG，自己实现坐标轴与刻度 |
| 兼容 | Chrome / Edge / Safari 近两年版本；375px 宽度可用 |
| 离线 | 双击 `file://` 打开即可完整使用 |
| 数据 | 不登录、不上传、不写 localStorage |
| 性能 | 滑块拖动到重绘不超过 100ms；无控制台报错 |
| 可访问性 | 滑块有 `<label>`；按钮可键盘触发；颜色对比度满足正文可读；尊重 `prefers-reduced-motion` |

## 8. 活动规则映射（F-047 自检）

| 规则要求 | 本作品对应 |
|---|---|
| 实际可体验、可交互、可使用 | 滑块、模拟、自测、计划生成四类交互 |
| 非简单套壳 | 核心是模型计算与图表绘制，不是聊天界面换皮 |
| 非批量生成 | 一个完整应用，单一主题，非模板批量产出 |
| 非重复搬运 | 文案原创，代码在豆包对话中逐步生成 |
| 非无实质功能 | 用户不操作则无结果；操作会改变计算结果 |
| 与科学/科研主题相关 | 认知科学 / 学习科学，含可核对的文献来源 |

## 9. 明确不做

- 不做登录、后端、数据库、用户系统。
- 不做 AI 对话入口（会落入「套壳」嫌疑）。
- 不做社交分享、排行榜、打卡。
- 不做真实用户实验或数据采集。
- 不做深色模式。
- 不引入构建工具；不做多文件工程。
