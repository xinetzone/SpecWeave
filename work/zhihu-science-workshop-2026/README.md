## 五、卡住了怎么办

| 现象 | 处理 |
|---|---|
| 豆包输出到一半停了 | 回复「继续输出剩余部分，从 `<!-- 断点 -->` 之后开始，不要重复已输出内容」 |
| 豆包改坏了已有功能 | 把上一版完整文件贴回去，说「回到这个版本，只改我说的那一处」 |
| 页面白屏 | 让豆包输出浏览器控制台报错对应的修复，并把完整文件重新输出 |
| 项目广场找不到「科学季」类型 | 见 checklist 的「部署兜底」 |
| 10-28 仍未部署成功 | 停止参赛，作品留着自己用；源文未规定未获奖作品的任何限制 |
