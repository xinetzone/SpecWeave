# 研究计划

## 用户目标
调研当下最好的 AI Agent 系统，以行业全景研究标准产出带可点击来源、交互图表和可独立阅读摘要的行业研究报告，覆盖宏观政策、市场规模、产业链、竞争格局、重点企业以及趋势机会风险六个维度。

## 范围
- 行业定义：AI Agent 系统行业——以大语言模型（LLM）为核心、能自主调用工具完成任务的软件系统，包括开源框架、商业平台、编码 Agent、浏览器 Agent 及相关基础设施（可观测性、协议标准）。
- 包含：
  - 开源 Agent 框架（LangGraph、AutoGen/MAF、CrewAI、MetaGPT、OpenAI Agents SDK、Claude Agent SDK、PydanticAI、Google ADK、Smolagents 等）
  - 企业级 Agent 平台（Microsoft Copilot Studio/MAF、Google Vertex AI Agent Builder、AWS Bedrock AgentCore、Salesforce Agentforce、IBM watsonx Assistant、ServiceNow AI Agents）
  - 编码 Agent 产品（Claude Code、Cursor、OpenAI Codex、Devin、Windsurf、Augment Code、GitHub Copilot）
  - 浏览器/通用任务 Agent（OpenAI Operator/ChatGPT Agent、Google Gemini Agent、Anthropic Computer Use）
  - Agent 基础设施（LangSmith、Langfuse、Arize、MCP Registry）
  - Agent 协议标准（MCP、A2A）
- 不包含：
  - 通用 LLM 模型本身的能力对比（如 GPT-5 vs Claude Opus 的纯模型基准）
  - 传统 RPA（Robotic Process Automation）工具
  - 传统对话式聊天机器人（无工具调用能力）
  - AI Agent 硬件（如机器人、无人机）
- 地域：全球（重点关注美国、欧洲、中国市场）
- 资料截止日：2026-08-25
- 历史观察期：以资料截止日可确认的最新完整年度（2025）及最新部分年度（2026 年 1-8 月）为准
- 预测期：无
- 指定企业或焦点：用户未指定具体企业；选样原则为选择代表不同架构路线和市场定位的厂商

## 研究问题

### 宏观与政策环境分析
- 核心问题：全球主要市场（美国、欧盟、中国）对 AI Agent 的监管政策框架走向如何？是否存在针对 Agent 自主决策的专项法规？
- 重要问题：MCP 捐赠给 Linux Foundation（2025年12月）对行业治理和标准化有何影响？A2A 协议的 Atlassian/Salesforce/SAP/ServiceNow 合作伙伴生态是否构成事实行业标准？

### 市场规模测算
- 核心问题：2025-2026 年全球 AI Agent 系统市场规模和增长率是多少？
- 重要问题：编码 Agent、企业 Agent 平台、浏览器 Agent 三大细分市场的规模占比如何？

### 产业链分析
- 核心问题：AI Agent 产业链上下游结构如何划分（LLM 提供商→框架/平台层→应用层→终端用户）？
- 重要问题：MCP/A2A 协议在产业链中扮演什么角色？工具编排是否是产业链关键瓶颈？

### 竞争格局分析
- 核心问题：开源框架与商业平台之间的竞争格局如何演变？
- 重要问题：厂商生态（OpenAI/Google/Anthropic/Microsoft）的 Agent 战略差异是什么？框架整合趋势如何？

### 重点企业研究
- 核心问题：LangChain（LangGraph）、OpenAI、Anthropic、Google、Microsoft 五大厂商的 Agent 战略和差异化定位是什么？
- 重要问题：编码 Agent 领域 Claude Code vs OpenAI Codex vs Cursor 的竞争差异如何？

## 运行的研究步骤
1. 研究规划（主 Agent 直接执行）
2. 宏观与政策环境分析（内部任务）
3. 市场规模测算（内部任务）
4. 产业链分析（内部任务）
5. 竞争格局分析（内部任务）
6. 重点企业研究（内部任务）
7. 趋势、机会与风险研判（主 Agent 直接执行）
8. 研究报告撰写（主 Agent 直接执行）
9. 关键事实与引用核查（脚本执行）

## 报告结构
行业概览 → 市场规模 → 产业链与关键瓶颈 → 竞争格局 → 重点企业 → 宏观与政策环境 → 趋势机会与风险 → 核心结论 → 结论与展望 → 参考资料

## 假设
- AI Agent 系统市场正处于从技术探索到产业化落地的转折期
- 编码 Agent 是首个达到生产级可靠性的应用类别
- MCP 协议收敛是行业标准化的关键信号
