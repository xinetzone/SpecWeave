# local/ · 真实执行数据隔离区

本目录用于存放**真实执行数据**，例如：打卡截图、到账原始记录、周核对数据、草稿等。这些内容属于私域数据，不进入公开仓库。

## 入库规则

- **仅本文件（`local/README.md`）入库**，作为隔离区机制说明。
- 本目录下的其余内容一律不入库，由上级 [`.gitignore`](../.gitignore) 保证：

  ```
  local/*
  !local/README.md
  ```

- 因此 `local/` 下的文件不会出现在 `git status` 的待提交列表中；本机制同时防止误提交。

## 红线

- **任何账号凭证 / 隐私信息不得放入本仓库任何位置**——包括但不限于登录凭据、手机号、真实姓名、收款账号、含个人身份的截图。
- 需要长期保存的敏感数据请放在本仓库之外的个人存储中。

## 建议子目录命名

| 目录 | 用途 |
|---|---|
| `screenshots/` | 打卡截图等过程凭证 |
| `earnings/` | 到账原始记录、周核对数据 |
| `drafts/` | 未发布草稿 |

以上子目录均被 `.gitignore` 覆盖，无需额外配置。
