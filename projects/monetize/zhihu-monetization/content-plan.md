## 一、领域定位决策法（W1-3）

**决策四维**（自评 1–5 分，模板见 §五 A）：

1. **能力匹配**：能否稳定产出该领域的 ≥100 字观点回答（[F-033](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md)）且不依赖 AI 生成（规避 [F-037](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md) 排除条款风险）；
2. **素材可持续**：该领域能否支撑每周 ≥3 个可回答问题（对齐 M1-2 目标）；
3. **竞争密度**：领域回答的平均密度（越低越易冷启动）；
4. **资产轨联动**：与项目广场作品（[F-002](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md)／[F-005](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md)）的联动潜力。

**流程**：8 个领域标签（[F-038](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md)：数码 / 游戏 / 动漫 / 影视 / 人文 / 母婴 / 职场 / 教育）→ 逐一自评 → 选定主攻 1 个 + 备选 1 个 → 记入 `local/content-plan.md`。

|---|---|---|---|---|---|

## 二、问题池建设法（W1-4）

**四个筛子**（收藏 ≥10 条，标题 + 链接存档）：

1. **领域契合**：落在主攻领域标签内（[F-038](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md)）；
2. **可驾驭**：能用个人经验 / 实测回答——优先"天然人类主导"型题目（与三问自检兼容度最高）；
3. **有效性**：问题本身稳定受关注（优先"回答少但问题稳"，避开纯热点速朽题）；
4. **合规**：无违规风险；无需以翻译或资料综述为主体。

**用法**：收藏池 → 标注优先级 → 每周自池中取用（M1-2 每周 ≥3 篇回答）。

## 三、双轨内容排期（衔接 tracker 节奏）

**每日底盘**（[F-032](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md) 45–60 分钟口径）：1 创作 + 3 互动（互动五选三，[F-034](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md)）。

**周节奏模板（建议值；数量口径对齐 M1-2／M1-3）**：

| 日 | 主任务 | 说明 |
|---|---|---|
| 一 / 三 / 五 | 回答 × 1（≥100 字，[F-033](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md)） | 自问题池取题；发布前过三问自检 |
| 二 / 四 | 想法 × 1（≥20 字 + ≥1 图，[F-040](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md)） | 碎片观点 / 实测片段 |
| 六 / 日 | 资产轨时间块 + 周核对 | 项目广场作品推进（M1-4）；核对 [records.md](records.md) |
| 每日 | 互动 × 3 | 关注 / 评论 / 赞同等（[F-034](../../awesome-okf-xs/doc/bundles/sheke/industry/zhihu-monetization/references/article-source.md)） |

**选题三源**：① 问题池（回答轨主供）；② 个人实测与踩坑（想法轨与资产轨素材）；③ 领域热点（仅作补充，不追突发）。
**选题红线**：以"资料综述 / 翻译 / 润色"为主体的选题慎入——与三问自检（含边缘场景）冲突概率高；优先"个人实测 / 经验 / 原创代码"型选题（天然人类主导）。
