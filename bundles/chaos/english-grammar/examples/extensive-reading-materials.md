# 广读材料推荐

优良的广读材料，内容方面要五花八门、适合各式各样读者不同的兴趣，程度方面又不能太难。市面上的广读材料消耗速度快，长期购买经济负担不小。以下整理原文推荐的四类免费网络资源，前三类是改写为 Special English 的低难度材料，第四类是未经简化的英文原著图书馆。

## VOA Special English

VOA 是 Voice of America（美国之音）广播电台。它的网站站内 Special English 部分有大量文章，分成各式各样的主题，大约都是半小时一篇的报导，有文字档与声音档可以免费下载。

- 特点：主题无所不包，容易找到自己感兴趣的话题；英文难度有控制，念得既慢又清楚
- 适用阶段：广读入门，适合一般程度的读者长期使用

## CDLP

CDLP 代表 California Distance Learning Project，由加州政府教育部出资、加州州立大学系统经营主办，Sacramento 县政府负责网路版的管理营运。

- 特点：旨在推广成人教育的网路杂志，英文低难度、适合广读；主题分成工作、法政、家庭、学校等十一项，底下各有许多文章
- 适用阶段：广读入门，主题丰富、难度适中

## The Key

这是 Milwaukee Area Technical College 专门为所谓 new readers 出版的杂志的网路版，里面的文字也都控制在比较低的难度。

- 特点：适合作为广读材料之用；缺点是更新的频率不是很高，不过也累积了相当份量的 archives 可供使用
- 适用阶段：广读入门，可作为补充材料来源

## Project Gutenberg

- 网址：[http://www.gutenberg.org/](http://www.gutenberg.org/)

这是规模最大的一座网路电子图书馆，完全免费。国际版权法规定版权保护时间大都是作者身故之后七十年，七十年后著作进入公共财领域——Project Gutenberg 里面大都是这种已经没有版权的东西。这座图书馆不但欢迎免费下载，还可以向它索取寄送光碟片（内含全数几万本藏书的电子版）。

- 特点：主题无所不包，读者感兴趣的题材都可以找得到；缺点是藏书都是原著、没有经过简化，一般程度的读者很可能会看不懂；而且年代大都比较旧
- 适用阶段：广读进阶，请先通过前三种 Special English 材料的训练，再尝试挑战

## 阅读进阶路径建议

1. **起步**：从 VOA、CDLP、The Key 三类 Special English 材料中挑选自己感兴趣的主题，用「不查单词、不求甚解」的广读方式持续阅读，培养阅读速度与理解能力
2. **检验**：判断材料难易度的方法是翻开第一页从头到尾一气呵成读完——如果基本看得懂、觉得好看，就是适合你的广读材料
3. **进阶**：阅读速度与理解能力提升后，尝试挑战 Project Gutenberg 的英文原著
4. **配合**：广读时碰到生单词，用「猜」（依据上下文）与「拆」（字根字首分析）处理，不必查字典；配合本书的语法句型训练，建立从简单句到复合句到简化从句的架构
